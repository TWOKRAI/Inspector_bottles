# `scripts/docs_verify` — сверщик документов наблюдаемости с кодом

Задача 5.1 плана [`observability-roadmap`](../../plans/observability-roadmap.md).

## Зачем

Приёмка F1 (2026-08-10) проверила 129 утверждений справочников **исполнением** и нашла шесть
расхождений с кодом. Сверщик жил в scratchpad'е координатора и умер вместе с сессией: свойство
«документы не врут» продержалось один день. Здесь оно возвращено в репозиторий — как проверка,
которая гоняется в дефолтном гейте и **умеет краснеть**.

## Запуск

```bash
python -m scripts.docs_verify.docs_check          # 0 — расхождений нет, 1 — есть, 2 — не проверено
python -m scripts.docs_verify.docs_check --list   # перечень проверок с их источником
```

Тесты (в дефолтном гейте, `testpaths`): `pytest scripts/docs_verify/tests`.

## Что проверяется

номером задачи плана (число сторожится тестом `test_readme_states_the_true_number_of_checks` —
первая редакция README обещала 15 проверок при факте 14, и это заметил только внешний приёмщик,
пересчитав руками):

| id | Документ | Утверждение |

| F1-1 | `observability/CONNECTORS.md` | имена аргументов `_track_error`/`_record_metric`/`_record_timing` — как в коде |

## Чего он НЕ делает (названо, а не умолчано)

1. **Это не восстановление всех 129 проверок S1.** Восстановлены шесть расхождений и их ближайший
   класс. Остальные 123 утверждения при приёмке совпали и здесь не сторожатся: перенос их всех
   превратил бы справочник в копию кода, а расходятся не они.
2. **Проверяется соответствие названному факту кода, а не полнота документа.** Абзац, которого нет
   вовсе, ни одна проверка не заметит.
3. **Проверка фразы остаётся проверкой фразы.** Там, где утверждение нельзя выразить структурно,
   сторожится формулировка — но её предпосылка **вычисляется из кода** (класс публичен, аргумент
   существует, поля схемы такие-то), поэтому исчезновение факта проверка увидит.

## Устройство

Читает через `Sources`, у которого есть `overlay` — подменённый текст файла. Отсюда
break-injection: тест подсовывает документ в состоянии «до правок 5.1» и требует, чтобы покраснела
**ровно одна** проверка. Инъекция, которой некуда лечь, даёт `Unverifiable` (ERROR), а не молчание:
негодная инъекция читалась бы как «проверка выдержала слом», которого не было.

Сам сверщик **не импортирует фреймворк** — только `ast` и регулярки. Оракул, падающий вместе с тем,
что он проверяет, ничего не доказывает.
