# STATUS — presence_watch

**Слой:** plugins · **План:** `plans/2026-10-27_system-run-state/plan.md` · **Ветка:** feat/run-state-2-2d

## Готово

- **2.2d:** проходной плагин, причины `out_of_spec` «нет изделия» / «слабое распознавание» только в работе;
  регистр из 9 полей; вписан последним в `recog` рецептов `hikvision_letter_robot` и `letter_robot_sim`
  (тексты «нет диска» / «слабое распознавание», порог 0.5). Тесты: приёмка, авторские, пин рецептов.

## Открыто

- **Срок на железе:** `absent_after_s: 10.0` проверен только на тестовых часах; на стенде не мерили.
- **Без `run_gate`:** плагин считает себя в работе в любом состоянии системы (README «Без `run_gate`»).
  Возможная правка во framework — публичный признак «система в работе» у `ProcessModulePlugin`.
- **Живой дрейф порога:** правка одного из регистров `presence_watch` / `word_layout` расходит пороги молча.
- **Гонка снимка с `pause`:** снимок готовности, прочитавший «в работе» до `pause`, один раз отдаёт
  устаревшую причину в «готов» (до ~5,5 с); GUI вне `running` её не показывает.
