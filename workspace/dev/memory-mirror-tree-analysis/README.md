## Скрипты, которыми получены числа

Скрипты лежат как `*.py.txt`, чтобы хуки ruff и bandit не проверяли одноразовый код (так же сделано в `plans/2026-10-04_atlas/reports/`); для запуска уберите `.txt`. Запуск: `python <скрипт> <корень репозитория>` (кроме `indexed.py.txt` — из корня репозитория, и `run_lint.py.txt`). Числа верны для дерева 2026-10-11 (после последнего коммита памяти и `modules.yaml`: `22e1e679c`) и сдвинутся с новыми уроками.
