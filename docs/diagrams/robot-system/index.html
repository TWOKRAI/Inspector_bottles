4. Что зашито в код, а не в настройки

  • Пауза между попытками переподключения 2 с.
  • «Домой» заканчивается выключением серво.
  • СТОП повторяется один раз в ветке.
  • Старая команда движения после обрыва не повторяется в ветке.
  • Новый вид прибора или новый робот другой фирмы: нужен новый драйвер и строка в таблице видов (kinds.py). Одним рецептом это не сделать.

5. Ловушки при настройке

  • Файл params.yaml главнее рецепта. Если он есть, robot_params из рецепта не применяются.
  • Параметры доходят до робота только при новой метке config_epoch. Изменили число, а метку нет: робот работает по-старому.
  • Смена рецепта на ходу не пересоздаёт драйвер. Новые настройки прибора действуют после перезапуска программы.
  • Вкладка «Робот» говорит на старом языке v1. С v2 двигайте только с Пульта.
  • Внешняя граница зоны забора по умолчанию 500 мм (P_ZONE_MAX), а расчётные точки забора 532–596 мм. Нужно измерить на роботе.

7. Что осталось до дня с роботом

  1. R2-S1a — заметить обрыв, не слать старое. Идёт стенд.
  2. R2-S1d — СТОП проходит всегда. Ревью пройдено, мелкие правки и проверки впереди.
  3. R2-S1c — переподключение для остальных Modbus-приборов. Не начата.
  4. R2-S1 — серво включает только оператор. Черновик есть.
  5. R2-DAY — ручной рецепт и «серво выкл» в рецепте букв. Готова, ждёт пунктов выше.
