## Расхождения (только сверх прогноза), причина одной строкой

- 1: прежний `safe_dump` кладёт `repr(object())` в message (`unserializable`), и пишет `normalize(body)` целиком, из-за чего переносимый ключ (`keys_moved_by_normalize`) исчезает из позиции файла.
- 5: при `before = {}` дельта непуста даже для неизменного стора, файл переписывается (`save_unchanged_store_writes_nothing`).
- 6: пересобранная `meta` с новым `created_at` делает дельту непустой при каждом сохранении (`unchanged_writes_nothing`) и затирает `description` (`stamps_current_version` ждёт прежний `keep-me`).
- 10: `test_explicit_migration_fn_wins_over_registry` тоже идёт путём миграции с перезаписью — пустая дельта оставляет `meta.version == 1`, а тест это не ожидает.
- 12a/12b: при `before = {}` и неизменном теле дельта непуста — файл переписывается, меняется `rev` (`same_body_no_write_same_rev`); в 12b дополнительно пропадают отказы `invalid` и `bad_request` для непарсимого и v1-файла.
