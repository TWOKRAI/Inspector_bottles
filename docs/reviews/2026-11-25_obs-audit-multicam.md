## 1. Вердикт аудита

**Частично.** Многокамерному тесту сегодня доверять нельзя. Видны процессы, циклы, SHM, рестарты; для семи управляемых полей камеры есть настоящее чтение из прибора (`state.plugins.hikvision.params` + `params_status.verified`; gain записан 23.0, прочитан 23.0119 [запуск]). Здоровье потока самой камеры не видно совсем: нет потерянных пакетов, неполных кадров, пропусков номеров, признака двойного перечисления и проверки подсети, формата пикселей, признака «чёрный кадр». Считыватель: запись триггера через регистр принимается, до прибора не доходит. Агент через MCP не видит того, что видит оператор: показанные кадры по дисплеям считаются только внутри gui.
