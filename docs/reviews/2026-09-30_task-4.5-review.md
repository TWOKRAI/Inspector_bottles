## Находки

### 1. [spec — blocker] CPU не считается при действующем гейте прототипа
`process_heartbeat.py:1428-1432`: `sample()` стоял внутри `if allowed_metrics is None or "cpu" in allowed_metrics`. В
`multiprocess_prototype/backend/config/system.yaml` — `telemetry.publish.default_enabled: false`, в metrics только
fps/latency_ms, поэтому `sample()` не вызывался никогда.
Вход: `hb.reconfigure_telemetry({default_enabled: False, metrics: {fps, latency_ms}})`, 4 тика по 0.3 с.
Выход: `last_cpu_cores after 4 ticks: None`; `introspect.status cpu: {'cores': None, 'seconds_total': 1.894,
'method': 'cycles'}`; `poll state keys: ['plugin_ms']`.
**Исправление:** `sample()` на каждом тике безусловно, гейт — только на `state["cpu"]`. + тест.

### 2. [tests — major] Замёрзшие cores после закрытия гейта
Вход: два тика без гейта с нагрузкой 0.5 с, затем три тика с `allowed={"fps"}` и простоем 1.5 с. Выход: опрос
`{'cores': 0.97}` → `{'cores': 0.97}`. Закрывается исправлением п.1.

### 3. [quality] Документация модулей не обновлена
grep новых полей в process_module/{README,STATUS}.md и router_module/{README,STATUS}.md → 0/0/0/0. Нужен раздел в README,
строка в STATUS, отступление «`~MHz` без калибровки» — в DECISIONS.md process_module.

### 4. [quality] `bytes_read` считает view
Вход: читатель с `zero_copy=True`, `restore_frame` кадра 480×640×3. Выход: `owndata False`, `bytes_read: 921600`. Для
отчёта о мощности «переданные» не отличить от «скопированных». Спецификация («копия или view») это разрешает.

### 5. [quality] `_queue_maxsize` для неограниченных очередей
`queue.Queue(0) -> None`, `mp.Queue(0) -> 2147483647`; при этом None по docstring — «неизвестно».

## Ответы на вопросы брифа
1. Конкурентность — замечаний нет (EMA под lock, байты под lock, одиночные писатели float/int под GIL).
2. CPU: такты против process_time — 0.988/1.000 (1 поток), 2.908/2.948 (3 потока), 0.001/0.000 (сон). push ⊆ poll
   соблюдено.
3. Горячий путь: `_StampedBatch` ~133 нс, `_note_ms` ~243 нс, `perf_counter` ~61 нс — < 1 мкс на кадр (~0.01 % бюджета).
4. Merge на каждом тике — безвредно; `plugins: {}` не воспроизвелся; снятие писателя (шаг 0) не затронуто.
