## Что осталось открытым / ненадёжным

- Тест F1 опирается на порог gen0 по умолчанию (700) и на то, что брошенный корень ещё в gen0 при входе в
  `unclosed_roots()`. Другая версия Python (инкрементальный gc 3.13+) или чужой `gc.set_threshold` делают тест
  зелёным и без правки. Инъекция лида «`RLock` → `Lock`» — единственное доказательство, что тест не вакуумный.
- Красный F1 отравляет процесс: лок сторожа захвачен навсегда. В матрице инъекций прогонять F1 отдельно.
- Тест F3 покрывает только `_release`; путь `_detach_child` (досрочный `child.close()`) без своего теста.
- Пороги времени F2 (`<= 0.1` с) — на загруженной машине возможен ложный красный.
- Вне scope: другие места `_roots_lock` (`open_scope`, `_forget_root`) — только через `RLock`; гонка
  `child.close()` против `close` родителя; reporter для отказа `own()`.
