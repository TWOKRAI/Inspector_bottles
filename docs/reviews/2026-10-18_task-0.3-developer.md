## Что я истолковал, а не выполнил буквально

1. Приёмка противоречива про выходной параметр: для `GetStringValue`/`GetEnumEntrySymbolic` вызывающий передаёт структуру
   (обёртка делает `byref`), для `XML_GetNode*` — `byref(mode)`. Обёртки принимают оба вида (`_as_pointer_arg`); тесты
   проверяют оба для XML-узлов.
2. `MV_CC_GetIntValue`: в DESIGN она в описи и "найденная" -> обёрнута, хотя прототипа в заголовке нет (см. ниже).
3. Константы перечислений: взял все элементы `AM_*` (7, включая `AM_Undefined`, `AM_CycleDetect`) вместо `AM_NI…AM_RW`, чтобы не обрывать enum.
4. Строковые `argtypes` — `c_char_p` (в образце `c_void_p`): точнее соответствует `const char*`. Реальная DLL приняла.
5. Ссылка на колбэк выставляется до вызова DLL (колбэк может сработать сразу).
6. Тест реальной DLL (`test_real_dll_exports_wrapped_functions`) — экспорт по именам, без вызова; вызов на NULL-хендле сделан скриптом в scratchpad, в тесты не включён (хендл в `MvCamera` — указатель на указатель, подмена `handle` в тесте хрупкая).

## Что я оставил открытым / ненадёжным

- `MV_CC_GetIntValue`: прототипа нет в заголовке SDK; раскладка `MVCC_INTVALUE` (4 x c_uint + 4 резерва) — по аналогии. Вызвана только на NULL-хендле. Настоящее доказательство — вызов на открытой камере (0.4 / стенд).
- Существующий `MvCamera.handle = pointer(self._handle)` передаётся в SDK как "хендл" — это указатель на `c_void_p`, а не само значение. В образце Hikvision так и есть для `byref(self.handle)` в `CreateHandle`, но для прочих вызовов проверено не мной; не менял (вне задачи), 4.1 должен проверить на камере.
- Все новые обёртки на открытой камере не проверялись (камеры нет); тесты — фейк и NULL-хендл.
- Файлы в рабочей копии CRLF (autocrlf=true, в индексе LF); `ruff format` оставил их согласованными, git выдаёт предупреждение LF->CRLF.
- `MV_CC_RegisterExceptionCallBack(None)` ("снять колбэк") не проверялся ни на фейке, ни на DLL; докстринг утверждает это допущение по аналогии с C-API, заголовок про NULL не говорит.
- Хук `lint-result` потребовал форму 0.7 — `0.3.result.md` переписан под неё; таблица описи там занимает часть бюджета 2 KB.
