## Что оставил открытым / ненадёжно

1. **12 красных в радиусе** (выше) — открыты до решения лида; блокируют коммит.
2. **Строгость «негодная причина = негоден весь лист».** Одна неверная причина обнуляет и остальные годные причины того же листа: процесс получает `not_ready` с одной причиной «лист негоден». Это безопасная сторона (никогда не принять мусор за «готов»), но для оператора теряется диагноз остальных причин и сама негодная причина не показывается. Альтернатива — отбрасывать только негодную причину и вести счётчик отброшенных; не сделана, нужно решение владельца полосы. Побочный эффект строгости — пункт 1 (старые тестовые данные не по контракту).
3. **Нет прямого теста на `BaseException` для `finally`.** Мутант ii-a показал, что `finally` для `Exception` избыточен; смысл он имеет только для `BaseException` в потоке L-исполнителя. Такого теста нет (поток с `SystemExit` внутри дописывания — хрупкий). Решение «оставить `finally`» — по заданию лида; если считать его лишним, убрать, оставив `except Exception`.
4. **Порог серии = `_run_stale_s()`.** Короткая серия (< порога) оставляет `ready` прежним и несёт причину `failure` в статусе: в `running` без `fault`, пока серия не дотянула. Выбор — решение лида из брифа; тест фиксирует порог литералом (интервал heartbeat 0.1 -> 0.3 с).
5. **`_eval_fail_since` не объявлен в `__init__`**, читается через `getattr(..., None)` (тестовые обвязки собирают PM без полного конструктора). Работает, но неявно; явный атрибут класса — мелкая чистка.
6. **ERROR серии не повторяется** при затяжном сбое (один раз на серию). Длинная серия видна только как `fault`/причина в статусе, не в логе. Сознательно (иначе ~2 ERROR/с), но оператор, читающий только лог, увидит одну строку.
7. **Цепочка через `stop_event`** (ребёнок умер внутри `stop_event.is_set()` -> `stop_event.set()` виснет на L-исполнителе -> STOP не выполняется) — описана в ADR-PMM-046 и amendments §12, не исправлена; Task 2.5. Воспроизведение ревьюера R6/R7 (`scratchpad/rs/repro.py`) в этой сессии не перезапускалось: R6/R7 покрыты своими тестами в новом файле, расхождения со сценарием репро (например, реальный SIGKILL ребёнка) не исключены.
8. **Предупреждения doc-size-guard** (хук): `DECISIONS.md` 349 KB, `amendments.md` 32.7 KB (бюджет 32 KB) — файлы были большими до правки; разбиение вне объёма задачи.
