## Как сняты литералы

Все наблюдатели (`_observe_*`) лежат в тестовом файле и принимают пути модулей. Литералы словаря `_EXP` сняты одноразовым
скриптом (`scratchpad/capture.py`), который импортирует тестовый файл и вызывает те же наблюдатели по СТАРЫМ путям
(`Services.dataset_gen.core.{catalog,config,metadata,backgrounds}`, `Services.line_sim.core.preset`). Команда:
`PYTHONPATH=<worktree> PYTHONIOENCODING=utf-8 python capture.py <worktree> exp.txt`. Вывод вставлен в файл между маркерами
как есть (затем `ruff format`). Окружение: Windows-10-10.0.19045-SP0, CPython 3.12.12, numpy 2.4.4, cv2 `5.0.0`
(`cv2.__version__` напечатал именно `5.0.0`, CLAUDE.md пишет 4.13 — расхождение не разбирал).

Снятые ключи `_EXP`: `names`, `entries`, `sprite_choices` (класс A: `[1, 0, 1, 1, 1]`, остальные `[0]*5`),
`catalog_procedural_bg`, `folder_bg` (blue 4 из 5, red 1 из 5 — оба файла выбраны), `gradient_bg`, `bad_sprite_tail`
(`нужен альфа-канал (RGBA, объект на прозрачном фоне), получено shape=(5, 6, 3)`), `procedural` (20 sha256),
`generators` (8 sha256), `load_meta`, `load_meta_not_dict_tail` (`ожидался словарь, получено list`), `write_meta`, `merge`,
`preset_roundtrip`, `to_yaml`, `preset_errors`, `load_none_none_msgs`.
`load_scene_preset(None, None)`: `loc == ()`, `msg == "Value error, пресет без catalog_dir и без layers: нечего рисовать — нужен хотя бы один источник"`.

Перекрёстный контроль: sha256 `catalog_procedural_bg[seed]` совпадает с `procedural[seed,24x32]` для seed 0..4 — каталог без папки
фонов отдаёт `procedural_background` как есть.

## Что я оставил открытым и в чём не уверен

- **sha256 привязаны к платформе.** Хэши процедурных фонов и `_cover_crop` сняты на win32/cv2 5.0.0/numpy 2.4.4. На macOS/Linux или
  другой сборке cv2 они могут разойтись без регрессии (прецедент: тесты 2.1, 2.3, 6.1). Оракулов без хэшей для фонов нет — кроме
  однотонного случая.
- **Хрупкость к реализации.** Пины `_EXP["entries"]` включают порядок ключей `model_dump` не как порядок (dict сравнивается без
  порядка), но фиксируют набор полей `ClassMeta`. Если 3.x добавит поле в `ClassMeta`, кейс упадёт — это верное поведение, но шумное.
- **Тексты ошибок пресета** (`preset_errors`) закреплены дословно, вместе с упоминанием `ObjectFactory` и `class://` — по спеке (`msg`
  литералом). Правка слов рамки в докстрингах (DESIGN) не должна менять эти `msg`; если разработчик перепишет текст ошибки — кейс красный.
- **Подпроцессные тесты** (`test_boundary_*`, 7 кейсов) стартуют `python -c` с `PYTHONPATH=<root>`; от зависания их защищает
  `subprocess.run(timeout=120)`, а не `pytest-timeout`: плагина в этом venv нет (маркер `timeout` дал `PytestUnknownMarkWarning`,
  маркеры я убрал). Время каждого — около 1-2 с.
- **Не проверено мной:** A6, A7 (по заданию), `test_frame_rule_grep_zero_matches_in_package_python_sources` на новых файлах
  (рамка `letter|букв|disk|диск`): в моём файле слова рамки есть (`диск` в комментариях/строках, `Жук`, «буквы» нет) — сам
  тестовый файл лежит в `tests/`, которые тест рамки не сканирует; убедился чтением условия спеки, не запуском.
- **Ни одного нового теста не доказано красным по свойству:** красные — по отсутствию модуля. Что набор ловит неправильный
  переезд (копия класса вместо реэкспорта, потеря `import os`, `REPO_ROOT` в другом модуле, правка литерала), проверит
  break-injection лида; ожидаемые красные для инъекций: «копия `ScenePreset` в `layer_render`» -> A1 identity/`__module__` + A2 AST;
  «убрать `import os` из старого preset» -> A2 `keeps_module_level_import_os` + A5 relpath `[old]`; «`REPO_ROOT` в `layer_render`» -> A5
  `repo_root_is_three_levels...`/`sees_repo_root_substituted`; «`layer_render/__init__` импортирует `dataset_gen`» -> `test_boundary_*`.
- **Утечек слепоты нет:** новые модули не читал (их нет); старые `preset.py`, `catalog.py`, `metadata.py`, `backgrounds.py`, `config.py`
  (фрагмент `CatalogConfig`/`SymmetryType`) читал — разрешено для снятия литералов. Тесты `line_sim/tests/test_hazards_1_0_paths.py`
  читал в строках 255-285 (способ подмены `relpath`), в остальные чужие тесты не заходил.
