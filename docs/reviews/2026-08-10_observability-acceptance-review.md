# B. Карта для будущих агентов

**Вопрос:** что должно быть верно, чтобы агент, впервые открывший проект, подключил модуль к трём разъёмам и не сломал систему.

**Вердикт линзы S2 (агент, у которого не было ничего, кроме документов): агент дойдёт до работающих записей, но остановится с ложным «доставка сломана» — из-за одного шва.** Всё, что документы утверждают **про механизм**, оказалось правдой (реестр объявлений отбивает чужого владельца и словарь текстом, почти дословно повторяющим документ; седьмой тип стока регистрируется без правок фреймворка; yaml переживает round-trip без потерь). Развалился шов между шагами: «объяви имя» и «пиши» не соединены — без `source_name=` в конструкторе миксина записи едут под именем менеджера, и проверка доставки из рецепта читается как провал при исправной доставке.

**Достижимость:** справочники — не мёртвый груз: ≥9 входных точек в четырёх слоях (карта, гайды, глоссарий, STATUS/README модулей, README конфига прототипа).

**Три правки документации с наибольшим выигрышем** (готовые формулировки — в отчёте S2): (1) шов `source_name` в шаге 3 рецепта; (2) обязательность `initialize`/`shutdown` в блоке кода шага 1; (3) адрес yaml + форма `logger_groups` в «Доказательстве доставки».
