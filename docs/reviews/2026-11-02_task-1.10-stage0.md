## Ответы на вопросы задачи (запуском)

- **Q-c.** Backend читает вложенный `config` поверх плоских ключей: `_extract_plugin_config({"fps":25,"config":{"fps":30}}) -> {'fps': 30}`. Слияние неглубокое: вложенный `params` заменяет плоский целиком
  (`gain` теряется) — поэтому `params` пишется как «текущий `config.params` модели + pending».
- **Q-d.** Вложенность не теряется: `PluginInstance.from_dict({... "config":{"fps":30}}).config == {'fps': 30, 'params': {'brightness': 20}}`; дельта в файл идёт на уровне листа, плоские строки остаются.
- **Q-a.** `dispatch(SetPluginConfig)` публикует `PluginConfigChanged` -> `app.py:836` `registers_manager.set_value` + IPC `register_update`; выключателя на команду нет. Для `fps`/`mjpg` двойной эффект безвреден (поля регистра,
  плагин не подписан). Для `params` поля в регистре нет -> один WARNING GUI и одна `log_error` backend (прецедент `control_panel`, `controls`). Вывод чтением кода, живым прогоном не подтверждён.
- **Q-b.** Save пишет всю модель (как все пути). После Camera Save `dirty=False`, `diverged=True` (запуск, probe110c); в undo 1–3 записи.
