**Находки инъекций (первый прогон):**
- I9 — хазард `rev` автора пересчитывал sha256 своей формулой и не звал обработчик → зелёный при
  случайном `rev`. Переписан на `BuiltinCommands._cmd_catalog_plugins` (`5925a3b5`).
- I1 — паритет тестера строит payload собственной копией кодировщика (`_build_catalog_payload`) →
  потеря `choices` в реальном `to_dict` проходила мимо. Добавлен паритет на реальном кодировщике
  (`test_remote_plugin_catalog_real_encoder.py`). Тест тестера оставлен как есть — он по-прежнему
  доказывает только свою фикстуру.

## Ревью

- Итерация 1 — REQUEST_CHANGES: один плохой плагин ронял весь каталог (Enum-literal, Path в
  `examples`, регистр без pydantic — `introspect.plugins` при этом 63). Фикс: изоляция по плагину +
  `failed_catalog`, рекурсивный `_json_safe`; `PydanticUndefined` → `None`; паритет kind по 417 полям.
- Итерация 2 — одна правка: проверка записи шла без `sort_keys`, dict с ключами разных типов
  проходил её и ронял `rev` всего каталога. Фикс `248eb51a`; условие ревьюера («62/63 и одна запись в
  `failed_catalog` → третий раунд не нужен») повторено лидом инъекцией I10.

Замеры ревьюера: обработчик 5.2 / 6.0 / 7.1 мс (мин/медиана/макс, 20 вызовов), ответ 239 604 байта
JSON; `introspect.plugins` байт-в-байт как в `main`; kind до/после JSON-round-trip — 0 расхождений из 417.

## Вход для 1b.2b (не решено здесь)

- `RegistersManager.from_catalog` без инстансов: `register_names`, `get_categories`, `get_register`,
  `get_field_metadata`, `validate`, `set_value`, `model_dump_all` пусты/False; `FieldSetHandler.apply`
  → `(False, "Регистр 'contour_draw' не найден")` — правка формы молча не уходит. Обязательное
  предусловие 1b.2b.
- Порядок `list_plugins()`: удалённый — по алфавиту, локальный — порядок discover.
- `Literal[Enum]`: в GUI уходит `str(x)`, бэкенд принимает только член Enum — поле не записать
  (как и на локальном пути, `builders_binding.py:284`).
- Текст исключения в `failed_catalog` входит в `rev`; адрес объекта в тексте сделал бы `rev`
  разным между процессами (не встречено).
