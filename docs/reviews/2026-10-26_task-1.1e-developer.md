  нет в файле, даже если он равен в `before` — стоит записи в том же mapping. Формат-хук, у которого `normalize`
  ДОБАВЛЯЕТ ключи (умолчания), протечёт этими ключами в файл при любой правке этого уровня. Первая версия моего теста
  хука это показала (`version: 3` дописался); я переписал тест на хук, меняющий регистр значений. Хуки приложения

- Переотступ: запись по файлу в стиле «тире без отступа» (`processes:\n- id: a`) переписывает отступы всего файла
  (engine indent 2/4/2). Фикстуры теста — в стиле движка. Файлы прототипа 22 рецептов не проверялись (1.1g).

  обработки в менеджере нет.

- Сила теста лока: красный только при сверке `rev` ДО лока (проверено); если сверка есть и до, и внутри лока — тест
  зелёный, это корректно.
