# Вердикт cto: когда СТОП обязан уходить на робота (2026-11-27)

Эскалация по двум находкам: F1 (ревью R2-DAY: СТОП отказывает при неудачном повторном connect во время движения) и F2
(разбор R2-S1a: `_link_lost` закрывает транспорт раньше ждущего СТОПа). Всё на симуляторе в процессе.

**Вердикт:** правки ревью R2-S1a — ACCEPT WITH CONDITIONS; слияние R2-DAY — BLOCK до правки затвора.

## Правило

СТОП оператора (`stop`, `abort`, стопы внутри `disconnect()` и `request_stop()`) пишется роботу всегда, когда у драйвера
есть клиент, подтвердивший прошивку v2 по этому адресу, и связь не закрыта законченным намеренным `disconnect()`.
`_ready`, `is_connected`, идущий или неудачный connect, лимит переподключений его не запирают. Попытка без эха называется
«стоп не подтверждён роботом». Нужен ADR-DH-016.

## F2

Открывать соединение, но только неявным connect pymodbus внутри записи: `_link_lost` не зовёт `transport.disconnect()`,
когда транспорт уже не подключён (`driver.py:624-630`). Явный reconnect из пути СТОП не добавлять (на мёртвом хосте
нажатие висит 2,4 с против 1,0–1,4 с). Не открывать: после законченного `disconnect()`; через `connect()` драйвера;
клиенту без подтверждённой прошивки; за сроком `request_stop`; больше одного раза на вызов. Гонку СТОПа с
`driver.py:364-365` закрыть тестом с навязанным порядком.

## F1 и затвор — задача R2-S1d (на базе R2-S1a)

`needs_link=False` у `_ABORT` (`Services/device_hub/spi.py:156-161`) и у `stop` v2 (`:205-210`); `manager.py:742` не
менять. Попутно: нейтральный текст вместо «журнала нет: драйвер не создан» (`plugin.py:924`, литерал журнала закреплён
`test_a6_…`); красный тест «v1 без связи → ответ-ошибка, 0 записей» (`_ABORT` общий, `robot_driver.py:604-607`).
Туда же правка `_link_lost` и ADR. Красные заранее: шесть отказов из прогона и «tick_first `[]` → `[HARD]`».

## Порядок

R2-S1a → R2-S1d → R2-S1c → R2-S1 → R2-DAY (rebase). Если R2-S1 не успевает к дню с роботом, R2-DAY идёт сразу после
R2-S1d. Если не успевает и `_link_lost`, в инструкцию дня: после обрыва СТОП с ПК может ответить ошибкой, средство —
аварийный грибок.

## Условия коммита правок ревью R2-S1a

1. Порядок в `test_stop_during_job_after_drop` — параметр с литералами: stop_first → `[HARD]`; tick_first → `[]`,
   `stop_unconfirmed is True`, текст в `last_error` ровно один раз. Шов только в тесте.
2. `R2-S1a.md:47` уточнить: СТОП уходит, когда запись берёт замок раньше `_link_lost`; tick_first — остаток со ссылкой
   на R2-S1d. Строка 35 действует только для R2-S1a.
3. Инъекция: без `mark_unconfirmed` в `_write_stop_twice` случаи `disconnect` в tick_first краснеют.
4. Наборы A16 прогнать на SHA коммита.

## Не проверено

Настоящий робот (приём второго TCP-сеанса после обрыва, срок сторожа); обход затвора проверен подменой в процессе, не
правкой `spi.py`; вариант «обёртка остаётся» — только на одном тесте; ПЧ через мост после неявного открытия.
Пробы: scratchpad сессии `cto/r2stop/`.
