1. Размер data-очереди читается из `GenericProcessConfig.build()[1]["queues"]["data"]["maxsize"]`, lag — из `proc_dict["config"]["chain_max_lag_items"]`; ключи рецепта — в `extras`.
2. Писатель кольца = процесс, чьё имя стоит в `chain_targets` другого процесса (получатель = цель), либо цель blueprint-`Wire`. У blueprint-`Wire` нет `shm_config`, поэтому его глубина — дефолт 8; тест на wire только дефолтный случай.
3. D = 4: в спеке «lag по умолчанию 2, queue = B - lag» даёт очередь 0 при B = 2, а «D < 4 -> ошибка» значит, что D = 4 допустим. Единственное разбиение с queue>=1 и lag>=1 — (1,1); тест ждёт его.
4. Явный lag без queue: queue добирает остаток бюджета (B - lag).
5. Глубина «не задана» = None, 0, отрицательное (как в текущем `_resolve_ring_depth`).
