1. ~~Hazard проверяет только broadcast-путь~~ — ЗАКРЫТО правкой по ревью этапа 5: hazard параметризован `[broadcast, session]`,

   сокет-клиенте» (≤ 0.5 с на запись, клиент снят) не измерено: это приёмка на стенде.

   (L1/L2/L3 краснят его). Сама гонка без лока на CPython 3.12.13 не воспроизводится (`test_forwarder_counters_threaded` зелёный
