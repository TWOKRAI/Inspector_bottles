## Скрипт снятия литералов (на коде ДО задачи)
Сначала в тесте стоят заглушки `@@A1_<cfg>@@` / `@@F_<func>@@`; скрипт проверяет, что оракул == текущий
`dataset_gen.core.augment`, и подставляет sha:
```python
import sys
import Services.dataset_gen.tests.test_augment_equivalence as t
import Services.dataset_gen.core.augment as aug

a1_old = {n: t._sha_of_50_frames(t._oracle_apply_photometric, f()) for n, f in t._CONFIGS.items()}
a1_cur = {n: t._sha_of_50_frames(aug.apply_photometric, f()) for n, f in t._CONFIGS.items()}
assert a1_old == a1_cur
fn_old = t._call_funcs(t._ORACLE_FUNCS)
fn_cur = t._call_funcs({n: getattr(aug, n) for n in t._SHA_FUNCS})
assert fn_old == fn_cur
# затем src.replace(f"@@A1_{n}@@", sha) / src.replace(f"@@F_{n}@@", sha) и запись файла
```
Кадры: `_FRAME_U8 = default_rng(2024).integers(0,256,(48,64,3),uint8)` (A1), `_FRAME_F32 = default_rng(7).uniform(0,255,(48,64,3)).astype(float32)` (функции).
Параметры функций — в `_call_funcs` теста.
