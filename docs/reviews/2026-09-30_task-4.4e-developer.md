## Отступления от буквы задания
- Тест счётчиков дополнен трассировкой опкодов (`sys.settrace`, `f_trace_opcodes`): без неё на CPython 3.12 гонка `+=` не воспроизводится. Причина записана в docstring теста.
- Для теста дедупа читатель подан в `_process` напрямую (приватный метод), `RemoteFrameSource(Mock(), ...)`; публичный путь через сокет-хост слишком тяжёл для счёта вызовов на границе читателя.
- `view_valid` переписан в один `with`-блок (gen<0 больше не идёт мимо lock) — поведение то же, но lock теперь берётся и на gen<0.

- Читатели `stale_drops`/`torn_reads` (properties) по-прежнему без lock — чтение int атомарно, но между двумя чтениями одного отчёта согласованности нет.
