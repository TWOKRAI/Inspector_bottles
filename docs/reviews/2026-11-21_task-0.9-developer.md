MEMORY LESSON feedback_test_double_journal_aliases_nested_dicts.md
```
---
name: A test double's journal shares nested dicts with its tree
description: Дублёр дерева (test double of a state tree) кладёт во вложенный узел тот же dict, что лежит в журнале вызовов, и следующее слияние правит запись журнала задним числом — снимай глубокую копию в журнал / aliasing journal deepcopy merge
role: developer
module: process_module
mechanism: test-double
---
`_Proxy.merge` in `process_module/tests/test_plugin_levels_hazards.py` journals `dict(data)` (a shallow copy) and then merges `data` into its tree; the tree keeps the SAME nested dict object, and the next merge mutates it in place. A recorded stamp from tick 1 later read `seq == 2` ([2, 2] instead of [1, 2]) — a defect of the double, not of the writer. A test that reads a nested value out of a journal of merges must record a deep snapshot (`copy.deepcopy`) separately from what is applied to the tree.
```
