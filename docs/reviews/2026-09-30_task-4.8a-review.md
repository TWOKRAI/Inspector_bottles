## Вопросы лида

- **(a) `_resolve_launcher`.** Для pid стенда безопасна: настоящий интерпретатор и spawn-дети запускаются из базового
  python uv, детей у них нет. Но единственный признак — путь exe. Модель virtualenv с настоящим python.exe:
  `requested pid 29192 -> measured pid 17204 cores 0.0` для процесса, который грузит ядро и имеет одного ребёнка.
  Предложение: `clock_selfcheck` запускает `sys._base_executable`, `_resolve_launcher` удалить, тесты перевести
  туда же.
- **(b) `samefile`.** Приемлемо. Остаётся I16: тест на `commit_dirty` на временном git-репозитории.
