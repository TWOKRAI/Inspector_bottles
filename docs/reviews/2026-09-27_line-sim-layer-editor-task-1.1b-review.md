## Находки

### SHOULD-1 — `make_font_letters`: широкая буква молча обрезается канвой
`Services/line_sim/tools/make_font_letters.py:130` (`_center_crop(final_mask, center_rc, size_px)`).
Масштаб подбирается только по высоте bbox, ширина не проверяется: всё, что шире `size_px`, срезает `_center_crop`,
а инструмент пишет файл и выходит с кодом 0.
**Вход → наблюдаемое:** `--size-px 300 --letter-frac 0.9`:
- Times New Roman «Ш»: ширина глифа 389 px при канве 300 → **потеряно 17.4 % альфы** (ножки срезаны);
- Arial Black «Ж»: 406 px → 15.3 %; Arial «Ж»: 346 px → 6.1 %; Times «Ж»: 355 px → 6.3 %;
- обрезаны также Times Щ, Ы, Ю, Arial Ю, Arial Black Ш, Щ, Ы, Ю.

Постусловие `_render_letter` («высота альфа-bbox == letter_frac·size_px, центр bbox — в центре канвы») формально держится,
а буква другой формы уходит в каталог класса как эталон. При дефолтных 0.6 обреза нет (самая широкая — Arial Black «Ж», 271 px).
**Исправление:** после перерендера сравнить ширину `final_bbox` с `size_px` и выйти `SystemExit` с именем шрифта, буквой и шириной
(или подбирать масштаб по `max(h, w)` — но это меняет контракт C1 «высота = letter_frac·size_px», решать лиду).
Нужен тест: Times New Roman/DejaVu «Ш» при `letter_frac 0.9` → ненулевой выход, либо альфа не касается края канвы.

### NIT-1 — холст объекта раздувается прозрачной канвой буквы (п.1 брифа): **безвредно для геометрии, стоит времени кадра**
Буква — квадрат 300×300 почти пустой альфы. При масштабе и повороте буквы холст объекта растёт до 654 px при видимой части ≤ 332 px.
Кто читает размер холста (проверено по коду):
- `SceneCompositor._bbox_intersects` — только отсев невидимых и список `passports`; плагин его выбрасывает (`_passports_in_view`);
- деспавн — только энкодер (`ObjectSpawner.tick`), размер не участвует;
- истина/matching/точка захвата — из паспорта (`spawn_encoder`, мм), не из спрайта;
- цена: `composite` 3.62 мс против 1.30 мс у кропа на объект за кадр (кадр 1440×1080, в кадре 1–2 объекта при шаге 164 мм)
  плюс кэш до 1.7 МБ на объект. С вариациями по умолчанию (выключены) холст 302..425 px — как у прежнего `letters_disk`.

**Рекомендация:** инструмент НЕ кропать — квадрат `size_px` закреплён приёмкой C1, а поворот слоя всё равно расширит холст.
Если вариации включат на стенде — симметричный кроп по альфе в конце `LayeredObject._compose` (центр объекта сохраняется;
докстринг модуля «по альфе не обрезается — иначе потерялся бы центр» относится к несимметричному кропу). Сейчас — follow-up.

### NIT-2 — неверный комментарий про пробный кодпоинт
`make_font_letters.py:42`: «`\U0010fffd` … Unicode noncharacter». Замер: `unicodedata.category('\U0010fffd') == 'Co'` (Private Use,
Plane 16), noncharacter — `U+10FFFE`/`U+10FFFF` (`'Cn'`). Утверждение «заведомо не занятый ни одним реальным шрифтом» для PUA не
гарантировано (иконочные шрифты занимают PUA). На 240 шрифтах macOS проверка отработала без ошибок — поправить текст или взять `U+10FFFF`.

### NIT-3 — неудачный прогон оставляет полкаталога и пустую папку класса
`build_font_letters` создаёт `out/<буква>/` до рендера (`make_font_letters.py:150`). `--letters К --font cmr10.ttf` → exit 1, на диске пустая `К/`;
предыдущий прогон `--letters АК --font DejaVuSans.ttf --font cmr10.ttf` → exit 1 с одним `А/DejaVuSans.png`.
`ObjectFactory(ScenePreset(catalog_dir=…))` на этом каталоге → `num_classes 1` молча (К пропущен).
Фикс: сначала проверить все пары шрифт × буква, потом писать; или `mkdir` после успешного рендера.

### NIT-4 — нормировка по bbox уменьшает буквы с выносными элементами и диакритикой
Высота bbox включает хвост «Щ» и кратку «Й», поэтому тело буквы мельче, чем у соседей: Arial, frac 0.6 — «Щ» шириной 163 px против
«Ш» 192 px (в шрифте Щ шире Ш), «Й» 116 px против «И» 142 px. На линии все буквы печатаются одним кеглем. Для текущих АКРХ не влияет.
Вопрос к владельцу при появлении Д/Ц/Щ/Й/Ё: нормировать по высоте прописной (например, по bbox «Н» этого шрифта), а не по своей букве.

### NIT-5 — scene_source: расширение сверяется с учётом регистра, `null` глушит движок
- `preset_path: …/LETTERS_LAYERED.YAML` → ветка каталога → `FileNotFoundError('Каталог классов не найден: …/LETTERS_LAYERED.YAML')`:
  на macOS файл существует, но трактуется как папка — вводящее в заблуждение сообщение. Фикс: `.lower().endswith(...)`.
- `defect_probability: null` в конфиге стенда с `.yaml` → `TypeError` из `float(None)` → движок недоступен (1 `log_error`, фон).
  Мягко, но «null = взять из файла» было бы естественнее. На `main` та же строка стояла вне `try` и роняла `configure()` —
  перенос внутрь `_build_preset` сделал ветку каталога мягче (изменение поведения в лучшую сторону, в докстринге не упомянуто).

### NIT-6 — битмап-шрифт даёт трейсбек вместо понятного выхода
`NISC18030.ttf` → `OSError: invalid pixel size` из `ImageFont.truetype`, не `SystemExit` с именем шрифта. Для шрифтов этикеток неактуально.

## Что сделано хорошо
- Ветка без `class://` не тронута: побитовое равенство с `main` по пяти сценариям, включая хвост `rng` — порядок розыгрыша сохранён.
- `_has_class_layer` считается до замены `sprite_source` на ndarray — ловушка «`==` на массиве» закрыта и описана.
- `class://` переживает `to_yaml` в другой каталог; `color_rgb` сериализуется списком; `base_dir` едет через `to_dict`, поэтому
  перекрытие `defect_probability` через `from_dict({**to_dict(), …})` не ломает относительные пути.
- Проверка глифа через сравнение с маской отсутствующего кодпоинта — 0 ошибок на 1680 парах реальных шрифтов.

  объектный уровень (RGBA, паспорта, хвост rng) сравнен полностью.
- Цена `composite` — микробенчмарк на этой машине (Mac), не живой стенд и не Orin; бюджет кадра на Orin не мерил.

## Замечания (не блокируют)
- **NIT-7 — та же молчаливая обрезка, но по вертикали и на границе.** Проверяется только ширина, `--letter-frac` не валидируется.
  Вход → наблюдаемое: `--letter-frac 1.2`, Arial «И», size 300 → bbox h=360 w=283, `exit 0`, **потеряно 12.85 % альфы**.
  При `1.0` высота выходит в 300..301 px и 4 пары из 32 молча теряют 0.03..0.90 % (Arial/Arial Black «Й», Times «Й», Courier «Щ»).

  Фикс одной строкой: `if max(width, height) >= size_px` (или `0 < letter_frac < 1` в argparse плюс `>=`).
- Фиксы NIT-5 (`.lower()`) и NIT-6 (перехват `OSError`) без тестов: в `Services/line_sim/tests` и `Plugins/sim/scene_source/tests` нет упоминаний
