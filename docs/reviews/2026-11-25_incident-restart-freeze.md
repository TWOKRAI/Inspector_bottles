## Что остаётся находками
1. **Несогласованность.** Пропажа камеры по кабелю аварию не подняла (линия «в прогоне», камера слепа). А действие по её восстановлению подняло аварию и остановило линию.
2. Ручной перезапуск неотличим от отказа: причина и текст те же.
3. Диагностика через MCP не навела на состояние прогона: `system_overview` показывал все процессы `running` без аномалии о `fault`.
4. Решение владельца: останавливает ли отказ одного источника всю линию — настраиваемо по узлу или всегда.
