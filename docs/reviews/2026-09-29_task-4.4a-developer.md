## Что я истолковал, а не выполнил
1. `write_frame` НЕ читает gen из `pack_images` напрямую: тест A4 подменяет `MemoryManager.write_images` отправителя, поэтому `write_frame` вызывает `self.write_images(...)` и читает поколение из буфера сразу после (single-writer-per-slot ⇒ оно не успевает измениться). `pack_images` возвращает `writing_gen + 1` по брифу, но потребителя этого возврата пока нет.
2. Reader: новый метод `read_ref(name, gen, *, copy)` рядом со старым `read_frame` (не изменённым): brief не требовал ломать сигнатуру, а `remote_frame_source` (4.4b) её вызывает. `frame_torn_reads` у middleware стал property поверх `reader.torn_reads` (подменный reader без него → 0).
3. `frame_view_valid(ref)` вместо `(name, gen)` — по DESIGN п.4.
4. `_shm_views` записывается в `data` (не `msg`), чтобы `_build_item` (`dict(data)`) донёс его до item.
5. `on_receive` оставляет `data["_shm_refs"]` на месте (как и до 4.4); `restore_frame` тоже.
6. Слот без seqlock (`MemoryManager(seqlock_frames=False)`, только старые тесты): `write_frame` вернёт `gen = -1`, читать такую ссылку нельзя.

## Что оставил открытым / ненадёжно
- Loan (флаг заморожен): при дропе в двери отправки ПОСЛЕ `pool.commit` займ своих слотов не отпускается (потребителя нет, refcount застрянет) — кольцо под loan-протоколом исчерпается. Не «улучшал» loan по брифу; воспроизведения нет, только рассуждение по коду.
- Fan-out replay детектируется по «в item есть ссылка с `owner == self`»: в циклической топологии (A→B→A) унаследованная ссылка с owner == self будет принята за повтор. Воспроизведения нет.
- Pickle-fallback: если запись ключа не удалась и массив остался inline как numpy-view на входной слот, дверь проверяет view ДО pickle-сериализации; окно между проверкой и pickle не закрыто (как и до 4.4).
- Мёртвый код: `_Ring.slot_seqlock`/`_slot_seqlock`, `import _log` в middleware (нужен другим путям?) — не трогал, чтобы не раздувать диффа; убрать в 4.4b/4.7.
- `_read_at_generation` при пустом слоте (num_images == 0, gen совпал) считает torn, а не «пусто» — на пути ссылок пустой слот не ожидается.
