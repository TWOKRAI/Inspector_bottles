затем `np.empty` -> `render_background` -> цепочка `composite` -> `apply_effects` только при непустом `effects`.
Отсечения, своего rng и копии `rgba` нет. Импорты: `background`, `compose`, `effects`, `interfaces`, `numpy`.

`SceneCompositor`: без стека фон — `[SolidFill((r, g, b))]` из `background_bgr=(b, g, r)`; ошибка `SolidFill` перевыбрасывается
своим текстом `from exc`, значение в текст не попадает. `scroll_px` считается только со стеком (флаг `_has_stack`), порядок
вычисления прежний: сдвиг тайла до чтения спавнера. Поле `_background_bgr` удалено (нигде не читалось).
