## Как `None`-лист проходит по коду

- `StateProxy.merge` (`state_store_module/proxy/state_proxy.py:271`): упаковывает `dict` в сообщение и шлёт `_send`; значения листьев не разбирает.
- `TreeStore.merge` -> `_merge_recursive` (`core/tree_store.py:281`): не-`dict` значение -> `self.set(child_path, value)`; `None` — обычное значение листа.
- `ThrottleMiddleware.before_merge` (`middleware/throttle.py:283`): разворачивает листья `_iter_leaves`; лист без правила уходит как есть (`_nested_set(kept, rel, leaf)`), лист с правилом — в `_pending[full] = (leaf, source)`; в прочитанной части проверок типа листа нет. `_iter_leaves` и `_nested_set` я не читал — пробел. Через throttle T14 не идёт.
- Доказано тестом T14: `handle_state_get` -> `status "ok"`, `value is None`; `TelemetryReadModel` держит `None` в снимке; `_record_history` через `_as_number(None) -> None` точку не пишет (история пустая для нового пути; старая точка `[(0.0, 5.0)]` остаётся).
