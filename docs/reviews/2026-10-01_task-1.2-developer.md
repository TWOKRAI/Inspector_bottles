## Свойства (для break-injection)
1. Маска считается по готовому тайлу (после масштаба и шва), вход — RGB (BGR->RGB один раз).
2. Границы hue и sat_min включительные.
3. Строки [0,TOP) и [h-BOTTOM,h) всегда 255; BOTTOM=0 не стирает всё (`h-0`, не `-0`).
4. Маска бинарная uint8, 2D, вход не мутируется.
5. Без `--gap-alpha` запись байт-в-байт прежняя; строка итога не меняется (нет transparent_frac).
6. С флагом RGB-каналы == тайлу без флага.
7. Кривые значения -> `parser.error("--flag: ...")`; TOP+BOTTOM>=h проверяется после сборки тайла.
