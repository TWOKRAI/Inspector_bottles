## Что я истолковал, а не исполнил

1. `from __future__ import annotations` добавлен в `interfaces.py` (в списке разрешённых). Аннотации стали
   строками; `inspect.signature` имён и значений по умолчанию это не меняет.
2. `IHandle`/`IScope` — без `@runtime_checkable`: спек требует его только у `Stoppable`.
3. `__post_init__` проверяет форму (строка вместо последовательности, пара не из 2), но не тип элементов:
   `survivors=(1, 2)` проходит. Спек этого не требует.
4. `from_dict`: элемент `errors` без ключа `path`/`error` даёт `KeyError`, а не `ValueError`; элемент-пара
   списком вместо словаря — `TypeError` индексации. Спек записал форму входа, но не текст этих отказов.
5. Строку на месте `errors` `from_dict` передаёт в `__post_init__` неразобранной (иначе `TypeError` вышел бы
   с текстом «string indices must be integers», без имени поля). Отказ был бы и без этой ветки — она даёт
   только понятный текст.
6. Маркер `Stability: partial` (уровни из skill `module-contract`): контракт и тесты есть, реализации нет.
7. ADR-BM-008 сжат до 7.9 КБ (хук doc-size-guard, бюджет 8 КБ). Причины отвергнутых альтернатив, которых
   нет в спеке дословно (`lifetime_module`, «три корня», «передача close потоку», «список обёрток»), —
   мои формулировки по DESIGN §4.
8. Путь реализации назван `base_manager/core/lifetime.py` — по DESIGN D1; спек 0.1 пути не называет.
