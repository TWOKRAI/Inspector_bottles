## What I interpreted rather than followed

- Журнал событий пишет полный payload send (`("send", "camera", "register_update", {...})`), а не только имя поля: строже, чем «send(frame_rate)» в критерии (1).
- (3) warning: требую в тексте WARNING-записи имя упавшего поля (`frame_rate`/`exposure_time`/`gain`), а не просто «любой warning». Иначе постороннее предупреждение дало бы зелёное.
- (5) «без registers_manager»: добавил приманку `services.registers_manager` (шпион должен получить 0 вызовов): фиксирует чтение менеджера из runtime. Разработчик, берущий менеджер из services, получит красный.
- (5)/(6) контроллер строится через `build_hikvision_controls` с `SimpleNamespace`-runtime (`command_sender`, `registers_manager`); `topology_bridge`/`bindings` не заданы (getattr-умолчание None; сборка проверена).
- (6) добавил второй триггер: клик по `_btn_apply` с текстом в полях (настоящая проводка виджет -> контроллер), кроме `_on_apply_params(30, 900, 2)` из брифа.
- Красные presenter-тестов — `TypeError` внутри теста (у конструктора нет kw), не на сборке файла; collect-only чистый (22 теста).

## What I left open / unreliable

- Не оговорено: вызывается ли set_value, если процесса камеры/sender нет (`set_parameters` возвращает `(False, [])`). Тестов на это нет; разработчик решает сам.
- `pytest-timeout` в окружении не установлен (`Unknown pytest.mark.timeout`), метку убрал. Тесты синхронные, на шпионах и настоящем `RegistersManager` без потоков; daemon-поток для Qt-виджетов небезопасен, поэтому защиты от зависания нет.
- Порядок в (6) не проверяется (там только итоговое состояние; порядок закрыт журнальными тестами (1)/(5)); мутация `swap` на (6) зелёная.
- Настоящий RegistersManager в (6) принимает значения без валидации-блока (проверено вручную: 30/900/2 -> True). `set_value` не ловит NaN (вернул True): вне критериев.
- Значения, которые разработчик передаёт в `set_value`, сравниваются через `==` с литералами; тип отдельно только в (7).
- (5) зелёные тесты защиты от регресса проверены мутацией `services`; тест (4) с kw «не передан» мутацией не проверялся (эталон — просто путь без менеджера).
