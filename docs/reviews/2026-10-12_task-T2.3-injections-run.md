## Расхождения

### Ожидали красный — выжил (дыры в тестах)

- **inj-3** (TLM_SPD_PCT после DONE не возвращается к P_SPD_DEFAULT): ни один тест не читает `TLM_SPD_PCT` в IDLE после нормального DONE; `test_scenario_moves_with_do_delay_speed` проверяет возврат скорости по времени следующего PTP_MOVE, а тот берёт `P_SPD_DEFAULT` напрямую, не из регистра — тест слеп к регистру. Дыра: «TLM_SPD_PCT в IDLE = P_SPD_DEFAULT» (докстринг модуля) не покрыто на пути DONE (аналогичный возврат в `_abort` в этом прогоне не инъецировался).
- **inj-4** (сдвиг pick по ленте с обратным знаком): `test_pick_carried_out_of_ring_trips_miss` проверяет только «вышел из кольца» — при обратном знаке pick уходит на y = -922, тоже вне кольца; направление трекинга (`P_BELT_DIR`, знак `trav`) в R_CORE не проверяется ни одним тестом. Дыра: нужен тест, где ленту двигают на малое расстояние и сверяют следимую точку/позу захвата с ожидаемым знаком.

### Красный там, где не ожидали

- **inj-1** (+7 красных): `TLM_SC_DONE_N` читают ещё `test_scenario_moves_with_do_delay_speed`, `test_scenario_on_battle_defaults` и 5 параметров `test_sc_record_nak_leaves_no_trace` — свойство покрыто шире прогноза (хорошо для тестов; прогноз был занижен).
- **inj-2** (+1): `test_sc_record_nak_leaves_no_trace[kind_at_offset]` (тест автора, hazards) ловит глобальный индекс вместо индекса в срезе — слепой тестер этого не ловит; значит свойство «rval0 = индекс в срезе» держится только тестом автора.
- **inj-6** (+1): `test_watchdog_trips_inside_scenario_between_exact_points` ловит и отсутствие остановки ленты (`belt_mm_s == 0.0` в конце) — отдельного теста на «сторож останавливает ленту» вне сценария нет, держится на этом одном ассерте.
- **inj-8** (+1): `test_delay_ms_counts_sum_of_dt` (hazards) тоже чувствителен к опросу mailbox каждый тик в сценарии — лишнее покрытие.

## Что я оставил открытым / ненадёжным

- **inj-7 — формулировка свойства.** «Сторож только на EXACT-точках» буквально требует двух правок (убрать вызов из `tick` и добавить его в `_sc_record_done` при `exact`) — в схему JSON (одна пара old/new) не ложится. В JSON записан одноместный вариант «в сценарии на тиках хода не проверяется вовсе» (`if not self._in_scenario(): self._handle_wdg()`), он ×3 даёт 1 красный (тот же тест). Дополнительно, вне JSON, по одному прогону: (а) буквальный двухправочный вариант «сторож только на EXACT-приходе» — тот же единственный красный; (б) моё первое приближение «сторож только пока отрезок ведёт к EXACT-точке» — 175 passed, ВЫЖИЛ, потому что в тесте оба отрезка EXACT (`KIND["LINE"]`), т.е. тест не содержит LINE_PASS-отрезка, на котором сторож должен срабатывать. Это сигнал: тест называется «между EXACT-точками», но отрезка LINE_PASS в нём нет.
- **inj-3 — что именно сломано.** Инъекция ломает только регистр `TLM_SPD_PCT` на DONE (затрагивает и несценарные DONE). Состояние `spd_pct/accel/accur` лежит в словаре `sc` и умирает вместе со сценарием — «не восстанавливаются» в структурном смысле (протечка в `_values`) эта инъекция не моделирует; такой вариант не прогонялся. Исключение: не проверено, ловит ли `_abort`-путь снятый возврат `TLM_SPD_PCT` (строка в `_abort` оставлена нетронутой).
- **inj-5 — span.** Для одной пары old/new пришлось взять 25-строчный участок `_op_cvt_job` (перенос инкремента); `old` встречается ровно 1 раз, но JSON громоздкий.
- **inj-16 — приём.** `_fault_refused_v2` статичен и не получает аргумент; значение подмешано через `sys._getframe(1).f_locals.get("data")` — хак ради одной правки, а не код продукта. Поведенчески эквивалентно «в сообщении есть значение»; для `fault.clear` данных нет, он не в прогнозе.
- **inj-13 — время.** Один прогон R_HOST ~42 с (воркеры ждут `_V2_STOP_TIMEOUT_S`); тест красный по ассерту, не по таймауту прогона (`timed_out = false` ×3). Рестарт после несдвинутого слушателя в реальном CI может быть медленнее.
- **inj-10.** Сдвиг адреса сделан подменой импортируемой константы `VFD_REG_FLAG` внутри `sim_core_v2.py`; если другой модуль импортирует `VFD_REG_FLAG` из `sim_core_v2`, он тоже увидит +1 — по R_CORE это не повлияло на набор красных.
- **flaky.** Все красные и все выжившие стабильны ×3 (множества идентичны); нестабильных нет. Тайминг-тесты не проверялись под нагрузкой процессора.
- Общая папка scratchpad содержит чужие файлы (`inject.py`, `common.py` и пр.); мои рабочие файлы — `defs.py`, `run.py`, `result_*.json` там же, в репозиторий не попали.
