## Двусмысленности и решения

1. **A1 → «копию держит A2», но в A2 такой строки нет.** Константы превью (`PREVIEW_*`, `PREVIEW_BG_RGB`, `OUTSIDE_ROOTS_MESSAGE`) я закрепил значениями-литералами на новом модуле (A1-блок) и AST-проверкой «в старом модуле нет присваиваний кроме `__all__`» (A2-блок). `is` по малым int считается вакуумным и в доказательство не засчитан.
2. **A3, «четвёртый пресет с p=0.5».** Первые три сделаны с p=0.0 (так читается спека буквально). На `defect_half` seed 0 даёт `None`, seeds 1–4 — `damaged`; без форса и с форсом результат на seeds 1–4 совпадает (форс там ничего не меняет). Ветка форса проверяется на первых трёх пресетах.
3. **A4: ошибка.** Литерал текста: `LayeredObject 'obj-7': итоговый RGBA полностью прозрачен` (одинаков для `make("obj-7", ...)` и для `render(rng, label="obj-7")`). Контроль: все четыре пресета с каталогом такую ошибку не дают — свойство именно пресета без каталога.
4. **A5: «флаг гасится только после `render` и `from_rendered`».** Сбой внутри `from_rendered` тестом недостижим (на валидном объекте он не падает). Покрыты две точки отказа до него: падающий `get_sprite` и прозрачный итог композиции.
5. **A7: `pytest-timeout` в venv не установлен** (метка давала `PytestUnknownMarkWarning`). Метку убрал; зависание ограничено `timeout=150` у `subprocess.run`.
6. **A9, A10** — проверки лида, не писались.

## Где модель спеки расходится со старым кодом (находки)

- Расхождений поведения старого кода со спекой я не нашёл: спека A3 («`rng.spawn` не двигает родителя; `compose_layers` зовёт `spawn` ровно раз», «ошибка прозрачного объекта только без каталога», «форс не меняет расход родителя») — подтверждены снимком: `rng_parent_next` и `rng_spawn_next` совпадают при `force=False` и `force=True` для всех 20 пар (пресет, seed).
- **Слабое различение seed в A6-раскладке.** `render_layout(no_catalog, s)` не тратит rng: три seed дают один хэш (так и должно быть). Для `class_layer` и `auto_base` seeds 0 и 2 дают один хэш (оба — класс D). Поэтому правка «раскладка игнорирует seed» ловится только по seed 1 и только на пресетах с каталогом.
- В тексте A1 стоит «`line_sim.core.factory.{_DEFECT_SIDE_FRAC, _DEFECT_OFFSET_FRAC}` равны значениям `layer_render.factory`»: равенство «старый == новый» молчит, если обе копии испорчены одинаково — добавил литералы 0.35 / 0.15 / `(60.0, 60.0, 60.0)` / `"damaged"` для новой фабрики.
