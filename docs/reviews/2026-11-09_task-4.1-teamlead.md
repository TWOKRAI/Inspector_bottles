## Решения в коде
- `scan.py`: `_V2Collector` — один рекурсивный обход. Декораторы, умолчания, аннотации и основы класса обходятся во внешней области (так их вычисляет Python), тело — во внутренней. `watch`: `Observer(...)` присвоен локальному имени в той же функции или `self.<a>` в любом методе того же класса. `ThreadSite` — присваивание конструктора + `.start()` той же цели в той же области, либо цепочка `Ctor(...).start()`.
- `scan()`: тело не кэшируется и при `v2_error` ∈ {`RecursionError`, `MemoryError`}, R5.
- Формат тела кэша (решение лида после провала гейта 8,04×): таблица `strs`, плоские `calls`/`test_defs`, код вида `c|f|m`, UTF-8 с ASCII-откатом при суррогате. Тело без любого из 6 новых ключей (и без `strs`) бросает в `from_json` — промах (тест 5 tester'а зелёный).
- `links.py`: `ImportIndex` A1 для разрешения. `from pkg import mod` (имя — подмодуль) считается импортом модуля: `mod.f()` разрешается. Голое имя: сначала своё определение верхнего уровня, потом from-импорт. `self.m()` — ближайший объемлющий класс по `defs`. Неразрешённый вызов с получателем — `call_sites_unresolved[имя] += 1`. Двойник — пересечение индексов «метод -> классы», наследник отсеивается по листовому имени основы.

## Что оставил открытым / ненадёжно
- Три места контракта прочитаны буквально, решение — лиду: (а) `subclasses` из того же файла не попадают («чей файл его импортирует»); (б) `tests` берёт `test_defs` любого файла-импортёра, `scope` записи всегда `"test"`, даже у prod-файла с `def test_x`; (в) `used_by` у методов — `[]`.
- `call_sites_unresolved` по имени шумный: `os.path.join()` считается для любого символа `join` (так по решению (д)).
- `LENGTH(body)` после UTF-8 считает символы, а не байты; честный счёт размера — файл БД (3,31×).
- Порог строк плана 18 303: `.py` в `scripts/atlas` теперь 22 697.
