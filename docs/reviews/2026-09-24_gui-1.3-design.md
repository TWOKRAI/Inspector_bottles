## DESIGN

1. `BridgeGuiProcess(HeadlessGuiProcess)`; без подписчиков дескрипторы не строятся.
2. Дескриптор `{"sender","name","idx","seqlock","bseq","ts"}` (~150 Б; `name`=`shm_actual_name`, `bseq` — свой монотонный счётчик).
3. Push каждому подписчику, чей фильтр `senders` пуст или содержит `sender`: `send_async({"type":"event","targets":[addr],
   "queue_type":"observability","command":"frames.frame",...})`.
4. Состояние `dict[addr, {"senders": set|None, "sent": int}]` под lock (команды — `message_processor`, дренаж — свой поток).
5. `frames.subscribe {subscriber, senders?}` → отказ при `FW_SHM_LOAN_PROTOCOL` с `reason`, иначе `{"success":True,"seqlock","owner_incarnation"}`.
6. `frames.unsubscribe {subscriber}`; `frames.stats` — `sent` по адресам.
7. Смерть сессии / рестарт `gui` — брокер (строка в `POINT_COMMANDS`).
8. `RemoteFrameSource` (Qt-free): push `frames.frame` через `client.add_push_listener`, mailbox размером 1 на `sender` (latest-wins),
   воркер `ShmFrameReader(track=False).read_frame(..., copy)` → `on_frame(sender, ndarray, bseq)` через dispatcher.
9. Дедуп: при seqlock по `(name, generation)`, иначе по `bseq`. 10. `FileNotFoundError` → `missing` + лог. 11. `None` при seqlock → `torn`.

## REDS (слепой tester)

- R1 кадр 480×640×3 с метками углов в реальный SHM → `cb` получает побитово равный `uint8` с тем же `bseq`.
- R2 подпроцесс читает через `RemoteFrameSource` и выходит → сегмент в родителе открывается (RED на текущем коде).
- R3 дескриптор с несуществующим `name` → без исключения, `missing == 1`, следующий валидный доставлен.
- R4 один дескриптор дважды → `cb` один раз.
- R5 seqlock + писатель в потоке → 0 расхождений углов у доставленных; без seqlock — число на 1000 кадров (без assert).
- R6 `cb` спит 200 мс → частота писателя падает < 10 %, очередь ≤ 1 на `sender` (daemon + join-дедлайн).
- R7 отказ хоста с `FW_SHM_LOAN_PROTOCOL` → исключение, текст называет флаг.
- R8 реконнект + `on_reconnected()` → хост получает `frames.subscribe` с новым `subscriber_address` (`SocketChannel(port=0)`).
- K1 брокер: `note_point("gui","frames.subscribe",{"subscriber":"x.abc"})` → True; `forget_session("abc")` шлёт `frames.unsubscribe`.
- B1–B5 мост на фейковом роутере: нет подписчиков → 0 `send_async`; subscribe + data → ровно один push (ключи дословно, JSON ≤ 300 Б);
  unsubscribe → 0; msg без `shm_actual_name` → 0; фильтр `senders`.
- L1–L6 живые (лид): класс в `system_overview`; ≥ 0,8×fps; ≥ 99,9 % углов; ошибка с флагом; `sent` замирает ≤ 1 с после
  unsubscribe и kill -9; после выхода Пульта второй читатель получает кадры.
