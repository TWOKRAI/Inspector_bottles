## Решения по умолчаниям (О1–О4 и места, где бриф молчит)

О1–О4 — по умолчаниям брифа. Дополнительно (прошу лида подтвердить):

1. Цепочка «отказ, отказ, принято» с одинаковыми `ARGS[2..9]` — оба отказа повторы (п.7 говорит про пару).
2. Отказанные блоки повтора не входят в проверку уникальности `seq` (драйвер может переиспользовать seq при `requeue_job`; не проверено).
3. Слова `--words` и слова журнала сравниваются без учёта регистра; `FAIL слово` ставится и строкам пропуска той заливки.
4. `#` в таблице — порядковый номер строки диска, а не номер строки файла; служебные строки («лишнее» до первого взятия, «лишнее у сима») имеют `#` = `-` и считаются в `FAIL K`.
5. Паспорта и журнал сима недоступны/нечитаемы — код 3, регистры нечитаемы — код 3, регистры не JSON/неполны — код 2 (бриф определяет код 3 только для обмена и диска).
6. `rz` принимается и со сдвигом на 360°, если доворот у ±180° (печатная сеть с одним знаком не различает сторону).
7. Строки диска сортируются по времени (устойчиво), таблица идёт по времени; задания — по порядку строк файла.
