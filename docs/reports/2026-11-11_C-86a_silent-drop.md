## Литералы (DESIGN лида, stage 0 — 2 раунда)

- слабый диск: `WordLayoutPlugin: диск '<Б>' <угол>° → пропуск: уверенность ниже порога (<Б> <c> < <порог>)`;
  `<c>` — два знака; `<порог>` — `min_confidence` с двумя знаками, если уверенность ниже него, иначе
  `порог ml_inference`;
- нет предсказания: `WordLayoutPlugin: диск '?' 0.0° → пропуск: нет предсказания`;
- один раз на `track_id`; хелпер зовётся после `_should_take` и пишет только `_logged_skip_key`.

Обе строки разбирает `scripts/alpha_sim/logic.py:50` (`_DISK_RE`) без правки скрипта.

## Что оставил открытым / ненадёжно

- Слабый диск без строки по-прежнему возможен: тракт без `track_id` (слабый кадр — пауза), триггер-режим,
  выходы «слово готово» / «слово не задано». В живом тракте α этих случаев нет (`use_trigger false`,
  `track_id` ставит `center_crop`), но «каждый диск» владельческого брифа выполнено не без оговорок.
- В многокадровом тракте диск «слабый, затем уверенный» даёт две строки (H1). Живой zone_edge — одно
  событие на диск, на стенде не проявилось.
- Дедуп помнит только последний ключ: чередование слабых `track_id` 2, 3, 2 даёт повторную строку.
- Буква слабой строки — топ-1 сети, а не поданная (прогон 2: подана «М», в строке «И»). Скрипт α сверяет
  букву и даёт `letter И ≠ М` — красное по точности сети, не по журналу.
- Ветка «нет предсказания» живьём не наблюдалась (модель загружена во всех прогонах); проверена тестами.
- Три прогона — малая выборка: «М» узнана в прогонах 1 и 3, слабая строка живьём видна один раз (прогон 2).
- Число «строк = дисков» на стенде — по счёту скрипта α (`lines.count`) и `grep -c` по файлу журнала;
  разогревочные диски до слова («слово не задано», 2–3 на прогон) в 21 не входят.
- Предсказание I2 не совпало (2 лишних красных) — моя ошибка чтения тестов, не дефект кода.
- Хук SubagentStop у агентов требовал `uv sync` (pytest из основного `.venv`); не выполнялся по правилам
  worktree; путь импорта `multiprocess_framework` — внутри дерева полосы.
- Коммиты не слиты в `main` и не запушены.
