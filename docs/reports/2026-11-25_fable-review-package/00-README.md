   `system.health.avg_fps`.

   номеру кадра; ошибка захвата не меняет здоровье процесса. Очередь, состояния, команды и подписка на register
   продублированы (таблица в `03-diagrams.md`, раздел (c)).
4. **Нарушения направления импортов:** в рабочем коде не найдены; в тестах есть (framework — 15 строк в 10
   файлах, Services — 41 строка, Plugins — 1). Список в разделе (a).

Это факты из чтения кода, а не вердикт разбора.
