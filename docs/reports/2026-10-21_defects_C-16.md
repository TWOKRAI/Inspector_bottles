# C-16 — collector процесса `draw` пропал из сборки `hikvision_letter_robot` (этап 1, расследование)

Дата: 2026-10-21. Полоса Д, сессия inspector-bottles-66. Исполнитель расследования — investigator (Opus); правок в коде и снимках нет.

## Вывод

**Регресс, снимок не устарел.** Join кадра и оверлея у процесса `draw` пропал из сборки. В снимке он записан правильно. Рецепт требует join (`metadata.inspector: {mode: join, inputs: [frame, overlay], primary: frame, timeout_sec: 0.25}`), а сборка на main отдаёт `draw.collector = {}`. В рантайме из этого получается fanin вместо `JoinInspectorManager`.

Решение владельца: **правка кода/рецепта, снимок не обновлять.**

## Коммит-виновник

`7e1640c97` (2026-10-15), «feat(code-reader): кадр с рамкой и надписями из рецепта через общий overlay_draw».
Строка `Plugins/render/overlay_draw/plugin.py:39`: входной порт `overlay` получил `optional=True`. До этого порт был обязательным с `dd70e2d91` (2026-06-08). Лид проверил это через `git log -L39,39`.

Кандидаты из реестра не подтвердились. `2942c949c` (D4) только переименовал `inspector` → `collector` в снимке. `589ba9308` не понадобился. Bisect не запускался: виновник и родитель наблюдались напрямую.

**Второй красный тест на main, которого нет в реестре:** `multiprocess_prototype/backend/topology/tests/test_join_collector_from_wires.py` — 2 failed / 3 passed (`test_draw_collector_equals_former_hoist_result`, `test_join_not_degraded_to_fanin`). Причина та же.

## Цепочка в коде

1. `multiprocess_prototype/recipes/hikvision_letter_robot.yaml:328–360`: у `draw` join задан только в `metadata.inspector`.
2. Провода `vision.circle_detector.* → draw.circle_draw.*` (стр. 412–417) и `line.line_filter.overlay → draw.overlay_draw.overlay` (стр. 424–426).
3. `multiprocess_prototype/backend/assembly/assembler.py:133` вызывает `infer_missing_collectors()`.
4. `multiprocess_framework/modules/process_manager_module/topology/blueprint.py:511`: провод в optional-порт пропускается, и у `draw` остаётся один обязательный источник.
5. `blueprint.py:534–535`: при `< 2` источников join не выводится, а `metadata.inspector` подмешивается только внутри ветки join (549–556). Это задокументированная граница ADR-PMM-017 п.5 (`process_manager_module/DECISIONS.md:425`).
6. Рантайм: `collector_registry.py:39` → пусто → `Plugins/_shared/fanin/factory.py:48–71` строит fanin.

Framework не менялся. Сломала правка плагина, а framework применил свои правила.

## Намеренность

Не найдено. Где искали:
- сообщение `7e1640c97`;
- `plans/code-reader-gui.md:46–48`: «прежнее поведение у всех рецептов», «существующие провода остаются валидными»;
- `plans/code-reader-gui/phase-1.md:46–56`: DESIGN меняет только `dtype` входа `frame`, а `optional=True` там стоит на выходе `sdk_plugin`;
- все `DECISIONS.md`;
- README и STATUS `overlay_draw`: до сих пор пишут, что frame+overlay сливает Join.

Optional на входе — неописанное отступление от плана.

## Варианты правки (этап 2, решает владелец)

- **А (рекомендация расследования).** В рецептах вынести join у `draw` из `metadata.inspector` в прямой ключ `collector` (escape-hatch ADR-PMM-017, `blueprint.py:525–531`). Затронуты `hikvision_letter_robot`, и, вероятно, `letter_angle_inspect`, `letter_robot_sim`, `dataset_circle_capture` — не проверено. Правка только в прототипе.
- **Б.** Вернуть порту `overlay_draw.overlay` обязательность. Это правка Plugins, плюс рецептам `qr_reader_sdk_demo*` нужен провод `overlay`, и есть риск для `check()` рецептов qr.

`blueprint.py` и framework не трогаются ни в одном варианте.
