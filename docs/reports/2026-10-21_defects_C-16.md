# C-16 — collector процесса `draw` пропал из сборки `hikvision_letter_robot` (этап 1, расследование)

Дата: 2026-10-21. Полоса Д, сессия inspector-bottles-66. Исполнитель расследования — investigator (Opus); правок в коде и снимках нет.

## Вывод

**Регресс, снимок не устарел.** Join кадра и оверлея у процесса `draw` пропал из сборки. В снимке он записан правильно. Рецепт требует join (`metadata.inspector: {mode: join, inputs: [frame, overlay], primary: frame, timeout_sec: 0.25}`), а сборка на main отдаёт `draw.collector = {}`. В рантайме из этого получается fanin вместо `JoinInspectorManager`.

Решение владельца: **правка кода/рецепта, снимок не обновлять.**

## Коммит-виновник

## Цепочка в коде

1. `multiprocess_prototype/recipes/hikvision_letter_robot.yaml:328–360`: у `draw` join задан только в `metadata.inspector`.
2. Провода `vision.circle_detector.* → draw.circle_draw.*` (стр. 412–417) и `line.line_filter.overlay → draw.overlay_draw.overlay` (стр. 424–426).
3. `multiprocess_prototype/backend/assembly/assembler.py:133` вызывает `infer_missing_collectors()`.
4. `multiprocess_framework/modules/process_manager_module/topology/blueprint.py:511`: провод в optional-порт пропускается, и у `draw` остаётся один обязательный источник.
5. `blueprint.py:534–535`: при `< 2` источников join не выводится, а `metadata.inspector` подмешивается только внутри ветки join (549–556). Это задокументированная граница ADR-PMM-017 п.5 (`process_manager_module/DECISIONS.md:425`).
6. Рантайм: `collector_registry.py:39` → пусто → `Plugins/_shared/fanin/factory.py:48–71` строит fanin.

Framework не менялся. Сломала правка плагина, а framework применил свои правила.

## Намеренность

Не найдено. Где искали:

Затронуты `hikvision_letter_robot`, и, вероятно, `letter_angle_inspect`, `letter_robot_sim`, `dataset_circle_capture` — не проверено. Правка только в прототипе.

# Этап 2 — правка (C-16 + C-17), ветка `fix/c16-collector`

Требование владельца 2026-10-21: «как правильно, без костылей… универсально в рецептах и плагинах на будущее». Его решения: поле `Port.join: bool | None`, умолчание `None` = `not optional`, `metadata.inspector` deprecated, C-17 — громкая ошибка `check()`. План: `plans/topology-port-join.md`.

## Что сделано

- `Port.join` + `effective_join`. Вывод join считает подключённые входы по `effective_join` через общий `_joining_sources()`, его вызывают `infer` и `check`.
- `overlay_draw.overlay`: `optional=True, join=True`. Join у `draw` выводится из портов во всех рецептах, ручной `mode` в рецептах не нужен.
- `metadata.inspector` / `metadata.collector` — предупреждение в лог. C-17: ошибка `check()`, если в любой секции `metadata` стоит `mode: join`, а join не выведен. Результат не зависит от того, вызывался ли `infer`.
- 5 рецептов (9 блоков) переведены на `collector: {timeout_sec: 0.25}` без `mode`. `catalog.plugins` отдаёт `join`. ADR-PMM-017 дополнен п.7.
- Framework-файлы правились в границе, согласованной с полосой Ф через координатора.
