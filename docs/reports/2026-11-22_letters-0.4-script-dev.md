## Решения
- **sim**: `LayerSceneGenerator` (тот же код, что кормит обучение) на пресете `letters_layered.yaml`: слои диск+буква, фон-лента, смещение центра `lateral_offset_px [10,20]` со случайным знаком, вырез radius/14/128, дефекты 0. Заданный угол сетки — через `angle_range_deg=(a,a)`. Истина — `label.angle_deg` генератора; тест сверяет её с заданным углом.
- **`--crop pipeline`, а не `hough`**: у `circle_detector`/`hsv_mask`/`morphology` чистых функций нет (всё в методах плагина с регистром), НО плагины создаются без процесса (`configure(ctx)` + `process([item])`, как в их тестах). Поэтому гоняются НАСТОЯЩИЕ плагины рецепта `roi_crop→hsv_mask→morphology→circle_detector→center_crop`; параметры читаются из YAML рецепта (`multiprocess_prototype.*` не импортируется). Приближения `hough` в скрипте нет.
- Метрики сверх брифа: «Верно» плана = верно И выше порога (55.9 % ≈ 58.6 % ответивших × 95.4 %), поэтому печатаются обе величины: top-1 при любой уверенности и «верно и выше порога» от всех. Ошибка угла — 5 блоков: по модулю симметрии, то же только ≥ порога, без симметрии, инвертированная истина (с симметрией и без), плюс медиана по углам сетки.

## Что оставил открытым / ненадёжно
- sim: вырез по радиусу объекта из альфы спрайта, не по кругу Хафа (шаг `circle_detector` в sim не выполняется); фотометрия считается на окне W×W (известное расхождение `layer_scene`). Совпадение входа сети с живым стендом цифрами не сверено.
- `dir --crop pipeline` проверен ТОЛЬКО на синтетическом белом диске; на реальных кадрах дня №1 не гонялся (их нет в дереве). `color_convert` (RGB→BGR камеры) и `line_filter` не воспроизводятся; при нескольких кругах берётся первый по Хафу. `roi_crop` рецепта требует полный кадр 1440×1080; если кадры дня №1 уже вырезы — `--crop none`.
- Плагины конфигурируются через `MagicMock` вместо `PluginContext` (как в их тестах) — хрупко к смене контекста.
- Пороги PASS/FAIL не заданы (вопрос владельца β7 открыт). Угол «О» (симметрия full) не оценивается. `--data-root` требует рядом дерево репозитория (`Services/line_sim/presets`).
- Не проверено на Windows (кириллица в пути `dir` покрыта только тестом на macOS).
- Одна попытка 128-кадрового замера для оценки времени была отклонена классификатором прав — не повторял (правило «не запускать полный замер»).
