# Предсказания лида до прогонов α на других сидах сима (проверка перед записью 23)

Полоса «Приёмка α». Дерево стенда — `.claude/worktrees/alpha-hard-split` (код равен `main`). Три прогона на сидах `scene_source.seed` = 1, 2, 3
(сид 0 — прогоны 2026-11-12 `data/alpha_rerun/run1…run3`). Цель — проверить запас окон съёма §2.8 до возврата (запись 23, `alpha-record-23-draft.md`).
Предсказания записаны и закоммичены ДО старта первого прогона.

## Что сид меняет, а что нет (гипотеза, проверяется)

Случаи B, D, C подают диски списком (буква, угол заданы скриптом), поэтому сид `np.random.default_rng` сцены влияет на знак и величину
`lateral_px` (поперечное смещение → `px`, `ARGS[2]`) и на дефект/прочие розыгрыши, но НЕ на момент съёма (`py`, `ARGS[3]`): он идёт от часов сима и шага 6,6 px/кадр.
Следовательно, проверка на других сидах хорошо проверяет `px`/`ARGS[2]` и слабо — `py` (его разброс даёт тайминг, а не сид). Слабость проверки называем вслух.

## Предсказания (литералы)

| № | Предсказание |
|---|---|
| Q1 | `МЕХАНИЗМ: PASS` в 3 из 3 прогонов; строк диска 21 в каждом; `CVT_JOB` 15 в каждом; rc скрипта 0 или 1 (1 — только по ТОЧНОСТИ), rc 3 — 0 из 3. |
| Q2 | `px` и `ARGS[2]`: 45 из 45 в старых окнах (`454,9…461,5`; `4549…4615`) — предел `lateral_offset_px: [10, 20]` не зависит от сида. |
| Q3 | `py` и `ARGS[3]`: вне старого окна (`−344,0…−342,0`; `62096…62116`) 0 из 45 в двух прогонах из трёх; допустимо 1–2 диска вне в одном прогоне (запас 0,3 мм). Макс. `py` ≥ −342,6 и ≤ −342,0 в каждом прогоне. |
| Q4 | Знаковая картина `px` (диск выше/ниже 458,2) у каждого из сидов 1, 2, 3 отличается от картины сида 0 в `run1…run3` — подтверждает, что сид применился. Если совпала у какого-то сида — сид не применился, прогон недействителен. |
| Q5 | «Трудных» (порог 5,0°) 5–9 за прогон; причина везде `angle` (класс/порог — 0); потери диска 0. |
| Q6 | Макс. \|Δугла\| ≤ 15° в 2 из 3 прогонов (в сиде 0 было 18,5 / 13,4 / 12,4°). |
| Q7 | ДОМОЙ, СТОП — PASS 3 из 3; `outcome` 10 из 10 `exited`; порты свободны после остановки. |

## Правило решения (до просмотра результата)

- Вне окон съёма 0 из 45 по сидам 1–3 (вместе с сидом 0 — 0 из 90) — докладываем владельцу «запись 23 подтверждена».
- 1–2 диска вне окна по `py` — НЕ применять запись 23 молча: докладываем таблицу и варианты (вернуть как есть; вернуть `py` с запасом, напр. −344,0…−341,5; оставить расширение для `py`).
- ≥ 3 диска вне окна или любой вне по `px`/`ARGS[2]` — запись 23 отклонена, отчёт владельцу.
- Q4 не выполнено (сид не применился) — прогон недействителен, повторить.
