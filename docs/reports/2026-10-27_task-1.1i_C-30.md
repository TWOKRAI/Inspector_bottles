# Отчёт · C-30 · Task 1.1i — склейка комментариев у `- {}`, `YamlWriteRefused`

Полоса Д, сессия inspector-bottles-b1, 2026-10-27. План: `plans/2026-10-26_recipe-save-noise/plan.md`.
Ветка `fix/recipe-save-noise`.

## Итог

Задача закрыта. Движок записи рецепта больше не склеивает строки блочного списка рядом с `- {}` и комментариями.
Отказ страховки записи теперь имеет свой тип `YamlWriteRefused(ValueError)`. Переход к `xfail` не понадобился.

| Коммит | Что |
|---|---|
| `59ca2fa11` | тип `YamlWriteRefused`, REDS, перенос токена элемента, правка эмиттера ruamel (teamlead) |
| `d553422fe` | поправка №5: решение лида по эскалации (два класса причин) |
| `8b4e972b6` | фикс ревью р1: flow-элемент не трогается, сброс эмиттера зеркальный (teamlead) |
| `0bf9386fe` | поправка №6, ревью р1 |

## Решение по эскалации

Единой расстановки токена для B1–B9 нет.
- B1–B3, B7–B9: комментарий-хвост элемента переносится «перед элементом» (`_lift_item_tail`).
- B4–B6: дефект эмиттера ruamel 0.19.1, воспроизводится без нашего движка. Пустой `{}` не сбрасывает флаг
  `no_newline`, а `[]` сбрасывает. Исправлено подклассом `RoundTripEmitter` в `_ruamel_doc.py` под пином `<0.20`
  (решение владельца (в)).
