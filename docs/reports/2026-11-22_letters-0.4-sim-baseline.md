## Что это значит

- **Угол: инверсии знака нет** — подтверждено вторым способом (на 1056 кадрах, не на 15 дисках).
- **Для слова «ПЕРЕМИРИЕ» слабое место одно — буква «М»**: 12 из 32 → «И». Остальные четыре буквы слова читаются на 100 %. Это совпадает с живым стендом, где «М» не бралась 3 из 3.
- **Ниже 100 % полноты у 10 из 33 букв**, из них у Ё, Л, Ц, Д — почти ноль. Л → П во всех 32 кадрах и Ц → Т в 28 из 32 — не «слабая сеть», а похоже на систематику (форма буквы шрифта сима или метка/каталог); **причину не выяснял**. Для слова 1.0 эти буквы не нужны, для 2.0 и других слов — нужны.
- **Нельзя переносить на реальные кадры.** Сеть учили на реальных вырезах одного шрифта; сим — шрифты DejaVu (hold-out). Число для β7 даст только `scripts/letters_baseline.py dir` на кадрах дня №1.

## Что оставил открытым / ненадёжно

- Вырез диска в `sim` берётся по радиусу объекта из альфы спрайта, а не кругом Хафа `circle_detector` и не через `line_filter`: вход сети с живым конвейером **цифрами не сверен**. Живой стенд (P4, 15 дисков, \|Δ\| > 5° у 7 из 15; α-повтор: «М» не взята 3 из 3) показывает худший угол, чем здесь (24 %); причина не установлена. Ставить расхождение 24 % против 47 % на счёт конвейера нельзя: выборки 160 и 15.
- Один сид (0), без доверительного интервала: на 160 кадрах разброс доли «верно» ≈ ± 2,5 п.п. по бернуллиевской оценке (моя арифметика, не замер).
- Порогов PASS/FAIL нет (пороги владельца для β7 не заданы).
- Угол у «О» (симметрия full, 32 кадра) не оценивается; GUI-прогон (как в исходной таблице 10-01) не делался.
- Windows не проверялся; `dir --crop pipeline` гонялся только на синтетике (реальных кадров нет).
