## Что остаётся открытым / ненадёжно

1. **Стенд без окна гейта.** `machine_gate.sh request` на этой машине отвечает `rc 2 no machine.lock` (нет ни `machine.lock`, ни `stand.lock`); стенд-агент запустил стенд, хотя бриф велел не запускать при отказе гейта, — это моё нарушение процесса (бриф не различал «занято» и «нет замка») и причина столкновения с полосой Д на фиксированных портах 8766/8091/8092/5021. Чистый прогон проверен только по двум параметрам (`defect`, лента); вмешательства, не меняющие их (`scene.pause` туда-обратно), исключить нельзя, косвенно их нет (ритм ~8 с, 12 из 12 заданий).
2. **Стенд снят на `c8adcc000`, до правок раунда 1** (`a368b43f4`). Правки не меняют решения «брать» (дифф-фаззинг, 0 расхождений); число строк на моргающей уверенности меняется только в сторону «одна на диск». Повторного прогона не делал.
3. **Конвенция угла сим ↔ сеть не измерена**: журнала угла подачи в line-sim нет. Знак +RZ на железе — только β4. Сим ориентацию положенного диска не моделирует.
4. `ARGS[9]` уходит за −180° (−251,5, −212,9, −186,5): сим принимает (`E_RANGE 0`), на железе пределы RZ — заглушки GATE-1. Это граница Р2 (T4.1), не P3.
5. Доказательство `jobs=0` на старом стенде T5.6 — только подтверждение механизма на новом прогоне (пустое слово → 0 заданий); распознавания на входе `layout` тогда не логировались.
6. **Остаточные minor ревью:** ERROR-строка на кадр при постоянно битом входе (не раз на диск); сторож `_note_skip_guarded` только на выходах «не задано/готово»; в триггер-режиме сигнал, удерживаемый N кадров, даёт N строк (если `trigger` — уровень, а не импульс).
7. Побочно: `[run] не удалось записать рецепт в файл состояния … app.state.yaml` при `INSPECTOR_MANIFEST` на копию вне `recipes/` — родственно C-44(2); на запуск не повлияло.
8. Правило `.rules/plugins.md` («Plugins не импортирует Services») расходится с `.sentrux/rules.toml` и практикой — вынести отдельно.
9. На macOS каталог целиком не вердикт; гонял по файлу/по списку. Известные красные вне задачи: `test_cv_threads` ×6, `test_t45b` ×2.
