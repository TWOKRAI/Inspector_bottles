## 2. Что осталось открытым / ненадёжно

1. **M1 (2.7d)** закоммичен `7c3cbede4`. Решение на чтении teamlead: неизвестные имена команд в `run_locked_commands` тоже считаются «негодным» ключом (сузить — убрать строку `run_locked_invalid = True` в ветке `if unknown`); без `command_manager` ключ не разбирается; сброс атрибута при повторном разборе тестом не покрыт; текст ERROR «— запрета нет» не упоминает, что узел теперь не готов. Инъекции K1/K2/K4 совпали с предсказаниями.
   **`process_manager_module/tests` целиком красен и на базе:** 141 failed + 5 errors на `c6bae7d09` и столько же на `7c3cbede4` (наборы имён идентичны, M1 добавил 4 зелёных теста; 2353 → 2357 passed). Причина (по виду: тесты с реальным spawn на macOS) не разбиралась; параллельный запуск двух прогонов даёт 546–582 красных из-за перегрузки — гонять только по одному.
2. **Свежее слепое ревью Opus перед main** ни по одной ветке не проводилось; повторный сквозной обзор Opus (с 2.7d, S4b, П3) не проводился.
