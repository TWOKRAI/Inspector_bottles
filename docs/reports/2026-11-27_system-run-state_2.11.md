# 2.11: кадр, прошедший мимо обработки, помечен и не показывается как результат

- **Суть:** плагин на паузе, пропуская кадр без обработки, ставит в него метку `paused_by` (framework, ADR-PM-066). Экраны результата помеченный кадр не показывают.
- **Итог:** код, ревью и стенд готовы (`feat/run-state-2-10`, `d9d0277d0`), в `main` не слито.
- **Проверка:** тесты 82 из 82; все 14 поломок покраснели; ревью APPROVED со второго раунда; стенд: сырой кадр 0 из 10 на ЗАПУСТИТЬ и ОСТАНОВИТЬ, 0 из 3 при аварии; принудительная задержка снятия паузы: без проверки метки сырой кадр в 10 из 10 запусков, с ней в 0 из 10.
- **Проблемы:** ревью нашло гонку (состояние плагина читалось дважды), исправлено `c0ff75ea7`. Без задержки дефект запуска за 64 попытки не воспроизвёлся, поэтому его закрытие доказано принудительным опытом.
- **Агенты:** spec `a38a8021a04e95a64`, стадия 0 `aa4ff792c314071f6`, tester `ae78cae759858d632`, developer `a17f61bac9c4f84d8`, reviewer `a134be7af725bb8e8`, стенд `aaf0ed6f4ac9cf99a`.
- **Открыто:** только симулятор, свободной памяти на замерах было меньше 1,5 ГБ; пропуск плагина по circuit breaker или `enabled=False` метку не ставит.
- **Дальше:** слияние по слову владельца вместе с 2.2e и 2.10.
