# C-25 + C-28 — точка в имени процесса; deprecated `metadata`, которую сборка не применяет

**Полоса:** Д (inspector-bottles-53) · **Дата:** 2026-10-25 · **Ветка:** `fix/c25-c28-blueprint`
**Реестр:** `plans/queue/defects.md`, строки C-25 и C-28. **План:** `plans/topology-port-join.md`, «Фаза C-25 + C-28», Task C25.1, C28.1, C28.2, C28.3.
**ADR:** `process_manager_module/DECISIONS.md`, ADR-PMM-017 п.9 (C-25) и п.10 (C-28).

## Итог

- **C-25.** `SystemBlueprint.check_structure()` и `check()` отвергают `process_name` с точкой.
  - Почему точка опасна: роутер читает адрес `a.b` как процесс `a`, то есть первый сегмент адреса.
  - Текст ошибки называет процесс, причину и пример имени для переименования, со ссылкой на ADR-PMM-017 п.9.
- **C-28.** `check()` выдаёт ошибку, если есть непустая `metadata.collector` или `metadata.inspector`, которую `infer_missing_collectors` не применит.
  - Секция применяется, только если у процесса ≥ 2 join-источников и `mode` явной секции пуст или равен `join`.
  - Вариант (б): ошибка и для секции из одного `{mode: fanin}`.
  - Процесс, по которому уже есть ошибка C-17, второй ошибки не получает.
  - C28.2: непустая `metadata.inspector` рядом с применённой `metadata.collector` (затенённая) — тоже ошибка.
  - C28.3: затенённой считается только та часть секции, которую `infer` подмешал бы. Ключи `mode`, `inputs`, `primary` не в счёт. Их список — одна константа `_STRUCTURAL_COLLECTOR_KEYS` для `infer` и для проверки.
  - Процесс с точкой в имени судит только C-25: правила C-17, C-22 и C-28 его пропускают.
- **Рецепты не менялись.** В репозитории 0 процессов с точкой в имени и 0 процессов с непустой `metadata.collector` или `metadata.inspector` (проверены 80 YAML-файлов).

## Причина

- **C-25.** `_joining_sources` и ещё 4 места в `blueprint.py` берут имя процесса до первой точки. У процесса `draw.a` провод `draw.a.frame` засчитывался процессу `draw`. По контракту адресации (`message_module/addressing/address.py`, `process_of = address[0]`) точка — разделитель, поэтому имя с точкой недоставляемо. Выбран запрет точки (вариант Б), а не поддержка точки в разборе адреса.
- **C-28.** ADR-PMM-017 п.7(в) оставил deprecated `metadata.<ключ>` читаемой. `infer` подмешивает её не во всех случаях, а только при ≥ 2 источниках без явного `mode`. В остальных случаях настройка пропадала молча.
