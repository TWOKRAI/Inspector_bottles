# C6.1 — приёмка камер одной командой

- **Суть:** `python -m backend_ctl.probes.camera_stand_probe` печатает таблицу по камерам и даёт выход 1 при сбое.
- **Итог:** готово (`f08c18b01`). Стенд `camera_device_demo` (фейк), 60 с: выход 0, `samples` 13, `dropped` 0, `frames` 3122, `fps` 48.
- **Проверка (живой бэкенд, всё как предсказано):** несуществующий плагин, несуществующий процесс, остановленный прогон
  (`frames_stalled`), выключенный бэкенд — все выход 1. 49 passed; ревью APPROVED, два раунда.
- **Проблемы:** по первой редакции брифа камера без кадров давала бы выход 0. На стенде подтверждено: после `run_stop`
  остаются `state=grabbing`, `link=up`, и сбой ловит только `frames_stalled`.
- **Агенты:** developer `ad1c30123e875c8bc`, reviewer `ae3c20f49b46c5961`, сверка брифа `a4c81bfc440fae244` (sonnet).
- **Открыто:** плагин, ни разу не опубликовавший блок, автовыбор не видит; всплеск ошибок с восстановлением в середине прогона даёт 0;
  в источнике без импульсов триггера выход будет 1; на настоящей камере не запускался (C6.3).
