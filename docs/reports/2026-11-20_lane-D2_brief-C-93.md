# Бриф C-93: закрытый процесс не должен жить в куче теста — три корня удержания SemLock

Автор: teamlead полосы Д2, 2026-11-20. База: `main` `ad3dc7b72`. Машина: Darwin, Python 3.12, `kern.posix.sem.max` = 10000. Режим: только диагностика и прототип в одноразовом worktree `/private/tmp/claude-501/d2-c93-wt`; код в ветку не писался, worktree удалён.

**Брифу нужен слот писателя; сам по себе код не меняет.**

## Цель

После `shutdown()` процесса (PM или любого `ProcessModule`) и `del` его объекты собираются сборщиком. В процессе, который создаёт и снимает много PM (pytest, встройщик), число живых SemLock не растёт от PM к PM. Проверка: в каталоге `process_manager_module/tests` нет `OSError [Errno 28]` из `SemLock.__init__`.

## Главная находка: посылка строки C-93 верна лишь частично

Строка C-93 в `plans/queue/defects.md` называет один корень: `std_facade._CACHE` → `StdLoggerFacade._writer` → `LoggerManager` → PM. Мой замер на fifo-стенде это **опровергает для 9 из 10 менеджеров**. Число 1384 в конце файла совпало с диагнозом. Но только последний LoggerManager связан с фасадами из `_CACHE`: это 2 фасада. Ручная отцепка всех `_writer` в `_CACHE` не освобождает ничего (1384 → 1384, живых LM 10 из 10). Корней три:

| # | Корень | Что держит | Где лечится | Слой |
|---|---|---|---|---|
| R1 | `threading.Thread.__init__` (CPython, `_make_invoke_excepthook`) копирует `sys.excepthook` и `threading.excepthook` в замыкание каждого нового потока. Слот занят **связанным методом** `ProcessHooks._on_sys_exception`, а он держит `ProcessHooks._services`, то есть процесс. Потоки-фидеры `mp.Queue` процесса живут, пока жива очередь. Очередь держит тот же процесс. Получается цикл, который никогда не умирает: его корень — `threading._active` | **каждый** PM навсегда, даже без заморозки `gc` | `logger_module/core/process_hooks.py` | framework |
| R2 | `StdLoggerFacade._writer` обновляется лениво, на следующей записи. Вид, который после `shutdown()` молчит, держит закрытый менеджер | максимум один менеджер на фасад (последний, к которому фасад привязался) | `logger_module/adapters/std_facade.py`, `core/logger_manager.py` | framework |
| R3 | Граница теста `_gui_memory_boundary` (оба conftest) делает `collect` и `gc.freeze()` в teardown. В этот момент pytest ещё держит значения фикстур в `item.funcargs`: pytest обнуляет их **после** teardown (`_pytest/runner.py: runtestprotocol`). Всё, что создал тест, замерзает живым и остаётся в куче до конца сессии | **всё** содержимое каждого теста до конца сессии | `conftest.py` и `multiprocess_framework/modules/conftest.py` | тестовая обвязка (общая инфраструктура) |

Все три корня нужны. Если убрать любой один, рост остаётся (таблица «матрица корней» ниже). Корни R2 и R3 для прогона каталога **сильнее** R1: заморозка превращает временное удержание на границе в постоянное.

### R1 (хуки): варианты

- **(h1) `weakref.WeakMethod` в слоте — рекомендую.** Обёртка без ссылки на объект, фолбэк — штатный обработчик интерпретатора (`sys.__excepthook__`, `threading.__excepthook__`, `warnings._showwarning_orig`). Хуки работают, пока жив `ProcessHooks`: его держат `_installed` и `process._process_hooks`. Сравнения `slot is self._hook_*` в `uninstall` и `_slots_are_ours` не ломаются: обёртка хранится в объекте. Цена — один вызов на **исключение**, не на запись.
- (h2) Трамплин уровня модуля, который смотрит на `_installed`. Работает, но после `uninstall` трамплин потока, созданного ранее, зовёт «предыдущий» хук, а его надо хранить глобально. Слоёв больше, выгоды нет.
- (h3) Закрывать фидеры (`Queue.close()` / `join_thread()`) при teardown процесса. Лечит один вид потока, а не класс: любой поток, рождённый при стоящих хуках, держит процесс так же. И это код SRM и PM, то есть чужие полосы.

### R3 (граница теста): варианты — **решение за владельцем или лидом**

- **(t1) Перенести `collect_now(refreeze=True)` из teardown фикстуры в хук `pytest_runtest_logfinish`.** pytest зовёт его после `item.funcargs = None`. В фикстуре остаются `enforce()` и проверка `enabled_violations` с `pytest.fail` (провал нужен в отчёте теста). Эксперимент «R3 снят» — ближайший замер этого варианта (0/0/0). Сам вариант (t1) я **не прогонял**.
- (t2) `refreeze=False` на границе: обходит заморозку целиком, но теряет ускорение полной сборки, ради которого её ввели (`qt_gc_policy.py:165`).
- (t3) Чистить `request.node.funcargs` в teardown фикстуры: хак по внутренностям pytest.

**Рекомендация:** P1 (h1) + P2 (б) в одном коммите framework (ADR-LOG-013). R3 (t1) — отдельный коммит тестовой обвязки, после решения владельца. Порядок слияния любой, но приёмка каталога (ниже) имеет смысл только со всеми тремя.

Зонд — диагностика, а не тест: в ветку не класть. `c93probe/c93_probe.py`:

```python
# -*- coding: utf-8 -*-
"""pytest-плагин C-93: живые SemLock и удержанные LoggerManager после каждого теста и в конце сессии.

Подключение: PYTHONPATH=<worktree>:<этот каталог> pytest -p c93_probe ...
C93_UNBIND=1 — в конце сессии вручную отцепить _writer у всех фасадов _CACHE и пересчитать.
"""

from __future__ import annotations

import gc
import os
import weakref
from multiprocessing import synchronize

_LM_REFS: list[weakref.ref] = []
_CREATED = [0]
_SEMS: "weakref.WeakSet" = weakref.WeakSet()


def _semlocks() -> int:
    gc.collect()
    return sum(1 for o in gc.get_objects() if isinstance(o, synchronize.SemLock))


def _install() -> None:
    from multiprocess_framework.modules.logger_module.core.logger_manager import LoggerManager

    original = LoggerManager.__init__

    def tracked(self, *args, **kwargs):
        original(self, *args, **kwargs)
        _LM_REFS.append(weakref.ref(self))

    LoggerManager.__init__ = tracked

    sem_init = synchronize.SemLock.__init__

    def counted(self, *args, **kwargs):
        _CREATED[0] += 1
        sem_init(self, *args, **kwargs)
        _SEMS.add(self)

    synchronize.SemLock.__init__ = counted


_install()


def _alive_lms() -> list:
    return [lm for lm in (r() for r in _LM_REFS) if lm is not None]


def _line(tag: str) -> str:
    alive = _alive_lms()
    procs = sorted({type(getattr(lm, "process", None)).__name__ for lm in alive})
    n_alive = len(alive)
    del alive
    return (
        f"[c93] {tag}: semlocks_alive={_semlocks()} semlocks_weakset={len(_SEMS)} semlocks_created={_CREATED[0]} "
        f"lm_created={len(_LM_REFS)} lm_alive={n_alive} lm_process_types={procs}"
    )


def pytest_runtest_logfinish(nodeid, location):  # noqa: ARG001
    print("\n" + _line(f"after {nodeid.rsplit('::', 1)[-1]}"), flush=True)


def pytest_sessionfinish(session, exitstatus):  # noqa: ARG001
    from multiprocess_framework.modules.logger_module.adapters import std_facade

    print("\n" + _line("session end"), flush=True)
    alive = _alive_lms()
    lm = None
    for i, lm in enumerate(alive):
        keys = [k[0] for k, f in std_facade._CACHE.items() if f._writer is lm]
        print(f"[c93]   alive LM #{i} ({lm.manager_name}) bound facades in _CACHE: {len(keys)} {keys[:4]}", flush=True)
    del alive, lm
    if os.environ.get("C93_UNBIND") == "1":
        for f in std_facade._CACHE.values():
            f._writer = None
            f._epoch = -1
        print(_line("after manual unbind of _CACHE"), flush=True)


def _describe(o) -> str:
    import types

    if isinstance(o, dict):
        if "__name__" in o and "__loader__" in o:
            return f"MODULE-GLOBALS({o.get('__name__')})"
        return "dict{" + ",".join(map(str, list(o.keys())[:5])) + "}"
    if isinstance(o, types.FrameType):
        return f"frame({o.f_code.co_filename.rsplit('/', 1)[-1]}:{o.f_code.co_name})"
    if isinstance(o, (list, tuple, set)):
        return f"{type(o).__name__}[{len(o)}]"
    if isinstance(o, types.CellType):
        return "cell"
    if isinstance(o, types.FunctionType):
        return f"function({o.__qualname__})"
    if isinstance(o, types.MethodType):
        return f"method({o.__func__.__qualname__})"
    return type(o).__module__ + "." + type(o).__qualname__


def find_root_path(target, max_depth: int = 40):
    """BFS по обратному индексу ссылок (один проход get_referents) к корню: глобалы модуля / класс / кадр."""
    import sys
    import types

    me = sys._getframe()
    objs = gc.get_objects()
    rev: dict[int, list] = {}
    for o in objs:
        if o is me or o is objs:
            continue
        for ref in gc.get_referents(o):
            rev.setdefault(id(ref), []).append(o)
    seen = {id(target), id(objs), id(rev)}
    frontier = [(target, [_describe(target)])]
    roots = []
    for _depth in range(max_depth):
        nxt = []
        for obj, path in frontier:
            for r in rev.get(id(obj), ()):
                if id(r) in seen:
                    continue
                if isinstance(r, types.FrameType) and r.f_code.co_filename.endswith("c93_probe.py"):
                    continue
                seen.add(id(r))
                p = path + [_describe(r)]
                if (isinstance(r, dict) and "__name__" in r and "__loader__" in r) or isinstance(r, (type, types.FrameType)):
                    roots.append(p)
                    continue
                nxt.append((r, p))
        if len(roots) >= 3 or not nxt:
            break
        frontier = nxt
    del objs, rev
    return roots


def pytest_unconfigure(config):  # noqa: ARG001
    if os.environ.get("C93_CHAIN") != "1":
        return
    alive = _alive_lms()
    if not alive:
        print("[c93] chain: no alive LM", flush=True)
        return
    import threading

    print(f"[c93] threads alive: {len(threading.enumerate())} {sorted({t.name.split('-')[0] for t in threading.enumerate()})[:20]}", flush=True)
    target = alive[0]
    del alive
    for p in find_root_path(target):
        print("[c93] chain LM#0: " + "  <-  ".join(p), flush=True)


_orig_logfinish = pytest_runtest_logfinish


def pytest_runtest_logfinish(nodeid, location):  # noqa: F811
    _orig_logfinish(nodeid, location)
    if os.environ.get("C93_UNFREEZE_PROBE") != "1":
        return
    frozen = gc.get_freeze_count()
    gc.unfreeze()
    gc.collect()
    alive = _alive_lms()
    print(f"[c93]   unfreeze-probe: frozen_before={frozen} after unfreeze+collect lm_alive={len(alive)} semlocks_weakset={len(_SEMS)}", flush=True)
    if alive:
        target = alive[-1]
        del alive
        for p in find_root_path(target)[:2]:
            print("[c93]   chain latest LM: " + "  <-  ".join(p), flush=True)
        del target
    else:
        del alive
    gc.freeze()
```
