## 5. Что предлагаю

По порядку. Каждый пункт — решение владельца; кода фич здесь нет.

**А. Сменить набор суда до любого прогона (поправка 11).** Развилка ваша:

- *Вариант 1 — паспорт остаётся справкой по известному имени.* Суд идёт на новом наборе из реальных влитых задач по
  коду `multiprocess_framework`, `Services`, `Plugins`. Автор набора не видит `passport.py`. Каждый вопрос помечен
  классом: «имя названо» или «дано описание задачи»; каждый адрес — `.py` или нет. N ≥ 10. База C0 ×3 и `atlas` ×3 на нём
  же. `r1` остаётся отдельной строкой «вне охвата»: её число говорит, какую долю реальной работы паспорт по коду не видит
  (сейчас 11 адресов из 22).
- *Вариант 2 — цель плана меняется на «найти место по описанию задачи».* Тогда `r1` — правильный судья, но до суда нужны
  поиск по описанию, модульные константы и не-`.py` файлы. Паспорт становится вторым шагом после поиска.

Рекомендую вариант 1 сейчас и бесплатную пробу для варианта 2: восемь вопросов `r1` подать в `qex` и посмотреть, входит
ли нужный файл в первые пять. Условие `qex.json` в бенче уже есть. Нужен Ollama; сегодня он выключен, пробу я не делал.

**Б. Шлюз Ш0 как команда и счёт пропусков.** `bench.py ceiling --text` по выводу `--format passport` с бюджетом по
умолчанию (мой черновик — 40 строк). Правило в `plan.md`: без потолка по тексту на наборе суда `--yes` не запускается.
В ручную сверку 10 паспортов (5.1) добавить полноту: `used_by`, `subclasses`, `threads`, `commands` против `git grep`.

**В. Одна задача на пропуски и срез, до платных прогонов.** По убыванию пользы (номера строк — по таблице дополнения):

1. `ref` разрешает реэкспорт так же, как `map` (строки 1, 2, 13). Приёмка: `process_managers.py:356` и
   `ProcessManagerProcess` видны.
2. Адреса вызовов «по имени метода» под отдельной меткой, когда их мало; при частом имени — честное «имя частое»
   (строки 5, 6). Hold-out: 3 из 5 → 4 из 5.
3. В срезе продукт раньше тестов; члены класса режутся (строки 7, 8).
4. Оговорка «видит только …» у `threads`, `commands`, `io`, как уже есть у `links` (строки 3, 4).
5. `ref` без флага отдаёт паспорт; строка вложенных юнитов; префикс юнита один раз (строки 9, 10, 11).

Мерить платно известные дефекты нет смысла.

**Г. Процесс — перенести вес вперёд.**

1. Форма — исполняемые эталоны, а не проза. К эталонам на фикстуре добавить эталоны **на реальном дереве по
   закреплённому SHA**: `--ref` делает вывод детерминированным. Классы А, Б и Д — 58 из 83 — это то, что вскрывают
   конкретные примеры. Stage 0 ревьюит эталоны и контракт, не более двух раундов.
2. Шаг «глазами агента» на стадии INTERFACE: лид запускает прототип на пяти реальных целях и читает вывод как
   потребитель. 20 минут, без агентов. Этот шаг дал §2.
3. Лимит 8 192 заменить парой: контракт ≤ 4 КБ и справочник без лимита, который построчно не ревьюят.
