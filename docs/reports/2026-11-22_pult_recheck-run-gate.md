## Предсказания лида против наблюдений
Совпало: P1 (`ready`, 0 кадров), P2, P3 (0,013 с — лучше), P4, P5 (Enter ≤ 2 с — 0,04 с), P7, P8 (отказ после «Домой» воспроизведён), P9, P13 (после ОСТАНОВИТЬ слово встаёт без «Серво ВКЛ»), P12 (C-105 воспроизведён, зависимости от пробы нет).

P10 — предсказывал «применится» (55 %), не применилось. P11 («✕», рецепт на диск) — «✕» НЕ ПРОВЕРЕНО. ## Красные → `plans/queue/defects.md`
- **C-103** — уточнён: лента встаёт мгновенно (прямое `belt.status`), опаздывает метрика `belt_mm_s` в state сима (0,13…4,82 с); критерий плана ≤ 1 с к ленте выполнен, к публикации — нет. **Вопрос владельцу:** что мерим, ленту или публикацию (если публикацию — ужесточать период публикации сима, не Пульт).
- **C-104** — добавлен второй путь потери: «Домой» при диске в полёте (`last_error «идёт основная остановка робота»`); в `park.dropped.jobs` потеря не видна (0 при `jobs_dropped 2`).
- **C-105** — подтверждён 5/5 на `run_gate: true`, при `QT_MCP_PROBE=1` и без; причина не исследована (`investigator`, полоса Ф).

## Открыто / ненадёжно
- Кнопки GUI «Домой», «ОСТАНОВИТЬ» и ленточные кнопки в `ready` не нажимались (драйвером или не снято); «✕» — ветка «Yes» не проверена (модалку закрыл сторож `INSPECTOR_GUI_UNATTENDED`).
- «Домой» при диске в полёте — один захват (n = 1); S6-B проходил по сети с шумом: «трудный» диск не считается красным по раскладке, но `jobs_emitted` литералом не снят.
- `run_alpha.py` не гонялся (при `run_gate: true` он сам START не шлёт; design §2.1 об этом молчит — нужен `--autostart` по README alpha_sim:37).
- Кнопки пульта через `emit_control` на backend ленту не двигают (действие исполняет GUI, `presenter.py:72`) — headless-проверка кнопок невозможна.
- Живые QLabel `True/False/done` на экране не считывались; расхождение значений мониторов backend- и GUI-подъёма не объяснено (в GUI-подъёме ленту остановили — дисков не было, вероятная причина, не доказано).
- Нагрузка: load 10,0 в 12:12 (чужой `dry_run.py`), 1,8–5,9 дальше; числа ленты сняты при 5,2–5,9; прямой источник ленты — модель сима, не физика; Modbus-регистр 5021 напрямую не читали.
- β не гонялась (R4, ORDER #21); `make gate` не запускался (только Markdown).
