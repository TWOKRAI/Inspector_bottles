Аналоги вне списка (всё **[не проверено]** — веб закрыт для роли, по памяти):
- **LSP / Serena-подобные символьные инструменты** (`get_symbols_overview`, `find_referencing_symbols`): приём — **обзор файла по символам без тел** → кандидат №1; `serena` в проекте запрещён (`team-protocol` §7), так что это ниша атласа.
- **Agentless / SWE-agent ACI**: приём — иерархическая локализация «файл → класс/функция → строки» по **скелету файла** (сигнатуры + первая строка докстринга) → тот же кандидат №1; «окно просмотра ≤ 100 строк» = P2.
- **Sourcegraph/Cody, Pyright/jedi**: точные места вызова по типам → п. 21 (Pyright), условно.
- **universal-ctags**: индекс определений — = `atlas index`; ничего нового.
- **Repomix / «репозиторий одним файлом»**: приём — пакет под бюджет = `map --depth 1 --budget` (п. 11); ничего нового.
- **Cursor / Claude Code**: Cursor — эмбеддинги (= qex, сосед Д7); Claude Code — без индекса, grep/glob — это и есть наш C0. Ничего брать.
- **ast-grep** (в проекте есть как MCP): приём — детекторы как YAML-правила; **не брать**: один язык, три образца, бинарная зависимость; `ast` хватает.
