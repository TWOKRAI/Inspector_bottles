# Н2 · сим-аудит GUI — кнопки Пульта на симе

Сессии: inspector-bottles-a2 [589037] (до 21:13), inspector-bottles-bd [56bee4] (дальше). Дерево `../Inspector_bottles--sa-gui`, коммит `e4443c487`, ветка `test/sim-wire-audit`. Стенд: Python 3.14.7, PySide6 6.12.0, окно прототипа из дерева `--pult-speed`. Отчёт не закоммичен.

**Суть.** Каждую кнопку и поле Пульта нажимал владелец, запись шла через `ui_tap`; клик, команда и провод сверялись с `robot_exchange.log`, `sim_robot.status` и `system.log`. Предсказания записаны до нажатий (раздел ниже).
**Итог.** Все кнопки Пульта делают то, что предсказано, кроме перечисленных находок. «Домой» в `ready`: `SERVO 0` без `SC_RUN`; при роботе не дома: `SC_RUN`, через 0,5–1,0 с `SERVO 0`. «Серво ВКЛ»: `SERVO 1`; диск до него отказан с C-104, после — `CVT_JOB`. Лента, поле «Слово», смена слова на ходу, «✕» отработали. Провод: 6 `CVT_JOB`, `CMD_SEQ` уникальны, ответ у каждого; 8 дисков отказаны при выключенном серво (аудит называет их «потеря»).
**Проверка.** Нажатий: «Домой» 3 в `ready` + 3 при диске, «Серво ВКЛ» 6, «Лента стоп» 3, «Лента пуск» 5, «ЗАПУСТИТЬ» 5, «ОСТАНОВИТЬ» 9 (8 из `running`, 1 в `ready`), «✕» 2 ветки, поле «Слово» 3 ввода. Аудит `wire_audit`: `docs/reports/2026-11-22_sim-audit-gui_wire/audit.md`, `wire_commands.md`.
**Проблемы → решение.**
1. «ЗАПУСТИТЬ»/«ОСТАНОВИТЬ» не шлют `kind=command` (только `ui.event` button) → решает владелец (тап нужен шире).
2. «ОСТАНОВИТЬ» → `ready`: по метке бэкенда `system.run.since` 0,85–1,00 с; в таблице 0,93–1,13 с — замер смешанными часами (клик по часам GUI минус приём дельты тапом, +0,07…0,14 с). Время — два такта опроса по 0,5 с (тик драйвера робота `poll_interval_s`, такт снимка готовности процессов), фиксированной паузы нет; по коду на других фазах может быть > 1 с (не воспроизведено). `STOP_REQ` = `stop_seq*4 + уровень`: одна SOFT-запись на стоп, шаг 4 — норма; «5, две записи» относится к `system.shutdown`, а не к ОСТАНОВИТЬ → поправить критерий, код не менять.
3. «ЗАПУСТИТЬ» ленту не запускает, «ОСТАНОВИТЬ» её стопит (`0x1200 = 0`) → по дизайну или нет, решает владелец.
4. В Пульте не было скорости ленты, пуск затирал частоту → добавлено `belt_freq` в два рецепта и запоминание частоты в `VfdClient.run()` (ветка `feat/pult-belt-speed`, дерево `--pult-speed`, не закоммичено, нужны ревью и слово владельца).
5. Потерянный диск занимает ячейку (слово `··Р······`) → вопрос к владельцу/Р2: нужна ли дыра. Breaker `layout` пишет «×5 подряд» через 6 успешных `CVT_JOB`: `robot_io` не вызывает `health.record_success()` вопреки ADR-PM-011 п. 1 (`Plugins/io/robot_io/plugin.py:256-263`); в `ok` вернулся сам через 63,6 с тишины.
6. «Домой»: команда → провод 0,03–0,37 с — это фаза тика драйвера робота (период ≈ 0,505 с, шаги park идут только в тике, `plugin.py:679,766`, `park.py`): модель «0,5 − (accept − конец прошлого тика) + 2–6 мс» совпала в 7 эпизодах из 7; максимум по коду ≈ 0,51 с. Код работает по проекту T5.3e, неверным было моё ожидание ≤ 0,15 с → решает Р2/владелец: допуск «≤ тик» или пробуждение тика (ADR). `SERVO 0` после `SC_RUN` — ожидание DONE хода и позы дома (интервал 1–2 тика), смысл DONE на настоящем Delta не проверен → Р2 до железа.
7. Тап не пишет Enter поля «Слово» → время Enter → команда не измерено.
8. «✕» первым показывает диалог несохранённых правок графа, а не «Yes/No»; «gui terminated»/C-105 в логах не найдено → уточнить текст/код.
9. `wire_audit` называет отказ при серво-офф «потеря»; сборщик `collect` убит `kill -TERM` при перезапуске прототипа в 20:47:34 (SIGTERM не обработан, `meta.json` без `stop_reason`), три перезапуска умерли молча (код 2, `ModuleNotFoundError` в дереве без `scripts/wire_audit`), живость никто не проверил; столбец Б при устаревшем журнале даёт 6 ложных «сим не видел» (`core.py:756-757`, `839-840`, нет сравнения времён) → правка нашего `wire_audit` (SIGTERM, пульс, реконнект, интервал покрытия, исход «отказ hub» из `layout/system.log`).
**Агенты.** Субагенты в этой части не запускались: нажатия делал владелец, снятие и таблицы — лид.
**Открыто / ненадёжно.**
- `qt-mcp` не подключился (CONNECTION_CLOSED): кнопки нажимал владелец; активность «ОСТАНОВИТЬ» в `ready` не подтверждена владельцем.
- Время Enter → команда не измерено (тап не пишет Enter); «gui terminated» — поле `outcomes.gui` ответа `system_shutdown`, а не строка лога (WARNING `did not stop in 5.0s, terminating` в `logs7` нет, gui вышел сам); смысл DONE на настоящем Delta не проверен.
- Смена слова снята цепочкой `РЕИ → МИР → ПЕРЕМИРИЕ`, а не `ПЕРЕМИРИЕ → МИР → ПЕРЕМИРИЕ`; серво в этих проходах выключено.
- Не проверено: `chain_check.yaml --gui` отдельно, β-рецепт, `run_alpha.py --autostart` (вне GUI-части).
- Ветка `feat/pult-belt-speed`: правки лежат без коммита; решение по безопасности пуска на реальном ПЧ (последняя заданная скорость вместо `default_freq_hz`) за владельцем.
**Дальше.** Решения владельца по п. 1–6, 8; ревью `reviewer` и слияние `feat/pult-belt-speed` через координатора `inspector-bottles-95 [3d753e]`; затем handoff и /clear.

## Предсказания на «Серво ВКЛ» и «Домой» с диском (записаны ДО нажатий, сессия bd)
