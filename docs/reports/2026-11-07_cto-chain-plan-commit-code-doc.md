Вычисляется: для 500+ старых коммитов связь коммит → ADR выводится `origin` как `how: inferred` (Refs → план → упоминания ADR в плане/DECISIONS) и так помечается — честный «не точно». Один раз скриптом (junior, один `docs(plans):` коммит): нормализовать статусы 34 активных `plan.md` в словарь и строки ledger; `--baseline-init` для `atlas check`. Остаётся как есть: `plans/_archive` (88), старые id `ADR-001`, форма `[DONE дата — sha]` (парсер читает обе), 500 коммитов.

**Что замораживаю (FREEZE, не удалять):** трейлеры `Risk/Reversible/Tested/Rejected` (остаются распознаваемыми); `CONTEXT.md` модулей и `/core:quality:sync-context`; `docs/decisions/` как каталог (указатель на шаблон); `sessions/` как тип — по слову владельца; `Task:` — не замораживать, оставить необязательным.

## 10. Взгляд «лучший инструмент для агента» и аналоги

## 11. Риски и чего не делать

Второй источник истины (рукописный реестр, колонка «коммиты» в ADR от руки, «Происхождение» в README) — нет; ретро-правка 500 коммитов или перенумерация 539 ADR — нет; обязательные поля без читателя (`Task:`, `Risk`…) — нет, FREEZE; `Decision:` обязателен только при добавлении ADR — иначе его никто не заполнит; git notes — нет; YAML-frontmatter на 1 100 документов — нет, одна строка `Refs:`; LLM-пересказы как «итог» — нет, итог пишет лид ≤ 30 строк; `atlas origin` до Kill-3 — нет (иначе ещё один недоказанный механизм).
