  2. Вход журнала обмена `--exchange` (файл `robot_exchange.log`). Встречаются и строки, которые разборщик пропускает молча: склейки `#n … ×k` (без `in|out`), `W 0x1200…0x1204`, `SC_BUF`, `STOP_REQ`, `RES_SEQ..+80`, `connect ok`, `disconnect`. Файл дописывается между запусками: судится только последняя инкарнация — от последней строки с `robot_main: #1 ` (номер n = 1, обычно `connect ok`).
  3. Блок `CVT_JOB` открывает `CMD_OPCODE` с именем `CVT_JOB`, `CMD_SEQ` стоит перед ним. Блок другой команды (`SERVO`, `SC_RUN`, `STOP_REQ`) — не задание. Ответ задания — **первая** строка `R` с `RES_SEQ == CMD_SEQ` после `CMD_FLAG` блока. Вторая строка `R` с тем же `RES_SEQ` (в прошлых прогонах: `+80`, чтение телеметрии через 16…25 с, у 2 заданий из 15) — не FAIL, если `RES_STATUS` и `RES_ERRNO` те же; разные — FAIL `ответ противоречив`. Нет `R` — FAIL `нет ответа`.
  4. Вход журнала диска `--layout` (файл `layout/messages.log`): `#72 2026-11-12 13:33:26,837 [INFO] [layout] word_layout: WordLayoutPlugin: слово 'ПЕРЕМИРИЕ' (источник: регистр)`; `… смена слова 'ПЕРЕМИРИЕ' → 'МИР' (источник: регистр) — ячейки с нуля (было заполнено 9/9)`; `… диск 'Е' 91.9° → ячейка 3: взять(460.2,-341.3) → положить x320.0 y-110.0 z-132.0 r-91.9° [4/9]`; `… диск 'Ш' 160.5° → пропуск: слово не задано`. Число после буквы — **сырой угол сети**, `r` — **доворот**. Файл дописывается: судится последняя инкарнация — от последней строки `LoggerManager initialized`. Строки пропуска до первого слова («слово не задано») — PASS, «заливка 0», в `--words` не входят. Слово/смена слова режут журнал на заливки.
  5. Расшифровка: слово ≥ 32768 → `n − 65536`; мм и градусы = слово / 10. Порядок: `[0]` ecap_lo, `[1]` ecap_hi, `[2]` pick x, `[3]` pick y, `[4]` pick z, `[5]` flags, `[6]` place x, `[7]` place y, `[8]` place z, `[9]` place rz; `CMD_ARGC` = 10; `ecap = ARGS[1]·65536 + ARGS[0]` (беззнаковые слова; пример 18178, 1 → 83714) — в таблице отдельным столбцом.
  6. Привязка «диск ↔ задание». Строки взятия (`ячейка N`) идут по времени. Для строки взятия k (время t_k, ячейка N_k) кандидат — первое по порядку строк файла ещё не занятое задание с временем ≥ t_k (при равенстве — порядок строк файла), с `ARGS[7]` равным ожидаемому слову ячейки N_k и временем **меньше** времени следующей строки взятия в ту же ячейку N_k (если такой нет — без верхней границы). Нет кандидата — FAIL `потеря`. Задание, оставшееся не занятым после прохода, — FAIL `лишнее` у ближайшей предшествующей по времени строки диска (пометка `после пропуска`, если это строка пропуска; до первой строки — `до первого взятия`). Пропуск без последующего лишнего задания — PASS. Допуск «−50 мс» убран: замеры положительные (0,025…0,514 с).
  7. Повтор после отказа: блок `CVT_JOB` со `RES_STATUS ≠ 1`, за которым следует блок с теми же `ARGS[2..9]` и `RES_STATUS = 1`, — «повтор»: первый не занимается строкой взятия, не FAIL, считается в счётчике `повторов`; привязывается второй. Отказ без последующего повтора — FAIL `статус N`.
