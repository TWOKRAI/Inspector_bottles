Уборка (и) выполняется и при любой ошибке шагов б–ж.
  4. Вердикт одного прогона. **МЕХАНИЗМ = PASS**, если одновременно: в `alpha.out` есть строка `МЕХАНИЗМ: PASS`; код аудита 0; все порты `free_after` свободны после остановки; все запущенные скриптом процессы завершились; сборщик завершился. Иначе FAIL с перечнем причин (по одной строке: `alpha`, `audit`, `порты`, `процессы`, `сборщик`). Код возврата α (1 допускается при `МЕХАНИЗМ: PASS`) в вердикт не входит. **ТОЧНОСТЬ** — информативно: строка `ТОЧНОСТЬ: …` из `alpha.out` дословно, на вердикт и код не влияет. В `verdict.md` также: метка времени, режим (`headless`/`gui`), пути файлов прогона, строка `ИТОГ:` аудита дословно, `# дефекты сима: defect_rate 0.0` (что скрипт изменил в симе).
