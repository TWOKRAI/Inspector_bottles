# Что хорошо и чего нет

Часть отчёта [README.md](README.md).

## Что хорошо и не трогать

- Поток-владелец и ящик. Порт зовёт только владелец; другие потоки ставят команды (`session.py:328-392`). Каждый вызов порта виден сторожу через `_port_call` (`session.py:438-447`).
- Проверка записи чтением с допуском по `Binding.vtype` (`profiles.py:48-59`, `:98-147`). В `param_errors` нет значений рецепта.
- Одна ошибка порта `PortError` без значения в тексте (`interface.py:70-81`). Коды MVS переводит одна таблица (`driver.py:83-92`).
- Тонкий вендор: драйвер 437 строк, плагин 65, register 91. Контракт порта — только stdlib (`interface.py:1-9`).
- Наблюдаемость средствами framework: `declare_metric`/`publish_metric`, `merge` только отличий, инциденты по смене (`plugin_base.py:437-524`).
- Readiness с литеральными причинами без серийных номеров (`plugin_base.py:369-396`).
- `apply_params` «всё или ничего»: проба всего пакета на копии register'а до первой записи (`plugin_base.py:733-785`).
- Фейк по записи реального прибора `testing/recordings/mvs_MV-CS020-10GC.json` и общий контрактный набор `PortContractSuite`.
