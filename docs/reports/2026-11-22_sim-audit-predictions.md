## 0. Допуск (предложение координатору, владелец допуск не задавал)

Квант провода: `WIRE_SCALE = 10`, округление «от нуля» (`Services/robot_comm/core/client_v2.py:1184`, `protocol_v2.py:409`) → ошибка слова ≤ **0,05 мм / 0,05°**. Расчёт аудита берётся из журнала `layout`, где значения печатаются с одним знаком (`_fmt1`) → ещё ≤ 0,05. Сумма:

- **x, y, z (мм): ±0,10** при сравнении «слово ↔ журнал `layout`», плюс 1e-6 на плавающую точку;
- **rz (°): ±0,10** там же; угол `rz` на проводе = `P_PICK_RZ (−100,0) + r` из журнала;
- **5,0°** (умолчание α) остаётся только для «угол сети против подачи» — это ТОЧНОСТЬ сети, на PASS/FAIL механизма аудита не влияет.

Допуск шире 0,10 скрыл бы ошибку на один шаг слова (0,1 мм); уже — дал бы ложные FAIL на границе округления.

## 2. «Домой» при диске в полёте (n ≥ 3)

Что именно делает робот с диском — вне ПК-части. Инварианты на стороне ПК (в каждом из n ≥ 3):

- одно нажатие → ровно один park `SC_RUN`, `RES_STATUS = 1`, `RES_ERRNO = 0`;
- число `CVT_JOB` в журнале не уменьшается, `CMD_SEQ` без дублей;
- взятий в журнале `layout` = `CVT_JOB` (нет взятия без задания и задания без взятия). `CVT_JOB` без строки взятия после park — находка.

## 3. Прочие пункты описи

- **C-104 (при выключенном серво):** в `system.log` процесса `layout` строка вида `[health] ResourceUnavailable @ robot_io.forward.refused: hub отказ (буква 'М', ячейка 0): робот остановлен: включите серво` (`docs/handoffs/2026-11-22_R2-merge-request.md:27`); для отказанного диска `CVT_JOB` в журнале — ноль. Условие запуска (как выключить серво) — из handoff R2 п. 3, уточнить в брифе тестеру. В `messages.log` строки нет.
- **β `hikvision_letter_robot` на симе:** как есть не поднимется до кадров — камера реальная (`DA1689923`), SDK/DLL отсутствуют; с override только робота (`127.0.0.1:5021`) камера не откроется → 0 строк диска, 0 `CVT_JOB`. Это находка «β на симе требует источник кадров», не дефект провода.
- **GUI (видимый прогон, п. «Домой», «ОСТАНОВИТЬ», «✕ → Yes», поле «Слово»):** «Домой» → park `SC_RUN` в журнале; «ОСТАНОВИТЬ» → `STOP_REQ`; «✕ → Yes» → завершение процессов, порты свободны; смена слова в поле → строка «смена слова 'A' → 'B' (было заполнено k/n)» в журнале `layout`, новые диски идут в ячейки нового слова. Числа не заданы заранее (k зависит от регистра) — сверяются по журналам.

## 4. Что не предсказываю (честно)

- Знак `rz` от `angle_deg` к слову: лог печатает `r = +angle_deg`, α ожидает `wrap180(0 − angle)` (`logic.py:526`). Предсказание П7 задано через `r` из лога, не через угол сети; знак — отдельная проверка в задаче 3/4.
- Абсолютные значения `CMD_SEQ`/`RES_SEQ`: старт счётчика зависит от прогона; предсказана только структура (уникальность, пары).
- Сколько дисков сеть потеряет/прочтёт ниже порога (это ТОЧНОСТЬ, не механизм; «М» → «И» не дубль, LESSONS промпта).
