## Главная находка ревью

F1: при вставке GUI писал плагин в полной форме, `plugin_class: null` и `config: {}`. Бэкенд
(`_restore_plugin_configs`) при `plugin_class: None` восстанавливал 0 конфигов вместо 1. Это вред поведению, а не
только шум. Старый писатель делал то же, регрессии нет. Исправлено в `f08923425`.

## В Task 1.3 (ADR / OPEN_QUESTIONS)

- F3: хук `InspectorRecipeFormatHook.normalize` на невалидном теле (`[1, 2]`, строка, `blueprint: "x"`) возвращает
  значение вместо `RecipeFormatError`, а на `None` бросает TypeError. Восемь проб из восьми красные. На пути менеджера
  вред закрыт `_normalize_file`. Хук вне FILES 1.1g.
- F7: `topology_to_canonical` без `blueprint` в базе вставляет `wires: []`, `displays: []`.
- F10: проверка бэкенда отбрасывает `config == {}` без условия; добавить проверку, что у класса конфига нет поля `config`.
- F11: сравнение не видит `description` и `target_process`; свойство «`plugin_class: None` → 0 конфигов» держится
  только литералом текста файла.
- F4: тест «у GUI и хаба один хук» сверяет имя класса через AST. Поведенческая замена — Task 1.4.
