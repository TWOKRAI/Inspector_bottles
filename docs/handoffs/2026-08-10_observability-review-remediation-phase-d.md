## What did NOT work

**Две инъекции разошлись с предсказанием, и обе вскрыли дефект СОБСТВЕННЫХ проверок, а не продукта.**

- Страж дедлайнов (D2.3) нёс самопроверку «вижу ≥ 40 файлов». Инъекция «разломать путь одного из четырёх каталогов» оставила его ЗЕЛЁНЫМ: остаток списка перекрывал порог. Переписан на поимённую сверку — теперь краснеет.
- Тест D2.5 искал в плоскости ошибок просто маркер. Раздражитель `health.report(level=ERROR)` бьёт туда ДВУМЯ дорогами (инцидент `state.report_error` + ERROR-лог), и убийство лог-дороги тест не заметил. Ассерт переставлен на лог-дорогу поимённо, вторая печатается в сообщении.

**Две редакции живой пробы D5 были красными законно** — и обе оказались находками, а не помехой: «каталог живого процесса не тронут» живьём неразрешимо (его метёт собственный подметальщик), а проверка «чужое дерево названо» шла по пустому месту, потому что единственный кандидат `<cwd>/logs` в tmp-стенде совпадал с активным каталогом.

**`git commit` забрал весь индекс.** Удаления `git rm`, сделанные в начале сессии, уехали в первый же коммит другой задачи (34 файла D2 внутри коммита D3). История переписана (ветка не запушена), четыре коммита пересобраны по задачам. Урок в памяти: [[feedback_commit_takes_the_whole_index]].

**Сорванный pre-commit спрятал час работы.** При незастейдженных правках хук прячет их в `~/.cache/pre-commit/patchNNN`; `ruff format` переформатировал файлы, восстановление упало «patch does not apply», рабочее дерево осталось пустым. Вернул `git apply --3way <патч>`. Профилактика — прогонять `ruff format` по своим файлам ДО `git add`.

**Мелочи:** `grep -rn` по всему репо из Bash уходит в таймаут (>2 мин) — пользоваться инструментом Grep; консоль Windows cp866, русские отчёты скриптов читаются мохнатым, числа при этом верны.

- **Радиус D2.2 — владелец выбрал «снести дерево целиком».** 7 тестовых файлов не собирались никогда (`ImportError: ProcessManagerCore`, символа нет в истории репозитория), их подпорки — `template_app/`, раннер и 8 гайдов на несуществующий API — ссылок извне не имели. Прототип не трогаем. **Работа не начата** — см. «Next step».
- **Два пункта плана D6 опровергнуты и оставлены как есть** (координатор): ветку `drained.get(KIND_LOG)` держат 3 живых теста и документированный умысел; докстринга `_LoggerSlotSplitter` в `store_tap.py` не существует — адрес в плане неверен.

## Открытые долги

- **D7 принята и закоммичена** (`6056aa08`). При приёмке координатор нашёл два зазора: запись pymodbus выходила ДВАЖДЫ при любом обработчике на stdlib-root (закрыто `propagate=False`), и у моста не было ни одного теста (дописаны пять). Задача тянет на отдельный заход (уровень Senior, исполнитель `teamlead`), `/graph-slice` обязателен ДО правки.
