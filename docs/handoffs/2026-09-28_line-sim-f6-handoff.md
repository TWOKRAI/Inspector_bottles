## Что это даёт стенду

Через `backend_ctl` 8766 либо через веб-пульт (`http://127.0.0.1:8092`):

- `scene.pause {"paused": bool}` — остановить/пустить поток объектов (деспавн продолжается);
- `scene.flow {"interval_s": [lo, hi]}` ЛИБО `{"spacing_mm": [lo, hi]}` — сменить правило шага на живом движке;
- `scene.defect_rate {"probability": p}` — доля брака следующих спавнов (файл пресета не переписывается);
- `scene.defect_now {}` — следующий объект дефектный; нажатия не схлопываются;
- `scene.status` — применённое состояние: `paused`, `flow`, `defect_probability`, `force_defect_pending`.

  первые два заработают, когда соседняя сессия проведёт код наружу. Связка закреплена тестом

  репозитории (67 файлов). Записано соседней сессией в `docs/claude/OPEN_QUESTIONS.md`.
