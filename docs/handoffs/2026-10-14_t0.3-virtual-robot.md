## Следующие шаги (когда вернёмся)

1. Владелец: DRAStudio 07.62 → «VA» → модель → «ETHERNET» → «Virtual Robot» → «Connect»; сообщить, что на экране.
2. `netstat -ano | grep LISTENING` + PID процессов VRC → порт Modbus; `Test-NetConnection 127.0.0.1 -Port <порт>`; чтение одного регистра (FC3, unit 2 и, при отказе, 1).
3. Загрузить и запустить `probe.lua` в Virtual Robot; в консоли ждать «probe: готова …».
4. Координатору — «probe start» и порт; `python robot/pc_platform_probe/pc_probe.py --host 127.0.0.1 --port <порт> --unit <unit> safe`, затем `all`.
5. Сводка по `reports/<время>_*/report.json`: тест → прошёл / не прошёл / неприменим на виртуальном.

## Что виртуальный робот подтвердить не может (остаётся за визитом)

- сохранение `0x3000..0x3FFF` при выключении питания;
- второе TCP-соединение и атомарность — на VRC проверяется, но перенос на железо не гарантирован;
- модель с шильдика и параметры зоны `P_WS_*`.
