## Долг, вынесенный за радиус (в `docs/claude/OPEN_QUESTIONS.md`)

- **A.** Дренаж тела нужен на ВСЕХ ранних отказах (403/415/400), не только на 413 — иначе Windows рвёт
  соединение RST'ом. Это корневая причина флейка радиуса `pult_web`, найдена замером: база 5 падений
  на 8 прогонов, под инъекцией «дренировать после любого 4xx» — 5 из 5 зелёных. Отдельный ход нужен
  для `Content-Length: -1`.
- **B.** `rfile.read(length)` идёт без таймаута и без 408: клиент объявил длину в пределах потолка,
  прислал меньше и замолчал -> обработчик висит бессрочно (>12 с без ответа). Предсуществует 1.2h.
- **C.** `@pytest.mark.timeout` в 67 файлах репозитория — пустышка, `pytest-timeout` не установлен.
