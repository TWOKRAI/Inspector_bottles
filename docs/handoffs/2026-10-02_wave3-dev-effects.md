## Ловушки для Ф3 (спеки в пресетах)
- `EffectSpec` не проверялся на pickle/`copy`: поле `params` — `MappingProxyType` (не пиклится), нужен `__reduce__`.
- `params` read-only только верхний уровень; значения параметров не валидируются (кривая пара упадёт в numpy), тип `prob` не проверяется.
- Мост требует, чтобы каждый ключ `EFFECTS` был полем `AugmentConfig`; пресет с эффектом без поля даст `AttributeError`.
