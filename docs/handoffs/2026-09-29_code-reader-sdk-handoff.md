## Ловушки (сегодня на себе)

- **Bash-инструмент схлопывает `\\` в heredoc** — байтовые литералы и `"\n"` в сгенерированных скриптах
  ломаются. Файлы с обратными слешами — через Write/Edit. (память: `feedback_bash_heredoc_collapses_backslashes`)
- **`setattr` в ctypes-структуру с чужим именем молча создаёт атрибут** — тест подаёт нули и зеленеет.
  Хелпер с проверкой `_fields_`. (память: `feedback_ctypes_setattr_unknown_field_is_silent`)
- **VPN (WireGuard) прячет прибор** от `EnumDevices` — 0 устройств при живом линке.
- **IDMVS держит прибор эксклюзивно** — перед SDK-стендом закрыть; пока IDMVS подключён, по TCP коды,
  похоже, не идут (изолированно не проверено).
- Запуск рецепта по имени перезаписывает `pipeline:` в `app.yaml`; `git checkout -- app.yaml` в этой
  сессии запрещён правами — возвращать точечными правками.
- Хук `lint-brief` требует у брифа агента блоки DESIGN/FILES/REDS/REPORT (шаблон
  `.claude/plugins/dev/templates/executor-brief.md`), REDS ≤ 10 — большой RED-набор делить по механизмам.
- SDK лежит в `C:\Program Files (x86)\IDMVSSTD\Development\Development.zip` (заголовки, PDF-гайд, DLL);
