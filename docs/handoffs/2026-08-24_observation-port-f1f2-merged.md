## Что осталось открытым — по убыванию цены

1. **Ц1, назван ревью.** Иерархия появилась в дереве, но не в управлении:
   `TelemetryPublishConfig.resolve` ключуется ИМЕНЕМ ЛИСТА, поэтому правило
   `metrics.fps` гасит три разных листа сразу (`state.fps`,
   `state.plugins.<a>.fps`, `state.plugins.<b>.fps`), и адресовать их порознь
   нечем. До Ф1 такого не могло быть — двух писателей одного имени не существовало.
   Закрывает **Ф4** («политика одним glob»).
2. **Ц2.** Ключ `state.plugins` стал зарезервированным и **ничем не охраняется**:
   `declare_metric('plugins', ...)` принимается, а порядок слияния в
   `process_heartbeat.py:837/847` даёт агрегату фреймворка молча перезаписать
   всё поддерево наблюдений. Сегодня не стреляет только потому, что никто не
   назвал метрику `plugins`.
3. **М1 нельзя объявлять выполненным.** На дефолтном конфиге гейт закрыт, и порт
   не везёт в дерево ни одной плагинной метрики — выигрыш новой адресации виден
   только опросом. Вопрос Ф4.
4. **Д1 отрицательный.** Боевого триггера у снятия Ф2 нет: `retract` зовётся
   только при остановке всего процесса, а тогда PM сносит `processes.<имя>`
   целиком. Механизм исполнен и охраняем, но live-критерий фазы невыполним по
   построению. Кандидат в носители — `set_enabled → lifecycle`, это **Ф3**.
5. **Ц3.** У `PluginLevels._values` нет потолка (помечено `ponytail:`).
6. **Ц5.** Корневой гейт не собирает тесты модулей фреймворка: из шести новых
   файлов приёмки/hazard'ов — ни одного. Не дефект (CI гоняет
   `run_framework_tests.py`), но человек с корневым `pytest` увидит про Ф1/Ф2 ноль.
7. **Латентный класс Н1.** ~12 мест вида `if not <менеджер>` вне тестов
   (`log_stats_channel.py:125`, `manager_adapter.py`, `version_manager.py`,
   `process_manager_process.py:441,3192` …). Живых экземпляров нет: ни один
   объект этих слотов не определяет `__len__`/`__bool__` — проверено. Класс
   остаётся, стрельнёт при первом менеджере с контейнерным протоколом.
8. **Учёт ветки транспорта.** План (`plan.md:1006`) называет её «~845 строк» —
   это механизм + ADR **без 1843 строк тестов**; реальный след 2681 строка.
   Ревьюер квалифицировал её как **adjacent, не necessary**: дефект старше Ф1
   на шесть недель, их диффом не задет, приёмка Ф2 закрылась за 3 ч 11 мин до
   начала ремонта.

## Ловушки, найденные в этой сессии — читать ДО следующего замера

- **Дефолтный стенд не исполняет GUI-код.** `multiprocess_prototype/run.py` в
  unattended поднимает `frontend/headless_process.py::HeadlessGuiProcess` — голый
  `ProcessModule`, дренирующий data-очередь: ни `GuiStateProxy`, ни четырёх
  подписок. Настоящий GUI даёт только `frontend/run.py` (presentation-overlay,
  `INSPECTOR_PRESENTATION`). **Всякий замер «старта GUI» обязан называть вход.**
- **Цифра 20.03 с мертва.** Она снята ДО починки грейса; `_NO_PUMP_GRACE_SEC = 0.5`
  существовал уже на базе, живая цена была 2.044 с. Не переносить её в новые тексты.
- **Ключевые тесты Ф1/Ф2 названы `test_writer_*`** — любой отбор `-k` по
  очевидным словам (`plugin_levels`, `telemetry`, `heartbeat`) их ПРОПУСКАЕТ.
  Ревьюер на этом получил ложные «0 красных» в трёх инъекциях из шести.
- **Ноль тестов при опечатке в пути молчит.** `pytest` на несуществующий файл даёт
  «collected 0 items / no tests ran» без ошибки — читается как «всё зелено».
- **Worktree агента без `.venv`** — точка входа ре-exec'ится в отсутствующий venv;
  запускать модуль напрямую с `PYTHONPATH=<worktree>`, а не гонять `uv sync`.

- Содержание девяти живых записей `StateProxy` не разбиралось — только их наличие.
- Замеры A/B — n=1 на плечо, прогоны последовательные (два бэкенда конфликтуют
