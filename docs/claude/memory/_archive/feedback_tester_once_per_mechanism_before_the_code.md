Решение владельца 2026-08-20. Тестер по-прежнему запускается на КАЖДЫЙ механизм —
запрещён второй заход по ТОМУ ЖЕ. Это не возврат к «выборочно» из
[[feedback_tester_always_and_inject_against_it]]: пропуска нет, есть запрет на дубль.

Измерено на Ф1 `observation-port`: Task 1.2 и Task 1.3 заказали независимого тестера по
одному и тому же механизму поддерева писателя. Второй стоил **479k токенов и 16 минут и
нашёл ноль** — он переприёмывал то, что уже приняли тестер и ревьюер. Тот же ролевой агент,
запущенный ДО кода на Task 1.4, вернул **6 красных тестов, ставших спецификацией
реализатору**. Ценность роли — в позиции во времени, а не в количестве заходов.

**Why:** зелёная повторная приёмка неотличима от отсутствия приёмки — она подтверждает
согласие двух наборов, а не соответствие реальности; красный набор до кода задаёт контракт.

**How to apply:** тестер — один на механизм, обязательно до реализации, его красное и есть
ТЗ. Вторая проверка того же механизма — матрица инъекций своей рукой плюс `reviewer`
синхронно. Гонять в worktree — [[feedback_tester_blindness_needs_a_worktree]].
