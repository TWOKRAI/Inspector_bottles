Ревью Ф3 `observability-unified-routing` (2026-08-05, Fable): **принята 8/10, вход
в Ф4 разрешён**. Отчёт: `docs/reviews/2026-08-05_f3_review.md`. Модель OTel
байт-в-байт; 3 своих слом-инъекции убили ровно предсказанные наборы.

Починено в сессии (красный тест → фикс → зелёный):
- **Б-1** окно частичной миграции стора: DDL автокоммитится, UPDATE — нет;
  гейт `if added:` терял дореформенную историю НАВСЕГДА → засыпка безусловна;
- **Б-7** `recipe` не доезжал live: `_build_resource` читал плоскую форму, ключ
  лежит под `config.` → `read_process_config` (повтор класса
  [[feedback-config-delivery-shape-differs]], хелпер уже существовал!);
- **Б-2** контракт-таблица `LogRecord` молчала про `trace_id`/Resource (стык 3.2↔3.3/3.5).

Открыто (решение владельца, пакетом в 5.2): **Б-3** `observed_ts` — колонка без
писателя (live: 0 из 303 016 — стор пишет эмитент, штампует GUI, пути не
пересекаются); **Б-4** форвардер метит всё `kind='error'` (logger-tap без kind);
**Б-8** вкладки Логи/Статистика структурно пусты (store-tap только ERROR
write-through; 293 теста зелены на фейках). Отдельно: **Б-5** `process.restart`
не исполняется на живом стенде (points/seg, pid не сменился — инкарнация
непроверяема штатно; рядом с graceful-stop долгом); **Б-6** шторм-петля хвоста
измерена: DEBUG-подписка на 21fps → 97k router errors / 21903 flush_failed /
88313 evicted / 303k строк стора за ~25 мин (приоритет QoS Ф7 G.4).
