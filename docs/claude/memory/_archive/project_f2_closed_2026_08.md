Ветка `feat/observability-unified-routing`, 2026-08-04. Ф2 закрыта: 2.1, 2.2, 2.4
(`d8ab81b5`), 2.5 (`0674c7fe`), 2.6, 2.7 (`d0689101`), 2.8, 2.9, 2.W, 2.V.

Три оси адресации записи теперь такие: **скоуп** (обычная строка, группа заводится
конфигом), **иерархическое имя** источника с longest-prefix, **ярлык** — алиас набора
префиксов, раскрываемый при сборке дерева. Объявление источника у модуля активно:
реестр наполняется импортом, конфликт двух владельцев — отказ.

**2.3b остаётся заблокированной**, и условие уточнено запуском: не «после 2.4/2.5»
(эта посылка опровергнута), а после того, как решение гейта перестанет зависеть от
`scopes` — то есть радиус Ф8.1.

**Дальше по плану:** Ф3 (модель записи, словарь OpenTelemetry) целиком, Ф4
(процессоры), остатки Ф5, вся Ф6 (миграция), затем гейт → Ф7/Ф8.

**Why:** номера задач фазы разбросаны по огромному файлу плана, и «что осталось»
без этой записи собирается заново каждую сессию.

**How to apply:** начиная новую сессию по этому плану — сверяться отсюда, а таблицу
задач фазы читать как первичный источник. Родня: [[project_f2_4_scope_is_a_string]],
[[feedback_a_plans_premise_expires]], [[project_observability_config_layers]].
