Обнаружено 2026-09-02 при ревизии `.claude/`: все 12 файлов `.claude/agents/dev/*.md` (зеркало,
которое читает Claude Code) отличались от источников `.claude/plugins/dev/agents/*.md` на 55–65
строк каждый. Блок «Общие правила проекта», `skills:` и шаг про graphify были дописаны 2026-08-26
только в зеркало. `.claude/{agents,commands,skills}/` — материализованные копии из
`.claude/plugins/<id>/`; любой `claude-kit sync` / `upgrade` перезаписал бы зеркало из источника и
**молча снял бы правила со всех агентов**. Ошибки не было бы — правило просто перестало бы
действовать.

Заодно в блоке правил во всех 12 копиях жила устаревшая посылка «индекс qex стар намеренно»,
снятая в корневом `CLAUDE.md` ещё 2026-08-27, — двенадцать копий никто не обновил.

**Why:** дублированный текст в 12 местах не сопровождается; зеркало без источника не переживает
пересборку; расхождение не видно ни одному линтеру (`lint_agents` смотрит frontmatter, не diff).

**How to apply:**
1. Правило, общее для всех агентов, — в один skill (`plugins/dev/skills/project-rules/SKILL.md`),
   агенты подключают его через `skills:` и заканчиваются указателем на файл. В агенте — только роль.
2. Любая правка агента: сначала источник в `plugins/<id>/agents/`, потом копия в зеркало
   (или материализация). Перед `claude-kit sync/upgrade` — `diff -q` источника и зеркала по всем
   файлам; расхождение чинить до пересборки, а не после.
3. Новый агент/команда/skill регистрируется в `.claude/.plugin-materialized.json`, иначе он для
   claude-kit невидим.
4. Числа на 2026-09-02: 12 агентов 2557 → 1907 строк, skill ~140 строк; контекст одного агента не
   уменьшился (skill грузится целиком), выигрыш — в сопровождении и согласованности.
