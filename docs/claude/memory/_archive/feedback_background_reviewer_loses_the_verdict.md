Ревьюера и тестера гонять **синхронно** не только ради правила «вердикт в том же ходу»:
фоновый агент, не дошедший до `SubagentHandback`, **не оставляет ничего**. Замер line-sim Ф1
(2026-09-20/21), две попытки на одной задаче:

- **Фон.** Запущен в соседней сессии, сессия кончилась раньше него. Ни записи о завершении,
  ни строки текста, ни одной находки. Обнаружилось через сутки: порт свободен, дерево чистое,
  `pytest` не бежит, сосед `idle` — то есть **«вердикт готовится» выглядит ровно как «вердикта
  не будет»**.
- **Синхронно.** Обрыв на `ECONNRESET` после 154k токенов и 36 вызовов (~37 мин). Харнесс сразу
  сказал: отчёт не доставлен, агент жив в транскрипте, `SendMessage` возобновит. Возобновил с
  «отдай что есть, новых прогонов не начинай» — пришёл полный отчёт: 5 углов из 8 с
  воспроизведениями, 3 честно помечены NOT-RUN. **154k токенов работы спасены.**

**Why:** у фонового агента нет адресата, пока он сам не позвал handback, — конец сессии
стирает его молча. У синхронного обрыв виден сразу, транскрипт остаётся. Цена синхронности —
заблокированный ход; цена фона — потерянная работа, о которой узнаёшь не вовремя.

**How to apply:**
- `reviewer`, `tester`, любая live-проверка — явный `run_in_background: false`. С Claude Code
  2.1.212 фон стал ДЕФОЛТОМ, правило больше не выполняется само —
  см. [[feedback-subagent-live-test-monitor-hang]].
- Агент упал по сети — **не перезапускать с нуля**. Сначала `SendMessage`: «отдай собранное,
  новых прогонов не начинай». Без второй половины он честно пойдёт перепроверять и сожжёт
  бюджет заново.
- Требовать разметку «дошёл — с воспроизведением, не дошёл — NOT-RUN»: иначе неполный
  честный отчёт достроится по памяти в полный правдоподобный.
- Спрашивать про хвосты (живые процессы, занятые порты) тем же сообщением: оборванный агент
  за собой не прибрал.
- Потолок `.budget` требует фонового spawn'а (имя файла — `agent_id`, известен только после
  старта). С синхронным ревьюером потолка нет — осознанный размен, называть вслух.
  См. [[feedback-agent-hard-budget-is-off-by-default]].
- Возобновление **упавшего** безопасно (оригинал мёртв), в отличие от **застрявшего** — там
  можно породить второй инстанс, см. [[feedback-agent-resume-ghost]].
