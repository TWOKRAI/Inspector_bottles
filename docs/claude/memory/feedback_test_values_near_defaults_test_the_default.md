Ф7.2: страж «порог берётся из схемы, а не из константы» просил `write_deadline_sec=0.30` и
проверял «ждали ≥ 0.25». Инъекция «зашить константу 0.25» оставила его **зелёным**: 0.25 ≥
0.25. Тест сторожил сам факт ожидания, а не то, что ручка вообще читается. После разведения
чисел (0.60 против проверки ≥ 0.45) инъекция стала 2/2.

**Why:** значение для теста выбирают «правдоподобным», то есть близким к дефолту — и тогда
поведение с ручкой и без ручки неразличимо в пределах допуска. Особенно коварно с временами
и размерами, где сравнение идёт через `>=`.

**How to apply:** в тесте на операбельность параметра брать значение, **заведомо
отличающееся от дефолта в разы**, и проверять диапазон, в который дефолт НЕ попадает.
Обнаруживается только инъекцией «зашить дефолт константой»; зелёный тест об этом не
скажет. Третий случай того же класса за одну фазу — родня:
[[feedback_fake_that_always_succeeds_mutes_the_gate]],
[[feedback_two_safeguards_hide_which_one_holds]].
