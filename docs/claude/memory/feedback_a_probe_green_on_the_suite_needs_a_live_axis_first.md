План 0.5 (lifecycle-owner-scope) записал базу «проба `offmain_gc` падает 3 из 3» (старая база, 2026-10-03). На main `4381fe9d4` (после T1) та же проба на 4 файлах 5.5d: **3 из 3 survived**, в момент пробы `wrappers 0`; без conftest (без T1) — **3 из 3 survived** при 1750 обёртках и 4853 собранных вне главного потока объектах, и на offscreen, и на нативной платформе. Зелёный набор не доказывает ничего: нечему падать или падение зависит от формы мусора.

**Why:** abort нужен определённый мусор — Python-владеемые деревья `QWidget` (QTreeWidget, QStackedWidget, родительские цепочки), **показанные** (`top.show()`), с запущенным `QTimer` без родителя, в цикле ссылок при выключенном gc; сборка вне главного потока. Мои две синтетические «оси» (виджеты в циклах `self_ref`; 6 деревьев + таймер без `show()`) не падали 0 из 8. Живой репродуктор CTO (`chain.py` в scratchpad прошлой сессии) давал `thread` — падение 3 из 3, `main` — выживание 3 из 3.

**How to apply:**
- Перед приёмкой «набор пережил пробу» — проверить ось отдельно: репродуктор, который ДОЛЖЕН упасть (режим «чужой поток»), и контроль, который ДОЛЖЕН выжить («главный поток»). Мёртвая ось → прогон набора не запускать и не засчитывать (`probe run` → код 2, «ось не живая»).
- Репродуктор прошлой сессии лежит в её scratchpad (`…/<id сессии>/scratchpad/`) — искать там до собственной синтетики; кладите такой артефакт в репозиторий (`docs/reviews/…/*.py.txt`).
- Исход «проба не сработала» (нет теста `logger_module`, нет PySide6) — отдельный класс `not-triggered`, не `survived`; признак — строка журнала `at first logger test`, свежий журнал на прогон.
- Код возврата падения читать как беззнаковый (`3221225477`), а имитировать в тестах как `os._exit(-1073741819)`: `os._exit(3221225477)` на этом Python — `OverflowError`, слепой тестер этого не увидел, пока не запущен код.
