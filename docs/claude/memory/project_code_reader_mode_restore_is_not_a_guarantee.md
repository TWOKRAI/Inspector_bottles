Опыт 2026-10-16/17, стенд `qr_reader_sdk_dual_demo` с самотриггером (`trigger_mode: On`, `trigger_source: SelfTrigger`, `trigger_period_ms: 40`), логи `logs_live/dual_20261016_trigger/`.

**Что выяснено.**
- Запись при старте прошла у обеих камер. Возврат при остановке (6 записей: период, источник, режим на двух камерах) отказал на всех шести с `0x80020206` = `MV_CODEREADER_E_NETER` («сетевая ошибка», `MvCodeReaderErrorDefine.h`). Следующая инкарнация процесса прочитала у обеих камер ИСХОДНЫЕ значения (`0/0/300` и `1/0/300`): запись, возможно, дошла, а SDK вернул ложную ошибку (как `ForceIp` на этом приборе даёт `0x80020204`), или прибор сам вернул состояние. Логи не различают.
- Штатное закрытие приложения убивает читателей (`TerminateJobObject` через ~1,02 с после `system_stop_event`, `spawner.py`). 2026-10-16 (закрытие GUI после full-replace) вторая инкарнация не записала строк возврата.
- 2026-10-19 (Task 6.2, `logs_live/6.2_h3_20261019/`): безголовый `system.shutdown` — reader_2 вернул P/S/M с `ok` за 1,3 с до `TerminateJobObject`; `release_device` на живом процессе — 3/3 `ok`; зонд — 21/21 возврат после `stop_grabbing`. NETER не воспроизведён (0 из 30). Прибор, оставленный в самотриггере после чистого `close`, держит его 15 с (E6b). Путь full-replace не повторён.
- После отказа возврата следующий `start()` читает оставшееся как «исходное» и теряет настоящее (`Off` не вернуть) — воспроизведено на фейке.
- Процессы, поднятые после смены рецепта (full-replace), пишут в другой каталог логов (`logs/prototype_2/`), не в `INSPECTOR_LOG_DIR` стенда: при разборе искать там же.
- Скрипт стенда записывает активный рецепт в `multiprocess_prototype/app.yaml` (`[run] активный рецепт записан в манифест`): после стенда вернуть файл.

**Как применять.** Режим съёмки пишется в камеру декларативно и полностью при КАЖДОМ старте (включая `Off`), возврат при остановке — попытка, не гарантия; рецепт, который пишет режим, не ставить в `pipeline` по умолчанию (владелец 2026-10-17: два рецепта, `qr_reader_sdk_dual_selftrigger` запускают вручную). Проект — `docs/design/camera-device-service.md`. Проверка возврата — только на камерах. Связано: [[project_code_reader_selftrigger_period_sets_the_fps]].
