Ф8.2 (2026-08-07): `_last_pass` обязан хранить ТАЙМСТАМП, потому что поле читают два
механизма — оконный предикат и уборка по возрасту. Инъекция «класть индекс окна»
(`floor(now / interval)`) должна была покраснить стража роста
`test_lazy_prune_bounds_growth_under_unique_path_stream`. **Все 18 тестов уборки и flush
остались зелёными.** Причина: страж берёт `interval = 1.0` и целые секунды на часах, а при
таких числах `floor(now / 1.0) == now` — две противоположные реализации совпадают
поэлементно. Тест на интервале 0.05 краснеет сразу.

**Why:** тест различает реализации только там, где они дают разные значения. Круглые
числа (1.0, целые секунды, степени двойки) — именно те, на которых формулы схлопываются.
Зелёный такой тест читается как «свойство защищено», хотя он не смотрел на свойство вовсе.

**How to apply:** выбирая константы теста, спросить не «удобно ли читать», а «на этих ли
числах кандидатные реализации РАСХОДЯТСЯ». Для арифметики — брать интервал, не кратный
шагу часов, и время, не кратное интервалу. Если инъекция не покраснила ожидаемый тест,
первой гипотезой ставить совпадение констант, а не слабость теста.
