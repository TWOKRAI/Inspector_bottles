Владелец рассматривал публикацию `multiprocess_framework` на PyPI под именем **gorynych** (имя свободно на PyPI по состоянию на 2026-07-20, проверены также pygorynych/zmey/trigolov — свободны). Идея **отложена** после обсуждения.

Триггеры для возврата к идее (все три):
1. Вопрос прав на код решён с работодателем письменно (фреймворк развивался в рабочем проекте — ст. 1295 ГК РФ «служебное произведение»; публиковать без письменного «ок» нельзя).
2. Появилось второе приложение-потребитель фреймворка (сейчас единственный потребитель — multiprocess_prototype).
3. Прототип работает в проде, API фреймворка перестал меняться еженедельно.

Нюанс: PEP 541 запрещает резервирование имени на PyPI пустым пакетом — «застолбить README» не даёт гарантии владения именем.
