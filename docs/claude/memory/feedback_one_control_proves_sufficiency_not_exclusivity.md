Один контроль, который возвращает старое число сменой одного фактора, доказывает, что этого фактора достаточно.
Он не доказывает, что второй фактор не влияет. Для фразы «дело в A, не в B» нужен перекрёстный контроль: B меняется
при плохом A. Плюс контроль «нет ни того, ни другого» — он показывает, к какому числу система идёт без обоих.

Случай (layer-render Task 6.4, 2026-10-02). A7: старая формула выреза 8.59°, новая 37.74°. Мой контроль: новая сторона
+ `replicate` → 6.78°. Я написал «сдвиг дала чёрная заливка, не формула стороны». Ревьюер опроверг перекрёстными
вариантами: чёрная заливка на старой стороне 20.4°, на новой 42.2° (сторона влияет — задаёт ширину заливки); медиана
рамки 21.2° (дело не в чёрном цвете); без заливки вовсе 16–18° (хорошее старое число — свойство `replicate`, не норма).

**Why:** уверенное неверное объяснение переживает баг (CLAUDE.md: «Never write … cannot … without a reproduction») —
одна контрольная строка выглядит как воспроизведение, но закрывает только половину фразы.

**How to apply:** прежде чем писать «X, а не Y» — сетка 2×2 по двум факторам плюс «ни того, ни другого»; N малое —
писать «наблюдение». Связано: [[feedback_a_number_without_spread_across_repeats_is_an_observation]],
[[feedback_the_plans_stated_cause_is_a_hypothesis]], [[feedback_plausible_is_not_verified]].
