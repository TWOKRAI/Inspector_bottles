Ф2.4: тест однократности слал три ОДИНАКОВЫЕ записи, а детектор зовётся с промаха
кэша маршрута (ключ — тройка «скоуп-уровень-источник»). Сигнал был бы один и без
дедупликации — свойство сторожил кэш, а не тест. Вскрыто инъекцией (снять дедупликацию
→ тест остался зелёным); чинится вариацией уровня.

**Why:** «повторил вызов — сигнал не повторился» выглядит доказательством
идемпотентности, хотя доказывает лишь наличие кэша. Тот же класс, что вакуумный тест,
сравнивающий значения после сброса при неизменной таблице.

**How to apply:** прежде чем писать тест на «ровно один раз», выяснить ключ ближайшего
кэша на этом пути и варьировать вход ПО ЭТОМУ КЛЮЧУ — иначе проверяется кэш.
