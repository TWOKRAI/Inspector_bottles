Правило «фейковая оснастка доказывает оснастку» применяется не только к юнит-тестам.
**Стенд с вердиктом — это тоже оснастка**, и если приёмником данных выступает наш
собственный код, живая приёмка подтверждает нашу же догадку о форме.

**Замер (otel-export, Ф2, 2026-09-07).** Task 2.1 и 2.2 закрылись «живой приёмкой 10 из 10»
при том, что до внешнего потребителя не доехало **ничего**. Приёмником была своя заглушка
на `http.server`, отвечавшая 200 на POST по ЛЮБОМУ пути. Настоящий `otelcol` 0.158.0 на том
же адресе отвечал **404**: SDK шлёт по явно заданному endpoint дословно, путь `/v1/logs`
дописывается только на дороге переменной окружения. Счётчик `exported` рос, `export_failed`
кричал правду — но услышать её было негде.

**Числа, которые делают урок проверяемым:** 102 теста из 214 пинили форму адреса, не
доставившую ни одной записи. Инъекции поймать этого не могли **по построению** — они
проверяют, что код делает то, что утверждают тесты, а ни один тест не утверждал «доезжает
до настоящего потребителя». Нашлось случайно: критерий соседней задачи требовал файл
настоящего коллектора.

**Why:** зелёный набор и живой стенд создают ощущение доказанности, которое ни один из них
не даёт по отдельности, когда оба замкнуты на нас же. Дефект жил бы до финальной приёмки.

**How to apply:**
- у каждого механизма, чей результат уходит НАРУЖУ (сеть, файл чужого формата, чужой
  протокол), приёмка обязана хоть раз пройти через **внешнего** потребителя — не свой
  сервер, не свой парсер, не свою заглушку;
- поставляемый конфиг (yaml топологии, пример из README) обязан иметь сторожа: заплата
  «вернуть старое значение» должна давать красный. Проверить числом — до задачи давало 0;
- заглушка приёмника, принимающая всё, — не приёмник, а зеркало. Если она нужна для темпа
  (быстрый отказ, 401), пусть будет, но вердикт о доставке выносит настоящий арбитр.
