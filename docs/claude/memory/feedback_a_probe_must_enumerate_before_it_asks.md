Справочник, спрошенный про **несуществующее имя**, отвечает пустотой — той же самой, что
и про существующее имя без содержимого. Два разных факта приходят одним значением, и
зонд молча выдаёт неверный вывод.

Замер 2026-08-18 (S-25): я спрашивал `sys_config.defaults_for_category()` про категории
`sources` и `utility`, получил пусто и записал в докстринг «у этих категорий per-category
defaults нет». Таких категорий **не существует вовсе**. Реальные: `source` — пять ключей
и она в 17 рецептах из 17, `processing` — один, `output` — один, у остальных шести нет.
Вывод («тест зелен тривиально») уцелел, объяснение — нет. Нашло ревью.

**Правило:** прежде чем спрашивать справочник про имя, **перечисли населённое множество**
из самих данных (`grep` по рецептам/конфигам), и только потом спрашивай — по именам из
списка. Один лишний вызов против уверенного неверного объяснения в докстринге, который
переживёт баг.

Тот же класс, что [[feedback-unconnected-driver-reads-as-a-clean-zero]]: подтверждающий
ноль засчитывается только в паре с контролем, дающим ненулевое. Здесь контроль — сам
перечень. См. также [[feedback-plausible-is-not-verified]].
