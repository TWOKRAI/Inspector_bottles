Ловушка: ревью C-64 р.1 попросило не запоминать провода с прежним статусом `broken` и `None` (фильтр в `_wire_statuses_for`). Правка верная, но вход H7 как раз был `broken`: теперь он отсекался фильтром, а условие `info.get("status") == "broken"` в `_restore_wire_statuses` никто не проверял.

Замер: до правки мутант «условие → True» красил H7; после правки тот же мутант дал 20 passed, 0 красных. Поймал только повторный мутант ревьюера на р.2. Лекарство: H7b с прежним статусом `pending`, мутант снова красит (1 failed, 21 passed).

**Why:** матрица инъекций верна для кода, на котором её прогнали. Сужение входа не ломает ни один зелёный тест, поэтому гейт молчит.

**How to apply:** правка добавляет фильтр или ранний выход перед уже защищённым условием → снова прогнать инъекцию этого условия и назвать, какой тест её красит; соседний случай: [[feedback_a_guard_that_counts_at_least_once_is_blind]].
