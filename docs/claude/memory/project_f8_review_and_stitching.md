Внешнее ревью Ф8 (Fable, 2026-08-08): **8.0/10, GO**, блокеров нет. Отчёт:
`docs/reviews/2026-08-08_f8-review.md`. Обязательное условие: **M-1** (схлопывание
аудита ломается при отказе стока — `document_failed`/`document_error` не в
`_AUDIT_OWNED_FIELDS`) чинится ВНУТРИ 8.5 до сшивки.

**Вердикт по развилке сшивки — вариант B:** фабрика по import-path из конфига
(`observability.documents.factory`), `wire_document_sink` в `observability_wiring.py`,
фреймворк сшивает аудит себе сам (прецедент `wire_observability_store`,
`process_module.py:409-424`). A (generic-хук) / C (существующий шов) / D (плоскость во
фреймворк) отвергнуты с причинами. Замер конкуренции подтверждён дважды: 300/300 при 6
писателях — прямая запись годится, посредник не нужен, но WAL+busy_timeout задать явно
(m-2: сейчас держится на дефолте sqlite3 timeout=5s).

Спека исполнения — врезка Task 8.5 плана `observability-unified-routing` (контракт,
Р-8.5-А…Г, задачи 8.5a–8.5g, таблица разведанных точек врезки). Вердикты выделены в
**8.7** (перенос истории action_log — решение владельца). **Механика 8.5 и ADR Ф8.4 —
переданы в отдельный чат (Opus-модель), решение владельца 2026-08-08.**

Долги из ревью: `worker.pause_all` на gui — самозапирающаяся ловушка (командный насос

(реально 57/60 на квантованных часах — смягчить докстринг).
