**Ф8 закрыта 2026-08-09.** Внешнее ревью (Fable, 2026-08-08) дало 8.0/10, GO; отчёт —
`docs/reviews/2026-08-08_f8-review.md`. Обязательное условие **M-1** выполнено ДО сшивки.
Итог фазы — **ADR-PM-028** (`modules/process_module/DECISIONS.md`), это же и есть Ф8.4-ADR.

**Что построено (Task 8.5, вариант B ревью).** Второе правило допуска: у документа свой
приёмник (`IDocumentSink.append(dict) -> bool`) и свой срок per-kind ПО ВРЕМЕНИ; допуск от
severity не зависит вовсе. Реализация адресуется **строкой из конфига**
(`observability.documents.factory` → `Services.documents.wiring:make_document_sink`),
фреймворк резолвит её importlib и проверяет результат СТРУКТУРНО (`callable(obj.append)`) —
импорта `Services` во фреймворке не появляется. Сток есть у КАЖДОГО процесса, не только у
пилота hub'а; уборка — на такте heartbeat, не чаще `purge_interval_sec`.

**Ключ читается из разрешённых слоёв, а не из своего поля `proc_dict`** — поэтому оба
конструктора `BlueprintAssembler` (boot + switch) не правились, и ловушка спеки исчезла.
См. [[feedback-read-the-key-from-the-section-already-travelling]].

**Живая приёмка (webcam_sketch, headless):** `config.reload` на ребёнке `seg` и на
оркестраторе `ProcessManager` → 4 документа в `data/documents.db`, каждый называет
процесс-источник; `journal_mode=wal`; **рестарт `seg` (pid 24816 → 21168) документы
пережили** — «когда и где включили DEBUG» отвечается запросом, не grep'ом. Файл БД лежит
ВНЕ каталога логов, поэтому их ротация его не касается.

**Гейты:** фреймворк 7067 passed / 6 skipped; инъекции **9/9 красные по предсказанию**
(откат — восстановлением файла). Независимый tester (получил только приёмку) принёс две
настоящие находки: WARNING без адреса ключа во ВТОРОЙ ветке отказа и седьмой случай
«тестов-невидимок». См. [[feedback-post-publication-mark-breaks-collapsing]].

**Цена, названная числами:** `append` зовётся синхронно из пути смены конфигурации; под
конкуренцией 6 писателей медиана 3.6 мс, p95 82 мс, **max 928 мс**, потерь 0/300. Терпимо
потому, что документы редки; клиент чаще единиц в секунду → бюджет пересчитать.

**Открыто:** **8.7** (вердикты как второй клиент — дорога уже есть, `svc.document_sink`;
перенос истории `action_log` — решение владельца), **8.6** отложена владельцем (пока не
исполнена, соответствие модели записи OTel остаётся ЗАЯВЛЕННЫМ, а не доказанным).
**Долги:** `worker.pause_all` на gui самозапирается; `ObservabilityStore` без ретеншена
растёт вечно. ~~Гейт на Services/Plugins~~ — ЗАКРЫТ 2026-08-09 решением владельца: оба слоя
в корневом `testpaths` (1937 passed / 48 с), страж
`test_services_and_plugins_test_dirs_are_collected` считает покрытие по префиксу.

**Дополнение 2026-08-09: 8.7 ЗАКРЫТА, ADR-PM-029.** Плоскость работает на ДВУХ клиентах.
Дорога приложения — `PluginContext.write_document(kind, summary, /, **fields)`; сток
остаётся ОДИН на процесс (`svc.document_sink`), второго механизма не заведено. Писатель —
`Plugins/control/robot_control`, документ рода `verdict` с порогом решения в payload.

**Вердикт пишется на ФРОНТЕ pass→reject**, не на каждом кадре брака: `append` синхронный
(3.6 мс медиана / 928 мс max) при бюджете кадра 16–40 мс. Живой прогон: **95 кадров брака
→ 1 документ**, 3163 инспекции, `verdicts_written=1` через `get_stats`, в БД `audit: 4 /
verdict: 1` — один файл на оба рода; пережил смерть всех процессов. Инъекции **14/14 по
предсказанию**; фреймворк 7087 passed, Services+Plugins 1959 passed.

Две находки вне постановки: [[guard-must-be-reachable]] (TypeError на линии вместо
защиты) и [[port-wire-is-not-a-process-route]] (плагин не вызывался ни разу, молча).
Правило «вердикты о качестве в диагностические логи не пишутся» — СНЯТО.
Независимый tester пропущен: субагенты в сессии выключены (объявлено в плане).

**Осталось по плану:** 8.6 отложена владельцем; Ф5.2, Ф5.4, Ф5.1-остаток; долги ревью.
