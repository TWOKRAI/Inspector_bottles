**line_sim («Виртуальная линия»)** — симулятор участка линии для отладки инспектора без
железа. Видение согласовано владельцем 2026-08-13, лежит в `plans/line-sim/vision.md`
(+ vision.html с рисунками; артефакт 0fc2df17-e1b0-4dc5-8366-7d0f19637e80). План создан
2026-08-13: `plans/line-sim/plan.md` + phase-1…6 (Ф0–Ф6, 19 задач, vertical slice в Ф1);
ветка feat/line-sim (worktree `.claude/worktrees/line-sim`, от main — НЕ от
telemetry-stage6). Находка кода: в hikvision_letter_robot датчик — зрение (line_filter),
Modbus-датчика в devices: нет → в v1 отдельный регистр датчика не строится; энкодер
робот→line — канал StateProxy, не второй Modbus-клиент.

Решения владельца: первый пресет — **буквы-диски** (реальный стенд SCARA есть для
сверки), бутылки — следующий проект; движок универсальный (объект = группа слоёв:
статика/аугментация/дефект); ~~v1 — встроенная в прототип сборка~~ — **ОТМЕНЕНО
2026-08-31**, см. ниже; функция правды (паспорт объекта → оценка вердиктов) — в v1; виртуальная
камера настраивается (fps/размер/цвет); **рецепты общие с инспектором** (сим-секция
опциональна в том же YAML); **спрайты из реальных фото** через прототип (боевая камера →
realcut → каталог пресета; для дисков cut_real_disks готов, каталог общий с dataset_gen); **максимум переиспользования** — сначала готовое из framework/Services/Plugins, запертое в прототипе выделяется в сервис/плагин (carve-out), не копируется.

Ключевые инварианты: **один объект → одна команда роботу** — главная метрика v1 (мир
примерный — достаточно); энкодер ленты — ОДИН модуль правды на линию и робота (иначе
молчаливый дрейф); дорешено 2026-08-13: робот ОТДЕЛЬНЫМ процессом, сим-секция опциональна В ТОМ ЖЕ YAML, ПЧ/датчик через MODBUS-ФАСАД где боевой тракт ходит по Modbus; ядро без Qt/Modbus-импортов (принцип RobotSimCore); тайминги честные
(урок sim-monitor: «мгновенный» робот прятал дефект трёх заданий).

**Форма пересмотрена владельцем 2026-08-31 — это главное, что устарело выше.** Симулятор —
**автономный сервис со своим процессным деревом** (свой SystemLauncher → ProcessManager, свой
рецепт), то есть второе приложение на том же фреймворке. Прототип о нём не знает и стыкуется
только по внешним протоколам: робот/ПЧ — Modbus TCP (меняется лишь host/port в `devices:`).
Отменены: секция `sim:` в боевом рецепте и source-плагин внутри прототипа. Ф1 и Ф6 плана
написаны под старую форму и требуют переписывания до старта.

**~~Развилка кадров НЕ решена~~ — ЗАКРЫТА владельцем 2026-09-20, вариант (а): MJPEG из сима → боевой `camera_service`, тип `stream` (phase-1 Task 1.2). Прежний текст развилки:** (а) MJPEG/RTSP-поток + ~20 строк
в боевой `capture` (учится принимать URL) либо (б) `pyvirtualcam`. Оговорка: тракт Hikvision
(MVS SDK через ctypes) не эмулируется ни тем, ни другим.

**Ред. 3 плана / ред. 5 видения — 2026-09-21 (главное на сегодня).** Владелец уточнил идею:
симулятор — отдельный сервис из РАЗНЫХ УСТРОЙСТВ, которые дополняются, комбинируются и
взаимодействуют по боевым протоколам; доработку формулировки делегировал («сделай как лучше,
мои идеи можно менять»). Записано: **стенд из моделей устройств**. Устройство = ядро без
транспорта в `Services/` + плагин-хост в `Plugins/sim/`; каталог = реестр плагинов, комбинация =
`pipeline.yaml`, взаимодействие = общий мир в `StateProxy` (`sim.*`), события, которые нельзя
терять, — сообщениями. **Нового механизма и базового класса устройств НЕ вводим** — общая база
хостов появится со вторым Modbus-хостом. Лента — отдельный класс `BeltDrive` (Task 2.1), фасад ПЧ
остаётся в регистрах робота (на стенде ПЧ стоит за мостом). Правило одной карты регистров:
адреса mailbox ПЧ жили двумя копиями (`sim_core.py` и `gd20_bridge.yaml`) — контракт-тест.

**Находка сверки: Ф5.2 ред. 1 была несовместима с автономной формой** — везла паспорт в

Замена: **правда на проводе внутри сима** — задание роботу несёт `job_x/job_y/job_ecap`, по ним

целиком» оказалось неверным: Ф2 переписана, 3.4 и 5.2 переписаны, 3.5/5.4/5.5 новые; Ф4 и Ф6

Modbus): дубли рождаются на повторах после таймаута, устроить его по заказу умеет только сим.

счётчик «для людей» в дереве мира — обход порта. Урок: ред. 3 утром того же дня повторила
ошибку тестера Task 1.1 (`record_metric` + запрос по имени) — чужой арбитраж надо читать до
