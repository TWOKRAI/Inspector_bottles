Заглушка `SubPluginContext` (этап 6, задача 1.1) была поставлена ОДНОЙ функцией на четыре дороги
с доводом «сигнатуры совпадают по форме». Довод неверен: у эталона (`StatsManager`) параметр
таймингов зовётся `duration`, а у gauge/histogram значение обязательно и дефолта не имеет.

```
SubPluginContext().record_timing("frame", duration=0.016)
TypeError: _noop_stat() got an unexpected keyword argument 'duration'
```

Заглушка, поставленная РАДИ безопасности вызова без родителя, сама роняла линию. Тест автора рядом
звал её **позиционно** (`fn("проверка", 1)`) и был зелён — он подтверждал согласие автора с
собственной моделью, а не с контрактом. Нашёл независимый tester, писавший от критериев приёмки.

**Why:** «совпадают по форме» — это утверждение об арности, а вызывающий пользуется ИМЕНАМИ.
Позиционный вызов проверяет только первое. Оракул сигнатур у меня был, но покрывал фасад и не
покрывал дефолты суб-контекста — страж, не дотянутый до всех реализаций контракта, оставляет
непокрытую.

**How to apply:** к каждой заглушке/дублю/фасаду, объявленному «дословно как эталон», ставить пару:
(1) оракул `inspect.signature` против эталона — **по всем** реализациям контракта, не только по
главной; (2) вызов **именованными** аргументами. Инъекция «вернуть прежнюю форму» обязана красить
поимённо. Связано: [[feedback_test_authorship_three_roles]],
[[feedback_zone_guard_never_closes_the_class]], [[feedback_fake_that_always_succeeds_mutes_the_gate]].
