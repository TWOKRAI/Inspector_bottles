**Замер 2026-08-27, `graphify label . --batch-size=25 --backend=claude-cli`:**
53 вызова съели почти весь дневной лимит владельца. Полезной нагрузки в задаче
было на 1316 коротких имён сообществ.

**Почему так дорого — платит не задача, а обвязка.** `claude-cli` это не
API-вызов, а **полноценная сессия Claude Code на каждый батч**. В каждую грузится:

```
  ~1 462 токенов  ~/.claude/CLAUDE.md
  ~6 869 токенов  CLAUDE.md
  ~5 516 токенов  .claude/CLAUDE.md
  ~8 599 токенов  MEMORY.md
 ~22 400 токенов  только файлы контекста
 + системный промпт, схемы инструментов, списки скиллов и агентов
```

Порядка 45–50k токенов на вызов **до первого байта полезных данных** (вторая
половина — оценка). × 53 вызова ≈ 2.5 млн входных токенов чистых накладных.

**Рычаг стоимости здесь ОБРАТНЫЙ интуиции.** Я снизил `--batch-size` со 100 до 25,
чтобы починить качество, и этим перевёл 14 вызовов в 53 — утроил ровно ту
величину, которая и стоит дорого. Мельчить батчи у такого бэкенда = умножать
накладные. Батч больше, вызовов меньше.

**Оценка «~110k входных» промахнулась в ~20 раз**, потому что я считал как голый
API-вызов: полезные данные плюс короткий промпт. Считать надо иначе:
`вызовов × ~50k` — и озвучивать это ДО запуска, а не после.

**Модель выбирает не вызывающий.** Порождённый CLI берёт умолчание из
`~/.claude/settings.json` — на замере это была `claude-fable-5[1m]`, вариант с
миллионным контекстом. Ни ключом, ни флагом инструмента это не задавалось.

**Неочевидный побочный эффект: загруженный контекст меняет ВЫВОД, а не только
цену.** Каждая порождённая сессия прочитала проектный `CLAUDE.md` со строгим
правилом «весь вывод на русском» и вернула имена сообществ по-русски
(«Каналы Modbus-драйвера» вместо «Modbus Channel»). Побочно это сломало
лексическую метрику сверки имён с англоязычными путями — сравнение «до/после»
стало невозможным, гипотезу проверить не удалось. То есть накладные — это ещё и
поведение, а не только счёт.

**Как применять.**
1. Перед любым инструментом с `--backend=claude-cli` (или который в цикле зовёт
   `claude`) — посчитать число вызовов и умножить на ~50k. Назвать число вслух.
2. Дешевле: `ANTHROPIC_API_KEY` + прямой API-бэкенд (сессионных накладных нет),
   либо МАКСИМАЛЬНЫЙ batch-size, либо локальная генеративная модель в Ollama.
3. Спросить, нужен ли результат вообще. Имена сообществ graphify — удобство;
   `god_nodes`, `shortest_path`, `get_neighbors`, `query_graph` от них не зависят.
4. Долгий прогон такого бэкенда — только с явного согласия и с озвученной ценой.
