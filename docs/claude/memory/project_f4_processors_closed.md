Фаза Ф4 плана `observability-unified-routing` закрыта **целиком** (2026-08-05).
Шесть задач: механизмом закрылись три (4.1 цепочка `89a9a5d2`, 4.2 единая
эмиссия, 4.5 редакция `b0585c60`), три — сносом или одной строкой (4.6
`c23147d8`, 4.4 `416a0b89`, 4.3 `4ea08949`).

Что теперь есть в фреймворке:

- **`contextualize(**fields)`** — функция модуля `logger_core`, безопасная дверь
  к форточке `log_context` (пересоздание значения + возврат по токену).
  `frame_trace.log_correlation` на неё мигрирован. `bind()` **отклонён**
  решением владельца: прод-потребителей ноль, потоковый случай закрывает
  `push_context`.
- **`SecretRedactor`** (`logger_module/core/redaction.py`, ADR-LOG-006) —
  регистрируется в конструкторе `LoggerCore`, поэтому работает на **обоих**
  менеджерах и с первой записи процесса. Выключателя нет. Маскирует `extra` по
  точным именам ключей и текст сообщения (трейсбеки `log_exception` едут
  именно туда, включая пароль внутри URL). Отказ — fail-closed. Счётчики
  `records_redacted` / `redaction_failures` в `get_stats` и
  `PLANE_COUNTER_KEYS`. Цена: **+2.16 мкс на запись**.

Дальше по плану остаются Ф2.2–2.7 (иерархия адресации), остаток Ф3, Ф5 (5.1
остаток, 5.2, 5.4), Ф6, Ф7/Ф8. Ф7.1 (сэмплинг) — следующий заявленный
потребитель цепочки; он встанет ПОСЛЕ редактора и увидит уже замаскированное.

Долг, замеченный по ходу и не относящийся к Ф4:
`state_store_module::test_100_subscriptions_1000_matches_under_50ms` —
wall-clock бюджет, краснеет под нагрузкой (139 мс при пороге 100), изолированно
зелёный. Он в дефолтном гейте и будет случайно ронять сборку.
