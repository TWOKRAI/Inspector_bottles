Окна машины ключуются именем сессии. После перезапуска имя другое, прежнее может достаться чужой сессии, а фоновый прогон
продолжает идти без уведомления («didn't finish before the previous session ended» не значит, что процесс умер).

**Замер (2026-11-27).** Уведомление: фоновая команда не закончилась. `machine.lock`: окно под старым именем; `backend.log`
прогона обновлялся секунду назад. Второй запуск наложился бы на первый.

**Как применять:** прочитать `machine.lock` и время логов; живой прогон дождаться, затем `release <старое имя>`; координатору
назвать новое имя. Отдельно: окно стенда агента, кончившееся без `release`, держит очередь всех полос — в брифе стенда
требовать `release` сразу после последнего замера.
