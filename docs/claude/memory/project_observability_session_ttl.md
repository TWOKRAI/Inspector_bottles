Закрыта 2026-07-28 (ветка `feat/observability-unified-routing`), закрывает
резидуал R1 задачи 5.12 и инцидент «включил DEBUG и забыл» (messages.log 645 МБ).

**Решение: L3 временный ПО ПОСТРОЕНИЮ.** Срок несёт КАЖДАЯ запись сессии (дефолт
`session_ttl_sec` = 300с, ключ живёт в тех же слоях: L1 — политика машины, L2 —
политика конвейера, `0` = бессрочно явным решением). Опциональный срок инцидент
не закрыл бы: кто забыл про DEBUG, забыл бы и про `ttl`. Постоянной правку делает
ровно ОДИН путь — `observability.persist` (переезд в L2, где вечность обеспечена
файлом). Второй политики («эта правка шумная, а эта нет») нет сознательно.

**Исполнитель — такт heartbeat, не свой поток:** такт идёт в каждом процессе
(`ProcessManagerProcess` не переопределяет `run`), умирает вместе с процессом и
уже несёт дренаж hub'а / health / pump GC. Цена названа: срок — это срок, а не
таймер, возврат не позже `ttl + heartbeat_interval` (живьём +4.6с и +0.1с при
такте 5с). Процесс без heartbeat отвечает `ttl_enforced: false` с причиной.

**Грабли, которые ловить в соседних задачах:**
* мутация `layers.session` двумя шагами (read-modify-write) обязана идти под
  `layers.lock` целиком — иначе подметальщик в зазоре ВОСКРЕШАЕТ просроченный
  ключ уже без срока, а журнал успевает объявить возврат (блокер ревью);
* срок на пути-РОДИТЕЛЕ при истечении сносит всю ветку — отчитываться надо
  листьями (`session_reset_keys`), иначе сроки-сироты висят в readback'е;
* `ttl` неприменим к файловому `config.reload`: файл владеет бессрочным L1.

Резидуалы: запись о возврате идёт в журнал процесса, но не в `ObservabilityStore`
(→ 8.3); `logger.sink.*` не умеет продлевать срок (→ 5.10).
