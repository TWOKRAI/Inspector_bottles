Два теста аудита писали `{"metrics": {"fps": True}}`. Короткой формы у `MetricRule` нет:
получатель падает на ней валидацией, `resolve()` спросил бы у `bool` поле `enabled`. Тесты
всё равно были зелёными — в их харнессе `heartbeat` отсутствует, применять секцию **некому**,
и мусор просто лежал в слое. Предмет тестов (аудит) при этом верный; неверен был вход, и
покраснели они только когда форму начал судить валидатор на границе записи.

**Why:** отсутствующий получатель выглядит как безобидное упрощение фикстуры — «нам нужен
только слой». Но вместе с получателем исчезает единственный, кто знает форму, и тест
превращается в **образец того, как звать нельзя**. Хуже: такой тест потом цитируют как
документацию входа.

**How to apply:** если фикстура ставит адресата в `None`, форму входа брать из схемы
получателя (или из живого конфига), а не сочинять короткую. Проверка дешёвая: прогнать тот
же вход через `Model.model_validate` — если он не проходит, тест зелен по отсутствию, а не
по правильности. Связано с [[feedback_fake_that_always_succeeds_mutes_the_gate]],
[[feedback_test_authorship_three_roles]], [[feedback_plan_spec_can_lie]].
