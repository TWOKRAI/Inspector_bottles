Правило, исполняющееся в нескольких точках (у `still_relevant` в ready-gate их
ТРИ: вход, срезы цикла, пост-ожидание; у Р1 в 5.13 — ранний выход на обеих
формах), при частичной инъекции остаётся живым: тесты зелёные, и это читается
как «гарантии не существует» — ложная находка класса B1. Стреляло ДВАЖДЫ:
I-F (ревью 5.13) и I-7 (сквозное ревью Ф5, 2026-08-01 — снял 1 точку из 3,
18 passed; полная инъекция → 3 честных падения).

**Why:** частичная инъекция измеряет не гарантию, а полноту самой инъекции;
вывод «зелено под сломом» без пересчёта точек обвиняет тесты незаслуженно.

**How to apply:** перед инъекцией grep-ом пересчитать ВСЕ вхождения проверки
(та же строка/вызов встречается больше раза — снять все разом); расхождение
с прогнозом сначала объяснять неполнотой инъекции и только потом слабостью
тестов. Связано: [[feedback_test_survived_its_own_break]],
[[feedback_predict_injections_after_writing_tests]].
