Правило перенесено в `.claude/CLAUDE.md`, пункт «Break-injection is the proof» (2026-10-04). Ниже — доказательная база урока.

2026-07-30, задачи 5.13/5.6: **три слом-инъекции из семи разошлись с
предсказанием** (6 вместо 5, 4 вместо 3, 3 вместо 2). Причина каждый раз одна:
ожидания считались до того, как в файл добавлялся ещё один тест, который тоже
ходит по ломаемому пути.

**Why:** правило «назови ожидаемый набор ДО прогона» защищает от подгонки
объяснения под результат. Но названный набор, посчитанный по неполному файлу,
даёт расхождение по МОЕЙ арифметике — и оно маскирует расхождение по существу,
которое тем же способом ловится.

**How to apply:** порядок такой — дописать ВСЕ тесты → перечитать список
собранных (`--collect-only`) → назвать ожидания → гнать инъекцию. Расхождение
после этого означает дефект теста или кода, а не мою невнимательность. Если
расхождение всё же вышло — назвать его вслух и объяснить причину, а не молча
принять «упало больше, значит покрытие лучше».
