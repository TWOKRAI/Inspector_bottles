T1 приёмка 2026-10-07: минутная строка `gc-policy` печатает кумулятивные `max_gen0`/`max_full`. Soak на час доказывает лишь «не выше стартового пика», а не порог устойчивого режима: всё, что ниже стартового максимума, строка не покажет.

**Why:** пробой 1 млн контейнеров за один колбэк на главном потоке дал gen0 34 мс при тике 1.0 с и 37 мс при 0.1 с — пауза пропорциональна объектам, выделенным синхронно между тиками, а не интервалу.

**How to apply:** периодическая строка отдаёт максимум за окно (с прошлой строки); порог устойчивого режима проверяют по окну, а не по кумулятивному числу. Тяжёлую синхронную работу на главном потоке лечит вынос с потока или порции, не частота тика.
