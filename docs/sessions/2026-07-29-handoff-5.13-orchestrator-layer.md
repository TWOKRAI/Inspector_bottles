## Грабли сессии (стоили времени)

1. **Первая редакция зонда дала три ложных провала A5** — обратный switch отклонялся
   дебаунсом hot-swap (`{'debounced': True}`), то есть не состоялся вовсе. Проверка,
   принимающая неслучившееся действие за отрицательный результат, **обвиняет продукт**.
   Лечится паузой ≥3с между switch'ами.
2. **`git checkout -- <file>` для отката слом-инъекции** — снёс бы всю несохранённую работу
   шага. Откатывать заплату точечной правкой. Отказ разрешения это поймал.
3. **Heredoc шелла съедает `\n`** в python-строках — правки тестов делать файловыми
   инструментами, не через `<<'PY'` с экранированием.
4. **Формат спутника** — корневой ключ `observability:`, внутри та же форма, что у секции
   рецепта. Мой тест писал без него и падал (тест, не код).
5. **Логи PM** — в `logs/<recipe>/ProcessManager/`, не в `INSPECTOR_LOG_DIR`.
6. **`topology.replace` не существует** — команда называется `topology.apply`, аргументы
   `{topology_dict, recipe_path}`.
