     `_own_work` :416; докстринг «закрываются раньше воркеров, LIFO»).
  2. PM: `summary` и `children` переехать из `_own_work` (`process_manager_process.py:3537-3543`) в `_own_work_late`,
     порядок прежний. Закрытие `work` PM: `children → summary → workers (message_processor) → watcher'ы → state_store →
     plugins → hooks`. Фаза 1 корня прежняя (`_WorkersStop.request_stop` пустой). У обычного процесса порядок прежний.
  3. В фазе детей `message_processor` исполняет команды; спавн после системного стопа отказан (ADR-PMM-030, :3610) —
     REDS 3 проверяет `process.restart`.
  4. GUI: новый `frontend/shutdown/close_coordinator.py` (+ `__init__.py`), `CloseCoordinator`: `RUNNING → CONFIRMING →
     STOPPING → CLOSING`, Qt-родитель — окно (G6). `MainWindow.closeEvent` (`main_window.py:286-297`): не `CLOSING` →
     `event.ignore()` + `request_close()`; `CLOSING` → как сейчас. `request_close()`: `confirm_discard_topology_changes`
     («Отмена» → `RUNNING`) → `process_manager_proxy.shutdown_system()` (:112) → `QProgressDialog` окно-модальный без
     отмены → `QTimer` 250 мс: `supervision.status` через `RequestRunner` + `command_sender.request_system_command`
     (образец `process_manager_proxy.py:154-158`). Все дети, кроме `process.name`, `alive is False` → `CLOSING` → `close()`.
  5. Safety-таймер (`app.py:1115-1128`): 1000 → 200 мс; `app.quit()` только через `coordinator.commit_close()`
     (`CLOSING`, затем `quit`). Общий `process._get_system_stop_event()` (`process.py:329`) взведён при `RUNNING` →
     `STOPPING` без вопросов. Комментарий `app.py:1120-1126` переписать.
  6. `GuiProcess.run` (`process.py:305-327`): флаг координатора `shutdown_sent` → `_request_system_shutdown` не зовётся.
     Нет ни одного ответа `supervision.status` за 2,0 с после команды → `set()` общего события + WARNING «PM не ответил
     за 2,0 с — взвожу system_stop_event» (вопрос владельцу 4).
  7. Журнал `gui` (INFO): «закрытие: подтверждено», «закрытие: system.shutdown отправлен», «закрытие: все процессы
     остановлены (N), закрываю окно», «окно скрыто».
  8. ADR `ADR-PMM-0xx` (следующий после 038) в `process_manager_module/DECISIONS.md`, ссылкой на ADR-PMM-036 — 7-й файл с
