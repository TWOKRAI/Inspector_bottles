# C-86(а) — диск ниже порога сбрасывается без строки журнала

Заведено 2026-11-11 лидом приёмки α по решению владельца (запись 19 `amendments.md`). Владелец кода — полоса С (`Plugins/processing/word_layout`). Лид приёмки код не пишет. Точность сети на «М» (C-86 б) сюда НЕ входит: это ORDER #27.

## Проблема
Спека `design.md` §2.3 (решение 25 R2): запись в журнал на КАЖДЫЙ диск. Факт приёмки α: диск «М» поданного набора не оставил строки у `layout` (B: 11 строк из 12, `slots_filled 8`, `done false`; D: 1 из 3 прогонов). Правдоподобная причина по коду, не воспроизведена: `WordLayoutPlugin._top_pred` (`plugin.py:481-495`) возвращает `None` без записи, когда `top.below_threshold` (`:489`) или `confidence < min_confidence` (`:492`). Каскад: «было заполнено 8/9» в строке смены слова, `jobs_emitted` ниже литералов.

## DESIGN
- Каждый диск, дошедший до `word_layout`, оставляет ровно одну строку журнала: решение и причина. Для сброса — «пропуск: уверенность ниже порога (<label> <confidence> < <порог>)» в том же формате и с тем же ключом дедупликации, что у «пропуск: ячейки заняты» (`plugin.py:283-287`, `_logged_skip_key`).
- Строка пишется один раз на диск (`track_id`), не на каждый кадр того же диска; повтор того же `track_id` не дублирует.
- Поведение не менять: порог остаётся, решение (диск не берётся) то же, `jobs_emitted` и ячейки те же. Менять только наблюдаемость.
- Диск, у которого нет предсказания вообще (`pred is None` из-за пустого списка) — отдельная строка с причиной «нет предсказания», тоже один раз.
- Литерал строки согласовать с `design.md` §2.3/§2.4 через `amendments.md`, если формат отличается; спеку без записи не менять.

## REDS (слепой `tester` по критериям, без чтения `plugin.py`)
1. Диск с `below_threshold=True` → одна строка «пропуск: уверенность ниже порога …», `jobs_emitted` и ячейки не изменились.
2. Диск с `confidence` ниже `min_confidence` → то же.
3. Тот же `track_id` на 5 кадрах подряд → одна строка, не пять.
4. Три диска подряд: один ниже порога, два выше → три строки, у каждого своё решение; нумерация дисков в журнале без пропусков.
5. Пустой список предсказаний → одна строка «нет предсказания».
6. Одна проверка с настоящими объектами: `center_crop → ml_inference (фейк-сеть с заданными ответами) → word_layout`, диск «М» с confidence ниже порога виден в журнале у `layout`.

Break-injection (предсказания ДО прогона): убрать запись при `below_threshold` → RED 1, 4, 6; убрать дедуп по `track_id` → RED 3; убрать запись при пустом списке → RED 5.

## Приёмка живая
`scripts/alpha_sim` B, D, C: у каждого поданного диска в журнале `layout` есть строка (21 диск → 21 строка, если сеть выдаёт предсказание на каждый). Число строк против числа дисков — по каждому прогону. Красное «М не узнана» по-прежнему возможно (это C-86 б); строка должна объяснять причину.
