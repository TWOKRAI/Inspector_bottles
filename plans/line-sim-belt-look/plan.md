### Task 1.1 — период цепи на реальном фото
**Level:** Middle (Sonnet). **Assignee:** developer.
**Goal:** `make_seamless_texture` без флагов собирает из фото цепи тайл по периоду, а не зеркало.
**Files:** `Services/line_sim/tools/make_seamless_texture.py`, тесты `Services/line_sim/tests/`, README/STATUS `Services/line_sim` при изменении поведения.
**Причина (репродукция лида):** на `fixtures/belt_photo_full.png` инструмент печатает `method=mirror`,
note «период 43 px … шов 31.75 хуже внутренней 9.19». `find_period` берёт ПЕРВЫЙ локальный максимум
автокорреляции с `ac/ac0 >= 0.5` — это ложный лаг 43; истинный шаг — 204 (минимум средней разницы
профиля со сдвигом, 180..230). Зеркало на цепи рисует стыки звеньев буквой «Н».
**Steps:** 1. выбор периода устойчив к ложному короткому максимуму (например: среди локальных максимумов —
самый короткий лаг, чья автокорреляция не ниже заданной доли глобального максимума; гармоника 2P при W ≥ 4P
не должна выигрывать у P). 2. Прочие ветки (`mirror` при отсутствии периода, `--pitch-mm`, `--photo-width-mm`) — как были.
**Acceptance criteria:**
- [ ] `make_seamless_tile(fixtures/belt_photo_full.png)` → `method == "period"`, `period_px` ∈ [202, 206], высота тайла 484.
- [ ] Для этого тайла `seam_diff <= inner_diff` (критерий приёмки инструмента не ослабляется).
- [ ] Синтетика: профиль с периодом P и сильным побочным максимумом на коротком лаге (ac/ac0 ≥ 0.5) → `find_period` = P (±1).
- [ ] Синтетика: чистый период P при W ≥ 4P → P, не 2P.
- [ ] Плоское изображение → `None` / `mirror`, как раньше.
- [ ] Все существующие тесты `Services/line_sim/tests/*3_6*` зелёные без правки их ожиданий; если правка нужна — отдельный пункт в отчёте с причиной.
**Out of scope:** шов по бортам, кросс-фейд, изменение `SceneCompositor`.

### Task 1.2 — краска и диск как на реальном кадре
**Level:** Middle (Sonnet). **Assignee:** developer.
**Goal:** `make_font_letters` умеет рисовать букву «краской» (цвет, зерно, мягкий край) и вырезать диск из реального фото.
**Files:** `Services/line_sim/tools/make_font_letters.py`, тесты `Services/line_sim/tests/`, `Services/line_sim/presets/README.md` (команда сборки).
**Контекст:** `color_rgb` слоя ЗАМЕНЯЕТ RGB спрайта (`LayeredObject._transform`) — фактура в спрайте видна только
у слоя без `color_rgb`. Поэтому фактура живёт в спрайтах, схема слоёв (`LayerSpec`) не меняется.
**Steps / флаги (новые, все необязательные; без них вывод байт в байт как сейчас):**
1. `--ink-rgb R,G,B` — цвет буквы (дефолт — нынешний чёрный).
2. `--grain-sigma S` — гауссов шум σ по RGB непрозрачных пикселей буквы (и диска из п.4); `--seed N` — детерминизм.
3. `--edge-blur-px B` — размытие альфы буквы (гаусс σ = B); 0 — как сейчас.
4. `--disk-from-photo PATH` вместе с `--disk-out`: найти на фото самый крупный светлый круг, закрасить тёмную
   печать внутри (inpaint), вырезать и привести к диаметру `--size-px`; альфа — круг с мягким краем
   (переход 10→90 % шире 1 px и уже 5 px). Фото без светлого круга → `SystemExit` с путём в тексте.
**Acceptance criteria:**
- [ ] Без новых флагов — файлы байт в байт как на коммите до задачи (сравнить с эталоном, снятым в тесте).
- [ ] `--ink-rgb 65,70,82 --grain-sigma 9 --seed 1`: медиана RGB непрозрачных (α=255) пикселей буквы в пределах ±3 от (65,70,82), σ по каналу 6..12; повтор с тем же `--seed` — байт в байт, с другим — отличается.
- [ ] `--edge-blur-px 1`: есть пиксели с 0 < α < 255 шириной больше, чем без флага (число полупрозрачных пикселей растёт), непрозрачное ядро буквы сохраняется.
- [ ] `--disk-from-photo fixtures/real_disk_snapshot.png --disk-out X --size-px 300`: X — RGBA 300×300; в круге r < 135 нет пикселей темнее 150 по яркости (печать стёрта); медиана яркости круга ≥ 230; углы канвы α = 0; ширина края 10→90 % по радиальному профилю α — (1, 5) px.
- [ ] Фото без круга (например, сплошной серый 340×340) → `SystemExit`, в тексте путь.
**Out of scope:** `LayerSpec`/пресет-схема, редактор, аугментации на объект, шум камеры.
