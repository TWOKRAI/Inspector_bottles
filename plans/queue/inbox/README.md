# Входящие реестров очереди

Полоса не правит реестры `plans/queue/` (defects.md, ORDER.md, backlog.md) напрямую: чужая правка общего файла
даёт конфликт слияния. Вместо этого она кладёт в эту папку по одному файлу на запись.

- Имя файла: `<YYYY-MM-DD>_<session>_<N>.md` (дата, имя сессии полосы, порядковый номер за день).
- Первая строка: `registry: defects.md` или `registry: ORDER.md` или `registry: backlog.md` (целевой реестр).
- Дальше одна строка таблицы реестра целиком, как она должна встать в файл. Номер `C-NN` не присваивается.
- Файл входит в merge-коммит полосы.

Свёртка: раз в полдня одним коммитом, координатор или любая сессия. Строки переносятся в свои реестры, номера
`C-NN` присваиваются при свёртке по порядку, свёрнутые файлы удаляются тем же коммитом. Скрипта свёртки нет, это
ручная операция.
