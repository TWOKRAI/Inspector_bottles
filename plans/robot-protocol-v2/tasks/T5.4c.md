### DESIGN — `calib_belt`

DESIGN (decided by the lead — you type it, you do not derive it):
  1. `robot_driver_v2/params.py`, `ParamMixin._op_calib_belt(self, args: dict) -> dict`. Аргументы (m5):
     `marks` — `list` ровно из двух `dict`; в каждой `x_mm`, `y_mm` — `_number_arg(mark, key)`, `encoder` —
     `_int_in(mark, "encoder", -2**31, 2**31 - 1)`; `base_rev` — `_base_rev_arg(args)`; `dry_run` — нет ключа / `bool`.
     `_BadArgs` → `TEXT_BAD_ARGS` (тот же текст, что у `param_set`). Порядок:
     (а) разбор → `belt_from_marks(...)`; `CalibrationError` → `{"status": "error", "message": str(exc)}`;
     (б) `raw_factor` вне `param_bounds("P_BELT_FACTOR")` → `TEXT_BELT_FACTOR_RANGE` из `calibration`;
     (в) итог `calib = {"factor_mm_per_imp", "raw_factor", "direction", "axis_dev_deg", "travel_mm", "delta_enc"}`;
         `dry_run` → `{"status": "ok", **calib, "written": [], "applied": False}`; робот и файл не тронуты (связь нужна:
         `OpSpec` с `needs_link=True`, отказ «не подключено» даёт менеджер до драйвера);
     (г) иначе — проверки `_op_param_set` (`:165-181`: хранилище, связь, `_param_gate`) и под ОДНИМ захватом `_param_lock`:
         - **сначала (m1)** `current = self._store_call(load_params, store, self.entry.id).rev`; `current != base_rev` →
           `raise RevisionConflict(current)` → `_store_refusal` (ответ с `current_rev`) — даже когда записывать нечего;
           робот не тронут;
         - список изменений `[("P_BELT_DIR", direction), ("P_BELT_FACTOR", raw_factor)]` без пар, где значение уже равно
           `self._values[name]`; каждую — `self._param_set_locked(store, name, raw, rev)`, `rev` = `current`, затем `rev`
           предыдущего ответа;
     (д) **сбой шага ≥ 2 (решение лида M3):**
         - `RobotNak` (робот отказал, значение не принято) или ответ шага не `ok` (`TEXT_PARAM_NO_REPLY`,
           `TEXT_EPOCH_NOT_WRITTEN` — шаг сам вернул роботу значение файла): откат записанных шагов в обратном порядке
           одной попыткой каждый — `_param_set_locked(store, name, old_raw, rev_текущий)`; откат не прошёл →
           `self._publish_error(TEXT_BELT_HALF)` и лог; затем `RobotNak` — `raise` (как `_op_param_set`), ответ шага — как есть;
         - ошибка хранилища (`_StoreIOError` при `save_params`, `RevisionConflict`) — **НЕ откатывать** через
           `_param_set_locked`: робот уже получил значение и метку E+1, а `self._epoch` остался E; откат записал бы метку
           E+1 = метке робота, и `_resync_maybe` не увидел бы расхождения. Расхождение меток оставить: следующий тик вернёт
           роботу значения файла (`params.py:89-131`). Итог после тика: в файле и в роботе `P_BELT_DIR` — новое (шаг 1
           записан полностью), `P_BELT_FACTOR` — старое. Действия: `self._publish_error(TEXT_BELT_HALF)`, лог, ответ —
           `_store_refusal(exc)`;
         - сбой шага 1 — отката нет (записанного нет); ответ — как у `_op_param_set`;
     (е) записи прошли (или изменений нет) → `self._client.param_apply()` под тем же захватом (НЕ `_op_param_apply`: замок
         без повторного входа); исключение → лог и `{"status": "error", "message": TEXT_BELT_NOT_APPLIED, **calib,
         "written": [...], "applied": False, "rev": rev}`, без отката записей;
     (ж) успех → `{"status": "ok", **calib, "written": [имена], "applied": True, "rev": rev, "epoch": self._epoch}`;
         `rev` (m1) — ревизия `params.yaml` после последней записи; без записей — `current` из п.(г).
