# T5.2 — стадия 3: матрица инъекций

Вынесено из брифа `T5.2.md` (ред. 2, стадия 0 ревью — 2 круга) по бюджету размера документа. Полные предсказания лида (имена тестов) дописываются сюда ДО прогона.

## Инъекции (лид, после GREEN; одна строка — одно свойство)

Колонка «краснеет» — минимум. Полный предсказанный набор (имена тестов) лид пишет по готовым тестам тестера ДО прогона. После матрицы — `git status --porcelain` без новых путей.

| № | свойство | инъекция | краснеет |
|---|---|---|---|
| I1 | отказ чужой ревизии | убрать сравнение `base_rev != current_rev` | 1, 2, 3, 6 |
| I2 | сравнение и замена под одним замком | убрать замок в `write` | 2 |
| I3 | то же | замок только вокруг сравнения, замена вне его | 2 |
| I4 | `None` = создание | `base_rev is None` пропускает проверку | 3 |

| I6 | атомарность | писать прямо в цель (`open(path, "wb")`), шов не звать | 2, 4, 5, 10 |
