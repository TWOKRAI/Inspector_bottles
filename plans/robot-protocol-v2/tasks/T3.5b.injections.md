# T3.5b — кандидаты инъекций (материал лида, S4)

Файл лида для матрицы инъекций T3.5b (`T3.5b.md`). Developer и tester его не получают: прогнозы до прогона знает только лид. Прогнозы предварительные — лид уточняет их до прогона.

Инъекция — временная правка на ветке `test/robot-v2-t35b`, прогон 4 мигрированных файлов (`test_v2_host.py`, `test_v2_letter_straight.py`, `test_v2_line_cycle.py`, `test_v2_real_worker_manager.py`), затем откат. Цель — показать, что тесты держат клиент и провод, а не только обвязку. «Выживший» с пометкой «ожидаемо» — названный пробел, а не провал матрицы. Флаки-кандидат по стенным часам — `test_v2_host.py::test_belt_commands_on_v2`: сравнивать красные по имени с прогоном базы.
