### D5. `park.py` (новый, 1a) — `ParkMachine`, единственный писатель `.park`

- Класс драйвер не импортирует. Конструктор: `state`, `clock`, `publish(dict)`, `home_point()`, `launch_home(seq) ->
  dict`, `servo_off() -> bool`, `heartbeat()`, `record_err()`, `log_id`. Свой замок **`_mlock`** (имя `_lock` совпало бы с
  `log._lock` в `test_exchange_log.py:706-707` и сломало `_SEAMS`, Opus M7). Порядок: `_mlock` → замок состояния. Под
  `_mlock` — переход и одна публикация; `launch_home`, `servo_off`, `heartbeat` — вне `_mlock`.
- Поля и начальные значения: `_active = False`, `_seq = 0`, `_t0 = None`, `_deadline = None`, `_step = None`,
  `_launched = False`, `_home = None`, `_last_pub = None`.
- **Жизненный цикл (Opus M1, Sonnet M-2, m-9).** Холостое состояние — `_active is False`.
  - `accept(seq, timeout_s)`: под `_mlock` — `v = state.park_view()`; не (`v.parking and v.seq == seq`) → выход (park
    уже закрыт `abort` / `fail`). Иначе сброс всех полей: `_active = True`, `_seq = seq`, `_t0 = clock()`, `_deadline =
    _t0 + timeout_s`, `_step = "activity"`, `_launched = False`, `_home = None`, `_last_pub = None`; публикация
    `parking` / `activity`.
  - `guard(connected)` и `step(...)` первым делом под `_mlock`: `not _active` → выход; `v = park_view()`; не
    (`v.parking and v.seq == _seq`) → `_active = False`, выход (устаревший шаг, без записи).
  - Перед каждым вызовом вне `_mlock` автомат запоминает `seq = _seq`; после возврата под `_mlock` берёт `v =
    park_view()` и выходит без записи, если не (`_active and _seq == seq`) (Opus M1 п. 4) **или** `v.shutdown` (Opus
    r2-m1). Та же проверка `v.shutdown` — в обработчике исключения шага. Непрерывная публикация — только под `_mlock` и
    при `_active`.
  - `fail(seq, reason)` — `_finish(seq, False, reason)` (исключение `_op_park` до `accept`).
  - `abort(reason, *, stop=False)`: `v = park_view()`; `v.shutdown and not stop` → пропуск (при выключении итог ставит
    только `request_stop`); `v.parking` → `_finish(v.seq, False, reason)`. Закрывает и park, ещё не принятый автоматом.
    `request_stop` зовёт `abort(TEXT_STOPPING, stop=True)`, `disconnect` — `abort(TEXT_DISCONNECTING)`.
  - `_finish(seq, ok, reason)`: под `_mlock` — `won, jobs, returns = state.park_end(seq, ok)`; не выиграл → выход без
    записи. Выиграл → при `_seq == seq` `_active = False`; терминальная публикация (`elapsed_s` от `_t0` и `step =
    _step` — если `_seq == seq`, иначе `None` и `"activity"`, Opus r2-m3), одна `logger.info` (`done`) или
    `logger.warning` (`failed`); `dropped` не пуст → ещё `logger.warning(TEXT_PARK_DROPPED)`.
  - **Гарантия выключения:** при `_shutdown` ни `guard`, ни `step`, ни поздний возврат шага, ни `abort` не из
    `request_stop` терминал не ставят → `failed` / `TEXT_STOPPING` публикуется только после записи стопа (D7).
    Пример окна, которое так закрыто: `launch_home` → `admit_launch` видит `_stopping` от `process_stop_plan`
    (`state.py:432`) раньше записи стопа и отвечает `TEXT_STOPPING` — шаг видит `v.shutdown` и выходит.
- **Причины** (`_reason(v, connected)`, одна функция для `guard` и начала `step`, Opus m2), первая сработавшая:
  `v.shutdown` → **замереть**: выход без записи и без шага, терминал ставит `abort(TEXT_STOPPING)` из `request_stop`
  после записи стопа (Sonnet m-1); `v.disconnecting` → `TEXT_DISCONNECTING`; `v.cancel`; не `connected` →
  `TEXT_PARK_LINK`; `clock() > _deadline` → `TEXT_PARK_TIMEOUT`. Причина есть → `_finish(_seq, False, reason)`.
- `guard(connected)` — тик, первой строкой. `step(telemetry, free)` — после разбора TLM и `poll_errors`, до
  `_dispatch`. Без циклов ожидания и `sleep`: идёт до первого ожидания и выходит.
  - `activity`: ждать, пока `v.job_active`, `v.jog_busy` или `v.program_active`. Программы видов `"return"`,
    `"toolchange"` доезжают сами.
  - `idle`: ждать `free`.
  - `home`: поза в допуске `home_point()` → `_home = "already"`, шаг `servo`. Иначе `r = launch_home(seq)` вне
    `_mlock`; `r["message"] in _PARK_RETRY` → повтор следующим тиком; прочий отказ → `_finish(seq, False,
    r["message"])`; запуск прошёл → `_launched = True`, ждать `not v.program_active`. Исход `v.home_outcome`: `done` и
    поза в допуске → `_home = "moved"`; `done` без позы → `TEXT_PARK_NOT_HOME`; `aborted` → `TEXT_PARK_HOME_ABORTED`;
    `failed` или `None` → `TEXT_PARK_HOME_FAILED`.
  - `servo`: `heartbeat()`, `ok = servo_off()`, `heartbeat()` вне `_mlock`. `ok is False` (выключение) → выход, итог
    ставит `abort(…, stop=True)`. Иначе `_finish(seq, True, None)`. Устаревший `servo_off` (seq закрыт `abort` и начат новый) даёт
    ≤ 1 запись `SERVO 0` в безопасную сторону; новый seq тогда находит робота дома (`already`).
  - Исключение в `guard` или `step` → `record_err()`, `logger.warning`, `_finish(seq, False, f"{type}: {exc}")`.
- Срок шага `home` вышел → `failed`, программа дома доезжает сама, серво остаётся ON. SOFT не пишется: SOFT посреди
  хода `run_chunks` превращает в `RobotAborted` (`client_v2.py:1110-1124`), робот всё равно доезжает.
