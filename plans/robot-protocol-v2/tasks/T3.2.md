       `program.py:267`); вне `W_MIN..W_MAX` → тот же отказ с `R_OUT_OF_ZONE`; `params` — словарь `compile_program`;

       ≥ `half` LINE_PASS подряд) → `CompileError(step_of[start + half - 1], 0, f"шаг …: ряд LINE_PASS из {half} и более
       записей не делится на куски")`; обрезанное концом сценария (последняя запись LINE_PASS) →

     `servo(on: bool)`, `do_set(channel, on: bool)`; `param_set(name, raw)`/`param_get(name) -> int` — по имени из
     `PARAM_ID`; `cvt_job(ecap: int, ...)` делит `ecap` на `dw_lo`/`dw_hi`. Возврат — `CmdResult` (`ping` и
     `param_get` — значения `rvals`). Обёртки — только `cmd()`; ожидание — вызывающий (`wait_done`).
  4. `upload(records, offset)`: проверка до записи (`ValueError`): каждая запись — `SC_STRIDE` слов, каждое слово в
     `W_MIN..65535`, `0 <= offset`, `offset + len(records) <= SC_CAP`. Пишет `& 0xFFFF` блоками FC16 по ≤ `WRITE_CHUNK`
     регистров (5 записей) с `SC_BASE + offset * SC_STRIDE`, по порядку, путём записи `cmd()` (ошибка транспорта —
     `_stale` и наружу). `_mailbox_lock` не берёт. Внутренний `_upload(records, offset, abort)` перед каждым блоком
     зовёт `abort()`; `True` — блок не пишется, возврат `False`. `SC_BASE`, `SC_STRIDE`, `SC_CAP`, `WRITE_CHUNK` —
     из `CONSTANTS` в момент вызова, без копий в модуле или экземпляре (на этом стоит приёмка d).
  5. `wait_done(seq, *, on_poll=None)`: семантика T3.1 не меняется; после каждого чтения блока TLM (32 слова с
     `REG["TLM_PROTO_VER"]`) и до проверок — `on_poll(tlm)`; исключение из `on_poll` выходит наружу. Свойство
     `stop_generation` (только чтение) — текущее `_stop_generation`.
  6. `run_chunks(scenario, *, params, on_progress=None) -> RunReport`:
     a. `encode_scenario` и `plan_chunks(kinds, SC_CAP // 2, step_of)` целиком до первой записи;
     b. флаг `_sc_active` под `_state_lock`: взведён → `RuntimeError`; взвод и сброс — `try/finally`. Замок на весь прогон
        не держится (инвариант `client_v2.py:21-22`). Pre (докстрока, README): на время `run_chunks` никаких
        `done_seq`-`cmd()` на этом клиенте;
     c. метка стопа: снимок `g0 = stop_generation`, `ack0 = TLM_STOP_ACK` (одно чтение TLM). «Метка» = `stop_generation
        != g0` или прочитанный `TLM_STOP_ACK != ack0`. Внутри загрузки — только `stop_generation` (без чтений);
     d. порядок: загрузить кусок 0 в половину 0 (`_upload`, `abort` = метка по поколению). Для куска k:
        (1) метка (с чтением TLM) → `RobotAborted(seq прошлого SC_RUN или 0, E_ABORTED, "стоп между кусками")`;
        (2) `sc_run(count, sc_id=k + 1, offset)`;
        (3) сразу после ACK — метка (одно чтение TLM): взведена → `stop(STOP_LEVEL["HARD"])`, затем `RobotAborted(seq,
            E_ABORTED, "стоп между кусками")`;
        (4) есть кусок k+1: метка (с чтением TLM), затем `_upload` в другую половину (смещения 0, 27, 0, …); метка до
            или во время загрузки → больше ничего не грузить и SC_RUN не слать, `wait_done(seq, on_poll=…)` текущего
            куска (ожидаемо `RobotAborted`), вернул DONE — всё равно `RobotAborted(seq, E_ABORTED, "стоп во время
            загрузки")`;
        (5) `wait_done(seq, on_poll=…)`;
     e. `on_poll` считает `done = start_k + TLM_SC_INDEX` и зовёт `on_progress(done, total)` при изменении; после
        последнего DONE — `on_progress(total, total)`;
     f. исключения: `RobotAborted` (из `wait_done`, из О5 внутри `cmd()`, свой) и `RobotNak` в ответ на SC_RUN (команда
        не начата; HARD оборвал бы чужой ход при `E_BUSY`) — наружу как есть, без стопа. Любое другое
        исключение с момента первого вызова SC_RUN (`RobotTimeout("response"/"done")`, `RobotCommandError`, ошибка
        транспорта, исключение `on_progress`) → `stop(STOP_LEVEL["HARD"])` в `try`; его ошибка — `add_note` к
        исходному; затем исходное наружу (урок T3.1: на `RobotTimeout("response")` не повторять `cmd()`);
     g. `RunReport` (frozen dataclass): `chunks: tuple[tuple[int, int, int], ...]` — `(start, count, offset)`; `total: int`.
  7. Пульс — не дело `run_chunks` (О4): README, абзац «пульс во время сценария — поток вызывающего»; там же — О2, Pre О8,
