## REDS c2: 13–17, 20

  13. `::test_wdg_zero_rejects_connect` (DESIGN 8; файл плагина) — `r1` на `E2eRig`, три случая, каждый с чистым каталогом данных: (а) `params.yaml` с полной картой умолчаний, `P_WDG_TIMEOUT_MS: 0`, `epoch: 1`; (б) без файла, `entry.params["robot_params"] = {"P_WDG_TIMEOUT_MS": 0}`; (в) исправный файл + тот же override. В каждом: подключение `r1` отклонено; последняя публикация `devices.state.r1.last_error` — ровно `"Сторож робота нельзя выключить: P_WDG_TIMEOUT_MS = 0"`; `conn` не `connected`; исключение из плагина не вышло; нет вызова `ctx.health.report_error` с `context="device_hub.connect"`; в событиях sim нет `op=PARAM_SET`. Контроль: `P_WDG_TIMEOUT_MS: 5000` (не меньше `4 × 0,5 с` — тика хаба: при 600 период пульса 0,15 с меньше тика, `connect()` публикует `TEXT_WDG_INTERVAL`, `robot_driver_v2.py:479-481`, `client_v2.py:442`; стадия 0 р.3 п. 6) → подключение проходит, `rig.client.param_get("P_WDG_TIMEOUT_MS") == 5000`. «В событиях sim нет `op=PARAM_SET`» — среди `rig.core.events()` после отметки перед подключением нет строки с `op=PARAM_SET` (формат `[v2] CMD seq=<n> op=<ИМЯ>`, `sim_core_v2.py:63, 1448`). Порядок проверки (DESIGN 8а): 0 отвергается подклассом, а не общим `RobotDataInvalid`. Формат файла и способ записи — как в основном брифе (REDS, преамбула).
  14. `::test_strict_int_overrides_rejected_visibly` (DESIGN 11; файл плагина) — `entry.params["robot_params"]` по очереди `{"P_SPD_DEFAULT": 50.0}`, `{"P_SPD_DEFAULT": True}`, `{"P_SPD_DEFAULT": "50"}`, без файла: каждый раз подключение отклонено, `last_error` ровно `"Данные робота не прошли проверку"`, `"50" not in last_error`, `conn` не `connected`, нет `report_error(context="device_hub.connect")`; контроль `{"P_SPD_DEFAULT": 50}` → подключено.
  15. `::test_bad_override_with_existing_file_rejected` (DESIGN 12; файл плагина) — `params.yaml` исправный (`P_SPD_DEFAULT: 55`, `epoch: 9`) + `robot_params {"P_NOPE": 1}` → отказ, как в п. 11 (текст, `conn`, нет health); убрать `P_NOPE`, оставить `{"P_SPD_DEFAULT": 30}` при файле 55 → подключено, `rig.client.param_get("P_SPD_DEFAULT") == 55` (override при файле не применяется).
  16. `::test_wdg_zero_refused_in_all_paths` (DESIGN 8; `Services/robot_comm/tests/test_robot_data_t53c_acceptance.py`, `RobotDataStore(tmp_path)`) — `load_params` по файлу с `P_WDG_TIMEOUT_MS: 0` → `RobotWatchdogDisabled`, `str(exc) == "Сторож робота нельзя выключить: P_WDG_TIMEOUT_MS = 0"`, `isinstance(exc, RobotDataInvalid)`, `exc.rev` — ревизия этого файла; `overrides={"P_WDG_TIMEOUT_MS": 0}` без файла и при файле → то же, `exc.rev is None`; `save_params` полной карты с 0 → то же, файл не создан и не изменён (байты прежние); значения `1` и `60000` проходят; `param_bounds("P_WDG_TIMEOUT_MS") == (1, 60000)`, `param_bounds("P_SPD_DEFAULT") == (1, 100)`; `param_bounds("P_NOPE")` и `param_bounds("P_CONFIG_EPOCH")` → `RobotDataInvalid`, `exc.rev is None`, и это именно `RobotDataInvalid`, не подкласс; `"param_bounds" in robot_data.__all__`.
  17. `::test_make_param_source_bad_override_with_file` (DESIGN 12; тот же файл тестов) — файл есть + `overrides={"P_NOPE": 1}`, затем `{"P_SPD_DEFAULT": 50.0}`, затем `{"P_SPD_DEFAULT": True}`: `make_param_source(...)()` бросает `RobotDataInvalid`, `exc.rev is None`; без файла — то же.
