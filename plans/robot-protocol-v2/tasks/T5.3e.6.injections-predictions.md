# T5.3e.6 — предсказания инъекций (до прогона)

Бриф — [`T5.3e.6.md`](T5.3e.6.md), слепая приёмка — [`T5.3e.6.acceptance.md`](T5.3e.6.acceptance.md). Тестеру этот файл не
читать. Прогон — автор по agentId, по одной поломке на чистом GREEN; факт — в `T5.3e.6.injections-result.md`.
«R» — REDS и сторожа автора (`tests/test_robot_controller.py`), «A» — критерии слепой приёмки. Указан минимум красного набора.

| № | поломка | предсказано красным |
|---|---|---|
| J1 | подписка снова на точный `….status` | R `merge_updates_telemetry`, `partial_merge_keeps_view`, `warm_cache_select_shows_cached_telemetry`; A1, A2, A12 |
| J2 | `_unbind_state` не снимает хэндлы `bind_fanout` | R `releases_previous_subscriptions`; A4 |
| J3 | фильтр префикса в `_on_telemetry_push` снят | сторож `foreign_device_leaf_ignored` (прямой вызов); A3 — зелёный (подписка снята, J2 цел) |
| J4 | «Связь с роботом активна.» на каждом пуше | R `push_keeps_button_text_while_link_ok`; A6 |
| J5 | на переходе после «Нет связи» итог park не возвращается | R `stale_then_push_restores_park_text`; A5 (а) |
| J6 | терминал не аннулирует срок (нет `_park_gen += 1` в `_render_park`) | сторож `deadline_cancelled_by_terminal`; A8 |
| J7 | запас 0 (срок = `timeout_s`) | R `deadline_shows_no_result_text` (нижние границы 3,5 / 4,0 с); A7 |

**Эквивалентный мутант по замыслу (не гоняем):** `_reset_park` без `_park_gen += 1` — слот выходит по `_park_seq is None`,
а новое ожидание всегда идёт через `accepted` с `_park_gen += 1` (DESIGN п.5). Прежний J9 заменён на `unbind()`.
