## Контракт R1–R10 (`test_robot_v2_state_acceptance.py`)

Вехи ставить переходами. «Связь поднята» = `connect_begin()` → `("go", False)` + `connect_link_up()` → True.
`dsp` = `disconnect_stop_plan(1, link_up=lambda: True)`; `dsoft` = `disconnect_soft_plan(lambda: False, lambda: True)`;
`K` = `disconnect_request(lambda: True)`.
- R1 связь поднята, K, `connect_finish()` → False; `connect_end()`; `dsp`; `dsoft` → True.
- R2 `connect_begin()` без `connect_link_up`, K, `connect_link_up()` → False; `connect_end()`; `dsp`; `dsoft` → False.
- R3 K без `connect`; `connect_begin()[0]` → `"cancelled"`; `disconnect_end()`; `connect_begin()[0]` → `"go"`.
- R4 связь поднята, `disconnect_request(lambda: False)`; `connect_end()`; `dsp`; `dsoft` → False (живой терм).
- R5 `request_stop_begin()`, затем K; `connect_begin()[0]` → `"shutdown"`.
- R6 `set_ready(True)`, `connect_begin()` → `("go", True)`, K, `connect_end()`, `dsp`: `dsoft` → True,
  `disconnect_owns_close()` → True.
- R7 (стадия 0 п.3) задание, как в `test_robot_v2_state_acceptance.py:122-124` (`enqueue_job(job)`,
  `take_next_action()` → `(None, job)`), K: `connect_begin()[0]` → `"cancelled"`.
- R8 (п.6, счётчик) K, K, `disconnect_end()`: `connect_begin()[0]` → `"cancelled"`, `disconnect_pending()` → True;
  `disconnect_end()`: `disconnect_pending()` → False; лишний `disconnect_end()` и затем K, `disconnect_end()`:
  `connect_begin()[0]` → `"go"` (пол 0).
- R9 (В4, В6; стадия 0 р.2 Н2) K: `disconnect_refusal()` → `{"status": "error", "message": "идёт отключение
  робота"}`; `jog_hold_check()` → тот же dict; `jog_hold_admit()` → `(тот же dict, None)`; `enqueue_job(job)`,
  `take_next_action()` → `(None, None)`; `disconnect_end()` → `(1, 0)`; `job_queue_len()` → 0;
  `disconnect_refusal()` → None. Голый `disconnect_end()` без K при задании в очереди → `(0, 0)`, длина 1.
- R10 (В5, В6) K: `admit_launch(lambda: True)` → `{"status": "error", "message": "идёт отключение робота"}`;
  `enqueue_return((1.0, 2.0, 0.0))`, `take_next_action()` → `(None, None)`; `disconnect_end()` → `(0, 1)`;
  `return_queue_len()` → 0; после этого `admit_launch(lambda: True)` → None.
