## Секции (номера строк — main `4b1a44050`)

`disconnect()` (`driver.py:392-416`, без `_param_lock`):
- D1 `disconnect_begin` (`state.py:329-337`): при не-выключении сброс поколения защёлки; `_stopping` НЕ ставит;
- D2 `disconnect_stop_plan` (`state.py:454-468`) под `_jog_tx_lock` (`stop.py:170-171`): `_stopping = True`;
- D3 `stop.py:196-209`, вне замка состояния: простой робот — `self.is_connected` (`_ready and transport.is_connected`),
  затем `latch_covers(SOFT)`, затем запись SOFT;
- D4 `threads_to_close` и закрытие потоков; D5 `_ready = False` (`set_ready`); D6 `transport.disconnect()`.

`connect()` (`driver.py:289-356`, под `_param_lock`): C0 `connect_begin` (сброс `_stopping`, защёлки, `_ready = False`,
`_connecting`, `_connect_linked = was_ready`) → C1 закрытие старого сокета → C3 `transport.connect()` → C4
`connect_link_up` (граница A3) → C5 `probe` → C6 `begin_sync` / `sync_params` → C7 `connect_restore` /
`_run_on_connect` → C8 `connect_finish` → C9 `connect_end`.

Корень: D3 смотрит `is_connected`, а `connect_begin` (C0) снял `_ready` на весь `connect`. После A3 простой робот
«не подключён» — SOFT 0. `connect_link_up` / `connect_restore` / `connect_finish` отказывают по `_stopping` (T5.3g,
уточнение 1), поэтому `connect()` False уже сейчас.
