DESIGN (decided by the lead — you type it, you do not derive it):
  1. Поведение хоста (то, что наблюдается снаружи): плагин `SimRobotHostPlugin` (`Plugins.sim.robot_host.plugin`) принимает в конфиге ключ `protocol` — `v1` (по умолчанию) или `v2`. При `v2` по Modbus TCP отвечает карта протокола v2: `TLM_PROTO_VER` (0x1040) = 0x0200; блок `PMIR` по 0x3080 читается одним FC3 (`PMIR_MAGIC` = 0x5632); mailbox v2 (`CMD_*`/`RES_*`, константы — `Services/robot_comm/core/protocol_v2`) исполняет опкоды. Команда плагина `sim_robot.status` отдаёт ключ `protocol` — он проверяется ВМЕСТЕ с проводом (`TLM_PROTO_VER`), одно без другого не доказательство.
  2. Потоки: при живом v2-хосте в `threading.enumerate()` нет потоков с именами `sim-robot-motion` и `sim-robot-server` (они принадлежат v1-пути), а тик и слушатель идут как воркеры `ctx.worker_manager`. Как наблюдать воркеры — по тому, что доступно из фикстур существующих тестов `Plugins/sim/robot_host/tests` (читать `conftest.py` и соседние тесты); нет доступного способа — тест проверяет только отсутствие двух имён и записывает в докстринг, чего не доказывает.
  3. Команды на v2: `belt.run` и `belt.status` дают растущий энкодер (через `sim_robot.status`/`belt.status`), а `belt.jog` без подкачки останавливает ленту по `jog_timeout_ms` (энкодер перестаёт расти) — всё это в одном тесте `test_belt_commands_on_v2`; `fault.drop`, `fault.delay_ms`, `fault.vfd_code`, `fault.clear` отвечают `{"status": "error", ...}` с сообщением, в котором есть слова «не поддерживается» и `v2`, и НЕ содержат введённого значения аргумента. Неизвестный `protocol` (например, `v3`) — старт кончается `state == "error"` (читать через `sim_robot.status`), процесс жив, текст ошибки не содержит `v3`.
  4. Перезапуск: `shutdown()` и повторный `start()` на том же порту поднимают слушателя заново; порт после `shutdown()` свободен (проба `bind`).
  5. Цикл «кадр → задание → DONE»: v2-хост и `SceneSourcePlugin` (`Plugins.sim.scene_source.plugin`) поднимаются в одном тестовом окружении по образцу `Plugins/sim/scene_source/tests/test_acceptance_1_3_stand.py`; стенд-водитель берёт у сцены (`scene.status`) положение объекта и энкодер, шлёт по TCP `SERVO 1`, `HB_PC`, `CVT_JOB` (pick из данных сцены, `ecap` из энкодера объекта, place — валидная точка с |J1| ≤ 100 при `P_HAND = 1`), дожидается `DONE_SEQ`; в сцену приходит `scene.job_done` с тем же `index`. Данные pick не литералы теста. Если связать плагины в одном окружении нельзя без правки кода плагинов — тест это записывает в докстринг и проверяет цепочку на границе (команда `scene.job_done` вручную из события хоста), не подменяя хоста.
  6. «Буква ровная»: `place_rz` берётся из продукта — `Plugins/processing/word_layout/assembler.py` (`offer(label, angle_deg, angle_valid, *, zero_deg, sign)` — `zero_deg` и `sign` только именованные; поле `job["angle_deg"]` — относительный доворот). Абсолютный RZ укладки = значение параметра `P_PICK_RZ` (читается опкодом `PARAM_GET`) + доворот. Правило «RZ робота до задания + доворот» не использовать: после `CVT_JOB` инструмент остаётся в позе укладки, и на втором диске подряд `TLM_RZ` ≠ `P_PICK_RZ`. Диски — с углами-литералами 30°, −45°, 0° (не все нулевые), задания подряд без `HOME` между ними. Итоговый угол буквы = угол диска + `TOOL_SIGN` × (RZ укладки − `P_PICK_RZ`) по модулю 360; допуск 1° (литерал). `TOOL_SIGN = +1` — одна константа вверху файла с пометкой ⚑ GATE-1; тест падает, если знак в продукте противоположен.
  7. Смоук «одно приложение»: два блюпринта — штатный `apps/line_sim/pipeline.yaml` с подставленным `protocol: v2` и он же с добавочным пустым процессом-хозяином — проходят валидатор блюпринта (публичный вход фреймворка; найти по существующим тестам сборки блюпринта), без `BlueprintError`; плагины те же классы; процессы `camera` и `mjpeg` остаются раздельными. YAML читается из репозитория и правится в памяти, файл на диске не меняется.
  8. Водитель — `Plugins/sim/robot_host/tests/v2_driver.py` (вы его пишете): синхронный `ModbusSdkClient` (по образцу `_write_cmd`/`_wait_res` в `Services/robot_comm/tests/test_sim_v2_tcp.py` в коммите `6cf91f824` — файл удалён в `3e0791009`, смотреть `git show 6cf91f824:Services/robot_comm/tests/test_sim_v2_tcp.py`), константы только из `protocol_v2`; методы probe, `cmd(op, *args)` с ожиданием `RES_SEQ`, `wait_done`, `heartbeat()`. Помечен `ponytail:` как временный до `client_v2`. Каждый блокирующий вызов — с дедлайном, сервер всегда гасится в `finally`.
  9. Каждый тест в докстринге называет, что он НЕ доказывает. Ожидаемые значения — литералы, не выведенные из кода под тестом. Вычисления с `time.monotonic` на Windows — только на сетку 15.6 мс.
