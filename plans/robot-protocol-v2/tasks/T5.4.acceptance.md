# T5.4 — вход слепого тестера (калибровка робота v2, бэкенд)

Тестер читает ТОЛЬКО этот файл и код на SHA стадии 1a (заглушки пакета). Бриф реализации не читать.
Задача — три новых файла тестов (ниже), красные до реализации по ожидаемой причине (`NotImplementedError` заглушек
или «Неизвестная операция» / неизвестная команда). Не коммитить, не пушить; отчёт — лиду.

## Файлы (больше ничего)

1. `Services/robot_comm/tests/test_t54_calibration_acceptance.py` — математика (A1–A9).
2. `Plugins/hub/device_hub/tests/test_t54_calib_commands_acceptance.py` — команды хаба против sim v2 (B1–B9).
3. `Plugins/calibration/camera_robot/tests/test_v2_driver_contract.py` — камера ↔ робот с драйвером v2 (C1–C3).

## Контракт (публичные имена — только они)

- `Services.robot_comm.calibration`: `belt_from_marks(p1, enc1, p2, enc2) -> BeltResult` (поля `factor_mm_per_imp`,
  `raw_factor`, `direction`, `axis_dev_deg`, `travel_mm`, `delta_enc`); `fit_frame(base, local) -> FrameFit` (поля
  `origin`, `on_x`, `in_plane`, `yaw_deg`, `residuals_mm`, `max_residual_mm`); `check_tool_points(points) -> list[ToolCheck]`
  (поля `tool`, `ok`, `missing`, `problems`); `CalibrationError` (`str(exc)` — текст отказа).
- `P_BELT_DIR`: 0 +X, 1 +Y, 2 −X, 3 −Y — направление хода детали при РОСТЕ энкодера. `raw_factor` = коэффициент в
  единицах 1e−5 мм/имп, округление до целого. Энкодер — целое со знаком, 32 бита (переход через границу законен).
- Команды хаба (у всех `device_id`): `robot_calib_belt {marks: [{x_mm, y_mm, encoder}, {…}], base_rev, dry_run?}` →
  `ok`: `factor_mm_per_imp, raw_factor, direction, axis_dev_deg, travel_mm, delta_enc, written (имена параметров), applied,
  rev` (`rev` — кроме `dry_run`); `robot_calib_frame {name, points: [{point: <имя сохранённой точки>, local: [x, y, z]}, …≥3], base_rev}` → `ok`:
  `rev, frame, yaw_deg, residuals_mm, max_residual_mm`; `robot_calib_tools {}` → `ok`: `tools [{tool, ok, missing,
  problems}], rev`. Отказ — `{"status": "error", "message": <текст>}`; конфликт ревизии добавляет `current_rev`.
- Тексты отказов (дословно): «неверные аргументы команды робота» (плохие аргументы команды), «неверные отметки ленты»,
  «энкодер не изменился между отметками», «мало хода ленты между отметками», «лента не вдоль оси робота»,
  «коэффициент ленты вне диапазона параметра», «неверные точки подгонки СК», «точки СК вырождены», «точки не совпадают
  с размерами СК», «СК перевёрнута: ось Z вниз», «точка не найдена», «точка СК должна быть в базе».
- Пороги по умолчанию: ход ленты ≥ 100 мм; отклонение ленты от оси ≤ 1.0°; невязка подгонки СК ≤ 0.5 мм.
- Коды проблем инструмента: `not_in_base`, `over_not_above_pick`. Имена точек: `t1_over`, `t1_pick`, `t1_exit`,
  `t2_over`, `t2_pick`, `t2_exit`.

## A — математика (файл 1)

- A1 **Лента, известный ход → коэффициент с ошибкой < 0.5 %.** Истинный коэффициент 0.14447 мм/имп, ход 200 мм вдоль
  каждой из четырёх осей, отметки с шумом ±0.1 мм по X и Y (seed фиксирован, ≥ 100 прогонов) → `|factor − 0.14447| /
  0.14447 < 0.005` в каждом прогоне и `direction` — та ось, по которой шёл ход.
- A2 Ход 200 мм; энкодер убывает при ходе по +Y → `direction == 3`; `delta_enc < 0`.
- A3 Переход энкодера через границу 32 бит (`enc1 = 2**31 − 100`, `enc2 = −2**31 + 1284`) → `delta_enc == 1384`.
- A4 Ход 200 мм; лента под углом 0.5° к оси +X — успех, `axis_dev_deg ≈ 0.5`; под углом 1.5° — отказ «лента не вдоль оси робота».
- A5 Отказы ленты: энкодер равен; ход 60 мм (меньше порога 100 мм); координата `nan` → три текста выше (по одному на случай).
- A6 **СК из трёх точек с шумом 0.1 мм восстанавливает поворот ±0.1°.** Номинал — углы листа A4: (0,0,0), (297,0,0),
  (0,210,0); истинный поворот yaw в [−180°, 180°), сдвиг XY в пределах ±300 мм, Z в пределах ±50 мм; шум ±0.1 мм по
  каждой оси каждой точки (seed, ≥ 200 поз) → `|yaw_deg − истинный| ≤ 0.1°` (по модулю 360) и `origin` в пределах
  0.5 мм от истинного начала.
- A7 Подгонка по 4 точкам (добавлен угол (297, 210, 0)) без шума → невязки < 1e−6 мм; сохранённое `FrameDef` из полей
  результата переводит каждый номинал обратно в базовую точку с точностью 1e−6 мм.
- A8 Отказы СК: номинал (0,0,0), (297,0,0), (0,210,0), yaw 30°; базовая точка от (297,0,0) смещена на +2.0 мм вдоль
  локальной оси Y (в плоскости листа) → «точки не совпадают с размерами СК»; номинал в сантиметрах (масштаб в 10
  раз меньше) → то же (сдвиг по Z для этой проверки не использовать: при трёх точках он почти не даёт невязки); три коллинеарных номинала → «точки СК вырождены»; номинал зеркальный (y × −1) → не успех;
  СК повёрнута на 180° вокруг X (ось Z вниз) → «СК перевёрнута: ось Z вниз»; две точки → «неверные точки подгонки СК».
- A9 Инструменты: полный набор t1/t2 с «над» выше гнезда → оба `ok`; нет `t2_exit` → `missing == ("t2_exit",)`;
  `t1_over` на высоте `t1_pick` → `over_not_above_pick`; точка t1 с `frame` не `None` → `not_in_base`.

## B — команды хаба против sim v2 (файл 2)

Связать настоящие объекты: плагин хаба (или `DeviceManager`) → драйвер v2 → sim v2 (`Services/robot_comm/tests/e2e_rig_v2.py`,
`E2eRig`). Ожидания живого состояния — опросом с дедлайном, вызов в потоке с `join`; тест не висит.
Не обращаться к приватным атрибутам драйвера и плагина (имена с `_`): сторож `test_no_private_driver_state.py` сканирует
и `Plugins/hub/device_hub/tests`. Публичные способы чтения:
- параметр робота — `RobotClientV2.param_get(name)` клиента, полученного через `client_factory` драйвера
  (`DeviceManager(driver_options={("robot", "delta_v2"): {"client_factory": …}})`, рекордер `ClientRecorder` —
  `Services/device_hub/tests/conftest.py:17`);
- признак «есть неприменённые параметры» — регистр sim `TLM_CFG_PENDING`: `rig.core.regs[REG["TLM_CFG_PENDING"]]`,
  `REG` из `Services.robot_comm.core.protocol_v2` (sim ставит 1 при записи параметра класса `reinit`, 0 — при применении);
- описание команды в каталоге — `get_command_info(name)` менеджера команд стенда → `metadata.description`
  (образец — `Plugins/hub/device_hub/tests/test_spi_commands_acceptance.py:496-499`).

- B1 Отметки (250, −100, enc 1000) и (250, 100, enc 2384), свежая `base_rev` → `ok`, `applied is True`; параметр
  `P_BELT_FACTOR` робота и в `robot_param_get_all` == 14451; `P_BELT_DIR` == 1; `TLM_CFG_PENDING` == 0.
- B2 Ход по −X → `P_BELT_DIR` робота == 2, в `written` оба параметра.
- B3 `dry_run: true` → `ok`, `applied is False`, параметры робота и ревизия файла параметров не изменились.
- B4 Плохие аргументы (нет `marks`; одна отметка; `encoder` дробный; `encoder` = 2**31 — вне 32 бит со знаком;
  `x_mm` — `true`; `dry_run` — строка) → «неверные
  аргументы команды робота»; параметры робота не изменились.
- B5 Ход 10 мм; угол 5° (ход 200 мм); энкодер равен (ход 200 мм) → тексты A5/A4; параметры робота не изменились.
- B6 Устаревшая `base_rev` → отказ с `current_rev`; параметры робота не изменились. То же, когда отметки дают уже

- B7 `robot_calib_frame` на трёх сохранённых точках (`robot_point_save` или `robot_point_capture`) с номиналом листа → `ok`;

  найдена»; точка в чужой СК → «точка СК должна быть в базе».

## C — камера ↔ робот с драйвером v2 (файл 3)

Образец — `Plugins/calibration/camera_robot/tests/test_sim_integration.py` (там v1); здесь настоящий `RobotDriverV2`

- C1 `RobotDriverV2.call("get_telemetry", {})` → `status == "ok"`, словарь `telemetry` с числами `x_mm`, `y_mm`, `z_mm`,
  `rz_deg`; `encoder` — `int`; после хода ленты sim энкодер больше прежнего.
- C2 Мастер `CameraRobotCalibrationPlugin` через адаптер «`DeviceHubClient` → драйвер v2» (как в образце): `cal_begin` →
  снимок → пять точек роботом → состояние мастера содержит пять пар мм и энкодер, ошибок нет, рабочий поток плагина не
  завис (дедлайн). «Пять точек роботом» — публичными операциями драйвера: `call("servo", {"on": True})`, затем
  `call("jog_step", {"dx": …, "dy": …, "spd": 50})` шагами не больше 20 мм от дома sim (300, −210, −40) мм, после каждого
  шага — ожидание, что поза в `get_telemetry` дошла до цели (±0.5 мм, дедлайн); все точки внутри зоны sim по умолчанию
  (радиус 100..600 мм, Z −150..0 мм). Пары мм мастера равны позам телеметрии с точностью 0.5 мм.
- C3 Ответ `robot_get_telemetry` v2 содержит все ключи `telemetry`, которые читает `camera_robot`, и те же ключи, что
