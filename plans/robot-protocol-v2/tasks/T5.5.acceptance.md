# T5.5 — приёмка для слепого тестера

## Вход

Поверхность вызова: хаб — `DeviceHubPlugin`, команды `robot_draw_polyline {device_id, points: [{x_mm, y_mm, pen}], z?}`,
`robot_enqueue_job {device_id, x_mm, y_mm, z_mm?, e_capture?, place_x?, place_y?, place_z?, place_rz?}`,
счётчики драйвера — `plugin._manager.get_driver(<id>).snapshot()` (поля `jobs_done`, `queue_len`); состояние программы — публикация `devices.state.<id>.program`
(`{name, state, done, total, error}`); sim v2 — `Services/robot_comm/tests/e2e_rig_v2.py` (`E2eRig`, `bounded`).
Плагины — `Plugins.io.robot_draw.plugin.RobotDrawPlugin`, `Plugins.io.robot_io.plugin.RobotIoPlugin`; их транспорт в хаб —
атрибут `_client` с методом `request(command, data, timeout=...) -> dict`. Образец сборки хаба с v2-роботом на sim —
помощники `_plugin`, `_add_v2`, `_cmd`, `_shutdown` в `Plugins/hub/device_hub/tests/test_robot_v2_commands_acceptance.py`.
Случаи (значения — литералы, каждый вызов с дедлайном):
- B1. Сквозной рисунок из плагина: `RobotDrawPlugin` (настоящий) с `_client`, который передаёт `request(...)` в команду
  хаба в том же процессе; плагин взведён `cmd_send`, `process([{draw_points: <квадрат 20×20 мм внутри зоны, начало pen=0>}])`,
  воркер плагина или прямой вызов его цикла одной итерацией → в хаб ушла `robot_draw_polyline`; `.program` робота v2:
  `name == "draw"`, `state == "done"`, `done == total > 0`; счётчик плагина `jobs_sent == 1`.
- B2. Два штриха (две буквы, между ними точка `pen=0`) → программа доходит до `done`; поза sim в конце — дом
  (`P_HOME_*` sim по умолчанию; поза — регистры sim `TLM_X/TLM_Y/TLM_Z` ×0.1 мм через `E2eRig`, ±0.1 мм).
- B3. Точка вне зоны (0, 0) → ответ команды `status: error`; `.program` не появляется; `jobs_dropped` плагина +1.
- B4. Пустой список точек / `pen = 2` → `status: error` с одинаковым текстом без значений.
- B5. Подача: `RobotIoPlugin` (настоящий) с тем же мостом `_client`; задание `{pick_x_mm, pick_y_mm, place_x_mm, place_y_mm}`
  внутри зоны → в хаб уходит `robot_enqueue_job`; через дедлайн `snapshot()["jobs_done"]` драйвера вырос на 1, `queue_len == 0` (sim дал DONE).
- B6. v1 не задет: на роботе v1 (фейк-транспорт conftest хаба) `robot_draw_polyline` → `status: ok` (как на `main`).
Можно читать: этот раздел; `e2e_rig_v2.py`; тесты-образцы хаба (помощники). Запрещено: остальной `T5.5.md`,
`robot_driver_v2/programs.py`, `ops.py`, `spi.py`, тесты автора `test_robot_v2_draw.py`.
Ожидаемо до кода: B1–B4 красные («Неизвестная операция робота: 'draw_polyline'»), B5–B6 зелёные (код уже есть) —
зелёные до кода — не дефект теста, а факт «подача уже на v2».
