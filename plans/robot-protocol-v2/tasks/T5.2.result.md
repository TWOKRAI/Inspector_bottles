## Отклонения от DESIGN
- `_read` ловит `Exception`, а не только `YAMLError`: разбор идёт в памяти, без ввода-вывода, а PyYAML на мусоре бросает не только `YAMLError` (`d: 2020-99-99` -> `ValueError`, `v: !!bool foo` -> `KeyError`, `v: !!timestamp foo` -> `AttributeError`, `v: !!int ''` -> `IndexError`, `[` x 3000 -> `RecursionError`); по смыслу п.4 это «не разбирается» -> `StoreDocumentInvalid(rev)` (ревью р.1, решение лида).
- `_dump` ловит `(yaml.YAMLError, RecursionError)`: тело с вложенностью ~600 уровней -> `StoreDocumentInvalid(None)` (ревью р.1 п.3).
- `_atomic_write` ловит `BaseException` (удаляет tmp и пробрасывает), а не `Exception`: tmp не остаётся и при `KeyboardInterrupt` (тест автора добавлен по ревью р.1).
- Лог повтора замены (`log.warning` на паузу) в брифе не оговорён: лог повтора — не свойство, теста нет (решение лида).

- `mkstemp` создаёт tmp с правами 0600: после замены файл данных тоже 0600 (на Windows не важно; на POSIX отличается от umask по умолчанию). Не обсуждалось в брифе.
