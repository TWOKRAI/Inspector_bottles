DESIGN (decided by the lead — you type it, you do not derive it):
  1. `manager.py`: `read_canonical(slug) -> tuple[dict | None, str | None]` = `(format_hook.normalize(файл), rev)` одного
     чтения байтов; файл не парсится / не mapping / хук бросает → `RecipeFormatError(ValueError)` (экспорт), частичного
     результата нет. `format_hook` — тип `RecipeFormatHook` из `service.py:137` (не новый Protocol, задан в 1.1e).
     Отказ на смене формы корня (симметрично 1.4 DESIGN 1, ревью F10/G11): `N(файл)` вводит любой корневой ключ, которого
     нет в файле (v1 `topology:` → `blueprint:`; или только добавил ключ) → `patch_recipe` бросает `RecipeFormatError`
     «файл в устаревшей форме — сначала миграция», файл цел. Удаление/перенос вглубь (legacy top-level `gui_positions` →
     `blueprint.metadata`) отказа не даёт.
  2. `yaml_io.apply_delta(target, before, after, *, on_insert=None)` и движок: `on_insert(path: tuple, value) -> value`
     вызывается ТОЛЬКО для поддерева, вставляемого целиком (ключа/элемента нет в цели); изменённые листья — без него.
  3. Новый публичный `recipe/hook_contract.py` (lite-скаффолд в docstring: Purpose / Public API / Stability):
     `assert_format_hook_contract(hook_factory: str, docs: list[dict], invalid_docs: list[object] = ())` —
     идемпотентность, тотальность (валидный → dict, невалидный → `RecipeFormatError`), детерминизм, пустая дельта без
     правок. Хук задаётся строкой `"pkg.module:Attr"` (вызываемое без аргументов → экземпляр): так он доходит до
     подпроцессов `PYTHONHASHSEED` 0..3 (`[sys.executable, "-c", …]`, `cwd` = корень репозитория, `PYTHONPATH` явно; `docs` — JSON-файлом во временном каталоге,
     результат — JSON на stdout, сравнение в родителе). Синтетические хуки фреймворка — на уровне модуля
     `recipe/tests/test_canonical_form.py` (пакет: `recipe/tests/__init__.py` есть). Один набор проверок на все хуки.
  4. `interfaces.py` `RecipeManagerProtocol.read_canonical` — docstring Pre/Post (design.md §10 п. 2–3).
