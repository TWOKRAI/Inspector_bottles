## DESIGN (decided by the lead — you type it, you do not derive it)

  1. `recipes/save.py`: приватная `_editor_owned_processes(topology, doc) -> list`. Если `topology["processes"]` не список — вернуть его как есть
     (ошибку даёт `Topology` дальше, поведение прежнее). Иначе:
     `editor` = процессы топологии, у которых НЕТ truthy `protected` (элемент не mapping считается непротектед);
     `file_procs` = mapping-элементы `doc["blueprint"]["processes"]` (не список -> пусто);
     результат = `editor`, и для каждого `file_procs[i]` с truthy `protected`, по порядку файла, вставить ЭТОТ элемент файла в позицию `min(i, len(result))`.
     Следствия: protected редактора игнорируется целиком (берётся версия файла); protected, которых нет в файле, не пишутся; protected файла, которых нет
     в топологии редактора, остаются.
  2. `save_editor_topology_to_recipe`: сразу после `doc is None` -> `RecipeNotFoundError` добавить
     `if expected_rev is not None and rev != expected_rev: raise RecipeConflict(slug, expected_rev, rev)` (импорт
     `from multiprocess_framework.modules.recipe import RecipeConflict`, как в `display_catalog_recipe.py:27`). `rev` — `compute_rev` байтов файла, та же функция, что у
     базы сессии. Авторитетная сверка под локом в `save_raw` остаётся.
  3. Вызов правила: после проверки «blueprint — mapping», до `topology_to_canonical`:
     `topology = {**topology, "processes": _editor_owned_processes(topology, doc)}` — внутри функции, не мутируя аргумент.
  4. Докстринги: `save_editor_topology_to_recipe` (правило владения, ранний `RecipeConflict`), `_editor_owned_processes` (Pre/Post).
