## DESIGN (decided by the lead — you type it, you do not derive it)

  1. `TopologySession.mark_layout_saved()`: `self._set(layout_unsaved=False)`. Другие флаги НЕ трогает (`mark_saved` не годится: он гасит `dirty`). Уведомляет подписчиков
     только при реальной смене флага (так работает `_set`). Docstring по образцу `mark_layout_unsaved`.
  2. `LayoutController._persist_layout_to_recipe`: внутри `try`, после `session.rebase(active_slug, new_rev)`, в той же ветке `if session is not None and new_rev is not None`
     вызвать `session.mark_layout_saved()`. Вне ветки (`new_rev is None`) флаг не трогать: запись не подтверждена ревизией. Ветки `except RecipeConflict` и `except Exception` не меняются.
  3. Порядок: сначала `rebase`, затем `mark_layout_saved` (если `rebase` бросит, флаг остаётся `True` — запись под вопросом).

## ACCEPTANCE (слепому тестеру; настоящие `TopologySession`, `RecipeStoreFromManager` + `RecipeManager` на tmp-копии фикстуры; образец — `test_layout_unsaved_blind.py`; ожидаемое — литералы)

  1. `layout_unsaved is True` (после `mark_layout_unsaved()`) -> `mark_layout_saved()` -> `layout_unsaved is False`; подписчик вызван ровно 1 раз.
  2. Повторный `mark_layout_saved()` при `False` -> подписчик не вызван, флаг `False`.
  3. `dirty=True`, `diverged=True`, `layout_unsaved=True` -> `mark_layout_saved()` -> `dirty is True`, `diverged is True`, `layout_unsaved is False`.
  4. Ручная правка файла после захвата базы -> автосейв раскладки (конфликт, `layout_unsaved is True`) -> правку откатили (байты файла == база) -> перенос узла -> автосейв:
     в файле позиции новые (`gui_positions["camera_0"] == [111.0, 222.0]` по разбору YAML; литерал `b"111"` не годится — он есть в фикстуре в `1119.9999999999998`), `layout_unsaved is False`.
  5. Автосейв при конфликте (файл правлен и не откатан) -> `layout_unsaved is True` (1.12 не сломана); байты файла == ручной правке.
  6. Автосейв без активного рецепта -> `layout_unsaved` не меняется (был `True` -> остаётся `True`).
  7. `layout_unsaved is True`, `save_layout` бросает `OSError` (двойник на `store.save_layout`) -> автосейв не падает наружу, `layout_unsaved is True` (запись не состоялась — флаг цел).
