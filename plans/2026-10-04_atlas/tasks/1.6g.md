DESIGN (decided by the lead — you type it, you do not derive it):
  1. `codemap.checkout(tree, rows) -> Path` becomes a plain function (no context manager, nothing deleted on exit). Key `f"{sha[:12]}-{digest}"`: `sha = resolve(tree.root, tree.ref)` (`tree.py:46`), `digest = hashlib.sha256("\n".join(roots).encode()).hexdigest()[:8]` over the sorted `roots` it already computes. Directory `tree.root / CHECKOUT_DIR / key`, module constant `CHECKOUT_DIR = Path("data/atlas/checkout")`, `KEEP = 3`. Hit (directory exists) -> `os.utime(dir)` and return it, no `git archive`.
  2. Miss: `tmp = Path(tempfile.mkdtemp(prefix=f".tmp-{key}-", dir=cache))`; `git archive` as today; unpack `subprocess.run([tar, "-x", "-f", "-"], input=..., cwd=tmp, capture_output=True)`. No `tar` on PATH -> stderr line `atlas: tar not found, fallback to tarfile`; non-zero rc -> `atlas: tar failed (rc=<n>), fallback to tarfile`; then `tarfile` with `filter="data"` as today. Then `os.rename(tmp, final)`; `OSError` while `final` already exists (another process won) -> `rmtree(tmp)` and return `final`; any other exception before the rename -> `rmtree(tmp, ignore_errors=True)` and re-raise. A partial tree is never visible under the final name. `/dev/shm` is dropped.
  3. Prune after a successful rename: entries of `cache` not starting with `.`, newest first by `st_mtime`, `rmtree(..., ignore_errors=True)` beyond `KEEP`, never the current key; `.tmp-*` entries older than 3600 s are removed too.
  4. `code_of(tree, rows) -> Code`: in-process memo `_CODES` (insertion-ordered dict, at most 3) keyed by `(str(checkout path), json.dumps(rows, sort_keys=True, default=str))`; a hit whose `parsable` is `False` is rebuilt (1.6e: a failure never sticks). `forget()` clears the memo (tests simulate a new process with it). `views.py:137` and `reference.py:320` become `code = code_of(tree, rows)` with the `with` block removed; the body keeps its order and indentation logic. `__all__` and the `Public API` line gain `code_of`, `forget`.
  5. `Code.graph`: `cache_dir=str(self.base / ".grimp_cache")` instead of `None`; nothing else in `graph()` changes. `Code.__init__` lists only `.py`, so the cache directory stays invisible to it.
  6. Existing 1.6e tests: their warm asserts stay; the cold controls get a helper `_cold(repo)` in `test_cache_1_6e.py` = `codemap.forget()` + `shutil.rmtree(repo.path / "data" / "atlas" / "checkout", ignore_errors=True)`, called right before the cold call in `test_second_ref_and_card_do_no_checkout_and_no_build_graph` (each loop pass), `test_core_version_change_invalidates_cache` (before `again, cold`) and `test_cache_1_6e_code.py::test_source_edit_of_atlas_invalidates_view_cache` (before `_, cold`). Author hazard tests (new file): two threads `checkout` the same key at once -> both return the same complete directory, no exception, one non-dot entry; `tarfile` and `tar` both raising mid-unpack -> no final directory, no `.tmp-*` left; four revisions -> 3 entries, the current one kept.
