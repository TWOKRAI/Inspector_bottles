DESIGN (decided by the lead — you type it, you do not derive it):
  1. The contract under test. `atlas ref|card` on a revision unpacks the `.py` of that revision into `<repo>/data/atlas/checkout/<key>/` (one directory per revision, `<key>` opaque to you) and leaves it there after the process ends; at most 3 such directories are kept (names starting with `.` are temporary and never counted), the newest win. Unpacking uses the system `tar` and must not fall back to `tarfile` when `tar` works; when `tar` is missing or fails, it falls back to `tarfile` and prints to stderr a line containing `fallback to tarfile` (and `rc=<n>` when `tar` ran and failed). In one process a second module of the same revision reuses the parsed revision: no `git archive`, no `tarfile`, no `grimp.build_graph`. `scripts.atlas.codemap.forget()` drops that in-process reuse — call it to simulate a new process. Output of `ref`/`card` is byte-identical whether the revision was warm or cold.
  2. Fixtures and spies are reused, never re-implemented: `from scripts.atlas.tests.test_cache_1_6e import _REFS, _call, _install_spy, _new_repo` (the precedent is `test_cache_1_6e_code.py:17`). `_new_repo` builds modules `m` and `n`; `_call` returns `(Result, {"build_graph": n, "checkout": n})`, where `checkout` counts `git archive` runs plus `tarfile.open` plus `TarFile.extractall`. Calls go through the `atlas` fixture of `conftest.py` (main() in a deadline thread); a subprocess goes through `conftest.run_with_deadline`.
  3. `test_tar_unpacks_without_tarfile_fallback`: skip with a reason when `shutil.which("tar") is None`; monkeypatch `tarfile.open` to raise `AssertionError("tarfile fallback used")`; `ref m` and `card m` -> exit 0, `err == ""`. `test_tar_failure_falls_back_with_warning`: a temp dir prepended to `PATH` (monkeypatch.setenv) holding a fake `tar` that exits 3 — `tar.bat` with `@exit /b 3` on Windows, an executable `#!/bin/sh` script `exit 3` elsewhere; `ref m` -> exit 0, `err` contains `fallback to tarfile` and `rc=3`; `out` byte-equal to `ref m` on a second `_new_repo` without the fake tar.
  4. `test_checkout_survives_the_process`: process 1 = subprocess `sys.executable -m scripts.atlas card m --ref main --main-ref main`, `cwd=repo.path`, `env=dict(os.environ, PYTHONPATH=<worktree root>, PYTHONUTF8="1")` (precedent `_cli`, `test_cache_1_6e.py:196`) -> rc 0; `data/atlas/checkout` holds exactly one non-dot entry with `m/interfaces.py` inside; record its `st_ino`. Then in-process: `codemap.forget()`, spy, `_call(..., "ref", "m", *_REFS)` -> exit 0 and `checkout == 0`; the entry list and `st_ino` unchanged. `test_checkout_keeps_three_revisions`: three more commits each editing `m/core.py`; `ref m --ref <sha> --main-ref main` for the 4 shas oldest first, recording the new entry name after each call; after the 4th -> exactly 3 non-dot entries and the first-recorded name is gone; then `codemap.forget()`, `monkeypatch.setattr(build, "CORE_VERSION", "test-1.6g")` (otherwise the view cache of 1.6e answers without touching the checkout), spy, `ref m` on the oldest sha again -> exit 0, `checkout >= 1`, the first-recorded name is back, `out` equal to its first output.
  5. `test_second_module_in_process_reuses_code`: spy; `card m` (cold control: `build_graph >= 1` and `checkout >= 1`, else the spy did not hook — fail with that message); then `card n` -> `{"build_graph": 0, "checkout": 0}`. GUARD `test_warm_output_is_byte_equal_to_cold`: `ref m` and `card m` cold, then `monkeypatch.setattr(build, "CORE_VERSION", "test-1.6g")` (view-cache miss on a warm revision; precedent `test_cache_1_6e.py` A4) -> both outputs byte-equal to the cold ones, `err == ""`; then the same two views as subprocesses (new process: checkout and grimp cache from disk; same env as in item 4) with `--ref main --main-ref main` -> rc 0, stdout bytes decoded as UTF-8 equal to the cold in-process outputs.
