## Решения

- **Р1. Индекс не хранится (условие А).** Строка индекса `<путь> — <description>` собирается при запросе;
  `search.py --list` выводит все. Сохранённый индекс 367 строк — 116 697 Б, в 14 раз больше 8 КБ. `MEMORY.md` канона
  остаётся ручным (≤ 8 КБ, правит только лид).
- **Р2. Словари (условие Б) — из существующих источников.** `module:` ⊆ id `modules.yaml`; `role:` ⊆ имена файлов
  `.claude/agents/dev/*.md` без `.md`; `mechanism:` ⊆ `docs/claude/memory/TAGS.yaml` (≤ 30). У урока — хотя бы один из
  `module:`/`mechanism:`. `role:` = роль-автор: ставится скриптом по каталогу-источнику; у уроков лида его нет.
- **Р3. Проверка — проектный скрипт** `scripts/memory/tags.py --check`, не `memory_lint.py` (сид `.claude/plugins/core/`
  перезаписывается `claude-kit upgrade`; правки 2.4g.4 в `.claude/plugins/` покрывает правило «`diff` перед upgrade»).
  Подключение к `scripts/validate.py` — **в 2.4g.3, тем же коммитом, что разметка**: раньше `validate` красный
  (модель reviewer на текущем каноне — около 357 ошибок).
- **Р4. Поиск — по main-checkout (условие В).** Корень канона = родитель
  `git rev-parse --path-format=absolute --git-common-dir` + `docs/claude/memory`; вывод — **абсолютные** пути
  main-checkout (относительный путь агент прочтёт в своём устаревшем дереве).
- **Р5 (вердикт CTO `ae4867d0998758143`, вариант (б)).** Новый урок субагент не пишет ни в одно дерево: он отдаёт его

## 2.4g.1 — механизм: словари и поиск (tester → developer)

**Files:** `scripts/memory/tags.py`, `scripts/memory/search.py`, `scripts/memory/tests/` (тестер — свой файл приёмки,
автор — свои), `pyproject.toml` (строка `"scripts/memory/tests"` в `testpaths`), `docs/claude/memory/TAGS.yaml`

**Раскладка корня (`--root DIR`, по умолчанию `git rev-parse --show-toplevel` текущего дерева — не Р4):**
`DIR/modules.yaml` (`modules:` → элементы с `id:`), `DIR/.claude/agents/dev/<role>.md`, `DIR/docs/claude/memory/*.md`,
`DIR/docs/claude/memory/TAGS.yaml`, `DIR/.claude/agent-memory/<role>/`.

**Схема `TAGS.yaml`:**
```yaml
mechanisms:
  - id: break-injection
    def: "one line: what lessons with this tag are about"
```
Число механизмов = число элементов `mechanisms`; 30 — допустимо, 31 — `vocab-too-big`.

**Какие файлы — уроки:** `DIR/docs/claude/memory/*.md` (без подкаталогов) кроме `MEMORY.md`, `ARCHIVE.md`,
`CRAFT*.md`. Тот же набор — для поиска и `--list`.

**Разбор frontmatter — построчный, без YAML-библиотеки** (в 4 файлах frontmatter не разбирается `yaml.safe_load`):
`\r` снимается; frontmatter — строки между первой строкой `---` (первая строка файла) и следующей `---`; ключи
`module`, `mechanism`, `role`, `description` читаются и на верхнем уровне, и с отступом под `metadata:`; одинаковый ключ
в обоих местах — объединение значений; значение — `a`, `"a"`, `a, b`, `[a, b]`, `["a", "b"]` (кавычки у элементов
снимаются, пробелы обрезаются); пустое значение = ключа нет; неэкранированное `: ` в `description:` не мешает чтению
тегов; файла без frontmatter — `no-tag`.

**Контракт `tags.py --check [--root DIR]`:** строка на ошибку `<путь от DIR>: <код>: <значение>` (значение — `repr`,
обрезано до 80 символов: тег из файла репо нужен для правки, управляющие символы экранируются). Коды:
`unknown-module`, `unknown-mechanism`, `unknown-role`, `no-tag`, `vocab-too-big`, `desc-lang` (в `description:` нет
`[А-Яа-яЁё]{3,}` или нет `[A-Za-z]{3,}`), `stray-role-lesson` (файл, кроме `MEMORY.md`, в `.claude/agent-memory/*/`),
`role-index-too-long` (`.claude/agent-memory/<role>/MEMORY.md` > 3 непустых строк).
Выход 1 при ≥ 1 ошибке, иначе 0. Вывод — UTF-8 (`sys.stdout.reconfigure(encoding="utf-8")`).

**Контракт `search.py [WORD...] [--module M] [--mechanism X] [--role R] [--limit N] [--list]`:** нужен хотя бы один
WORD, фильтр или `--list`, иначе выход 2. OR по словам (без учёта регистра, подстрока) в `name:`, `description:`, тегах
и имени файла; ранг = число совпавших слов, при равенстве — по имени файла; фильтры — AND, сравнение точное
(`--module frontend_module` совпадает и с `frontend_module/widgets` — по префиксу до `/`); не больше `--limit` строк
(по умолчанию 8); строка `<абсолютный путь main-checkout> — <description>`; нет совпадений — ровно `none`, выход 0.
Корень — Р4; `--root` — для тестов. Вывод — UTF-8.
