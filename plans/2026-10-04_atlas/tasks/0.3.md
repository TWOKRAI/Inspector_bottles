# Task 0.3 — `modules.yaml` v0: путь → модуль

**Level:** Middle+ (Sonnet). **Assignee:** tester (RED до кода) → developer.
**Goal:** у каждого исходника репозитория есть ровно один модуль; модуль знает слой, ярус и свои документы.
**Plan:** `plans/2026-10-04_atlas/plan.md`, Task 0.3. Потребители: 1.3a (адаптер modules), 1.3b (коммит → модуль), 1.6 (`atlas card`).

## DESIGN (решение лида)

1. Файл `modules.yaml` в корне репозитория. Формат:
   ```yaml
   version: 1
   other_allowed: [run.py, conftest.py, ".claude/", "docs/"]   # что законно остаётся без модуля
   modules:
     - id: process_module            # уникален; правило имён — п.3a; у подмодуля — "<parent id>/<путь от каталога родителя>"
       paths: ["multiprocess_framework/modules/process_module/"]   # префиксы путей от корня, каталог кончается "/"
       layer: framework              # framework | services | plugins | prototype | scripts | tools | docs | infra
       tier: core                    # core | optional | frozen — только у модулей multiprocess_framework/modules; иначе null
       docs: [".../README.md", ".../STATUS.md", ".../DECISIONS.md"]   # только существующие файлы
       parent: null                  # id родителя у подмодуля
   ```
2. Резолвер `scripts/atlas/modules.py` (stdlib + PyYAML, без импорта кода проекта):
   - `load_modules(path: str | Path = "modules.yaml") -> list[dict]`;
   - `resolve(rel_path: str, modules: list[dict]) -> str` — id модуля с САМЫМ ДЛИННЫМ совпавшим префиксом; нет совпадения → `"other"`. Разделитель путей нормализуется к `/`.
3a. Имена id: модуль framework — имя каталога (`process_module`); остальные — `<префикс>/<каталог>`: `services/sql`, `plugins/processing`, `prototype/frontend`, `tools/backend_ctl`; служебные — `framework_meta`, `services_shared`, `plugins_shared`, `prototype_root`.
3. Состав:
   - каждый каталог `multiprocess_framework/modules/<m>/` — модуль, `tier` из таблицы §1 `multiprocess_framework/docs/MODULE_TIERS.md`;
   - корневые файлы `multiprocess_framework/*.py` и `multiprocess_framework/docs/` — модуль `framework_meta` (layer framework, tier null);
   - каждый `Services/<s>/` — модуль (layer services); каждый `Plugins/<category>/` — модуль (layer plugins); `Plugins/_shared/` и корневые `Plugins/*.py`, `Services/*.py` — модули `plugins_shared`, `services_shared`;
   - каждый `multiprocess_prototype/<subpkg>/` — модуль (layer prototype); корневые файлы прототипа — `prototype_root`;
   - `backend_ctl/`, `apps/`, `tools/`, `scripts/`, `Utils/`, `robot/`, `examples/` — по одному модулю (слой: backend_ctl → tools, apps → prototype, tools → tools, scripts → scripts, Utils → tools, robot → prototype, examples → docs).
4. Подмодули (решение владельца 2026-10-04): каталог получает свою строку с `parent`, если в нём ≥ 15 нетестовых `.py`, а в его родительской единице ≥ 60. Правило применяется рекурсивно. Обязательны при любом счёте: `process_module/generic` (`multiprocess_framework/modules/process_module/generic/`) и `prototype/frontend/widgets/tabs/pipeline` (`multiprocess_prototype/frontend/widgets/tabs/pipeline/`, 43 нетестовых `.py`; владелец назвал его «frontend_module/widgets/pipeline», а в framework такого каталога нет).
5. «Нетестовый `.py`» = путь из `git ls-files '*.py'`, у которого ни один сегмент не равен `tests` и имя не начинается с `test_`/не равно `conftest.py`.

## FILES

## REDS (tester пишет до кода; все красные на коммите `ad42c0dd1`)

- `test_every_source_file_has_a_module` — каждый нетестовый `.py` из `git ls-files` резолвится не в `other`, кроме путей под `other_allowed`; `len(other_allowed) <= 10`.
- `test_framework_tiers_match_module_tiers_md` — множество id модулей framework (layer framework, parent null, путь под `modules/`) == множество строк §1 MODULE_TIERS.md (27), ярус совпадает построчно.
- `test_no_dead_rows` — каждый префикс из `paths` совпадает хотя бы с одним путём `git ls-files`.
- `test_docs_exist` — каждый путь из `docs` существует.
- `test_ids_unique_and_parents_valid` — id уникальны; `parent` ссылается на существующий id; пути подмодуля лежат внутри путей родителя.
- `test_longest_prefix_wins` — файл внутри `process_module/generic/` → `process_module/generic`; файл в корне `process_module/` → `process_module`; `README.md` в корне репо → `other`.
- `test_layer_and_tier_values` — layer из разрешённого множества; tier ∈ {core, optional, frozen} у модулей `multiprocess_framework/modules/*` и null у остальных.
- `test_submodule_rule_holds` — тест сам считает по `git ls-files` каталоги, подпадающие под правило п.4, и требует строку для каждого.
- `test_resolve_all_files_fast` — резолв всех путей `git ls-files` < 1 с.
- `test_windows_separators` — `resolve("Services\\sql\\x.py")` == `resolve("Services/sql/x.py")`.

## ACCEPTANCE
