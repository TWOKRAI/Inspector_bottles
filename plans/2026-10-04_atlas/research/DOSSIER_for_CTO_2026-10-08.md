# Досье Атласа для CTO (Fable) — 2026-10-08

Собрано лидом по просьбе владельца: «собрать весь анализ, идеи и данные; пусть Fable подскажет, как улучшить, увидит
иное применение функций, предложит новые механизмы и инструменты, которые повысят эффективность и качество системы».
Числа — замеры этой недели; источник у каждого блока.

## 1. Цель владельца

Атлас — фундамент разработки Inspector_bottles: единая карта проекта, база, планы, автоматизация планирования и
исполнения для многих параллельных агентов (облачных и локальных). Слова владельца: «важно, чтобы система дала и
качество исполнения, а не только экономию»; «если есть способ сделать систему лучше — делать». Справочник (1.6b):
«каждый новый агент и разработчик без разведки видит, что есть и как этим пользоваться; глубже — по ссылке».
Владелец — один человек, проект — многопроцессный фреймворк + прототип инспекции (PySide6, OpenCV), Windows 10.

## 2. Что построено (план `plans/2026-10-04_atlas/plan.md`, ADR `scripts/atlas/DECISIONS.md` ATL-001…003)

- `scripts/atlas/` — 3 049 строк кода, 8 106 строк тестов (197 тестов). Команды: `build`, `check`, `card`, `pack`,
  `ref`, `index`, `log`. База — SQLite `data/atlas.sqlite`, ключ кэша — sha ревизии, main_ref, отпечаток кода, дерево.
- Адаптеры: `plans` (через `plans_progress --json`), `modules` (`modules.yaml`, поле `purpose`), `commits` (трейлеры
  `Refs`/`Task` всех предков без слияний), `code` (AST `interfaces.py`: находки `INTERFACE_WITHOUT_TEST`,
  `PRE_POST_MISSING`), `rules` (1.6c: находки П1–П4 по ADR-175).
- Виды: `card <module>` (назначение, API, задачи, коммиты, находки, «кто использует», доля соответствия правилам);
  `pack <plan>#<task>` (файлы-кандидаты и хвосты прошлых задач: «Осталось», «Не проверено», `NEEDS LEAD`);
  `ref <module>` (справочник: сигнатуры с типами, первая фраза docstring, Pre/Post, `файл:строка`, реализации
  интерфейса явно/структурно, шапка вида ABC/Protocol, «кто использует»; на griffe + grimp); `index` →
  `docs/atlas/INDEX.md` (проект на одной странице, 134 строки).
- Правила кода ADR-175 (принята 2026-10-08, `multiprocess_framework/DECISIONS.md`): П1 реализация явно наследует
  интерфейс (дрейф сигнатур ловит pyright `reportIncompatibleMethodOverride`, включён как warning: 327→380); П2
  docstring Google; П3 `__all__` = публичный API; П4 одна функция атомарной записи для файлов, которые читает другой
  процесс или наблюдатель. Вводятся «храповиком». Находки на пине: P1 29, P2 344, P3 2, P4 18.
- Заморожено (DEFERRED, решение K0): 1.4 адаптер docs, 1.5b инъекции/mutation, 1.8 job mutation, строка доказанности.
  Не начато: 1.7 гейты CI.

## 3. Процесс исполнения (`plans/2026-10-04_atlas/CLOUD.md`, `.claude/CLAUDE.md` «Task launch convention»)

- Реализация — облачные сессии Claude Code (Linux, без qex/sentrux/стенда); локальный лид пишет промпты и проверяет PR
  на Windows; владелец сливает кнопкой.
- Цикл задачи: бриф → стадия 0 (reviewer `MODE: plan`) → слепой tester (RED, worktree на коммите брифа) → developer →
  инъекции с прогнозом отдельным коммитом → reviewer → итог `tasks/<id>.result.md` (≤ 2 КБ) → PR → проверка лида.
- Факт: владелец слил до проверки лида PR #21, #23, #24, #25, #27 (после «пока не вливай»), #29. Задним числом
  дефектов, требующих отката, не найдено; найдены: CRLF/скорость 1.6c на Windows, нестабильный тест 1 из 38.
- Цена: кредит облака $250 → осталось ~$15 (2026-10-08); ~$150 — Атлас P1.1…1.6b, ~$40 — K0 (5 задач), ~$15–20 —
  1.6c; ~$8–15 на задачу при полном цикле. Кредит до 2026-11-05, дальше — лимиты плана.

## 5. Проверка 1.6c на Windows (лид, 2026-10-08, main `2d7e9d8f6`)

- Тесты: 196 из 197; красный — вывод CLI на Windows `\r\n` против `\n` в сравнении байт в байт (дефект вывода/теста).
- Скорость: холодный build 5,5 → 6,1 с; **`card`/`ref` повторный вызов 0,3 → 7,5 с** (облако: ≤ 2,3 с);
  `ref --ref origin/main` 19 с; набор тестов 24 мин 33 с (`test_card_on_origin_main_pin` — 659 с).
- Профиль одного `card` (10,0 с под cProfile): выгрузка ревизии tar → диск, 4 503 файла — 4,6 с; `grimp.build_graph`
  2,3 с (Rust-сканер 1,9 с); чтение 5 633 файлов 1,5 с. Всё повторяется на каждый вызов. План лида — задача 1.6e:
  кэш результатов griffe/grimp/rules в SQLite по ключу ревизии, LF в выводе CLI. Многопоточность/Rust отклонены лидом:
  узкое место — повтор работы и файловый ввод-вывод Windows, ядро grimp уже на Rust.
