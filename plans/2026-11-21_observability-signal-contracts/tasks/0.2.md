DESIGN (decided by the lead — you type it, you do not derive it):
  1. `freshness.py`: `FRESH_KEY = "_fresh"`; `stamp(seq, src_ts, incarnation, tick_sec) -> dict` ровно с этими ключами;
     `src_ts` — стенные часы писателя (`time.time`).
  2. `classify(subtree, now, alive_incarnation) -> Literal["no_data", "fresh", "stale", "writer_gone"]`, по порядку:
     поддерева нет или нет `_fresh` → `no_data`; `alive_incarnation` задан и не равен `incarnation` → `writer_gone`;
     `now - src_ts > 2 * tick_sec` → `stale`; иначе `fresh`. Ноль — значение, не класс.
  3. `read_value(subtree, key, now, alive_incarnation) -> {"class", "value", "age_s"}`: ключа нет или он `None` →
     класс `no_data`. Четыре ответа D1 — разные пары: нет данных (`no_data`, None); ноль (`fresh`, 0);
     устарело (`stale`, последнее значение); писатель ушёл (`writer_gone`, последнее значение).
  4. Экспорт из `__init__.py`. Чистые функции над `dict`; `now` передаёт читатель.
  5. ADR: `TreeStore.revision` (`tree_store.py:81–94`) — счётчик дерева, а не писателя; `Delta.timestamp`
     (`delta.py:93`) — монотонные часы процесса стора; ни то, ни другое не даёт возраст значения у писателя. Возраст
     между машинами требует синхронных часов (самопроверка — 1.6).
  6. Контракт-тест (tester, слепо). Параметры читателей: `tree` (`read_value` над поддеревом `StateStoreManager`),
     `read_model` (`TelemetryReadModel`), `telemetry_snapshot` (`backend_ctl`, подставной транспорт). Тесты на каждый
     читатель: `test_stopped_writer_is_stale` (такт 5.0 с; через 10.1 с после последней метки → `stale`) и
     `test_four_answers_distinct` (четыре пары п. 3).
