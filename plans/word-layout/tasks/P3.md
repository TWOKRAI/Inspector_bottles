### Д1. Строка журнала на каждый диск — `plugin.py`, `_handle_item` (`:157-235`)

Ровно одна строка `ctx.log_info` на диск. Диск — item, у которого `_top_pred` не `None`; кадр ниже порога (`below_threshold`, `confidence < min_confidence`, NaN) — **не диск, строки нет** (иначе строка на каждый кадр; инвариант «ниже порога кадр не сжигает слот», `README.md:51-56`).

**`_should_take`, `_taken_track`, `_armed`, `_settle`, `_cur_label`, `_trig_armed` — не меняются**, порядок `_handle_item` (`:157-235`) — прежний: пустое слово `:158-160` и «готово» `:170-172` по-прежнему выходят **до** `_should_take`. Правки по шагам:

1. Пустое слово (`:158-160`) и «готово» (`:170-172`): перед `return item` — `self._note_skip_once(item, "<причина>")`. Новый метод только **читает** `self._top_pred(item)` и `self._disk_id(item)` и пишет одно своё поле `self._logged_skip_key` (заводится в `configure`, `None`): ключ диска = `("tid", tid)` при `tid is not None`, иначе `("label", label)`; `pred is None` (пауза) → строки нет, ключ вида `("label", …)` сбрасывается в `None` (следующий диск без `track_id` — новый, даже с той же буквой), ключ `("tid", …)` на паузе не трогается (моргнувшая уверенность или контрольный item того же `track_id` — тот же диск); ключ совпал с `_logged_skip_key` → строки нет; иначе строка + запомнить ключ. Причину ключ не хранит: когда слово задали, тот же диск идёт обычным путём (шаги 2–4). В триггер-режиме ключ не применяется, строка — на каждый item с сигналом `item[trigger_source]` (чтение, `_trig_armed` не трогать). При `settle_frames > 1` пропуск пишется на первый кадр диска, без ожидания стабильности (в рецепте `settle_frames 1`).
2. Нет `pick` при `require_pick` (`:188-191`): `_note_no_pick()` как было **и** строка «пропуск: нет координаты забора» (после `_should_take` — один раз на диск по построению).
3. `offer → None` (`:202-204`): причина по `self._assembler.slots_of(pred["label"])` (Д2): `[]` → «нет в слове», иначе «ячейки заняты» со списком.
4. Взятый диск: строка по формату ниже вместо `:229-234` **и** запись своего ключа в `_logged_skip_key` (своё поле; иначе тот же tid после `done` даёт лишнюю «слово готово»).

Следствие (закрепляет RED 11): диск, пропущенный по «слово не задано» / «слово готово», **не** помечен взятым — задали слово, тот же `track_id` в следующем кадре берётся, как до правки. Пропуск + решение — две строки на один диск (RED 11).
