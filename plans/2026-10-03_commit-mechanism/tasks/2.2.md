## DESIGN (решено лидом — исполнитель печатает, не выводит)

  (a) **Одна копия гайда — `.claude/COMMIT_GUIDE.md`.** Собрать в неё всё проектное из обеих копий, привести к формату v2
      (ниже). `docs/claude/COMMIT_GUIDE.md` — заглушка ≤ 5 строк: заголовок и строка «Единственная копия —
      `.claude/COMMIT_GUIDE.md`». Ссылки на старый путь не править (заглушка их держит).
  (b) **Формат v2 в гайде** (разделы): тема `<type>(<scope>): <описание>` — ориентир 72 символа, после 72 и 100 —
      предупреждение, отказа нет; типы, в том числе `merge` (без scope); scope `[a-z0-9_./,-]`; трейлеры `Why`, `Layer`
      (9 значений из `.claude/commit-layers.txt`), `Refs` (путь плана; обязателен на ветке с планом; подходит любой
      существующий план, не `plans/queue/`, не `.result`), `Task: <slug>#<id>` (по желанию; slug — поле Slug плана без
      даты; примеры `commit-mechanism#2.1`, `atlas#1.3a`, `atlas#K1.1`), необязательные `Risk`/`Reversible`/`Tested`/
      `Rejected`, `Co-Authored-By`. **Правило блока:** все трейлеры — один абзац в самом конце, пустая строка между
      телом и блоком, внутри блока пустых строк нет, `Co-Authored-By` — в том же блоке; перенос значения — с отступом.
      Почему: иначе `git log --format=%(trailers)` их не видит (пример: 0 из 200 коммитов до 2026-10-04). Раздел
      «Слияния»: `merge: <что вошло>` + Why/Layer/Refs; синхронизация `merge: main (<sha>) в <ветка> — <зачем>`. Раздел
      «Фаза»: сейчас предупреждения, строгий режим — Task 3.1.
  (c) **Раздел «Привычки» в гайде** — три команды литералами:
      - сообщение — файлом через Write, затем `git commit -F <файл> -- <пути>`; без heredoc с прозой;
      - слияние — `git merge --no-ff <ветка> -F <файл>`, файл писать и сливать ОДНИМ вызовом Bash (`-F -` не читает stdin);
      - после записи `.py` через Bash/cp/sed/merge — `ruff format <пути> && ruff check --fix <пути>` до `git add`;
        F401 чинится руками;
      - без `| grep` / `| tail` после `git commit`: прячет отказ хука и подменяет код выхода.
  (d) **`.gitmessage`** — тот же формат: без «≤72» как лимита, 9 слоёв, `Refs: plans/<…>/plan.md`, строка `Task:`, пример —
      одним блоком вместе с `Co-Authored-By`, без пустой строки перед ним.
  (e) **Корневой `CLAUDE.md`**, раздел «Формат commit-сообщений» — одна строка добавляется: «Трейлеры — одним абзацем в

      Атласа).
  (f) **`project-rules` §4** (источник `.claude/plugins/dev/skills/project-rules/SKILL.md` и зеркало `.claude/skills/…`
      байт-в-байт): вторую строку списка заменить на «Conventional Commits; трейлеры `Why:`/`Layer:` обязательны, `Refs:`
      из плана — одним абзацем в конце вместе с `Co-Authored-By`, без пустой строки внутри. Сообщение — файлом, `git
      commit -F <файл> -- <пути>`. Гайд и привычки: `.claude/COMMIT_GUIDE.md`.» Размер ядра не растёт больше чем на
