## Замер

MEASURED (шаги 1–2, лид, 2026-10-04, `main` 2918e7dea; скрипты в scratchpad сессии):
  Метод: вход настоящей правки (`tool_name=Write`, путь `D:/…`) в исходный хук и в копию с `| tr -d '\r'` после Python.

  - **check-imports.sh** — мёртв на Windows, ПОДТВЕРЖДЕНО.
    - Файл с синтаксической ошибкой: исходный хук — 0 байт вывода, 332 мс; копия с `tr` — предупреждение 319 Б, 554 мс.
    - Делает `py_compile` (имя врёт: импорты не проверяет).
    - Даже живой, пишет обычный текст в stdout. Агенту такой текст не виден: нужен JSON `additionalContext`.
    - Дублирует 1.2: живой `autoformat-python.sh` на том же файле отдаёт в `additionalContext` две строки
      `invalid-syntax` от ruff.
    - Цена сейчас: ~330 мс на КАЖДУЮ правку любого файла (запуск Python до проверки расширения), пользы ноль.
  - **typecheck-changed.sh** — мёртв по построению на ЛЮБОЙ платформе, дефектов три:
    1. выключен флагом `CLAUDE_TYPECHECK_ON_EDIT` (не задан нигде: проектные и глобальный settings) → выход за 92 мс;
    2. дефект `\r` на Windows;
    3. `OUT=$(timeout 30 pyright …) || exit 0`: pyright при найденных ошибках выходит с rc=1 → хук выходит
       молча ровно тогда, когда есть что сказать. Опыт: `return undefined_name` → pyright rc=1, errorCount=1;
       копия с `tr` — 0 Б stderr; копия с `tr` и без `|| exit 0` — `pyright: 1 type error(s)… "undefined_name" is not
       defined`;
    4. (канал) вывод в stderr при exit 0 агенту не виден.
    - Даже починенный, говорит редко: в `[tool.pyright]` десять правил понижены до `warning`, хук берёт только `error`.
      На 5 реальных файлах (22–790 строк) — 0 ошибок, 0 предупреждений.
    - Цена живого: pyright на один файл 0,9–2,9 с на каждую правку `.py` (каждый запуск холодный, второй прогон не
      быстрее: 915–2858 мс).
    - pyright уже стоит в pre-commit (`|| true`, advisory) и в `make check`.
  - **semgrep-scan.sh** — инертен трижды: не зарегистрирован нигде (шапка: «OPT-IN»), semgrep не установлен, дефект
    `\r`. Вывод — stderr, тоже невидим. Цену не замерить без установки semgrep (пакеты ставит владелец).
  - Копий этих хуков в репозитории нет; глобальная копия `check-imports` в `~/.claude/settings.json` — отдельный вопрос
    владельцу (1.2.result.md).
