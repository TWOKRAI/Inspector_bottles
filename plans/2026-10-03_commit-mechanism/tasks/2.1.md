## DESIGN (решено лидом — исполнитель печатает, не выводит)

  (a) **Режим.** Модульная константа `STRICT = False` в обеих копиях. Всё, что в таблице помечено «WARN → ERR в фазе 3»,
      при `STRICT = False` идёт в `result.warnings`, при `True` — в `result.errors`. Task 3.1 переключит константу.
      Env-флага нет.
  (b) **Слияния больше не пропускаются.** Из `SKIP_PREFIXES` уходят `Merge ` и `merge: `; остаются `Revert `,
      `fixup!`, `squash!`, `amend!`. Тип `merge` добавлен в разрешённые; у `merge` нет scope (`merge(x):` — ошибка
      всегда). Текст git по умолчанию — regex `^Merge (remote-tracking )?branch |^Merge pull request ` — WARN.
      Для коммитов типа `merge` все нарушения трейлеров (`Why`, `Layer`, `Refs`) — WARN → ERR в фазе 3.
  (c) **Scope:** `[a-z0-9_./,-]+` (добавлена точка). Пробелы в scope — как сегодня (не трогать).
  (d) **Слои.** `.claude/commit-layers.txt` — 9 строк: `framework services plugins prototype docs scripts tests infra
      mixed`. Семантику валидатора для пустого файла НЕ менять (пустой → `Layer:` необязателен): это поведение сида
      для других проектов, а копии обязаны совпадать. A4 закрывает сторож-тест на файле этого проекта.
      *Отклонено:* «пустой файл → отказ» (CTO B2b) — сломало бы коммиты проектов на сиде с файлом-заготовкой. CTO
      принял это решение при арбитраже (стадия 0, 2026-10-04).
      *Отклонено:* WARN `layers list empty` в обоих режимах (страховка CTO от отката файла upgrade-ом) — проекты, которые
      выключили Layer заготовкой сознательно, получали бы предупреждение на каждом коммите. Откат ловит G2.
      Нарушения `Layer` для обычных коммитов (нет / вне списка) — WARN → ERR в фазе 3.
  (e) **Длина subject** = вся первая строка, `len(first_line)`, включая `type(scope): ` (кириллица = 1 символ). После 72
      — WARN, после 100 — другой WARN. Отказа нет ни в каком режиме (решение владельца).
  (f) **Refs.** Если ветка разрешается в план — `Refs:` обязателен (как сегодня, ERR) и подходит ЛЮБОЙ существующий
      план: путь из `PLAN_PATH_RE`, файл есть на диске от корня worktree, не под `plans/queue/` и без `.result` в
      имени. Иначе — ERR с текстом, называющим причину. Если ветка в план не разрешается — `Refs:` не проверяется.
  (g) **Фолдинг трейлеров** (из `scripts/`) переносится в шаблон: после задачи копии равны по `ast.dump(ast.parse())`.
  (h) Тексты предупреждений — литералы ниже; тест сверяет подстроку.

| Код | Текст (подстрока в stderr) |
|---|---|
