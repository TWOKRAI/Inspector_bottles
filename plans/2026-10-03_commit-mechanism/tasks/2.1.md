  (b) **Слияния больше не пропускаются.** Из `SKIP_PREFIXES` уходят `Merge ` и `merge: `; остаются `Revert `,

      всегда). Текст git по умолчанию — ЛЮБАЯ первая строка, начинающаяся с `Merge ` (заглавная; ветки, remote-tracking,
      pull request, `Merge tag …`, `Merge commit …`) — WARN. *Ред. 4:* узкий regex ред. 3 отклонял `Merge tag`/

## Ред. 6 (2026-10-04): трейлер `Task:` и трейлеры одним блоком

Источник: atlas `research/O3_git_freshness.md` вопрос 3, atlas Task 0.1 (предусловие), решение владельца 2026-10-04
«2.1 плюс трейлер Task: из п.3». Формат сверен с сессией Атласа: все id плана atlas ложатся в грамматику (j).

### FACTS (замер лида 2026-10-04)

- `git log -200 --format='%(trailers:key=Refs)'` на `main` — 0 непустых; `%B | grep ^Refs:` — 201 (CTO_VERDICT §1).
- `git interpret-trailers --parse` на шаблоне «Why/Layer/Refs/Task, пустая строка, Co-Authored-By» печатает только
  `Co-Authored-By`. Без пустой строки — все пять. Перенос значения `Why:` без отступа внутри блока — git не видит
  НИ ОДНОГО трейлера (блок перестаёт быть трейлерным). Перенос с отступом — видит все, значение склеено. Строка `#`
  внутри блока git не мешает.
- Цена вызова `git interpret-trailers --parse` на Windows: медиана 17 мс, 15–35 мс на 20 вызовах.

### DESIGN (решено лидом)

  (i) **`Task:`** — известный трейлер (в `KNOWN_TRAILERS`, ищется по всему сообщению, как остальные). Необязателен в
      обоих режимах; обязательность решает владелец в 3.1. Значение — один id на строку, несколько задач — несколько
      строк `Task:`. Грамматика значения целиком: `^[a-z0-9][a-z0-9-]*#[A-Z]{0,3}\d+(?:\.\d+)*[a-z]?$` — slug плана без
      даты (поле Slug плана), `#`, id задачи (`2.1`, `1.3a`, `K1.1`, `P1.1`). Значение не по грамматике — W-TASK-FORMAT,
      WARN → ERR в фазе 3. Существование slug и id НЕ проверяется (atlas 1.7, CI).
  (j) **Один блок.** Оракул — сам git: текст сообщения без строк `#` → `git interpret-trailers --parse` (stdin). Ключи из
      `KNOWN_TRAILERS`, найденные в сообщении (тот же поиск «где угодно»), которых нет в выводе git, — W-TRAILERS-SPLIT
      с перечнем ключей, WARN → ERR в фазе 3. Сообщение без известных трейлеров — git не зовётся. Правило одно для
      обычных коммитов и `merge:`; `Revert`/`fixup!`/текст `Merge …` по умолчанию — как раньше, до него не доходят.
  (k) **git недоступен** (нет бинаря, rc ≠ 0, таймаут 5 с) — предупреждение W-TRAILERS-UNCHECKED, НЕ фаза 3: ошибкой
      не становится ни в каком режиме. Молча пропускать нельзя (правило «ошибки не глушить»).
  (l) Окно шума: до 2.2 шаблон в документах ставит пустую строку перед `Co-Authored-By`, и W-TRAILERS-SPLIT сработает
      почти на каждом коммите. Поэтому 2.1 вливается в `main` только вместе с 2.2 (согласовано с сессиями Атласа и
      plans-progress 2026-10-04).

| W-TRAILERS-SPLIT | `trailers git does not see` (дальше — имена ключей) |
