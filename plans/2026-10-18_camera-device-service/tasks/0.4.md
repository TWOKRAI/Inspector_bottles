DESIGN (decided by the lead — you type it, you do not derive it):
  1. `--dump --serial <s>|--ip <ip> --out <path.json>`: открыть, для курируемого списка узлов (`TriggerMode`, `TriggerSource`, `ExposureTime`, `ExposureAuto`, `Gain`, `GainAuto`, `AcquisitionFrameRate`, `AcquisitionFrameRateEnable`, `Width`, `Height`, `PixelFormat`, `GevSCPSPacketSize`, `GevSCPD`, `DeviceSerialNumber`, `DeviceModelName`) записать снимок в двух состояниях — до захвата (`idle`) и во время (`grabbing`). Схема — [`recording-schema.md`](../recording-schema.md) (`schema_version: 1`; фиксирует эта задача, стадия 0 1.5 принимает): верхние ключи `schema_version`, `vendor`, `sdk_version`, `device`, `states`, `nodes`; у узла `type`, `min`, `max`, `inc`, `entries`, `entry_values` (enum) и по состоянию `{value, access, rc}`. int — `MV_CC_GetIntValueEx` (`GetIntValue` устаревший, `MvObsoleteInterfaces.h:502`).
  2. `--experiment h1|h2|h5`: H1 — запись `TriggerMode` после `StopGrabbing` (`--delay 0` и `1.0`), H2 — `same`/`split` потоки, H5 — провокация кода ≠ 0 записью `Width` во время захвата (ожидается `MV_E_GC_ACCESS` `0x80000106`, `MvErrorDefine.h:55`; на приборе не проверено), затем чтение `Width`. После каждой записи — чтение узла, строка `node= rc=0x… read= ms= thread=`.
  3. `--fake`: тот же код на `FakeMvCamera`, который живёт в `mvs_probe.py` (тест берёт его оттуда; инструмент не импортирует `tests/`). Фейк ведёт журнал вызовов `(имя, args)` и состояние узлов; запись `Width` во время захвата отвечает `0x80000106`.
  4. Только чтение по умолчанию; запись — только с флагом `--write` и с сохранением исходных в `--orig <path.json>` ДО первой записи (та же схема, `states: ["idle"]`, только узлы, которые опыт будет писать).
  5. Возврат: после опыта с `--write` — записанные узлы возвращаются к значениям `--orig` в обратном порядке записи, каждый читается, строка `restore node= rc=0x… read=`; расхождение -> строка `RESTORE MISMATCH node= want= got=` и код выхода 2 (образец — `Services/code_reader/tools/mvcr_probe.py:258-279`). Отдельный режим `--restore <orig.json>` делает только возврат (тем же загрузчиком).
