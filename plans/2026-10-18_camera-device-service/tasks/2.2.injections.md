# Task 2.2 — прогнозы break-injection (лид, 2026-11-15, ДО прогона независимой проверки)

Исполнитель уже прогнал свои J1–J11 (rest до stop_grabbing; нет чтения после записи; чтение исходных; rest после close; отказ прерывает план; допуск `==`; без `inc`; без `eps_abs`; H5 не распознан; enum числом; профиль не из потока владельца) — лид видел их результат ДО записи этого файла, поэтому они в зачёт «прогноза лида» не идут. Ниже — ПЯТЬ НОВЫХ инъекций, которых исполнитель не гонял; прогнозы записаны по спецификации (имена пунктов ACCEPTANCE), без чтения тел тестов. Прогон — независимый ревьюер волны (Opus); откат — cp.

| # | Инъекция | Прогноз |
|---|---|---|
| K1 | пропущенный по родителю шаг не добавляется в `blocked` (транзитивность снята) | красный только hazard «родитель отказал -> дети и внуки не пишутся, `errors == 1`»; слепой файл зелёный |
| K2 | rest выполняется и в состоянии `error` | красный hazard «error-состояние -> rest не выполняется»; слепой зелёный |
| K3 | упал `open` ветки reopen, а итоговый `close` всё равно зовётся | красный hazard «упал open reopen -> close не зовётся, errors += 1»; слепой зелёный |
| K4 | `params_status` не сбрасывается в начале `start()` (params и param_errors сбрасываются) | красных нет — предсказанная ДЫРА покрытия (спека требует сброс всех трёх; тест на `params_status` второго прогона не заявлен) |
| K5 | `errors` сбрасывается в начале каждого `start()` | красный `test_второй_старт_после_отказа_rest` (ожидает `errors == 1` и после второго старта) |

Сверка: «красный только …» — точное множество; K4 — прогноз «ничего не краснеет» (если краснеет — дыры нет, и это хорошо).
