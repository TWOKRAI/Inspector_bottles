  1. `frame_watch.py`. Докстринг new-lite: `Purpose:`, `Public API:`, `Stability: lite`; `__all__ = ["FrameWatch"]`.
     Класс `FrameWatch(deadline_s: float)`. Pre: `deadline_s > 0`; `now` не убывает и берётся под замком вызывающего; не потокобезопасен.
     Pre для источника: `on_trigger` зовётся ДО прихода кадра этого импульса, иначе ложный пропуск. Помощник ничего не знает о связи: импульсы во время обрыва — пропуски.
     - `on_trigger(now)`:
       - очередь (`deque`) уже 1024 -> самый старый снять как пропуск (`misses += 1`, `open_miss = True`, `last_miss_mono = now`);
       - затем добавить импульс, `triggers += 1`.
     - `on_frame(now)`:
       - сначала учесть просроченные по правилу `poll`, без возврата: учтённые войдут в следующий `poll`;
       - затем снять самый старый оставшийся (если есть);
       - `open_miss = False`. Кадр без ждущего импульса ничего не считает.
     - `poll(now) -> int`: каждый ждущий с `now - t > deadline_s` снять, `misses += 1`, `open_miss = True`, `last_miss_mono = now`. Возвращает пропуски с прошлого `poll`, включая учтённые в `on_frame` и при переполнении.
     - `withdraw_last() -> bool`: снять самый новый ждущий и `triggers -= 1`. Нужен источнику, чей импульс не состоялся (W2-t2, `software`). Очередь пуста -> `False`.
     - `drop_pending()`: очередь пуста, `open_miss = False`, счётчики целы.
     - `reset_counts()`: `triggers = misses = 0`, `last_miss_mono = None`, `open_miss = False`, очередь цела.
     - `snapshot() -> dict`: `{"triggers", "misses", "open_miss", "last_miss_mono"}`.
     Предел (в докстринг, `info` поля и `plate-modes.md`): у кадра нет номера импульса, сопоставление FIFO. Пропуск виден вовремя, только если задержка кадра < срок < период импульсов; иначе следующий кадр маскирует пропуск.
     Почему так:
     - FIFO — номера импульса в кадре нет;
     - кадр без импульса не считается — свободный поток и поздние кадры не должны давать «пропуск наоборот»;
     - `maxlen=1024` — потолок памяти при источнике без кадров: при 100 Гц это ~10 с ожидания, все сверх — уже пропуски.
