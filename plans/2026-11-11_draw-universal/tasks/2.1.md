     `from` (путь `get_path`), `each`, `figure` (`circle|line|polyline|rect|text|point`), пути по виду (`center`,
     `radius`, `points` (`"."` = сам элемент), `xyxy`, `p1`, `p2`), `group`, `type`, `enabled: bool = True`, `when` /
     `unless` (путь, проверка на истинность; отсутствие поля = ложь), `text` или `parts: [{text, when?, unless?}]`
     (шаблоны `ItemTemplate`; `MissingField` в части → часть пропускается), `anchor` (`[x, y]` или путь к списку чисел —
     берутся первые два: `center`, `bbox`) и `offset`
     `[dx, dy]`, `group_when: [{when, group}]`, переопределения стиля (`color`, `thickness`, `alpha`, `fill`, `font`,
     `font_px`). Правило `{from: overlay}` → `scene_from_overlay`. `compile_rules(rows) -> list[MappingRule]` —
     `ValueError` с номером правила; `build_scene(item, rules, frame_wh) -> Scene`. ndarray-точки контура формы
     `(N, 1, 2)` и `(N, 2)` → `list[list[int]]`: сцена остаётся JSON.
  2. `scene.py:StyleTable` — строки `styles` первыми, затем `color_table` (живой, r1 `:257`), тот же порядок резолва;
     новые ключи `font`, `font_px`, `alpha`, `fill`.
  3. `registers.py`: `backend: str = "auto"`, `burn: bool = True`, `max_fps: float = 0.0`,
     `mapping: list[dict] = [{"from": "overlay"}]` (умолчание = сегодняшнее поведение), `styles: list[dict] = []`;
     только для чтения: `active_backend: str`, `drawn: int`, `skipped: int`, `last_error: str`. Старые регистры — без
     изменений.
  4. `plugin.py`: `configure` — `compile_rules`, `get_backend(reg.backend)` один раз, `RateGate(reg.max_fps)`.
     `process`: `allow()` ложь → `skipped += 1`, вернуть `None` до сборки сцены и до копии (кадр не идёт дальше: иначе
     показ мигает); иначе `build_scene`; `burn` → копия (правило 1.1: серый — без копии) + `render`, выход
     `{**item, "frame": canvas, "scene": scene}`; `burn: false` → кадр не трогается, выход `{**item, "scene": scene}`;
     `drawn += 1`. Правка `mapping`/`styles` вживую: механизм смены регистра называет стадия 0 по path:line в
     `registers_module`; нет хука — сравнение `is` с последним скомпилированным списком в начале `process`; неверная
     правка — остаётся прежний набор, текст ошибки — в `last_error` и лог.
  5. Порты: входы `detections` (`list[dict]`), `contours` (`list[ndarray]`), `predictions` (`list[dict]`), `mask`
     (`image/gray`) — `optional=True`, `join` не задан; выход `scene` (`list[dict]`, `shape="-"`). `frame` и `overlay`
     — без изменений (`design.md` §4).
