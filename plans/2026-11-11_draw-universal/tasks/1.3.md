DESIGN (decided by the lead — you type it, you do not derive it):
  1. Фигуры сцены: `rect` (`xyxy`), `polyline` (`points`, `closed`), у любой фигуры — `fill: bool`, `alpha: float`
     (по умолчанию 1.0). `lower`: `rect` → `Op("rect")`; `polyline` → `Op("polyline", closed=...)`; фигура с
     `alpha < 1` или `fill` с альфой → `Op("patch")`: маска фигуры — uint8-ROI её рамки (`cv2.fillPoly` / `cv2.rectangle` /
     `cv2.circle`), цвет и альфа — в `Op`. Покрытие пикселя `c = m * alpha` (0..255, не бинарное): смесь
     `roi = (roi*(255-c) + color*c) / 255`, как в Task 1.2 шаг 4; `cv2.copyTo` по маске не годится.
  2. `Cv2Backend.render` — коды `line`, `polyline`, `circle`, `rect`, `patch`; `caps = Capabilities(kinds=все пять,
     native_text=False, antialias=True, pixel_formats={"bgr8"}, inplace=True, exact_as=None)`. Смешивание `patch`
     читает пиксели холста в момент операции — порядок операций = порядок сцены; пересечение двух полупрозрачных
     фигур смешивается последовательно, не «дважды из исходника» (ловушка r1 `:161`).
  3. Реестр (`design.md` §1.1): фабрика бэкенда кидает `ImportError` → `get_backend` поднимает `RuntimeError` с именем
     бэкенда и подсказкой; неизвестное имя → `ValueError` со списком; `get_backend("auto")` выбирает первый доступный по
     порядку регистрации (сейчас `cv2`) и пишет выбранное имя в лог один раз; замены по ошибке нет.
