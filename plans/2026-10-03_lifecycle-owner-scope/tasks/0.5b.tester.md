DESIGN (decided by the lead — you type it, you do not derive it):
  1. Плагин `scripts.lifecycle_guards.pytest_plugin` подключается ключом `-p scripts.lifecycle_guards.pytest_plugin`. Все тесты, кроме чистых вызовов функций, идут в ПОДПРОЦЕССЕ: `sys.executable -m pytest -q -p no:cacheprovider -c <tmp>/pytest.ini -p scripts.lifecycle_guards.pytest_plugin <tmp>`, `cwd=<tmp>`, `<tmp>/pytest.ini` содержит `[pytest]`, env: `PYTHONPATH=<корень репозитория>`, `PYTHONUTF8=1`, `QT_QPA_PLATFORM=offscreen`, срок `timeout=120`. Внутри `<tmp>` вы пишете свои мини-проекты тестов.
  2. Ручки env: `LIFECYCLE_G3`, `LIFECYCLE_G4` ∈ `off|report|fail`; умолчания G3 `report`, G4 `report`; неизвестное значение → `report` и строка предупреждения. В конце сессии раздел `lifecycle-guards report` в выводе pytest. Строки: `G3 unclosed roots: N` и `  <path> (<state>)`; `G4 threads without scope path: N` и `  <nodeid> :: <имя потока>`. Режим `report` код возврата pytest не меняет (зелёные тесты → код 0 при любых N); `fail` при N > 0 → код возврата 1; `off` — раздела нет вообще. Раздел выводится и при зелёной сессии без нарушений (строки с `0`) в режимах `report` и `fail`.
  3. G3: незакрытые корни области процесса на конец сессии. Источник — `multiprocess_framework.modules.base_manager.open_scope` и `unclosed_roots()`. Мини-проект: тест создаёт `open_scope("leaky", budget_s=1.0)` и не закрывает → `G3 unclosed roots: 1` и строка с `leaky`; закрытый `root.close()` → `G3 unclosed roots: 0`.
  4. G4: после каждого теста новый живой поток, в имени которого нет символа `/`, — запись. Мини-проект: тест стартует `threading.Thread(target=stop_event.wait, name="rogue-1")` и не останавливает → `G4 threads without scope path: 1` и `  <nodeid> :: rogue-1`; поток с именем `r/tab/w` (живой после теста) → не запись; поток, завершившийся до конца теста, → не запись.
  5. Раннер пробы: `python -m scripts.lifecycle_guards.probe run [--mode offmain_gc] [--runs N] [--targets P ...] [--no-conftest] [--cwd DIR] [--skip-axis]` и `python -m scripts.lifecycle_guards.probe axis [--runs N] [--script PATH]`. Раннер запускает `pytest` в подпроцессе `runs` раз в `--cwd`, цели — пути от `--cwd`; плагин пробы `-p scripts.lifecycle_guards.probe.crashprobe` в режиме `offmain_gc` пишет в `CRASHPROBE_LOG` (раннер ставит свежий файл на каждый прогон) строки `[offmain_gc] at first logger test: gc-tracked QWidget/QWindow wrappers alive-or-garbage = W` и `[offmain_gc] collected K objects on thread …` — только на первом тесте, у которого в nodeid есть `logger_module`, и только если загружен `PySide6`; иначе плагин молчит.
  6. Классы исхода прогона (проверять в таком порядке): `crashed` — в выводе `Fatal Python error` или `access violation`, либо код возврата из `{134, 139, -6, -11, 3221225477, 3221225725, 3221226505}`; `not-triggered` — не crashed и в журнале нет строки `[<mode>] at first logger test` (её пишут все режимы); `failed` — иной ненулевой код (в том числе 3 — `INTERNAL_ERROR` pytest); `survived` — код 0 и строка `[<mode>] at first logger test` есть. Итоговая строка `probe offmain_gc: survived S/N, crashed C, failed F, not-triggered T, wrappers W (secs a/b/c)`; код возврата раннера 0 только при `survived == N`; при мёртвой оси (без `--skip-axis`) — слова `ось не живая`, код 2, прогонов набора нет.
  7. Ось: `axis` запускает скрипт `<script> thread` и `<script> main` по `runs` раз (offscreen); жива, если `thread` упал (класс `crashed`) во всех прогонах и `main` выжил (код 0 и в выводе `SURVIVED main`) во всех; печатает `axis: alive` (код 0) или `axis: dead (thread crashed X/N, main survived Y/N)` (код 2). `--script PATH` подменяет репродуктор и включает проверку на любой платформе. Ваши подмены — маленькие скрипты на Python: `thread` вызывает `os._exit(3221225477)` (или `faulthandler`-падение, если нужно проверить признак текста), `main` печатает `SURVIVED main` и выходит 0.
  8. `test_runner_works_without_pythonpath`: запустить `python scripts/run_framework_tests.py base_manager/tests -q` из корня репозитория с env без `PYTHONPATH` (`os.environ` копия без этого ключа), срок `timeout=600`: код 0 и в выводе `lifecycle-guards report`.
