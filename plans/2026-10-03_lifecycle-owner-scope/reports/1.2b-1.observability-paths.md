# 1.2b-1 — пути логирования: один ли механизм (reviewer `adf97e39ec14658b3`, 2026-10-12)

Запрос владельца: идёт ли вся наблюдаемость через один механизм. Дерево `lifecycle-impl-1.2b`, только чтение. Репро — scratchpad лида `repro/` (`r_paths.py`, `r_slots.py`, `r_console.py`). Счётчик писателя — прирост `messages_processed` у `LoggerManager` процесса. Текст перенесён лидом.

**Вывод: ожидание опровергнуто.** Писатель журнала один — `LoggerCore` (экземпляр процесса `LoggerManager._instance`). Дорог к нему две, и в случаях (a) «логгер не подключён» и (c) «логгер уже погашен» они ведут себя по-разному. Плюс задуманные прямые выходы в stdlib (только stderr). Плоскость ошибок — второй `LoggerCore` (`ErrorManager`), так задумано (ADR-BM-006: факт и голос).

3. (c): после `lm.shutdown()` P1/P4 → `True`, `processed +1`, `unresolved_channel_records +2` в погашенном; строки нет. Вид → stderr.

## Ошибка останова и плоскость ошибок

ADR-BM-006 (`base_manager/DECISIONS.md:77`): отказ менеджера — `report_error`: факт в плоскость ошибок всегда и первым, голос — по окну. Порядок корня (LIFO): `work` → `transport` → `planes` (observation → stats → error → planes_report → final_status → logger): транспорт, `stats`, `observation` гаснут при живой плоскости ошибок; отказ самого `ErrorManager` — только голос; после `logger` — только `emergency_log`. На `config={}` слота `error` нет ни у кого; боевой конфиг не проверен.

## Рекомендация ревьюера

- 1.2b-1: ОДИН вызов — вид `FallbackLogger(__name__)` для обеих строк шаблона; `_log_error` не звать. Подключено — одна строка в журнале; (a) — буфер + stderr, в файл при подъёме; (b) — общий гейт уровня; (c) — stderr. Закрывает №1 и №2.
- Отдельной задачей (не 1.2b-1): (1) `_call_manager_result("logger")` при «нет слота / менеджер `None` / менеджер закрыт» — на вид, тихо только при явном `disable`; (2) `ProcessModule._log_*` → `bool` из `super()`; (3) затем шаблон → `report_error(exc, context="shutdown")` по ADR-BM-006 (у `BaseManager` без миксина — вид); (4) ADR в logger_module «одна дорога к писателю».
