DESIGN (decided by the lead; it is the CONTRACT; you must NOT read `presenter.py` and `display_slot.py` (reading the neighbour tests is allowed), so these names are the whole interface):
  1. Tests use the real `ImagePanelPresenter` and the real `DisplaySlot` (`multiprocess_prototype.frontend.widgets.image_panel.presenter`, `.display_slot`), registered through `presenter.register_slot(slot_id, slot)`; a `QApplication` is provided by the fixture style of the neighbour files `test_display_slot_resize.py` and `test_on_frame_shapes.py`. Expected values are literals from the ACCEPTANCE block of `tasks/T6.md` or references the test computes itself from the RAW frame (`cv2.resize(raw, size, interpolation=cv2.INTER_AREA)`, then BGR to RGB), never taken from the code under test.
  2. Public calls: `presenter.on_frame(slot_id, frame)`, `presenter.frame_stats(slot_id)` (`received`, `shown`, `rejected`), `presenter.get_last_frame(slot_id)`; the slot shows the frame in its label (`label.pixmap()`); the label size is set through the slot geometry (`slot.resize(...)` or a fixed label size, as `test_display_slot_resize.py` does). `slot.update_pixmap(QPixmap)` is the call the presenter makes to show the picture; spy on it with `monkeypatch.setattr(slot, "update_pixmap", wrapper)` to read the size of the pixmap the slot receives.
  3. Behaviour: a frame larger than the label is reduced by the presenter to the size `QSize(w, h).scaled(label_size, Qt.AspectRatioMode.KeepAspectRatio)` (the test computes the reference size with Qt) before it becomes a pixmap; a frame not larger than the label is passed on as is and the SLOT enlarges it; the slot resize always ends with a shown picture or the placeholder, never skips the slot scaling; a resize re-renders from the RAW frame, not from the reduced pixmap; the label floor is 320x240.
  4. Frames: 1440x1080x3 BGR uint8 with fine detail (checkerboard 4 px plus diagonals, as `test_display_slot_resize.py` builds), 1280x1024x3, 320x240x3, gray 1440x1080 (2D) and `(1080, 1440, 1)`; an unsupported shape (for example a 4-channel array) for the rejected-frame guard. Gray constant fill 100.
  5. Each new `.py` has a `Purpose:` line in its module docstring; a test that can block runs the call in a daemon thread with a join deadline. Import the presenter and the slot INSIDE each test so a RED fails per test, not at collection.
