## Контекст

Владелец 2026-11-11: для кадров с сима записать к каждому сохранённому кадру настоящий угол и букву из сима и ответ
сети, чтобы пары «кадр + `.json`» из `frame_saver` шли в дообучение. Основа — кандидат DS-1 (текст — незакоммиченная
правка `plans/queue/backlog.md` в основном дереве); из него в плане только запись «истина против ответа» для сима.
Текущая модель выучила один шрифт (`plans/letters-retrain/plan.md:36-38`); DS-1 кормит её переобучение. Факты и
схема — [`design.md`](design.md) §1–§2.

## Цели

1. Каждый вырез с сима на диске — пара `.png` + `.json` (`source: synthetic`); после `join_frame_truth` в `.json` есть
   `truth`, `pred`, `delta_angle_deg`, `hard` (`design.md` §4).
2. Метка верна, а не только сведена (Task 2.3): среди сведённых и ответивших (`below_threshold: false`) доля
   `truth.class == pred.class` ≥ 0,7 (сдвиг ключа на шаг дал бы ~1/33); 20 из 20 случайных вырезов — буква на картинке
   равна `truth.class` (лид смотрит глазами).
3. Машинная метка — только `truth` синтетики: `training_label` даёт `None` для всего остального (тесты 1.1c).
4. Вырез на диске — чистый: декодированный `.png` равен выходу `center_crop` при непустых предсказаниях.

## Out of scope

Реальные кадры (DS-В4: задачи DEFERRED); сборка датасета для `ml_train` (потребитель — letters-retrain, дверь —
`training_label`); GUI-разметчик; экспорт YOLO/COCO; правка `word_layout`; запись кадров симом; ключ K1 (`e_capture`).
