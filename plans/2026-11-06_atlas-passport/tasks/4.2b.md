DESIGN (decided by the lead; решения CTO по идеям — `ideas.md` п. 11, №1, №3, №4, №7):
  `atlas map <юнит> --depth N --budget N --format passport|json` — паспорт юнита: члены по рангу, бюджет как в 4.2a
  (`--depth 1 --budget 1500` — модуль одним экраном). `atlas map <файл.py>` — **скелет файла** (`kind: file`): по
  каждому `def`/`class` — `qualname`, сигнатура, первая строка докстринга, `line`; тел нет (~40 строк над фактами Д2).
  `status.stale` — пути паспорта (`path` и `where` его связей), изменённые в рабочем дереве относительно `sha`:
  `git diff --name-only <sha> -- <пути>` (при `sha` = HEAD равно `git status --porcelain` ∩ пути для отслеживаемых файлов);
  нет git/рабочего дерева → `null` (не искали), чисто → `[]` (~20 строк). `status.frozen` — из строки докстринга модуля
  `FREEZE YYYY-MM-DD: <причина>; <ссылка>` (формат — `design.md` §1; не первая строка): нашли → `{date, text, where}`,
  искали и нет → `false`; класс и символ наследуют `frozen` юнита (~10 строк). JSON-схема паспорта — контрактный тест по
  образцу MCP `outputSchema`: словарь «ключ → тип» конверта и шести разделов для `kind` symbol/unit/file, проверка руками,
  без `jsonschema` (~40 строк, в тесте, не в коде).
