DESIGN (decided by the lead; решения CTO по идеям — `ideas.md` п. 11, №1, №3, №4, №7):
  1. `atlas map <цель> --depth 1|2 --budget N --format passport|json` (флаги `--root`, `--exclude`, `--ref` — как у
     `ref` 4.2a). Цель — id юнита из `load_modules()` (`kind: unit`) или путь `.py` (`kind: file`). Члены юнита: его
     файлы без `scope: test`; `--depth 1` — файлы и их верхние `def`/`class`, `--depth 2` — ещё методы. Бюджет — строки,
     как в 4.2a; по умолчанию 50 («один экран»). Неизвестная цель — запись `{"id", "error": "not found"}`, stderr
     `atlas map: цель не найдена`, код 2.
  2. Скелет файла: по каждому `def`/`class` из `defs` 4.1 — `qualname`, сигнатура, первая строка `doc`, `line`; тел нет.
  3. `status.stale`: `null`, если нет git или `sha` ≠ HEAD корня (`--ref` на чужой ревизии, условие бенча 4.3);
     иначе один `git diff -z --name-only <sha>` на запуск (через `tree.git_z`), пересечение в Python с путями
     паспорта (`path` и `where` связей без `:строка`); чисто — `[]`. Атлас здесь впервые читает рабочее дерево (для `stale`/`frozen`; слой 4.2a берёт из ревизии) —
     строка-дополнение к ADR-ATL-005 (ADR-ATL-003: «читает ревизию»).
  4. `status.frozen` — список шапок по цепочке снизу вверх: файл символа, затем `__init__.py` пакетов до юнита;
     элемент `{date, text, where}`, `text` — всё после `FREEZE YYYY-MM-DD: `; `[]` — искали, нет; файл с `error` →
     `null`. Источник — новое поле `scan.py` `freeze: tuple[(date, text, line), ...]` (строки докстринга модуля по
     `^FREEZE \d{4}-\d{2}-\d{2}:`, любая строка докстринга; поле `doc` A1 не меняется). Класс и символ берут цепочку
     своего файла.
  5. Текст: `stale` и `frozen` — строки раздела `status`, входят в бюджет; срез `stale` — «показано K из N».
  6. JSON-схема — контрактный тест: словарь «ключ → тип» конверта, шести разделов и подключей `status` для
     class|function|method, unit, file; `list | null`, `dict` элемента `frozen`; проверка руками, без `jsonschema`
     (новая зависимость ради теста не нужна).
