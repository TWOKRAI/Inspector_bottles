DESIGN (Д1 - `cto-atlas-path-verdict.md` §4; `ideas.md` п. 11, №3, №4, №7):
  1. `status.stale`: `null`, если `sha` != HEAD корня (`--ref` на чужой ревизии), HEAD не разрешается или `git diff` упал
     (bare-клон); `AtlasError` ловим только вокруг `resolve(root, "HEAD")` и `git_z`. Иначе после сборки паспорта один
     `git --no-optional-locks --literal-pathspecs diff -z --name-only --no-renames <sha> -- <пути паспорта>` на паспорт (не в
     `resolve_ident`). Пути: `path`, путь из каждого `where` (связи, `checks.tests`, `runtime.*`, `members`, `bases`),
     путь из `structural.twins` (`путь::qualname`). `--no-renames`: старое имя тоже в списке. Чисто - `[]`;
     элементы - `путь`, по порядку пути. `where: null` пропускаем; неотслеженные не ищем. Рабочее дерево читает только `stale`. Правка: докстринг
     `passport.py` (`Post`, `Purpose`, `status`; «не меняет репозиторий» - кроме stat-кэша `.git/index`); строка в ADR-ATL-005: сужает ADR-ATL-003 для `stale`; бюджет
     `ConfigFileWatcher` - 40 строк до 1 шапки, 41 при 2, 42 при 3.
  2. `status.frozen`: шапки файла символа, затем `__init__.py` общим обходом с `interface.all` (вынести функцию из
     `_all_chain`; границы и дыры - как там, юнит с `paths` без `/` - `stop=""`, до корня). Без повторов (символ в
     `__init__.py`). Звено с `error` пропускается; `v2_error` не влияет. Элемент `{date, text, where}`: `text` - после
     `FREEZE YYYY-MM-DD: `; `where` - `путь:строка` сырой строки; `[]` - искали, нет. Класс и метод - цепочка файла.
  3. Источник - `scan.py`, поле `freeze: tuple[(date, text, line), ...]` у `FileFacts`: строки докстринга модуля по
     `^FREEZE \d{4}-\d{2}-\d{2}:` (регэксп по сырому `value.split("\n")`; `doc` A1 не меняется). `line` -
     `Constant.lineno` + индекс (`get_docstring` строк не даёт). В `to_json`/`from_json` (иначе тёплый вызов даст
     `[]`); `SCANNER` меняется сам.
  4. Текст: хвост `; stale …; frozen …` уходит из строки `status:` (`tier`/`doc_missing`/`dynamic` остаются). Далее строки
     с отступом в 2 пробела: `  stale: —` (`[]`), `  stale: не искали` (`null`), `  stale: a.py, b.py` (без среза);
     `  frozen: —` (`[]`; `null` у `frozen` в v1 нет), иначе строка на шапку `  frozen: <date> <text> (<путь:строка>)`.
     Строки - в служебном минимуме бюджета (не режутся). `SHOW_ALL_SECTIONS` не меняется.
  5. JSON-схема - контрактный тест, руками: «ключ -> тип» конверта, шести разделов, подключей `status` для
     class|function|method (unit/file - 4.2b-2); `stale`/`frozen` - `list` (чистый репо `[]`), элемент `frozen` - `dict`.
  6. Пин `tests/test_passport.py:160` (`stale is None and frozen is None`) -> `== [] and == []` (чистый репо, `sha` = HEAD,
     файл без шапки) - единственное изменение чужого теста.
