DESIGN (decided by the lead; В11 — CTO 11-07; `bench.py:N` — на `930c5f2a3`):
  **Копия.** Поле набора `"copy": "archive" | "clone"`, умолчание `archive` (как сейчас, без `.git`); `copy` входит в
  хеш `clean_copy_path` только при ≠ archive (копии 1.2 не пересобираются). Иное — код 2:
  `ОТКАЗ: copy набора должен быть archive или clone`. `clone`: (1) `git clone --shared <repo_root> <копия>`;
  (2) `checkout --detach <repo_sha>`; (3) `remote remove origin`, `update-ref -d` по каждой строке `for-each-ref
  --format=%(refname)`, `reflog expire --expire=now --all`; (4) `repack -a -d` (без `-l`), удалить
  `.git/objects/info/alternates`; (5) удалить пути `exclude` и `update-index --skip-worktree -- <пути>`; (6) условие с
  `bash_allow`: `rev-parse HEAD` копии `startswith(repo_sha)` (у `k0`/`arch` sha короткий), иначе ОТКАЗ.
  **`bash_allow`** — шаблоны `fnmatch`. `build_command` (`:392`): непустой → `Bash` в `--tools`, `Bash(<шаблон>)` в
  `--allowedTools` (грамматика — по `claude --help` текущей версии). Подстановки `{repo_root}`, `{repo_sha}`, `{run_root}`
  (posix) до сравнения; неизвестный плейсхолдер — ошибка. `audit_violations` (`:558`): параметры `bash_allow`, `exclude`
  необязательные; `Bash` в `allowed_tools` при непустом `bash_allow`. Команда Bash → `TAINTED`, если не совпала целиком
  ни с одним шаблоном или **часть под `*`** содержит путь `exclude`, цепочку (`;` `&&` `||` `|` `>` `<` `` ` `` `$(`)
  или флаг `--output`, `-O`, `--git-dir`, `--work-tree`, `-c`. Путь: `shlex`-токены части, резать по `:` и `=`, posix,
  `casefold`, без `./` и префикса копии; равен пути `exclude` или начинается с `путь/`. Литералы шаблона не
  проверяются. Голый `git log` — свой шаблон. Текст: `<правило>:<команда ≤ 80 символов>`. CLI ограничивает, аудит —
  детектор (`*` шире; `git -C . log` — ложный `TAINTED`).
  `grep-read+git.json` = `grep-read.json` **без** `Bash` в `disallowed_tools` + `bash_allow` [`git log`, `git log *`,
  `git show *`, `git blame *`, `git grep *`] + `prompt_prefix` «Navigate by reading the code (Read, Grep, Glob) and by git
  history: through Bash you may run only git log, git show, git blame, git grep; no other shell commands.»
