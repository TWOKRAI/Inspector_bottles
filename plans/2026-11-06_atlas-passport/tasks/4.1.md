  2. `defs`: `DefFact(qualname, kind, line, signature, decorators, abstract, is_async, doc, bases)`; `kind`
     class|function|method; `qualname` через точку; `signature` = `ast.unparse(args)` + ` -> <returns>`, у класса `""`;
     `decorators` — листовые имена; `doc` — первый абзац или `None`; `bases` — `ast.unparse`.
  3. `calls`: `CallFact(name, line, enclosing, receiver)`; `receiver` — `None` у голого имени, иначе
     `ast.unparse(func.value)`; `enclosing` — ближайший def/class, на уровне модуля `<module>`.
  4. `io`: `IoFact(op, path, line, enclosing)`. `watch` — `X.schedule(...)`, где `X` присвоен `Observer(...)` в той
     же функции (`self.<a>` — в том же классе); путь = `args[1]` при ≥ 2 позиционных, иначе `path=`, иначе не `watch`.
     `replaces` (F3) — `os.replace`/`os.rename`/`shutil.move`, путь = `args[1]` (`Path.replace` — нет: путь в получателе).
  5. `thread_sites`: `ThreadSite(pattern, line, enclosing, daemon)`; `THREAD_PATTERNS = ("Thread", "Timer",
     "Observer")` — константа, не конфиг (ключ кэша — хеш `scan.py`); запись только при `.start()` той же цели в
     той же функции (цепочка `Thread(target=f, daemon=True).start()` — запись есть); `line` — конструктор; `daemon` — True/False/None.
  6. `test_defs` — `(qualname, line)` с префиксом `test` (и в `Test*`); `v2_error` — имя исключения:
     новые поля в своём `try`, сбой не трогает поля A1.
  7. `links.py`: `build_links(facts) -> Links`, `Links.of("путь::qualname") -> dict | None`, без кэша.
     Связь: `where`, `how`, `scope`, `enclosing` (+ `same_file` у `call_sites`). `used_by` (import); `call_sites`
     (name-call): голое имя в своём файле или по from-импорту, `m.f()` по импорту модуля, `self.m()` своего класса,
     прочее — счётчик `call_sites_unresolved`; вызовы по алиасу (`as`), через реэкспорт `__init__` не разрешаются
     и не считаются: «не видно» паспорта; `subclasses` (import); `structural`: обязательные имена — все
     неприватные не-dunder методы базы, < 2 → `None` + «слишком общий протокол», двойник — неприватный не-наследник;
     `tests` (`how: test-body`) — функция `test_defs` называет символ в теле, файл его импортирует. `scope: test` —
     путь `(^|/)tests/` или файл `test_*.py`, `*_test.py`, `conftest.py` (шире `_TEST_FILE` A1: тестовые помощники
     в `tests/`); иначе `prod` (`testing/` — поставляемые двойники, не тесты).
  8. Сторож R1 (зелёный с рождения): AST всех `scripts/atlas/**/*.py` с тестами; `import`/`from`,
     `importlib.import_module`/`__import__` с литералом `multiprocess_framework|Services|Plugins`. Ошибка — путь, без ввода.
