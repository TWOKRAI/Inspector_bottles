DESIGN (decided by the lead):
  Якоря — по тексту. Обе копии — одинаково (AST-равенство, `test_g1`). `Refs:` коммита — на оба плана. `Co-Authored-By` парсить как сейчас.
  1. `KNOWN_TRAILERS` (множество `REQUIRED_BASE_TRAILERS | {…}`): + `"Decision"`. Грамматика значения: ровно один id на строку (несколько id — несколько строк `Decision:`), `fullmatch` `ADR-[A-Z][A-Z0-9]*-[0-9]+` (ASCII) после `strip()`. Не по грамматике — `_phase3` «Decision: malformed value (expected ADR-<MOD>-NNN, one id per line)» без значения. Числовые `## ADR-001` не в счёт.
  2. Точка вставки — новый шаг между шагом 6 (блок `Refs`, комментарий «# 6. Plan-driven workflow») и шагом 7 (комментарий «# 7. Tests-discipline gate»). Репозиторий — `find_repo_root()`; нет корня или git упал — пропустить (как tests gate). Слияние (`is_merge`) — шаг пропускается целиком.
  3. «Добавленный ADR»: `git diff --cached -U0 --no-color -- '*DECISIONS.md'`; id из строк `+` с регэкспом заголовка `^#{2,3} (ADR-[A-Z][A-Z0-9]*-[0-9]+)` (H2 и H3: `### ADR-PM-059`) минус id из строк `-` ТОГО ЖЕ диффа (правка заголовка — не новый ADR). Для каждого добавленного id без строки `Decision:` с этим id — `result.warnings.append("Decision: this commit adds ADR-… — add the line `Decision: ADR-…`")`, по строке на id. НЕ `_phase3`: предупреждение остаётся предупреждением при `STRICT = True`. Пометки «error from phase 3» нет. В тексте — только id, прошедший регэксп.
  4. `Decision:` с well-formed id, которого нет ни среди добавленных, ни в индексе (`git grep --cached -E "^#{2,3} <id>([^A-Za-z0-9-]|$)" -- '*DECISIONS.md'`; «дерево» = индекс, закрывает `--amend`) — `_phase3` «Decision: ADR-… not found in the index» (предупреждение сейчас, ошибка при STRICT; тот же класс, что `Refs`/`Task`). Не отказ: ADR мог лежать в соседней ветке.
  5. `scripts/validate_commit/README.md`: две строки в таблицу правил (после «Unknown trailer key»): «ADR added by the diff without `Decision:` | warning (always)» и «`Decision:` id not in the index / malformed | warning (error in STRICT)».
