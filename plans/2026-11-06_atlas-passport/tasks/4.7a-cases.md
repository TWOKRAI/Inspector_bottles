## Формат `entry_cases.json`

Строка: `{"name", "repo": "F"|"F+aa"|"pilot"|"real", "argv", "code", "stdout_mode", "pin", ...}`; `stderr_exact` — весь stderr списком строк (нет ключа — не проверяется). Режимы `stdout_mode`:
  - `lines` — `"stdout": [строки]` идут в stdout подпоследовательностью точных строк; `"stdout_absent": [подстроки]` — ни в одной строке. Пример: `{"name":"A-dup","repo":"F","argv":["ref","dup"],"code":2,"stdout_mode":"lines","stdout":["== dup ==","ambiguous"],"stderr_exact":["atlas ref: id 1: ambiguous"]}`.
  - `exact` — `"stdout": "<весь stdout>"` (без завершающего `\n`). Пример: `{"name":"flag","repo":"F","argv":["ref","../x.py::f"],"code":2,"stdout_mode":"exact","stdout":"","stderr_exact":["atlas: путь выше корня репозитория"],"pin":true}` (по умолчанию `pin: false`).
  - `json` — `"json": {"0.id": "pkg/a.py::Driver", "1.error": "not found", "len": 2}` (путь: индекс списка `.` ключ; `len` — длина списка; сравнение строгое). Пример: `{"name":"C-json","repo":"F","argv":["ref","pkg/a.py::Driver","Nope","--format","json"],"code":0,"stdout_mode":"json","json":{"len":2,"1.error":"not found"}}`.
  - `ids` — только для `pilot`/`real`: `"resolved": [id | null по порядку целей]`, `"errors": ["not found"|"ambiguous"|null]`, `"list_lines": число строк списка (если есть)`. Пример: `{"name":"pilot-8","repo":"pilot","argv":["ref","is_valid_window","ProcessConfig","RecipeBlueprint"],"code":0,"stdout_mode":"ids","resolved":[null,"multiprocess_framework/modules/process_manager_module/topology/blueprint.py::ProcessConfig",null],"errors":["not found",null,"not found"]}`.
`pilot`/`real` пропускаются без ревизии. Баг ревью — новая строка до исправления.
