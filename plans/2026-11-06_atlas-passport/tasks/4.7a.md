### C. Ошибки и код `ref` — `_ref_passport`, `_error_block`
Код `ref --format` (текст и json): 0, если разрешён хотя бы один id, иначе 2. Блок ошибки (текст): `== id ==`, `not found`|`ambiguous`, строки кандидатов `путь::qualname — путь:строка[ — назначение]` (первая строка докстринга ≤ 80 знаков), `ещё M; уточните путь::имя`, строка `есть ещё` (если есть), `пример: ref <первый кандидат по ключу>`; без кандидатов `пример: ref <путь>::<Имя> | ref <Класс>.<метод> | map <юнит>`.
  Бюджет (шов `_candidate_lines`): `fixed = 3 + [строка есть ещё]` (заголовок, ошибка, `пример:`). Влезли все (`K + fixed ≤ budget` и `K ≤ N`) — все, без хвоста (правило 4.5c). Иначе `keep = min(N, max(budget - fixed - 1, 0))`, `ещё K - keep; уточните путь::имя`.
  K > 30 (`name` 309, `__init__` 1607): кандидатов нет, строка `кандидатов: K (прод P, тест T); уточните Класс.имя или путь::имя`, `есть ещё` (если есть), `пример: ref <первый кандидат>`; 4–5 строк при любом бюджете.
  Подсказка `not found` (текст): имена, равные без регистра (`casefold`), затем `difflib` (cutoff 0,6; дополнение, не запасной вариант; дубли по имени снимаются), ≤ 5 имён, порядок `(-ratio, имя)` по кодпоинтам без `casefold` (явная сортировка по `SequenceMatcher.ratio()`; `get_close_matches` при равенстве отдаёт иначе). Подсказки идут через тот же шов `_candidate_lines`. Пул — ТОЛЬКО определения из `facts` (33 092 имени; привязки не берём): для голого имени — последние сегменты, для `путь::имя` — `qualname` определений файла `путь` (нет файла — подсказки нет). Каждое имя — одна строка `путь::qualname` (первый по ключу). Цель — id юнита -> `это юнит: map <id>`; `.py` без `::` -> `map <путь>`, только если путь есть в `facts`. Вызов в подсказке без `<...>` обязан разрешаться (R1.1).
  JSON не меняется. stderr: `atlas ref: id N: <error>` на каждый ошибочный id (и при коде 0). Один `_Ctx.open` на вызов: `passports_for(root, ref, idents, *, exclude=(), hints=False)` (решение 3); при `hints=True` в записях ошибок внутренние поля, JSON их не печатает.
