DESIGN (decided by the lead; Д1 — `cto-atlas-path-verdict.md` §4 + поле `scope`; дефекты — `design.md` §3; идеи — `ideas.md`):
  `passport.py` строит объект Д1: конверт `passport: 1`, `kind`, `id` (`путь::qualname`), `path`, `line`, `sha`,
  `scanner`; шесть разделов `purpose`, `interface`, `links`, `runtime`, `checks`, `status` — ключи всегда, пустое =
  `null` (не искали) или `[]`/`0` (искали, нет). Текст печатает те же шесть заголовков в том же порядке, пустые — «—».
  Счётчик: «найдено N (формы: …); не видно: динамика»; у модуля «рецепты: не найдено (просмотрено N YAML)», не «0».
  Усечённый список: «показано K из N; все: `--all <раздел>`», порядок — ранг (число входящих связей prod), не порядок
  файла. Бюджет: `--budget <строк>` (по умолчанию 40), `--full`. `purpose` класса — докстринг + «зовут из: <объемлющая
  функция> — <её первый абзац>». Класс наследует `all` и правило слоя своего юнита. `runtime.commands` — `where`/`how:
  declared`; элемент `command_specs()` — кортеж литералов или `CommandSpec(...)` с литеральными аргументами (`ast.Call`),
  прочее → «динамических: M» (`design.md` §1); запись без `where` → находка, `atlas check` красный (R2).
  CLI: `atlas ref <id> [<id> …] --format passport|json` — несколько id за вызов (~10 строк, снижает `calls_ratio`):
  текст — паспорта подряд под заголовком id, бюджет на каждый; JSON — список объектов в порядке аргументов; неизвестный id
  — запись `{"id": …, "error": "not found"}`, остальные печатаются, код выхода 1. Без `--format` `ref` — прежний текст
  модуля с ровно одним позиционным аргументом (pinned). ADR-ATL-005 — в `DECISIONS.md` (вердикт CTO 11-07, правка 7).
