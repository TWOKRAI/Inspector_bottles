  1. `threads` (v2, `scan.py:165-167`): место потока - каждый `ast.Call` с `_ctor_pattern` (`:536`), без `.start()`;
     дубль по `(enclosing, line)` не пишется (цепочка `Thread(...).start()`, `:654-659`). Форма записи та же;
     докстринг - правка; ключ кэша сменится сам. `worker_lifecycle.py:74, 103, 260` - три потока; prod 69 -> ~74.
  2. Оговорка вместо прочерка - только текст паспорта символа (`render_text`, `passport.py:966-980`); JSON и `map`
     не меняются. Раздел `[]` (у `commands` и `null`) печатается с образцами из констант `scan.py`, текст один:
     `threads: — (ищет: Thread, Timer, Observer)`; `commands: — (ищет только def command_specs(); register_command(...)
     не читает)`; `io: — (ищет: <перечень>)`. У `commands: null` текст `_NO_SPECS` остаётся перед оговоркой (пин
     `test_passport.py:357`). `IO_PATTERNS` собрать из `_REPLACES` (`scan.py:514`) и записи `Observer.schedule`;
     оговорка - из констант, не литералом. `register_command(` не читается (Ф9.7, `design-open.md` §7).
  3. Вызовы метода по имени: `Links` хранит адреса вызовов `x.m(...)` с `receiver is not None and receiver != "self"`,
     не отнесённых ни к одному символу, по имени метода, только `scope == "prod"`; голые затенённые вызовы 4.5a
     (`receiver is None`) сюда не идут. Паспорт метода: ключ `call_sites_by_name` `{"count": N, "items": [...]}`;
     `count` - эти вызовы; `items` - записи формы `call_sites` с `how: "by-name"` при N <= 10, `null` при N > 10.
     Порог 10 - по распределению на HEAD (r1: у 74% prod public методов <= 10 адресов); константа в коде, в тесте
     литерал. Текст: `по имени метода, тип не проверен (N):` и адреса; N > 10 - `по имени метода (prod, без self): N
     вызовов .<имя>(...) - имя частое, адреса не печатаются`. Имя - в `SHOW_ALL_SECTIONS` (`passport.py:235`, его
     сверяет `__main__.py:132`) и раздел `_alloc` (`:860`); при `items == null` `--all` адресов не печатает.
  4. Схема: ключ у `kind` method в `_schema` (`test_passport_schema.py:100-108`); ADR-ATL-005 - строка.
  5. Не меняется: `call_sites` (точные адреса), `call_sites_unresolved`, `links.of` для классов и функций, `map`.
