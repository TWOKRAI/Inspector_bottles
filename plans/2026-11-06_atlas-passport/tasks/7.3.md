DESIGN (decided by the lead):
  `atlas origin <путь|каталог|символ|ADR-id> [--since D] [--ref <sha>] [--root <к>] [--exclude <путь>]… [--all] --format text|json`.
  Читается **ревизия `--ref`** (`ls-tree`, `show`, `log`), не рабочий каталог; `--exclude` скрывает пути из дерева и вывода.
  Флаги как у 4.2a. Запуск `python <repo>/scripts/atlas`: корень в `sys.path` (`Path(__file__).resolve().parents[2]`, `4.2a.md:41`), если нет.
  **Цель** по порядку: ADR-id `^ADR-[A-Z][A-Z0-9]*-\d+$` или `^ADR-\d+$`; путь или каталог в `git ls-tree -r -t --name-only <ref>` (каталог = префикс, `git log -- <каталог>`); символ через факты A1 (`scan.py`).
  Несколько определений и «не найдена» — **код 2** (как 4.2a; код 1 за `check`/`lint-*`); у ambiguous пути в stdout.
  **Трейлеры — один regex в `origin.py`** (не `interpret-trailers`: `Co-Authored-By` через пустую строку ломает его, `508674b22`): построчно по `%B`,
  `^(Why|Refs|Task|Decision|Rejected):[ \t]*(\S.*?)[ \t\r]*$`, `re.M`. `adapters/commits.py` не меняется.
  (1) `git log <ref> [--since=D] --format=%H%x1f%ad%x1f%s%x1f%B -- <путь>`; ≤ 15 коммитов, при срезе «показано K из N; все: --all» (JSON не режется).

  (3) ADR: по `Decision:` (`how: declared`); иначе коммит, добавивший заголовок в диффе `DECISIONS.md` (`diff-h2`/`diff-h3`); иначе `Refs` → план → упоминание (`inferred`).
  Заголовок `^#{2,3} ADR-<id>([^A-Za-z0-9-]|$)` (граница как 7.1a). Дом — все `*DECISIONS.md` дерева `--ref`. Первый по строке заголовок (лучше H2) — ADR (`adr.line`); следующие H3 с тем же id — дополнения, в `diff` не участвуют.
