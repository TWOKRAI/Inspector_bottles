DESIGN (decided by the lead):
  `atlas origin <путь|символ|ADR-id> [--since D] [--ref <sha>] [--root <каталог>] [--exclude <путь>]… --format text|json`.
  Читается **ревизия `--ref`** (`ls-tree`, `show <ref>:<путь>`, `log <ref>`), не рабочий каталог; `--exclude` скрывает
  пути из дерева и вывода. Флаги — как у 4.2a. **Цель** по порядку: ADR-id `^ADR-[A-Z][A-Z0-9]*-\d+$` или
  старый `^ADR-\d+$`; путь в `git ls-tree -r --name-only <ref>`; символ через факты A1 (`scan.py`), несколько
  определений — код 1 и пути.
  **Трейлеры — один regex в `origin.py`** (не `interpret-trailers`: `Co-Authored-By` через пустую строку его ломает,
  `508674b22`): построчно по `%B`, `^(Why|Refs|Task|Decision|Rejected):[ \t]*(\S.*?)[ \t\r]*$`, `re.M`.
  `adapters/commits.py` не меняется; дубль сознательный, расхождение — в отчёт.
  (1) `git log <ref> --format=%H%x1f%ad%x1f%s%x1f%B -- <путь>`. (2) `Refs: plans/…` → план и статус (как `adapters/plans.py`;
  нужен `BuildContext` — стоп, вопрос лиду); плана нет в дереве — `план: не найден`.
  (3) ADR: по `Decision:` (`how: declared`); иначе коммит, добавивший заголовок в диффе `DECISIONS.md` (`diff`); иначе
  `Refs` → план → упоминание (`inferred`, так и печатается). Заголовок `^#{2,3} ADR-` (H3: `### ADR-PM-059`). Дома — все
  `*DECISIONS.md` дерева `--ref`, совпадение по id в любом. (4) У ADR — первый абзац решения (секция `Решение`/`Decision`,
  если есть), `**Refs:**`, «отвергли»: заголовки H2–H4 без регистра `Альтернативы`, `Отвергнуто`, `Отклонённые
  альтернативы`, `Отвергнутые альтернативы`, `Alternatives` и жирные `**Альтернативы…**`/`**Отвергнуто…**`/
  `**Alternatives…**`; значение — первая непустая строка (у жирной — остаток строки),
  ≤ 200. Нет — `отвергли: не указано`; коммит без ADR — `Rejected:`. Закрытый план — `## Итог`, нет — `итог: не указан`.
  **Литералы без значения цели:** `atlas: origin target not found`; коммитов нет — `не найдено (история с <дата>)`, дата —
  автор-дата `git rev-list --max-parents=0 <ref>` (на `main` 2026-04-30), не константа. `--since D` → `git log --since=D`.
  `--format json`: `target`, `kind`, `commits[]` (`sha`, `date`, `subject`, `why`, `refs[]`, `task`, `decision`,
  `rejected`), `links[]` (`adr`, `how`), `adr` (`id`, `path`, `line`, `summary`, `plan`, `rejected`), `plan` (`path`,
  `status`, `itog`); ключи всегда, пустое — `null`/`[]`.
  **ADR-ATL-006** (занят — следующий): вывод, метки, парсер, заголовки, дома, литералы.
  **Условие `atlas-origin+git.json`** = `grep-read+git.json` (7.2) + шаблон `bash_allow`
  `python {repo_root}/scripts/atlas origin * --root {run_root} --ref {repo_sha} --exclude scripts/atlas/tests --exclude plans/2026-11-06_atlas-passport/chain.md --exclude scripts/nav_bench`;
  `*` **до** флагов (argparse берёт последнее); `--exclude` = `exclude` набора; код — `{repo_root}`, чтение — клон
  на `repo_sha`. Подстановок нет → стоп. `thresholds`:
  `{"hits_min": 4, "false_max": 1, "calls_ratio_max": 0.5, "tokens_ratio_max": 0.6}`.
