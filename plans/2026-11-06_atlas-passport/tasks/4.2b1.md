DESIGN (Д1 - `cto-atlas-path-verdict.md` §4; `ideas.md` п. 11, №3, №4, №7):
  1. `status.stale` - `build_passport` читает рабочее дерево (`git diff`). `null`: `sha` != HEAD корня (`--ref` на чужой
     ревизии - условие бенча 4.3) или `git diff` упал (`AtlasError` из `tree.git_z` ловим: bare-клон `root`, нет рабочего
     дерева). Иначе один `git diff -z --name-only --no-renames <sha>` на вызов, пересечение с путями паспорта (`path` и
     `where` связей без `:строка`); `--no-renames`: старое имя тоже в списке; чисто - `[]`; элементы - `путь`, порядок
     по пути. Новые неотслеженные файлы `git diff` не видит - не ищем. Читает только `stale`; `frozen` - из `scan`
     по ревизии. Правка: докстринг `passport.py` (`Post`, `Purpose`, строка `status`) и строка в ADR-ATL-005 (сужает
     ADR-ATL-003 «читает ревизию» только для `stale`).
  2. `status.frozen` - список шапок: файл символа, затем `__init__.py` тех же каталогов, что обходит `_all_chain`
     (общий обход - вынести функцию, не вторая копия цикла; границы, дыры в цепочке - как у `interface.all`). Элемент
     `{date, text, where}`: `text` - всё после `FREEZE YYYY-MM-DD: ` в строке докстринга модуля; `where` - `путь:строка`
     сырой строки; `[]` - искали, нет; файл с `error`/`v2_error` -> `null`. Класс и метод берут цепочку своего файла.
  3. Источник - поле `scan.py` `freeze: tuple[(date, text, line), ...]` у `FileFacts` (любая строка докстринга модуля по
     `^FREEZE \d{4}-\d{2}-\d{2}:`; `doc` A1 не меняется). `line` - по сырому значению: `Constant.lineno` + индекс строки в
     `value.split("\n")` (`ast.get_docstring` строки не даёт). Поле идёт в `to_json`/`from_json` (иначе тёплый вызов из
     `scan_cache` даст `[]`); `SCANNER` меняется сам.
  4. Текст: `stale` и `frozen` - строки раздела `status`; `stale` - `stale: —` (`[]`), `не искали` (`null`), иначе
     `stale: a.py, b.py` (без среза); `frozen` - по строке на шапку `frozen: <date> <text> (<путь:строка>)`; входят в
     служебный минимум бюджета (не режутся). `SHOW_ALL_SECTIONS` не меняется.
  5. JSON-схема - контрактный тест: словарь «ключ -> тип» конверта, шести разделов и подключей `status` для
     class|function|method (unit/file - 4.2b2); `list | null`, элемент `frozen` = `dict`; проверка руками, без `jsonschema`.
  6. Пин 4.2a: `tests/test_passport.py:160` (`stale is None and frozen is None`) -> `stale == [] and frozen == []`
     (чистый репо, `sha` = HEAD, файл без шапки) - единственное изменение чужого теста.
