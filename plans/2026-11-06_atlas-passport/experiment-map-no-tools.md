# Опыт «карта без инструментов» (T3, шаг 1 ревью Fable)

Статус: протокол, НЕ запущен. Порог и правила ниже фиксируются коммитом ДО прогона (sha протокола обязан быть старше записи прогона). Автор набора вопросов не знаком с Атласом: эталоны выведены по коду (`git grep` на коммите `42d9805d9`), а не по `INDEX.md`.

## 1. Цель

Проверить одну гипотезу: если агент без инструментов видит ТОЛЬКО карту юнитов (`docs/atlas/INDEX.md`, 89 записей), он по вопросу ориентации («в каком юните это лежит») называет верный юнит с первой попытки. Это дешёвый тест идеи «подсказка приходит сама». Провал убивает гипотезу «карта-файл помогает ориентироваться» за малые деньги; успех необходим, но не достаточен (раздел 9).

## 3. Входной материал (точно)

- Карта: `git show 42d9805d9:docs/atlas/INDEX.md` — 135 строк, 89 записей юнитов (90 строк без отступа: заголовок + 89), 13 486 символов (20 248 байт).
- git blob sha: `b174a0d51fbf640b1d74ff76445abf3069ae00c5`; sha256 содержимого: `e394d97c2c42284fa8f2cfe41761213616c41d99e2d137d253b4908ef645a917`. Раннер сверяет оба значения перед прогоном; несовпадение — стоп.
- Карта подаётся БЕЗ правок, целиком, в тексте промпта. Никаких файлов по пути, никаких инструментов, никакого `CLAUDE.md` в контексте (раннер запускается из пустого каталога вне репозитория, режим `--bare` или прямой вызов API).
- Способ вызова проверяется ДО прогона одним пробным вопросом, не входящим в 19 (только формат ответа `Q<n>: <unit-id>` и отсутствие инструментов в контексте); результат пробы в счёт не идёт. Если способ требует платного API-ключа — стоп, слово владельца.
- Модель: Haiku (алиас `haiku`, последняя версия на день прогона; версию записать в результат). Температура — по умолчанию.
- Один вопрос — один независимый вызов (в контексте нет других вопросов и ответов).

## 4. Точный промпт (дословно)

Системный промпт (одна строка):

```
Ты отвечаешь коротко и строго в заданном формате.
```

Пользовательское сообщение (шаблон; `{{MAP}}` — содержимое INDEX.md без изменений, `{{N}}` и `{{TEXT}}` — номер и текст вопроса из раздела 7):

```
Ниже карта репозитория: список «юнитов». Строка без отступа имеет вид «<id юнита> — <назначение>». Строка с отступом — список имён публичных классов и интерфейсов юнита (число в скобках и «… ещё N» — служебные пометки карты).
Юнит — каталог кода, его id стоит в начале строки без отступа (например: services/modbus). Если файл лежит внутри вложенного юнита, верный ответ — самый узкий (самый длинный id) юнит, в чей каталог он попадает.
У тебя нет инструментов и нет доступа к коду. Отвечай только по карте и своим знаниям. Один вопрос — один ответ, повторных попыток не будет.

=== КАРТА ===
{{MAP}}
=== ВОПРОС ===
Q{{N}}: {{TEXT}}
=== ФОРМАТ ОТВЕТА ===
Одна строка, строго: Q{{N}}: <id юнита>
Id скопируй из карты дословно. Больше ничего не пиши.
```

## 5. Что значит «с первой попытки»

- Для каждого вопроса делается РОВНО ОДИН вызов; засчитывается первая строка ответа в формате `Q<n>: <id>`. Повторов, уточнений, «подумай ещё», второго прогона «для надёжности» нет.
- Технический сбой (ошибка сети/API, пустой ответ, обрыв) без единой строки ответа не считается попыткой: вызов повторяют ОДИН раз с тем же промптом, повтор записывают в журнал. Ответ не в формате (текст вместо строки `Q<n>: <id>`) — это ответ: он засчитывается как неверный (строку для разбора ищут регулярным выражением `^Q(\d+):\s*(\S+)\s*$` по строкам ответа; берётся первая совпавшая; нет совпадения — неверно).

## 6. Правило оценки

- Ответ верен, если его id (после снятия обратных кавычек, пробелов по краям и приведения к нижнему регистру) равен эталонному id вопроса. Допустимых списков в этом наборе нет: у каждого вопроса ровно один юнит (неоднозначные выброшены, раздел 8).
- Id, которого нет в карте, — неверно. Несколько id в строке — неверно. Родительский юнит вместо самого узкого (Q19) — неверно.
- Считается число верных из 19 и доля. Дополнительно (НЕ влияет на решение) печатается разбивка по видам (A/B/C), слоям и априорной сложности — для разбора, если исход пограничный.
- Подсчёт — скриптом по таблице раздела 7 (раннер, шаг 3); ручных «зачтённых по смыслу» нет.

## 9. Что протокол НЕ проверяет

- Уровни 2–3 карты (по Атласу: паспорт модуля, отношения «кто зовёт / кто импортирует»): опыт касается только уровня «юнит + назначение + список классов» (F1). Успех не говорит ничего о ценности паспортов; в отношениях grep уже выиграл у карты (81 из 81 против 61 из 81).
- Агрегаты («сколько…», «какие все…»): таких фактов в карте нет, вопросов нет.
- Подачу карты ФАЙЛОМ по пути из `CLAUDE.md` (F2): здесь карта кладётся в промпт, цена вызова нулевая. Результат пилота «агент не зовёт (2 %)» относится к CLI, который надо вызвать; опыт не измеряет, прочитает ли агент файл сам. Это и есть шаг 1b/шаг 2.
- Задачи «где править строку» в известной области (на них grep насыщен, 17–21 из 22) и вопрос, снижает ли карта число вызовов агента: это шаг 2 (A против P).
- Адрес `путь::Класс` или файл: проверяется только юнит.
- Другие модели (Sonnet/Opus), другие версии Haiku, другие снимки карты.
- Расход и время реального агентского цикла.

## 10. Расход токенов (оценка числом)

- Карта ≈ 4,5–6,5 тыс. токенов (13 486 символов, из них 6 380 кириллица; оценка по символам, не замер). Инструкция плюс вопрос ≈ 0,5 тыс. Ответ ≈ 20 токенов.
- Один вызов при прямом обращении к API ≈ 5,5–7,5 тыс. входных токенов. 19 вызовов ≈ **105–140 тыс. входных токенов, ≈ 0,4 тыс. выходных**; из них при кэшировании префикса (карта идёт до вопроса) ≈ 100 тыс. — чтение из кэша.
- Если раннер идёт через `claude -p --bare --tools ""`, к каждому вызову добавляется служебный промпт CLI (размер не измерен; предположительно 3–10 тыс.): тогда ≈ 150–320 тыс. входных токенов.
- Итого ожидаемо **≈ 130 тыс. токенов (диапазон 100–320 тыс.)** — выше оценки Fable 60–100 тыс.: цена независимости вопросов (одна карта на вопрос). Если владелец хочет дешевле, есть вариант B (не основной): один вызов со всеми 19 вопросами, 3 повтора в разном порядке ≈ 25–30 тыс.; но тогда ответы видят друг друга (все 19 эталонов — разные юниты, модель может «исключать уже названные»), а прогон перестаёт быть «первой попыткой» в строгом смысле. Основной протокол — по вопросу на вызов.

## 11. Что осталось открытым / ненадёжным

- Эталоны выведены автором набора по коду и независимым резолвером; второй независимой проверки (слепой агент, повторяющий вывод по тем же командам) нет. Резолвер повторяет правила `modules.yaml`, а не вызывает код Атласа: расхождение с реальным `atlas` на крайних случаях не проверялось (проверены 19 путей).
- Ограничение по определению: вопросы «где определён класс» проверяют определение на коммите `42d9805d9`; реэкспорты через `__init__.py` (в том числе `Services/vfd_comm/__init__.py`, `device_hub/drivers/__init__.py`) не считались.
- Q6, Q8, Q10, Q12, Q14, Q16 — «по назначению»; проверка единственности места реализации сделана `git grep` по ключевым словам; другой способ реализовать ту же идею другими словами мог не попасть в поиск. Q12 и Q14 всё равно допускают два прочтения у человека (клиент или драйвер; маппер или плагин) — формулировка сужена, но не исключает спора.
- Априорная сложность (E/M/H) — суждение автора, не замер.
- Набор из 19 вопросов даёт широкий доверительный интервал (раздел 2); пограничный исход 10–13 не решает ничего сам по себе.
- Запуск через `claude -p --bare` не проверен: `--bare` может требовать `ANTHROPIC_API_KEY` (не читает keychain); версию Haiku и фактический расход раннер обязан записать. Лид выбирает способ вызова (API напрямую или CLI); протокол от способа не зависит, пока в контексте нет ничего, кроме раздела 4.
- Карта на коммите `42d9805d9` и код на нём согласованы по определению автора, но `INDEX.md` — снимок: возможен дрейф между картой и кодом; на ответы вопросов по символам он повлиять не должен, потому что символы берутся из кода.
- Исход опыта сам по себе не меняет «ориентация не измерена на реальной задаче агента»: опыт сильнее убивает гипотезу, чем подтверждает.

Вопросы, которые переживают задачу: нужен ли вариант B (дешёвый, с утечкой «исключения уже названных»), если владелец ограничит расход; кто делает слепую проверку эталонов. Запись в `docs/claude/OPEN_QUESTIONS.md` — за лидом.
