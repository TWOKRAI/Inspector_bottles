## DESIGN

**Входит: голый NaN и NaN на любой глубине `dict`/`list`/`tuple`.** Цена контейнеров — одна рекурсия; без неё исправление закрывает два поля из четырёх, где бывает NaN (`chain_targets` — `list[str]`), а `collector` и `io_peek` остаются с тем же ложным WARNING.

1. **`blueprint.py`, модульная приватная функция над `ProcessConfig`:**

   ```python
   def _same_config_value(a: Any, b: Any) -> bool:
       """Равенство значений конфига, где NaN равен NaN на любой глубине dict/list/tuple."""
       if isinstance(a, float) and isinstance(b, float) and math.isnan(a) and math.isnan(b):
           return True
       if isinstance(a, dict) and isinstance(b, dict):
           return a.keys() == b.keys() and all(_same_config_value(a[k], b[k]) for k in a)
       if isinstance(a, (list, tuple)) and type(a) is type(b):
           return len(a) == len(b) and all(map(_same_config_value, a, b))
       return a == b
   ```

   `math` импортировать одним Edit с использованием. `type(a) is type(b)`: `["a"]` против `("a",)` остаётся конфликтом, как сегодня; `1` и `1.0`, `1` и `True` остаются равными.
2. **`_pick`, `:314`:** `if key in extras and extras[key] != getattr(self, key):` → `if key in extras and not _same_config_value(extras[key], getattr(self, key)):`.

**Остаётся на месте (урок `feedback_an_edit_that_replaces_a_neighbour_drops_it`):**
