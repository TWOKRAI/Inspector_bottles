## 6. Лучшая архитектура против самой дешёвой

| Решение | Лучшее | Самое дешёвое | Цена разницы |
|---|---|---|---|
| дом кода | переезд первым, старый адрес — псевдонимы (ЛР-28) | оставить `layer_render` на месте | 32 файла `.py` + 3 из `dataset_gen`; правила sentrux; окно heavy; ссылки в документах |
| поворот объекта | премультиплицированный счёт, холст float32 (ЛР-42) | оставить как есть | одна пересъёмка эталонов и перемер базы 0.4 на симе |
| пресет | v2 + шаги миграции + конвертер старого формата + двойники | мост, читающий `GeneratorConfig` на лету | ЛР-39, конвертер, тест по полям, 4 двойника |
| генератор | один расширенный | два генератора с общим интерфейсом | 1 задача (ЛР-31) + замер (ЛР-32) |
| фон | фото и процедурный — модуль фона | оставить в каталоге | правка границы каталога; m4 держит байты |
| эффекты | эффекты слоя + геометрия кадра | только эффекты кадра | 2 задачи (ЛР-33, ЛР-34) |
| превью | общая смесь | своя смесь в `_fit_tile` | 1 литерал PNG (Р14, решено «да») |
| глифы | один инструмент | 3 инструмента | 1 задача, пересборка каталогов |

Кирпичи, проверенные на «переписать»:

- **холст слоёв и поворот** (`lr/layers.py:276-292`): **переписывается** (ЛР-42). Прежняя оценка «в кадре ≤0,5 уровня» не
  подтвердилась: замер CTO — до 2 уровней (3 слоя, 40 зёрен) и тёмный край в 53 уровня.
- **смесь**: целая формула, меняется дом (`draw`). Замер CTO: байты равны, быстрее в 1,4–1,6 раза (кадр 1440×1080 — 52 мс
  против 74).
- **каталог**: выборка фона уходит в модуль фона; классы и `meta.yaml` — без изменений.
- **эффекты, вырез, фабрика, `render_scene`**: расширяются полями; у эффектов добавляется ступень, у `EffectContext` —
  обязательность; дефект поворота — в холсте, не в `render_scene`.

## 7. Отвергнутые варианты

| Вариант | Почему нет |
|---|---|
| генерация в `draw` (первая группировка владельца) | уровень: `draw` — примитивы, ими рисуют и на реальных кадрах; CTO согласен |
| один плоский пакет | радиус тестов 1652 + будущие тесты `draw` в одном гейте |
| копия кода или `import *` на старом адресе | дубль всей живой логики; подмена имени не доходит до кода — тесты молча обесцениваются (опыт CTO) |
| переезд после стройки (прежний порядок) | новый код пишется по старому адресу и перевозится — двойная работа |
| поле `id` слоя | имена уже уникальны |
| пара `Field(ge, le)` + `FieldMeta` и тест «равны» | два объявления одного факта |
| `EffectContext` по желанию | два поведения одной функции |
| модель правки как «функции над словарём» | повторяет веб; неверная правка не падает сразу |
| перевести DE на общую фабрику | меняет замороженные байты: порядок rng другой (`engine.py:121-130` против `lr/factory.py:216-221`) |
| DE собирает кадр через `render_scene` | правка замороженного кода без пользы для живого пути |
| процесс-сервис рендера | кадр 1440×1080 через IPC каждый тик (CTO 10-01) |
| бэкенд и реестр для смеси | функции не прибавляет (CTO r2) |
| флаг округления в смеси ради литерала превью | второе поведение одной функции |
| имя `SyntheticSampleGenerator` | `synthetic` в `ml_train` = старый путь |
| фон стенда как запасной источник | два источника расходятся (находка 4) |
| панели фона и эффектов в вебе | веб заморожен; потом выбрасывается |
| своя схема пресета для веба (`model_json_schema` в `preset.get`) | вторая схема рядом с `data_schema` |

Правило «`draw` не грузит pydantic» снято: в процессе показа он уже загружен. Это не значит, что веса нет: в чистом
процессе (воркер DataLoader на Windows, любой CLI) `data_schema_module` стоит 0,78 с и 1113 модулей, `layer_render`
сегодня — 0,34–0,42 с и 509, pydantic — 0,12 с (замер CTO). Порог — приёмка ЛР-38.

## 8. Прежние решения CTO, которые CTO меняет

| Было | Стало | Почему |
|---|---|---|
| r2 §2.2: один пакет отклонён | одна папка `imaging`, внутри `draw` и `layers` | вес в показе не подтвердился; радиус тестов держат подпакеты |
| r2 §2.2: склейку `draw` не берёт | смесь — `imaging/draw/blend.py`, целая формула | замер: байты равны, быстрее в 1,4–1,6 раза |
| 10-01 №4: цепочка источников фона | один источник — пресет | цепочка дала находку 4 и «держать равными» |
| 10-01 №6: генератор в `dataset_gen` | генератор в `imaging/layers`, конвертер | слова владельца 4 |
| 10-01: команда `preset.schema`; «реэкспорты» | команда снята; псевдонимы модулей | схема одна, в коде; опыт с модулем-копией |

В силе: библиотека, а не процесс-сервис; одна `render_scene`; контракт rng; r2 «`blit` бэкенда — только по замеру»,
«`layer_render` вызывает только `get_backend("cv2")`».
