## Приёмка, известная заранее

| Задача | Приёмка |
|---|---|
| ЛР-25 | тест «импорт `draw` не грузит `layers`» — в чистом подпроцессе: в общем прогоне pytest порядок импорта прячет нарушение |
| ЛР-28 | `git mv`, история сохранена; один тест: каждое публичное имя старого адреса — тот же объект, что в новом; эталоны без правки; m4 зелёный |
| ЛР-42 | тест-инвариант: объект цвета C на фоне цвета C даёт C при любом угле, масштабе и числе слоёв. Эталоны живого пути (A7, раскладка, 12 кадров `scene_source`, 6.3.0 G2) переснять **один раз**, с инъекциями в новые литералы; в ту же пересъёмку — литерал превью (Р14) и ЛР-22 (Р6). После правки перемерить базу 0.4 на симе (`scripts/letters_baseline.py`). `DatasetEngine` остаётся на прежних `rotate_expand` и `fit_longest_side`, m4 держит |
| ЛР-24 (Р14) | новый литерал PNG превью отличается от старого не больше чем на 1 уровень |
| ЛР-39 | шаги — чистые функции «словарь → словарь» до проверки схемой; загрузка не меняет файл. Первый клиент — пресет v1→v2: `train.augment` → `effects`, `train.background_layers` → `background`. Шаг для `train.augment` выписывает явно и эффекты, включённые по умолчанию: старый файл даёт прежние байты (см. открытое 1 в plan.md) |
| ЛР-40 | реестр — словарь без порядка; ошибка перечисляет зарегистрированные виды; тест грузит все пресеты репозитория в чистом процессе |
| ЛР-06 | `EffectSpec` сохраняется в пресет (сейчас pickle падает); ключа нет — кадр байт в байт прежний (контракт rng — [history.md](history.md)); m4 зелёный. Список эффектов не по ступеням `scene` → `optics` → `sensor` → `codec` отвергается, ошибка называет пару; повтор вида запрещён, пока вид сам его не разрешит. Страница `pult_web` получает пресет v2 с `background`, `effects`, `train` и возвращает без потерь (стенд node из тестов 5.3). Схемы пресета не грузят cv2 и numpy — тест в чистом процессе |
| ЛР-38 | одна база `ImagingSchema(SchemaBase)` с `extra="forbid", frozen=True`; тест обходит все схемы `Services/imaging` и конфиги её плагинов и проверяет запрет на каждом уровне вложенности (см. открытое 2). Пределы поля объявлены один раз, в `FieldMeta(min, max)`. Время импорта `Services.imaging.layers` в чистом процессе до и после; прирост больше 0,3 с — чинить `data_schema_module` вперёд |
| ЛР-10 | выбор слоя на канве держится за имя; переименование идёт операцией модели и переносит выбор |
| ЛР-31 | каждая строка матрицы 1.1–1.19 — тест; эталоны 6.3.0 G1–G3 без правки (после пересъёмки ЛР-42); экспорт пишет паспорт набора: sha256 пресета, зерно, список эффектов |
| ЛР-32 | планка Р13 — [design-unified-migration.md](design-unified-migration.md) |
| ЛР-34 | `EffectContext` — обязательный аргумент; старый путь передаёт геометрию своего кадра (окно равно кадру), байты те же, m4 доказывает |
| ЛР-35 | сессия правки держит замороженный `ScenePreset`; неверная правка падает сразу; словарь появляется только в `preset.commit`; переименование правит и `train.label.angle_layer` |

**Общее правило (README сервиса).** Функция под эталоном m4 меняет байты только через новую функцию или новый вид.
`DatasetEngine` зовёт живые `apply_effects`, `composite`, `get_background`, `procedural_background`,
`cast_contact_shadow`: это замороженный контракт. В m4 добавить случаи: три вида процедурного фона держит один случай
каждый (задачу вердикт не назвал).
