## Цель простыми словами

Один сервис изображений `Services/imaging`. Он делает картинки для симулятора ленты, для обучения сети и для редактора —
**одним кодом**. В нём две части: `layers` (слои, фон, эффекты, кадр, вырез, генератор обучения) и `draw` (рисование:
смесь по альфе, фигуры, шрифты, текст). Старые модули замораживаются, их лучшее переходит в новые. Новое — лучше любого
прежнего, и это доказывает замер. Механизм не знает про буквы: новый продукт — пресет и каталог картинок, без кода.
Все настройки — схемы `data_schema`: поле описано один раз, форма строится сама. Редактор — на Qt; веб-редактор
заморожен ([design-unified-schema-qt.md](design-unified-schema-qt.md)).
