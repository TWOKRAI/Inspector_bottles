# Design: единая система изображений — матрица возможностей, часть 1

Родитель: [design-unified.md](design-unified.md). Часть 2 — [design-unified-matrix-2.md](design-unified-matrix-2.md).
Код дерева `docs/layer-render-status` (`main` 53efe24b9 + документы), прочитан 2026-11-26.

**Как читать.** Строка — одна возможность. «Где сейчас» — path:line. «Лучший» — у кого лучше и почему.
«В новой системе» — чем она станет, или «снята намеренно» с причиной. Правило приёмки: ни одна возможность
замороженного модуля не пропадает молча. Строки, номера которых взяты из отчёта помощника (haiku) и не перечитаны мной,
помечены «(п)».

Сокращения: `lr/` = `Services/layer_render/`, `dg/` = `Services/dataset_gen/`, `ls/` = `Services/line_sim/core/`,
`ss` = `Plugins/sim/scene_source/plugin.py`, DE = `DatasetEngine` (`dg/core/engine.py`),
LSG = `LayerSceneGenerator` (`dg/core/layer_scene.py`). Новая система — раздел 3 [design-unified.md](design-unified.md).
