# Задача РУ-1 — разметка угла диска после съёмки (`scripts/label_angle.py`)

**Уровень:** Middle (Sonnet) · **Исполнитель:** developer · **План:** [plan.md](plan.md)
**Основание:** решение владельца 11-27: диск снимается как лёг; потом картинку доворачивают до прямой буквы,
это 0, угол доворота записывается. Разрешение писать в `scripts/` — владелец, 11-27.

**Цель:** владелец за один проход размечает угол 240 снятых кадров; результат читает `letters_baseline.py dir`.

## Данные

- Вход: `<raw>/<БУКВА>/a<ddd>_<номер>.<png|jpg|jpeg|bmp|tif|tiff|webp>` — как пишет камера с префиксом `a000`.
  Цифры `<ddd>` во входе ничего не значат.
- Выход: `<out>/<БУКВА>/a<угол:03d>_<номер>.<то же расширение>` — **байт-копия** входного файла.
  `<номер>` — те же цифры, что во входе. Входные файлы не меняются и не удаляются.
- Угол в имени — на сколько градусов **против часовой стрелки** буква повёрнута на кадре (0 — стоит прямо).
  Владелец крутит вид на `turn` градусов против часовой, пока буква не встанет прямо; угол = `(-turn) % 360`.

## DESIGN

Один файл `scripts/label_angle.py`, PySide6. Из `scripts/letters_baseline.py` берутся `RecipePipeline`
(вырезка диска, как в боевом рецепте), `read_image`, `NAME_RE`, `IMAGE_SUFFIXES`; своих копий не заводить.
Папку `multiprocess_prototype` не импортировать (рецепт читается как YAML по пути).

Публичные имена:

```python
@dataclass(frozen=True)
class RawFrame:
    path: Path          # входной файл
    letter: str         # имя папки буквы, NFC
    index: str          # цифры номера из имени, как в имени
    angle: int | None   # угол из уже лежащей в out копии, иначе None

def scan(raw_dir: Path, out_dir: Path) -> list[RawFrame]
def truth_angle(turn_deg: int) -> int                      # (-turn_deg) % 360
def rotate_view(image: np.ndarray, turn_deg: float) -> np.ndarray   # против часовой на экране; размер тот же
def save_label(frame: RawFrame, out_dir: Path, angle: int) -> Path

class LabelWindow(QWidget):
    def __init__(self, raw_dir: Path, out_dir: Path, recipe_path: Path | None = None)
    current: RawFrame | None      # свойство; None — кадры кончились
    turn_deg: int                 # свойство, всегда в (-180, 180]
    def set_turn(self, deg: int) -> None

def main(argv: list[str] | None = None) -> int
```

**scan.** Порядок: буква, затем номер как число. `ValueError` с именами файлов, если: `raw_dir` нет или в нём
нет картинок; картинка во входе лежит не по схеме; два входных файла одной буквы имеют один номер (числом);
`out_dir` равен `raw_dir`, лежит внутри него или содержит его; в `out/<буква>` под номером входного кадра
лежит файл **с другим содержимым** или две копии. Тихо пропускать нельзя ничего.

**save_label.** Пишет копию с именем по углу `angle % 360`, затем удаляет прежнюю свою копию того же номера
(байты равны входному файлу) под другим углом. Если под этим номером в `out/<буква>` есть файл с другим
содержимым — `FileExistsError`, ничего не меняется.

**Окно.** Открывается на первом неразмеченном кадре (`angle is None`); если все размечены — `current is None`.
Показывает вырез рецепта (128×128, увеличенный); если `recipe_path is None` или круг не найден — весь кадр,
уменьшенный, и надпись об этом. Поверх вида — прямые вертикаль и горизонталь (только на экране). Текст: буква,
номер, «кадр N из M, размечено K», доворот, записываемый угол, подсказка по клавишам. Ползунок −180…180
связан с `turn_deg`.

| Клавиша | Действие |
|---|---|
| ← / → | вид на 1° против / по часовой (`turn_deg` +1 / −1) |
| ↑ / ↓ | то же на 10° (+10 / −10) |
| Enter, Return | записать копию, перейти к следующему кадру по порядку |
| S | следующий кадр, ничего не записывая |
| Backspace | предыдущий кадр |
| Esc | закрыть |

`turn_deg` при переходе на кадр: у размеченного — по его углу (`-angle`, приведённый в (−180, 180]); иначе тот
же, что был, если буква та же; иначе 0. Клавиши работают и когда фокус на ползунке или кнопке.
Нечитаемый файл: надпись, Enter ничего не пишет и не переходит, S переходит.
Ошибка записи или конфликт: сообщение в окне, кадр остаётся текущим, программа не падает.

**CLI.** `label_angle.py <raw> <out> [--recipe PATH] [--no-crop]`; `--recipe` по умолчанию
`multiprocess_prototype/recipes/hikvision_letter_robot.yaml` от корня репозитория. Ошибка входных данных —
текст в stderr и код 2, окно не открывается. После закрытия окна — сводка по буквам: сколько кадров, сколько
размечено, сколько разных углов; код 0.

## REDS (приёмка)

1. `truth_angle`: 0→0, 90→270, −90→90, 180→180, −180→180, 1→359, 360→0, 450→270.
2. `rotate_view`: метка у середины верхнего края после +90 — у левого края, после −90 — у правого; размер тот же.
3. `scan`: порядок «буква, номер числом»; `angle is None` без копии; каждый случай `ValueError` из «scan».
4. `save_label`: имя `<out>/П/a045_000007.png`; байты равны входу; вход не изменён; 405 → `a045`, −90 → `a270`;
   повторная разметка оставляет ровно один файл на номер; чужой файл под номером → `FileExistsError`, всё как было.
5. Связка: кадр `П/a000_000001.png`, довернули на −90, записали → `letters_baseline.scan_dir(out)` читает
   букву «П» и угол 90.
6. Окно: открытие на первом неразмеченном; каждая клавиша таблицы; `turn_deg` остаётся в (−180, 180];
   Enter пишет файл с углом `(-turn_deg) % 360`; правила `turn_deg` при переходе; Backspace + Enter = один файл;
   после последнего `current is None` и Enter ничего не делает; повторное открытие продолжает с неразмеченного.
7. Нечитаемый файл и кадр без круга не роняют окно; кадр без круга можно разметить.
8. `main`: несуществующий вход и конфликт → код 2, текст в stderr.
9. `day1_capture_check.py <raw> --angles 0 --min-per-cell 3` принимает входную схему (кадры резкие, нужной
   яркости, по 3 на букву) — `ИТОГ: PASS` с `--letters` по буквам набора.
