### Task 5.3 — канва редактора: сетка/привязка, мультивыбор, горячие клавиши, вписать, видимость/замок

- **Статус:** [IN PROGRESS] волна 2 · **Level:** Middle+ (Sonnet 5.5) · **Assignee:** tester → developer → инъекции лида → reviewer
- **Module contract:** n/a (клиентский JS страницы; команды бэкенда не меняются)
- **CHAIN:** `tester`(RED, worktree до кода) → `developer`(GREEN) → инъекции лида → `reviewer`
- **Dependencies:** нет (чисто клиентская; идёт сразу после Ф1)
- **Gate:** RED тестера → GREEN; инъекции записаны; все тесты `Plugins/sim/pult_web/tests/` зелёные; `reviewer` APPROVED по SHA

**Goal:** канва редактора слоёв удобна для работы руками: привязка к сетке, групповые правки, клавиатура, «вписать»,
скрыть/запереть слой — без единой новой команды бэкенда и без новых полей пресета.

**Files:**
1. `Plugins/sim/pult_web/plugin.py` — `_PRESET_SECTION` (разметка), `_PRESET_SCRIPT` (JS канвы)
2. `Plugins/sim/pult_web/README.md`, `STATUS.md` — раздел канвы
3. `Plugins/sim/pult_web/tests/page_offline.mjs` — только если харнессу не хватает событий (новые сценарии — да, правка существующих — нет)
- тесты тестера: `Plugins/sim/pult_web/tests/test_acceptance_5_3_canvas_tools.py`

**Контракт страницы (пинится тестами; всё остальное — дело реализации).** Контракт 1.3h-b (`tests/test_acceptance_1_3h_canvas.py`,
докстринг) действует как есть; ниже — только новое. Индекс `i` — индекс в `presetState.layers` (не в раскладке).

1. **Разметка.** `<input type="checkbox" id="presetGrid">` (сетка вкл/выкл, по умолчанию выкл);
   `<input type="number" id="presetGridStep" value="10" min="1">` (шаг сетки, px объекта); `<button id="btnPresetFit">`;
   в строке каждого слоя пресета (`div` в `#presetLayers`, первый потомок `<b>` с именем) — `<input type="checkbox" id="presetVis{i}">`
   (видим, по умолчанию отмечен) и `<input type="checkbox" id="presetLock{i}">` (заперт, по умолчанию снят).
2. **Привязка к сетке.** При отмеченном `#presetGrid` на `pointerup` жеста перемещения `offset_px` захваченного слоя по каждой оси —
   ближайшее кратное шагу `#presetGridStep` (px объекта); остальные выбранные слои сдвигаются на ту же дельту (взаимное
   расположение сохраняется). Сетка выкл — поведение 1.3h-b. Стрелки сеткой не привязываются. Смена `#presetGrid`/`#presetGridStep`
   не меняет `presetState`, не кладёт запись «Отмена», не шлёт запросов. При вкл. сетке канва рисует её линии (не пинится).
3. **Мультивыбор.** `pointerdown` ЛКМ с `shiftKey` на слое переключает его членство в выборе и жеста не начинает (ничего не
   сдвигается). `pointerdown` без Shift на слое, который уже в выборе, тащит **все** выбранные слои: на `pointerup` каждый
   выбранный получает одну и ту же дельту, ровно одна запись «Отмена», ровно один `POST /api/preset/layout`. `pointerdown` без
   Shift на слое вне выбора — выбор = только он (как 1.3h-b). Строки всех выбранных слоёв несут токен `selected`. Стрелки сдвигают
   все выбранные (1 px, Shift — 10), одна запись «Отмена» на нажатие. Ручки поворота/масштаба — только когда выбран ровно один слой.
   «Отмена» после группового сдвига возвращает `offset_px` всех сдвинутых слоёв.
4. **Горячие клавиши** (`keydown` на `document`; игнорируются, когда фокус в `INPUT`/`TEXTAREA`/`SELECT` — как сейчас):
   `Delete` и `Backspace` — удалить все выбранные слои, одна запись «Отмена» (авто-слой `base` не удаляется — его и выбрать нельзя);
   `Ctrl+Z` (или `Meta+Z`) — то же, что `btnPresetUndo`; `Ctrl+A` — выбрать все видимые незапертые слои пресета, `preventDefault`;
   `Escape` — снять выбор; `f`/`F` — вписать (п. 5); `g`/`G` — переключить `#presetGrid`. После клика по чекбоксам п. 1 фокус
   возвращается на канву (иначе следующая клавиша уйдёт в поле — как F1 1.3h-c).
5. **Вписать.** `btnPresetFit` и `F`: `presetZoom.value === String(Z)`, где `Z = clamp(Math.floor(95 * Math.min(W / cw, H / ch)), 10, 1000)`,
   `W, H` — `presetCanvas.width/height`, `[cw, ch]` — `canvas_px` последней раскладки; панорама сброшена — центр объекта в центре
   канвы (геометрия 1.3h-b п. 3). Запросов не шлёт, «Отмену» не трогает.
6. **Видимость и замок — состояние клиента**, по имени слоя. Снятый `presetVis{i}`: слой не рисуется на канве (пиксели на его месте
   — от слоёв ниже или прозрачные), выбрать его на канве нельзя (клик проходит к слою ниже), из выбора он убирается. Отмеченный
   `presetLock{i}`: слой рисуется, но на канве не выбирается и не тащится (клик проходит к слою ниже), стрелки и `Delete` его не
   трогают, из выбора убирается, `Ctrl+A` его не берёт. Ни флаг в `presetState`, ни тело `POST /api/preset/commit` и
   `/api/preset/layout` не попадает (тело с переключёнными флагами побайтно равно телу без них); записей «Отмена» не кладёт;
   флаги переживают перестройку строк и новую раскладку (после правки поля, добавления/удаления другого слоя) и сбрасываются
   перезагрузкой страницы. Превью бэкенда (`btnPresetPreview`) рисует все слои — поле `enabled` пресета придёт в Ф3.
