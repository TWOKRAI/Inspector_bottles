## Как читать

Формат поля — `design.md`, раздел «Фаза 3»: `- **После:** <план>[, <план>…] — причина` или `- **После:** ⛔ <условие>`. Имя плана — basename без `.md`.

Поле — про **весь** план. Страница считает план с полем «ждёт», пока условие не снято. Поэтому:

- **поле** — весь остаток плана ждёт условия; вписать как есть;
- **частично** — ждёт только часть задач, остальное можно брать сейчас. Поле не ставить: оно спрячет план из «можно начинать». Ждущую задачу пометить в строке задачи прозой (`⛔ О-12`); стрелки между задачами разных планов не делаем (`design.md`);
- **нет** — план независим; поле можно не писать или написать `- **После:** —`.
