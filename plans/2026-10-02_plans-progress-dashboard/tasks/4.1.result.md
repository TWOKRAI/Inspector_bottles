- Фаза — как прежний ledger: у плана с пунктами раздела порядка только `item.phase`; заголовок и `phase-N.md` — только без пунктов (находка ревью на `line-sim-layer-editor`).

## Что осталось открытым

- **Граница доверия.** `status`/`close`/`add` с `--root X` исполняют код `X/scripts/plans_progress/plans_progress.py`. Воспроизведено лидом: модуль с записью маркера и `raise SystemExit(7)` → маркер создан, ledger exit 7. Записано в README и docstring; переключателя нет.
- `check_plan_gate` и `build_summary` читают набор прежним кодом до 4.4: `SUMMARY.md` плана, закрытого адаптером, может показать задачи `PENDING`.
- Сторож режима «адаптер» в старых тестах ищет подстроки `load failed`/`analyze_plan failed`: смена текста сообщения ослепит его молча.
- Путь кэша без `normcase`: два написания одного корня на Windows загрузят модуль дважды (безвредно, не проверено).
- `.claude/plugins/.seed-manifest.json` устарел с `b1e03bafb` — вне задачи.
