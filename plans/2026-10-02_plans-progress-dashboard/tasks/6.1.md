  - Таблица — первая непрерывная серия строк блока, у которых первый символ после `lstrip` — `|`. Ячейки — части между неэкранированными `|`; пустая часть до ведущей `|` и пустая после замыкающей отбрасываются каждая по отдельности (строка без замыкающей `|` не сдвигает колонки; `_cells` «Снимка» не меняется). Колонки ищутся по тексту шапки после `clean_md` и `casefold`: `#`, `план`, `задача`, `заметка`; обязательна только `план`. Нет таблицы или нет колонки `план` — `OWNER_QUEUE_BLOCK`, очередь пуста.
  - Разделитель — строка, все ячейки которой вида `:?-+:?`. Пустая строка — все ячейки (и `#`) пусты после `clean_md`. Ни то, ни другое не пункт. Остальные строки — пункты, порядок — порядок строк. Ячейка `#` не читается (она для глаз): `n` — порядковый номер пункта с 1. Каждая строка-пункт попадает в очередь, и битая тоже (`known: false`): страница 6.2 покажет строку владельца на её месте.

Имя принимается, если это слаг `[a-z0-9][a-z0-9.-]*` или полное имя `ГГГГ-ММ-ДД_<слаг>`: своя функция очереди, `snapshot_slugs` и «Снимок» (3.7) не меняются. Поиск — `find_by_slug`: сначала точное имя (живой, затем архивный), потом имя с датой (живой, затем архивный). Ноль имён или больше одного — `OWNER_QUEUE_BAD`; имя без плана — `OWNER_QUEUE_UNKNOWN`.
  - Задача. Текст ячейки после `clean_md` и снятия начального `Task ` (без учёта регистра). Пусто, `—`, `–` или `-` — пункт-план (`kind: "plan"`, `task: null`); иначе пункт-задача (`kind: "task"`, `task` — этот текст, и при BAD тоже). Текст не совпадает целиком с `ID_PATTERN` — `OWNER_QUEUE_BAD`; задачи с таким id нет в найденном плане — `OWNER_QUEUE_UNKNOWN`. Повтор id в плане — берётся первая (как `_dedupe_first`).

  - Одна находка на пункт — первая по порядку: BAD плана → BAD задачи → UNKNOWN плана → UNKNOWN задачи → `OWNER_QUEUE_CLOSED` (известный закрытый пункт: заготовка 6.1 (`392a389de`, по идее владельца) называет закрытый пункт находкой — напоминание убрать пункт; страница покажет его зачёркнутым).

Пункт — ключи строго в порядке `n`, `kind`, `plan`, `task`, `note`, `known`, `closed`. `plan` — имя найденного плана; не найден, но имя одно — это имя (из ссылки — имя из пути); ноль или несколько имён — текст ячейки через `clean_md`. `note` — ячейка `заметка` через `clean_md`, нет колонки — `""`. `known` — план найден, у пункта-задачи и задача найдена, BAD нет. `closed` — `false`, если `known` ложно. Контракт ключей (верхний объект и пункт) — только дописывание в конец.
