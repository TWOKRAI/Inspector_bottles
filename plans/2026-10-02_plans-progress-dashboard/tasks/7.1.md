# Task 7.1: Вкладки, страница плана и переключатель — лаконичная страница без `<script`

TASK: 7.1 — вкладки сверху, страница плана по `#plan-<имя>`, переключатель планов   PLAN: plans/2026-10-02_plans-progress-dashboard/plan.md

CHAIN: reviewer(текст) -> tester(RED до кода, worktree) -> developer -> lead(инъекции, живой стенд в браузере) -> reviewer

DESIGN:
  - **Зачем.** Владелец (2026-10-05): страница «красивая, удобная, информативная», по умолчанию лаконичная, вкладки и поля скрываются; переключение между планами. CTO (вердикт «одно окно», условия 4–5): у каждой карточки якорь `id="plan-<slug>"`, страница плана по `:target` без `<script`, якорь закреплён тестом — по нему Атлас 3.1 встроит страницу вкладкой «Планы» (стык 7 в `ORDER.md`).
  - **Без JS.** На странице ни одного `<script` и ни одного `on…=` обработчика. Переключение — радиокнопки + CSS `:has()`; страница плана — `:target`; раскрытие свёрнутого — `::details-content` (Chrome 131+, Firefox 143+, Safari 18.4+; в старом браузере `<details>` раскрывается кликом).
  - **Разметка прежняя, добавки — рядом.** Порядок секций, их `id`, `<details id="waiting">`, `<details id="archive">`, `<section id="queue">`, атрибуты и порядок чипов карточки, `data-plan` (по нему тесты находят карточки) — без изменений. Вкладки не оборачивают секции: CSS прячет и показывает существующие элементы по состоянию радиокнопок. Новые элементы не несут `data-plan` и `id`, совпадающих с прежними.
  - **Верхняя полоса** (`<header class="topbar">`, липкая): заголовок, одна строка `meta` (собрано · SHA), счётчики и «можно начинать» — прежние `div.meta`, `#ready`; переключатель «Планы ▾»; полоса вкладок.
  - **Вкладки** — `<nav class="tabs">`: `<input type="radio" name="tab" id="tab-<ключ>">` + `<label for="tab-<ключ>">Название · N</label>`. Ключи и секции: `queue` → `#queue` (по умолчанию, `checked`); `waiting` → `#waiting`; `unlisted` → `#unlisted` (вкладка только если секция есть); `archive` → `#archive`; `who` → `#who`; `overlaps` → `#overlaps` (только при N > 0, метка с `⚠`); `priority` → `#priority` (только если секция есть); `lanes` → `section.lanes`. N — число планов (строк для `who`/`priority`, файлов для `overlaps`, полос для `lanes`). На вкладке `waiting`/`archive` содержимое `<details>` раскрыто CSS-ом без клика.
  - **Якорь карточки.** `id` — последним атрибутом `<details class="plan" …>`: `plan-<slug>`, slug — имя плана, символы вне `[A-Za-z0-9_-]` → `-`. Имя занято (живой и архивный план с одним именем) — у второго по порядку на странице `plan-<slug>-archive`, дальше `-2`, `-3`. Все `id` на странице уникальны.
  - **Ссылка на страницу плана** в `<summary>` карточки сразу после `span.name`: `<a class="plan-link" href="#plan-<slug>" title="страница плана">↗</a>`. Чипы и их порядок — прежние.
  - **Страница плана** (`:target` на карточке): видна только верхняя полоса и эта карточка — раскрытая, во всю ширину; остальное скрыто. Ссылка «← все планы» (`<a class="back" href="#">`) в верхней полосе видна только на странице плана.
  - **Переключатель** «Планы ▾» — `<details class="switcher">`: группы «Очередь», «Ждут», «Нет в ORDER», «Закрыто и архив» (пустая группа не выводится), в группе по одной ссылке `<a href="#plan-<slug>">имя</a>` на каждую карточку страницы с `_tally` рядом, порядок — как карточки на странице.
  - **Поля карточки свёрнуты.** В теле карточки ячейки задач (`div.cells`) видны; список задач `<ul class="tasks">` — внутри `<details class="tasklist"><summary>Задачи · N</summary>`; на странице плана раскрыт CSS-ом.
  - **Вид.** CSS-переменные цвета для светлой и тёмной темы (`prefers-color-scheme` — сохранить), карточки с рамкой и скруглением, полоса прогресса в цвет акцента, вкладки — «таблетки» с выделенной активной. Ширина строки ≤ 1100 px по центру. Вес CSS — не больше +4 КБ к текущему (~2,9 КБ).
