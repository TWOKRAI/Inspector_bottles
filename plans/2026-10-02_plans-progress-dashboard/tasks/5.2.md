DESIGN:
  - Корни: `git -C <root> worktree list --porcelain`, только если `git -C <root> rev-parse --show-toplevel` = `--root`. Иначе (нет git, фикстура без `git init`, tmp внутри чужого репозитория) корней нет: `active: []`, `--who` пуст, exit 0. Ветка корня — из porcelain (`branch refs/heads/X` → `X`, `detached` → `""`).
  - Сигнал: строки `<worktree>/data/agent-journal.jsonl` этого корня (журналы вне списка не читать). Пропускать битый JSON, `event == ""`, `ts` не по `datetime.fromisoformat`. `ts` — местное время без пояса. Свежая строка: `now - ts <= окно` (будущее время тоже свежее). Корень без свежей строки в выдачу не попадает.
  - По свежим строкам: `sessions` и `agents` — число разных непустых `session_id` и `agent_id`; `last_signal` — наибольший `ts` строкой как в журнале.
  - Резолвер плана, первый успешный шаг, имя шага в `via`: (а) `plan_ref`: `git -C <wt> config --worktree --get plan.ref` (exit 1 = не задан); (б) `refs`: строки `Refs:` в `git -C <root> log --format=%B main..<ветка>`, от новых коммитов к старым, первый токен `plans/…`, который даёт известный план; (в) `header`: строка `Ветка:`/`Branch:` в первых 30 строках главного файла плана (разметка `- **…:**` и обратные кавычки допустимы), первый токен вида `тип/имя`, хвост отброшен; ветка у двух планов → шаг не дал плана. При пустой ветке шаги (б) и (в) пропускаются.
  - Имя плана из пути: первый сегмент после `plans/` (после `_archive/<квартал>/`, если есть), без `.md`: `plans/X/tasks/1.1.md` → `X`, `plans/Y.md` → `Y`. Значение `plan.ref` — путь или голое имя. Сначала живой план, потом архивный. Неизвестное имя → шаг не дал плана.
  - `--json`: у каждого плана ключ `active` — список `{"branch", "worktree", "via", "sessions", "agents", "last_signal"}`, по `worktree` по возрастанию; `worktree` — путь как в porcelain. Остальные ключи не менять.
  - Новый флаг `--who`: на stdout объект `{"active": [...], "orphans": [...]}`. В `active` те же записи плюс `"plan"`; в `orphans` корни без плана, без `plan` и `via`. Нужен Task 5.3 для секции «Кто где».
  - Точки впрыска: `--now ISO` (местное без пояса; по умолчанию сейчас), `--active-window` в виде `\d+[mhd]` (по умолчанию `6h`, не измерено); иное значение → exit 2 и сообщение в stderr. Путь `main..<ветка>` — литерал `main`: нет ветки `main` → шаг (б) не дал плана.
  - Почему не `--journal`/`--worktrees` (прежний текст): фикстура — настоящий `git init -b main` с `git worktree add`, как в Task 5.5. Меньше флагов, а шаги (а) и (б) без git не проверить.
  - Задел Task 5.1: в записи есть `session_id`, `branch`, `source`. Журнал исчезает вместе с worktree: «нет журнала» = «неизвестно». `--html` и `--check` эта задача не трогает.
