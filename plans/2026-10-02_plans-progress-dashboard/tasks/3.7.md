DESIGN:
  - Запрос владельца 2026-10-04: «чтобы приоритеты было видно». В `ORDER.md` порядок приоритета стоит в таблице раздела `## Снимок <дата> — …` (сверка очереди 2026-10-03): колонки `# | Полоса | План | Сейчас | Следующий шаг | Чего ждёт`, строки по приоритету. Страница его не знает: очередь идёт в порядке таблицы §4.1.
  - Разбор (`parse_snapshot(path) -> (дата, строки)`): первый заголовок второго уровня, начинающийся с `## Снимок`; дата — первый токен `\d{4}-\d{2}-\d{2}` заголовка (нет — `""`). Таблица — первая после заголовка, до следующего `## `. Строка — `#` (целое; иначе строка пропускается), полоса, ячейка «План», «Следующий шаг», «Чего ждёт» как текст через `clean_md`. Колонки ищутся по тексту шапки таблицы, не по позиции. Нет раздела или колонок `#`/`План` → строк нет, не ошибка.
  - Имена в ячейке «План»: части через `,`; часть — ссылка `[..](путь)` (имя через `_name_from_href`) или текст. Учитывается только часть вида `[a-z0-9][a-z0-9.-]*` (`фаза 5` пропускается молча). Совпадение: `p.name == часть` или `p.name == <ГГГГ-ММ-ДД>_<часть>`; сначала живой план, потом архивный. Часть вида слага без плана → находка `SNAPSHOT_UNKNOWN` (информационная, не блокирует) с текстом части.
  - Приоритет плана — наименьший `#` из строк, где он назван. В `--json` не выводится (ключи `--json` не менять).
  - Страница:
    - секция `<section id="priority">` после `<div class="meta" id="ready">` и до `<section class="lanes">`: `<h2>Приоритеты · снимок <дата></h2>`, затем `<ol>` с одним `<li data-priority="N">` на строку таблицы в её порядке, текст `#N · полоса <полоса> · <ячейка План> — дальше: <Следующий шаг> · ждёт: <Чего ждёт>`; строк нет → `<p>в ORDER.md нет таблицы «Снимок»</p>`;
    - у плана с приоритетом в `<summary>` сразу после `<span class="name">` чип `<span class="chip" data-chip="priority" data-priority="N">#N</span>`; в теле первой строкой `.info`: `<b>Приоритет #N:</b> дальше — <Следующий шаг>; ждёт — <Чего ждёт>` (из строки с этим `N`);
    - `#queue` (§4.1): сначала планы с приоритетом по возрастанию `N`, затем остальные в прежнем порядке; сводка `#ready` идёт в этом же порядке. Без таблицы «Снимок» порядок прежний. `#waiting`, `#unlisted`, `#archive` не переставлять.
  - Всё через `_e`; без JS и внешних ресурсов; новых цветов нет.
