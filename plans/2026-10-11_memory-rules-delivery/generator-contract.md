# Контракт генератора `scripts/memory/rules.py`

Один дом контракта: его читают тестер 1.1 (вслепую), developer 2.1, лид (инъекции) и reviewer. Ред. 2 — по ревью
`MODE: plan`, итерация 1 (2026-10-11). Тот же текст — в docstring `rules.py` (README в `scripts/memory/` не заводится).

1. **Вызов:** `python scripts/memory/rules.py --write|--check [--root DIR]`; DIR по умолчанию — `git rev-parse --show-toplevel`
   (как `tags.py`). Код выхода: 0 — чисто; 1 — есть находки (`--check`); 2 — отказ: `modules.yaml` есть, но не словарь
   или без списка `modules`.
2. **Вход:** уроки — `_lessons.iter_lessons(DIR/docs/claude/memory)`, ключ `module`; модули — `DIR/modules.yaml`
   (`yaml.safe_load`, ключи `id`, `paths`). Нет `modules.yaml` → 0 узлов модулей, не падает. Тег, которого нет в
   `modules.yaml`, пропускается (его ловит `tags.py`, код `unknown-module`). Только stdlib + PyYAML; `scripts/atlas` не импортируется.
3. **Узел:** `DIR/.claude/rules/memory/<id, «/» → «--»>.md` для каждого id с ≥ 1 уроком и непустым `paths`. Узел строится на
   точный id: уроки `process_module/generic` не входят в узел `process_module`. Текст узла ровно такой:

   ```
   ---
   paths:
     - "multiprocess_framework/modules/router_module/**"
   ---
   generated by scripts/memory/rules.py; edit lessons, not this file; more: search.py --module router_module

   - <имя урока без .md> — <description>
   ```

   Элемент `x/` → `x/**`, точный файл — как есть, каждый в двойных кавычках. Строки уроков — по имени. UTF-8, LF, в конце
   один `\n`. Канарейка `--canary.md`: `paths: ["__canary__/never"]` в той же форме, тело — строка
   `MEMORY-RULES-CANARY — paths ignored, tell the lead`.
4. **`--write`** делает каталог равным ожидаемому: пишет изменившиеся узлы, удаляет лишние `*.md`, восстанавливает
   канарейку. Модуль с уроком и `paths: []` узла не получает (файл без `paths:` грузился бы всегда).
5. **`--check`** — одно сравнение «сгенерировать в память → сравнить каталог». Строка находки в stdout:
   `<путь от DIR>: <код>[: <значение>]`, строки отсортированы. Путь на каждый код:

   | Код | Путь | Значение |
   |---|---|---|
   | `stale`, `missing`, `orphan` | файл узла | — |
   | `dead-path` (элемент `paths` модуля с узлом не совпал ни с одним файлом `git -C DIR ls-files`) | файл узла | элемент |
   | `no-paths` (у модуля с уроком `paths: []`) | `modules.yaml` | id |
   | `node-too-big` (строк `- ` > 40) | файл узла | число строк |
   | `budget` (сумма > `BUDGET_CHARS`) | `.claude/rules/memory` | сумма |
   | `canary-missing` | `.claude/rules/memory/--canary.md` | — |

   **Определение `budget` одно:** сумма `len(text)` полного текста файлов узлов модулей (frontmatter, шапка, строки),
   без канарейки — агент получает именно эти файлы. `--check` печатает её всегда одной строкой в stderr:
   `total <сумма> chars in <N> nodes`; stdout — только находки. LF гарантирует `.gitattributes`
   (`.claude/rules/memory/*.md text eol=lf`), нормализации CRLF в `--check` нет.
6. **Вложенность:** файл в `process_module/generic/` загрузит оба узла (glob родителя срабатывает на потомке). Это иное
   правило, чем «самый длинный префикс» в `scripts/atlas/modules.py:67-79`. Цепочка вложенных узлов (например,
   `prototype/frontend/widgets/tabs/*`) при касании глубокого файла грузит их все.
7. **При `node-too-big`, по порядку:** (а) слить родственные уроки через `merged_from`; (б) обрезать description в узле до
   120 зн. (у `process_module` −36 %); (в) делить по подпапкам только после новых строк `modules.yaml` (Atlas 1.10d) и
   перетегирования уроков.

**Размеры на 2026-10-11.** Строки указателей (ревью р. 2): `process_module` 36 строк, 9 869 зн.; `logger_module` 26/6 487;
`tools/backend_ctl` 26/5 985; узлов > 40 строк — 0, > 25 — 3. Полный текст с короткой шапкой п. 3 (пересчёт менеджера
скриптом, гипотеза до 2.1): `process_module` 10 047 зн., `logger_module` 6 663, `tools/backend_ctl` 6 132; **все 54 узла —
74 369 зн.**, из них шапки 9 596. Базу закрепляет 2.1 по строке `total` из `--check`. Лимит 40, обрезка 120, `budget` —
предложения, утверждает владелец (`plan.md`, О1, О2).
