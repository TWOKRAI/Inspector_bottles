## Обзор

Сегодня урок доходит до агента, только если агент сам вспомнил и вызвал `search.py` (pull). Цель: агент (лид или
субагент) читает или правит файл модуля — и сам получает строку-указатель на каждый урок этого модуля (push через
`paths:` в `.claude/rules/`). Источник истины не меняется: `docs/claude/memory/*.md`, id урока = имя файла, адрес =
теги `module:` ⊆ id из `modules.yaml` (уроков 371, с `module:` 224, без 147; узлов 54 из 88 модулей). Слой — опыт,
откатываемый одним коммитом; польза не доказана (ревью: потолок ≈ 27 % повторов) и проверяется замером Phase 3.

## Правила исполнения

- Канон (`.claude/CLAUDE.md`, Task launch convention): стадия 0 — `reviewer` `MODE: plan` на тексте задачи → независимый
  `tester` до кода в worktree на коммите до реализации → реализация → инъекции лида (прогноз до запуска) → живой стенд →
  `reviewer` синхронно после каждой задачи. CTO — не нужен (ревью р. 1).
- Подагенты не коммитят и не пушат (кроме явного поручения лида); один писатель на дерево; staging явных путей.
- Главное дерево не переключается с `main` (там могут работать peer-сессии): ветки — только `git worktree add <путь> -b <ветка>`.
- В worktree — главный `.venv` + `PYTHONPATH=<корень worktree>`, без `uv sync`.
- Коммиты: трейлеры `Why:`/`Layer:`/`Refs:` одним блоком с `Co-Authored-By`, `Why:` одной строкой.
- Failure-recovery: 2 итерации на цикл, на третьей — эскалация `teamlead` (лимит пишется в бриф, не только здесь).

## Риски

- Любой `.md` в `.claude/rules/` без `paths:` грузится всегда — README генератора не заводится, узел без `paths` не пишется.
- Худший случай (ревью р. 1): `paths:` игнорируется → все узлы в каждой сессии, ~74k зн. (~18–28k токенов, оценка по
  знакам). Ловят канарейка (слабо: держится на внимании агента) и `budget`.
- Новый урок без `--write` даёт `stale`, шаг `validate.py` краснеет — ответ Task 2.4.
- Две сессии пишут уроки одного модуля → конфликт слияния в узле. Мера: узел руками не правится; после слияния —
  `rules.py --write` и коммит узла.
- Цепочка вложенных узлов (`prototype/frontend/widgets/tabs/*`): касание глубокого файла грузит все узлы цепочки —
  накопление больше, чем «три модуля»; меряется в 3.1.
- Имя файла канарейки начинается с `--`: в командах — только после `--` (`git add -- <путь>`).
- `scripts/memory/rules.py` и `scripts/atlas/rules.py` — одно имя в разных каталогах; импорта между ними нет, не блокирует.
