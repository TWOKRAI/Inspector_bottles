# Приёмка, написанная слепым тестером до реализации

Файлы здесь — **не тесты дерева**, а сохранённое ТЗ. Расширение `.py.txt` намеренное: ни один
сборщик и ни один обходчик дерева их не подберёт, гейт от них покраснеть не может.

Прошлый раз приёмка слепого тестера жила в worktree `D:/wt13`, worktree удалили, и **два файла из
пяти не переехали** — один из них потом закрыл настоящую дыру, когда его вернули руками. Отсюда
правило: приёмка едет в git сразу, а не «когда дойдут руки до реализации».

## Как вернуть в работу

```
cp plans/observability-closure/acceptance/test_road_cost_contract.py.txt \
   multiprocess_framework/modules/tests/test_road_cost_contract.py
```
