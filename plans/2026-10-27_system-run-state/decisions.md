  обработка, запись и робот — только в «работает» (design.md §3.4; Task 1.1 п.6, 1.2 п.4; форма — К6).
- В3. Авария во время работы: робот стоит на месте; «домой» — только по ОСТАНОВИТЬ (design.md §3.5).

- В5. Рецепт с ошибкой preflight при смене не активируется (старый остаётся); на старте — «не готов» с причиной (Task 1.6).

  автоперезапуск, флаг процесса в рецепте (Task 1.8; design.md §3.5).
- В7. Смена рецепта во время работы — только после ОСТАНОВИТЬ (Task 1.5).
- В8. «Нет диска, лента пустая» — система ждёт и только отображает; состояния машины нет, причина — индикатор
  `out_of_spec` (design.md §3.7; Task 2.2, 2.3 п.5).

## Вопрос владельцу (закрыт 2026-11-02)

- В9. Прочтение В6 «автоперезапуск»: (а) падение процесса с флагом — не авария, процесс поднимается и встаёт в работу,
  линия не стоит, пока окно `run_restart_grace_s` (30 с) не истекло; (б) авария, затем автоквитирование и авто-START
  после готовности. Рекомендация лида — (а): в (б) линия всё равно стоит, а робот стартует без оператора (против В3).
  Блокирует только Task 1.8.
  **Ответ владельца 2026-11-02: (а).** Падение процесса с флагом `run_auto_restart` — не авария; не поднялся за
  `run_restart_grace_s` или супервизор сдался — `fault`. Task 1.8 разблокирована по В9 (остальные зависимости — в задаче).

## Вопрос владельцу В10 (открыт, блокирует только п.6 Task 2.2)

- В10. Индикатор «нет диска» (В8) в 1.0 без источника: `word_layout` не отличает «нет диска» от «диск есть, предсказание
  слабое» (оба — `pred is None`, `plugin.py:416-437`). Варианты: (а) разделить причины внутри `_top_pred` (нет списка
  детекций — «нет диска»; below_threshold / confidence < min — «слабое предсказание», индикатор тот же `out_of_spec`,
  текст другой) — правка в `word_layout` (полоса С, через координатора), в 1.0; (б) один индикатор «нет диска или слабое
  предсказание» без разделения; (в) индикатор не делать в 1.0. Рекомендация лида — (а), если чтение `_top_pred` на брифе
  подтвердит, что «нет списка» = пустые детекции; иначе (б). Остальной план от ответа не зависит.
