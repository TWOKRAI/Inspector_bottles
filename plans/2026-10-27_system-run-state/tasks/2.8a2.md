## DESIGN

### 1. `multiprocess_framework/modules/state_store_module/core/leaf_copy.py` — две функции модуля

`paths_with_matched_descendants`. Текст проверен ревью стадии 0 (`scratchpad/r28/exp/inj.py`):
```python
def paths_with_matched_descendants(pairs: list[tuple[str, Any]]) -> set[str]:
    """Пути, у которых среди pairs есть потомок: тот же шаблон матчит глубже."""
    covered: set[str] = set()
    for path, _ in pairs:
        if not path:
            continue
        covered.add("")  # любой непустой путь — потомок корня
        head, sep, _ = path.rpartition(".")
        while sep and head not in covered:  # цепочка предков уже внесена целиком
            covered.add(head)
            head, sep, _ = head.rpartition(".")
    return covered
```
Корень `""` остаётся в множестве: это запас на случай инъекции И5 из 2.8 (стража `p and` нет). На вывод стора он не влияет, потому что страж отсекает `""` раньше (находка 4 ревью).

`project_leaves(pattern, leaves)` — проекция копии-листьев на шаблон:
```python
def project_leaves(pattern: str, leaves: Mapping[str, Any]) -> list[tuple[str, Any]]:
    """Проекция копии-листьев на шаблон — правило replay стора (ADR-SS-024 A1, A3)."""
    segs = split_pattern(pattern.strip("."))
    fixed = sum(1 for s in segs if s != "**")
    var = "**" in segs
    matched: dict[str, None] = {}
    for leaf in leaves:
        parts = tuple(leaf.split("."))
        lo, hi = (max(fixed, 1), len(parts)) if var else (len(segs), min(len(segs), len(parts)))
        for k in range(lo, hi + 1):
            if match_pattern(segs, parts[:k]):
                matched.setdefault(".".join(parts[:k]))
    covered = paths_with_matched_descendants([(p, None) for p in matched])
    nodes = [p for p in matched if p not in covered]
    return _assemble(nodes, leaves)
```
- `split_pattern` и `match_pattern` импортировать из `.subscription_manager`: это те же публичные алиасы, что у `core/__init__.py:22-23`. Второго матчера нет.
- Шаблон без `**`: каждый лист даёт один кандидат длины `len(segs)`, цена как сегодня (один матч на лист). С `**`: кандидаты длиной от числа не-`**` сегментов до длины листа.
- `_assemble(nodes, leaves)` — один проход по `leaves`. Лист кладётся в dict своего узла из `nodes`: узел — префикс листа по границе-точке или сам лист. Если лист — сам узел, значение кладётся как есть. Результат — список `(узел, значение)` в порядке первого появления узла в `leaves`. Лист без узла пропускается.
- Пустой узел `{}` копия не хранит (2.8a) и не отдаёт.

## TRAPS

- `match_glob` обрезает точки по краям (`glob_match.py:49-50`), поэтому `project_leaves` и `static_prefix` получают `pattern.strip(".")`. Иначе шаблон с хвостовой точкой поведёт себя иначе, чем живой путь.
- Порядок выдачи — первый лист узла в копии. На него опирается `bind()`: последнее применённое значение выигрывает.
- Шаблон `**` (без префикса) даёт `snapshot("")` — полный скан, как сегодня. Не регресс, но и не ускорение.

## Что осталось открытым / ненадёжно

- Код `project_leaves` и `_assemble` не запускал. Литералы REDS 1-5 выведены по правилу и сверены с выводами стора у ревьюера и CTO (`e4.py`, `inj.py`), а не прогоном этой функции.
- Цена проекции под `**` на 12 тыс. листьев при привязке не мерена: O(листья × глубина) на одну привязку.
- Qt-фикстура для REDS 9 не проверена по имени.
