## DESIGN

1. `DisplayDefinition.run_view: str = "always"` (`always` | `running`; ошибка без входного значения, как `plate_mode`). Зеркало: `DisplaySpec`, два конвертера, `on_duplicate`. `_load_display` прощает негодный `run_view` как `plate_*` (умолчание + WARNING без значения). DOM-004.
2. `recipe_displays.py`: `build_plate_sources` читает `run_view` через `_plate_setting`. Чистая `run_plate_text(state, run_gate, run_view, title) -> str | None`: `run_gate is False` или `run_view == "always"` -> `None`; иначе по `state`: `running` -> `None`; `fault` -> `PLATE_FAULT`; `booting`, `not_ready`, `ready`, `stopping`, `shutting_down` -> `PLATE_IDLE`; нет листа или иное -> `PLATE_NO_STATE`.
3. Константы (`{title}` — имя display):
   `PLATE_IDLE = "{title}\nЛиния не запущена: обработанный кадр появится после ЗАПУСТИТЬ"`
   `PLATE_WAIT = "{title}\nРаботает: ждём первый обработанный кадр"`
   `PLATE_FAULT = "{title}\nАвария: обработка остановлена"`
   `PLATE_NO_STATE = "{title}\nНет данных о состоянии линии"`
4. `app.py`, `_setup_bridge_callbacks(..., bindings=None)`; `None` — разреза нет.
   - До подписки: `_run = {"state": None, "run_gate": None, "mark": 0.0}`, `_fresh: dict[slot, float]`, `_run_plate: set[slot]`. Затем `bindings.bind_fanout("system.run.*", _on_run_leaf, owner=image_panel)` — после первого `_rebuild_displays`.
   - `_on_run_leaf(path, value)`: смотрит только `system.run.state` и `system.run.run_gate` (полный путь); `DELETED` -> `None`. Значение не сменилось -> выход. Вход в `running` -> `mark = time.time()` (лист `since` не берём), `_fresh.clear()`. Затем `_apply_run_view()`.
   - `_apply_run_view()` (ещё в конце `_rebuild_displays`): по слотам — текст `run_plate_text`; иначе `PLATE_WAIT`, если `state == "running"`, `run_gate is not False`, display `running` и слота нет в `_fresh`. Текст есть -> `show_no_signal(slot, текст)`, слот в `_run_plate`. Текста нет и слот в `_run_plate` -> `show_no_signal(slot, None)`, убрать. Чужие плашки не трогает.
   - `_show_taken` сразу после `_seen.add(key)`: `run_plate_text(...)` не `None` -> `False`; display `running`, `run_gate is not False`, числовой `data.capture_ts < mark` -> `False`.
   - `_on_frame_received` при показе: `_fresh[slot] = time.time()`, `_run_plate.discard(slot)`.
   - `_on_silence`: после учёта `_silent_age`, до рисования: слот в `_run_plate` -> выход.
