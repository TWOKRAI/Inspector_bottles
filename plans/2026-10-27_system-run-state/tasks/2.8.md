## TASK (Goal)

Правило ADR-SS-024 A1 (вердикт CTO, A):
- Подписчик получает пары (путь, значение) по путям, которые матчит его шаблон.
- Узел-dict приходит целиком, если шаблон не матчит его потомков; иначе приходят потомки.
- Одно правило проекции для replay и для живой записи; оно не зависит от того, писали узел через `set` или через `merge`. Известные асимметрии A4a и A4b закрываются после 1.0:
  - **A4a:** `set` словаря выше глубины шаблона живьём ничего не даёт, replay даёт совпавшие узлы (H22);
  - **A4b:** `**` в голове или в середине шаблона (`**.conn`, `a.**.b`, `n.*.*`): П2 сверяет шаблон только с изменённым потомком, а replay — со всеми (H15). В коде прототипа таких шаблонов нет.

Сегодня правило нарушено с двух сторон:
- **Replay (S1).** `state_store_manager.py:464` отбрасывает все dict. Поздний пульт не видит `system.run.last_fault`, поздние вкладки не видят `devices.state.<id>.conn` и `system.progress.boot` (`scratchpad/f/target-architecture.md` §0, §3).
- **Живая запись (П2).** `merge` даёт дельты листьев (`tree_store.py:297-321`). Узловая подписка (`devices.state.vfd1.status`, `devices.registry.*`) их не матчит. Опыт CTO на базе: 0 живых дельт и 0 в replay. Вкладка ПЧ на базе вообще не получает живой статус.

Что воспроизвёл CTO (`scratchpad/f/cto-s1-verdict.md`, `e4.py`, `e6.py`, `e7.py`):

| Сборка | Вкладка ПЧ за 4,5 с |

Правило A2: писатель выбирает форму по смыслу (`set` заменяет узел, `merge` обновляет поля) и на шаблоны подписчиков не смотрит. Особый случай `Plugins/hub/device_hub/plugin.py:654-658` (`set` для `.conn`/`.io_peek`, иначе `merge`) становится лишним. Его снятие — после 1.0.

### П2 — узловая подписка получает узел, когда меняется его потомок

5. `core/subscription_manager.py` — индекс узловых подписок по длине шаблона. Ведётся под `self._lock` в `subscribe` (:259-263), `unsubscribe` (:276-288) и `unsubscribe_all` (:299-308) через приватные `_index_node(sub)` и `_unindex_node(sub)`:
   - `self._node_literal: dict[str, dict[int, Subscription]]` — шаблоны без `*` и без `**`, ключ — сам шаблон;
   - `self._node_wild: dict[tuple[int, str], dict[int, Subscription]]` — шаблоны с `*` без `**`, ключ — (число сегментов, первый сегмент); первый сегмент может быть `"*"`;
   - `self._node_var: dict[int, Subscription]` — шаблоны с `**` не в последнем сегменте;
   - шаблон с последним сегментом `**` не индексируется: он матчит всех потомков своего узла;
   - внутренний ключ — `id(sub)`;
   - новый метод: `def node_candidates(self, nodes: list[tuple[str, ...]]) -> dict[tuple[str, ...], list[Subscription]]:`. Один захват `_lock` на пакет. Если все три словаря пусты — сразу `{}`. Для узла длины k с головой h кандидаты — `_node_literal.get(".".join(node))`, `_node_wild.get((k, h))`, `_node_wild.get((k, "*"))` и все `_node_var`; в ответ попадают только узлы с кандидатами. В тексте метода строка `out.extend(self._node_wild.get((len(node), "*"), {}).values())` (её берёт И11).
6. `manager/delta_dispatcher.py`:
   - `__init__` (:57): kwarg `node_reader: Callable[[str], Any] | None = None`, хранить в `self._node_reader`. `StateStoreManager.__init__` (:64) передаёт `node_reader=lambda p: self._store.get(p, None)`;
   - `dispatch` (:118-125): `subscriber_deltas = self._match_and_group(deltas)`, затем `node_requests = self._node_requests(deltas, subscriber_deltas)`, затем `return self._buffer_deltas(subscriber_deltas, node_requests)`;
   - новый метод (текст — источник строк для инъекций, менять только форматированием):
   ```python
   def _node_requests(
       self, deltas: list[Delta], subscriber_deltas: dict[str, list[Delta]]
   ) -> dict[str, list[tuple[str, Delta]]]:
       """П2 (ADR-SS-024 A1): узловая подписка получает узел-предок, когда меняется его потомок."""
       changed = [(tuple(d.path.split(".")), d) for d in deltas if d.path]
       triggers: dict[tuple[str, ...], list[Delta]] = {}
       for segs, d in changed:
           for n in range(1, len(segs)):
               triggers.setdefault(segs[:n], []).append(d)
       if self._node_reader is None or not triggers:
           return {}
       cands = self._subs.node_candidates(list(triggers))
       if not cands:
           return {}
       direct = {(name, d.path) for name, ds in subscriber_deltas.items() for d in ds}
       got: dict[int, list[tuple[str, ...]]] = {}
       sent: set[tuple[str, str]] = set()
       requests: dict[str, list[tuple[str, Delta]]] = {}
       for anc, ds in sorted(triggers.items(), key=lambda kv: -len(kv[0])):
           path = ".".join(anc)
           for sub in cands.get(anc, ()):
               segs = _split_pattern(sub.pattern)
               if not _match_pattern(segs, anc):
                   continue
               live = [d for d in ds if not (sub.exclude_sources and d.source in sub.exclude_sources)]
               if not live:
                   continue
               mine = got.setdefault(id(sub), [c for c, _ in changed if _match_pattern(segs, c)])
               if any(g[: len(anc)] == anc for g in mine):
                   continue
               mine.append(anc)
               key = (sub.subscriber, path)
               if key in sent or key in direct:
                   continue
               sent.add(key)
               requests.setdefault(sub.subscriber, []).append((path, live[-1]))
       return requests
   ```
   - `_buffer_deltas(self, subscriber_deltas, node_requests: dict[str, list[tuple[str, Delta]]] | None = None)` (:173). Под `self._buffer_lock`, ДО цикла по подписчикам:
     - каждый путь из `node_requests` прочитать один раз через `self._node_reader(path)`; копия общая для всех подписчиков пакета, её никто не мутирует;
     - если значение — `dict`, дописать в конец `subscriber_deltas[sub]` (создать список, если нет) `Delta(path=path, old_value=MISSING, new_value=value, source=trigger.source, revision=trigger.revision)`;
     - не dict (узел удалён) — пропустить;
     - `stats` считает и узловые дельты.
   - **Почему чтение под `_buffer_lock`:** порядок в буфере равен порядку чтений, и каждое чтение — текущее состояние. Значит, последний узел у подписчика — самый свежий даже при двух потоках-мутаторах. Порядок локов: `_buffer_lock` -> RLock стора. Обратного пути нет (Факты).
   - `_split_pattern`, `_match_pattern` импортировать из `..core.subscription_manager` рядом с `SubscriptionManager`.
