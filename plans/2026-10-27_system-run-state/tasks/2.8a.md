## DESIGN

### 1. Новый модуль `multiprocess_framework/modules/state_store_module/core/leaf_copy.py`

`class LeafCopy(MutableMapping[str, Any])`. Это плоская копия «путь листа -> значение» плюс индекс детей.
- `self._data: dict[str, Any]` — листья в порядке вставки.
- `self._kids: dict[str, set[str]]` — путь узла -> ПОЛНЫЕ пути прямых детей; корень — ключ `""`.
- `__getitem__`, `__iter__`, `__len__`, `__contains__`, а также `get`, `keys`, `items`, `values` делегируют в `self._data` напрямую. Миксины `Mapping` не используются: `get` на горячем пути не должен идти через `KeyError`.
- `__setitem__(path, value)` — СЫРАЯ запись одного листа: значение кладётся как есть, dict не разворачивается. Если пути нет, он связывается в `_kids` вверх до первого уже связанного предка. Нужна существующим писателям `self._cache[path] = value` (`state_proxy.py:1244` — ресинк, там dict уже отфильтрован), чтобы индекс не разъехался с данными.
- `__delitem__(path)` — удалить лист и снять связи вверх, пока узел пуст.
- `put(path, value) -> tuple[list[str], list[str]]` — СМЫСЛОВАЯ запись дельты, возвращает `(written, removed)`:
  ```python
  def put(self, path: str, value: Any) -> tuple[list[str], list[str]]:
      """Дельта заменяет поддерево: dict -> его листья, {} -> пусто, скаляр -> один лист."""
      new = _flatten(path, value)
      keep = {p for p, _ in new}
      removed = [p for p in self._leaves_under(path) if p not in keep]
      for p in removed:
          del self[p]
      head, sep, _ = path.rpartition(".")
      while sep:
          if head in self._data:
              del self[head]
              removed.append(head)
          head, sep, _ = head.rpartition(".")
      for p, v in new:
          self[p] = v
      return [p for p, _ in new], removed
  ```
  Листья, которые есть и в старом, и в новом поддереве, НЕ удаляются: они сохраняют позицию в порядке вставки, а в read-model — кольцо истории.
- `drop(path) -> list[str]` — снять путь и всё поддерево, вернуть снятые листья: `gone = self._leaves_under(path)`, затем `del self[p]` для каждого.
- `_leaves_under(path) -> list[str]` — обход по индексу, цена — размер поддерева, а не размер копии:
  ```python
  def _leaves_under(self, path: str) -> list[str]:
      out = [path] if path in self._data else []
      stack = list(self._kids.get(path, ()))
      while stack:
          node = stack.pop()
          if node in self._data:
              out.append(node)
          stack.extend(self._kids.get(node, ()))
      return out
  ```
- `_flatten(path, value) -> list[tuple[str, Any]]` (функция модуля): непустой dict раскрывается рекурсивно в порядке ключей, `{}` даёт `[]`, иначе `[(path, value)]`. Семантика та же, что у `StateProxy._expand_leaf_paths` (`state_proxy.py:1182-1197`).
- `LeafCopy` не потокобезопасна, как и `dict` до неё. Лок держит вызывающий: `_cache_lock` у стока (`plugin.py:86`), `_telemetry_lock` у `backend_ctl` (`driver.py:2070`).
