2. **`parse_policy`** — якорь:
   ```python
   def parse_policy(raw: object) -> ReadinessPolicy | str:
       if raw is None:
           return ReadinessPolicy()
       if not isinstance(raw, dict):
           return f"ожидался словарь, получен {type(raw).__name__}"
       unknown = [k for k in raw if k not in ("hold_s", "severity")]
       if unknown:
           return f"неизвестный ключ {unknown[0]!r:.40}"
       hold_s = raw.get("hold_s", 0.0)
       if isinstance(hold_s, bool) or not isinstance(hold_s, (int, float)):
           return f"hold_s: ожидалось число, получен {type(hold_s).__name__}"
       if hold_s < 0 or hold_s > HOLD_MAX_S or not math.isfinite(hold_s):
           return f"hold_s вне [0, {HOLD_MAX_S}]"
       severity = raw.get("severity", {})
       if not isinstance(severity, dict):
           return f"severity: ожидался словарь, получен {type(severity).__name__}"
       scale = READINESS_SEVERITIES
       remap: list[tuple[str, str]] = []
       for k, v in severity.items():
           if k not in scale or v not in scale:
               return f"severity: пара {k!r:.40} -> {v!r:.40} вне шкалы"
           remap.append((scale[scale.index(k)], scale[scale.index(v)]))
       return ReadinessPolicy(hold_s=float(hold_s), remap=tuple(remap))
   ```
   Все строки якорей п.2–3 и п.6 — не длиннее 120 символов (`pyproject.toml:388` `line-length = 120`): `ruff format` их не переносит, замены инъекций остаются однострочными.
   Порядок проверки `hold_s` — границы ДО `math.isfinite`: `math.isfinite(10**400)` бросает `OverflowError`, сравнение `10**400 > 10.0` — нет. Опечатка ключа (`hold`) — отказ, а не молча выключенная политика. Пустой `hold_s:` в YAML (`None`) — отказ. Нормализация пар литералами шкалы — как `_canonical_items:570` (подкласс `str` из рецепта не уходит через границу).
3. **`apply_policy`** (часы снаружи, без IO, вход не мутирует) — якорь:
   ```python
   def apply_policy(items, policy, memory, now):
       remap = dict(policy.remap)
       mapped = [(remap.get(s, s), r) for s, r in items]
       if memory.seen_at is not None and now - memory.seen_at > OBSERVATION_GAP_MAX_S:
           memory = NEVER_CLEAN
       if not any(s in READINESS_BLOCKING_SEVERITIES for s, _ in mapped):
           kept = memory.clean_since is not None and memory.held_since is None
           return mapped, NodeMemory(clean_since=memory.clean_since if kept else now, seen_at=now)
       held = [("out_of_spec" if s in READINESS_BLOCKING_SEVERITIES else s, r) for s, r in mapped]
       if policy.hold_s > 0 and memory.held_since is not None and now - memory.held_since < policy.hold_s:
           return held, NodeMemory(clean_since=memory.clean_since, held_since=memory.held_since, seen_at=now)
       armed = memory.clean_since is not None and now - memory.clean_since >= policy.hold_s
       if policy.hold_s > 0 and memory.held_since is None and armed:
           return held, NodeMemory(clean_since=memory.clean_since, held_since=now, seen_at=now)
       return mapped, NodeMemory(seen_at=now)
   ```
   `remap` — кортеж пар, словарь строится один раз за вызов. Сначала переназначение, потом удержание: переназначенная в блокирующую причина удерживается так же, как своя. Текст причины не меняется, меняется только степень. Последняя строка («иначе»): узел в потере, окна нет (boot, окно истекло, `hold_s == 0`) -> история чистоты обнулена, отсчёт «чист» начнётся со следующего чистого вызова; без этого истёкшее окно взводилось бы снова тем же старым `clean_since`.
4. **Правило «был чист»** = в точках наблюдения собственные причины плагина без блокирующих, от первого чистого вызова до текущего — не меньше `hold_s`, и соседние вызовы отстоят не больше `OBSERVATION_GAP_MAX_S`. Разрыв больше (поток снимка висел, плагин был вне `RUNNING/PAUSED`) -> память `NEVER_CLEAN`: «чист» между наблюдениями не выводится. Узел, ни разу не бывший чистым (boot), не удерживается: **на boot** гейт START не слабеет. В открытом окне причина — `out_of_spec`, START **разрешён** (риск п.9). Возврат в чистое внутри окна закрывает окно; следующая потеря удерживается, только если узел снова был чист `hold_s`. Мигание с чистой фазой короче `hold_s` не прячется (RED 3).

Одна точка, через которую проходят все плагины, сразу после приведения формы: `ready` ребёнка, подпись push 3.3, `evaluate` в PM и пульт видят одну степень — PM и GUI не правятся. Чистая функция с часами снаружи проверяется без процессов (принцип 5).
