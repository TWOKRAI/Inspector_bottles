# Task 2.13: во время рисования ПЧ не принимает пуск и смену частоты (C-125)

- **Статус:** [PENDING] · **Level:** Middle · developer (Sonnet)
- **Goal:** пока робот-носитель в режиме DRAW, команда пуска или смены частоты не уходит в ПЧ и оператор видит причину; «Стоп» проходит всегда; пределы частоты вкладки берутся из рецепта.
- **Ветка:** `fix/vfd-draw-lock` от `main` `6aa7d0dad` · **Layer:** mixed (Services + prototype) · **Contract:** impl-only
- Решение владельца 2026-11-27: «чини сейчас».

## Факты (`main` `6aa7d0dad`)

- Режим DRAW есть только у `RobotDriver` (`mode`, `robot_driver.py:167`, `:443-444`, `:233-235`). У `RobotDriverV2` ключа `mode` нет; рецепты букв 1.0 (`delta_v2`) в DRAW не переходят.
- Во время DRAW прошивка не обслуживает команды ПЧ (шапка `vfd_driver.py`). Драйвер при этом пропускает только фоновый опрос; `run` и `set_freq` пишет.
- Вкладка ПЧ ждёт `carrier.mode` и `protocol_meta.cmd_freq` (`vfd/controller.py:234-250`); `DeviceManager.describe` их не отдаёт. Диапазон частоты, который драйвер проверяет: `entry.params.freq_min_hz` / `freq_max_hz` (`vfd_comm/core/client.py:177`, умолчания 0 / 50).
- `VfdWidget.set_controls_enabled(False)` гасит и «Стоп» (`vfd/widget.py:144-148`).
- `controller._on_run` / `_on_set_freq` ответ команды не читают.

## DESIGN

1. `Services/device_hub/drivers/vfd_driver.py`: до обработчика, для `run` и `set_freq`, если носитель (`transport.type == "bridge"`) в `mode == "draw"` — вернуть `{"status": "error", "message": ...}` с причиной и словом «DRAW». В транспорт ПЧ ничего не пишется, счётчик ошибок устройства не растёт. `busy` носителя (движение, доставка задания) команды не блокирует. `stop`, `reset_fault`, `get_status` проходят.
2. `vfd/controller.py`: `_on_run` и `_on_set_freq` получают ответ; отказ (`status` не `ok` или `success is False`) — его `message` в строке статуса вкладки (нет `message` — общий текст отказа). Ответ по устройству, которое уже не выбрано, не показывается.
3. `vfd/controller.py`: диапазон частоты — `protocol_meta.cmd_freq`, если он есть, иначе `entry.params.freq_min_hz` / `freq_max_hz`, иначе 0 / 50.
4. `vfd/widget.py`: `set_controls_enabled` не трогает «Стоп»; он доступен всегда.

`describe` поле `carrier` не получает: это снимок на момент выбора устройства, кнопка осталась бы выключенной после конца рисования. Замок стоит в драйвере.
