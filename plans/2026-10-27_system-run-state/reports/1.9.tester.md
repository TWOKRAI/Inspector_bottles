## ВОПРОС ЛИДУ

1. **DESIGN п.3 не выполняется как «проверить, что дорога уже ставит тег».** `inspection_status = "not_inspected"` ставит только `PluginOperationStep.execute` в ветке `except` (исключение плагина) — `generic/plugin_operation_step.py`. Bypass по `enabled == False` и по PAUSED тега не получает: раннер просто возвращает `items`, а `PipelineExecutor` тег на bypass не ставит. Выходит, п.3 = «тега нет — stop and ask». Тест `test_paused_bypass_marks_not_inspected` требует тег и после реализации п.1 останется красным (подтверждено заглушкой). Решить: (а) тег ставит `plugin_runner.py` в PAUSED-ветке (единственный файл FILES; рядом с мутацией in-place, `outputs is items` сохраняется) — тест это принимает; (б) расширить FILES на `plugin_operation_step.py`/`pipeline_executor.py`; (в) тег не нужен — тогда тест удалить. Я выбрал для тестового контракта (а)/(б) нейтрально: проверка идёт через `PipelineExecutor._execute_chain`, любое место постановки пройдёт.
2. Побочный вопрос того же происхождения: если тег ставится в раннере только для PAUSED, у bypass по `enabled == False` его по-прежнему нет — ожидаемо ли такое расхождение. Тестов на `enabled == False` я не писал (это существующее поведение).
3. Допущение: PAUSED задаётся присваиванием `plugin.state = PluginState.PAUSED`, раннер читает `plugin.state` (в DESIGN сказано `plugin.state == PluginState.PAUSED`). Объекты без атрибута `state` (старые двойники в test_plugin_runner.py) не должны падать — реализация обязана читать через `getattr(plugin, "state", None)`; моим тестом это не закреплено, но существующие test_plugin_runner*.py покажут на GREEN.
4. Допущение: `outputs is items` обязательно (ACCEPTANCE: «outputs is items») — тест требует тождество списка, не равенство.
5. Допущение: bypass по PAUSED не считается фейлом и не трогает breaker (`is_bypassed` остаётся False). В DESIGN прямо не сказано; следует из «как при enabled == False» + того, что `PluginOperationStep` после `call_process` зовёт `_on_success` (сбрасывает счётчик). Если лид хочет иного — тест `..._breaker_untouched` ослабить.
6. Допущение: `plugin_ms()` не копит EMA на bypass по PAUSED (docstring `plugin_ms` обещает это для bypass `enabled=False`).
7. REDS называет 4 теста, я добавил 5 сверх списка (resumed, hooks, ports, plugin_ms, executor+breaker). Лимит ≤ 10 соблюдён (всего 9); при желании лишние снять.
