### Task 3.1a — Контракт слоя: трансформ и аугментация (часть Task 3.1)

**Это не отдельная задача, а вторая половина спеки 3.1** — вынесена под свой заголовок
из-за размера. Тот же исполнитель (teamlead), тот же коммит-ряд, **один заход тестера на
обе половины** (правило «тестер один раз на механизм»).

**Goal:** режим `augmented` перестаёт быть пустым значением `Literal`: слой имеет положение
относительно объекта и диапазоны вариации, выборка детерминирована и делается один раз.

**Поля (в `interfaces.py`, рядом с `LayerSpec`):**
- `LayerSpec`: `name: str`, `mode`, `sprite_source`, `offset_px: tuple[float, float] =
  (0, 0)` (от центра объекта), `angle_deg: float = 0.0` (относительно объекта),
  `scale: float = 1.0`, `augment: LayerAugment | None = None` (только для `augmented`).
- `LayerAugment` — четыре диапазона `(lo, hi)`, дефолт каждого вырожден в «нет вариации»:
  `offset_x_px`, `offset_y_px`, `angle_deg` — `(0, 0)`; `scale` — `(1, 1)`;
  `hue_shift_deg` — `(0, 0)`. Значение добавляется к базовому трансформу слоя
  (`scale` — умножается).
- `ScenePreset.to_dict()` / `to_yaml(path)` — обратная сторона уже запланированных
  `from_dict` / `from_yaml`. Нужна редактору: он пресет **пишет**.

**Steps:**
1. Выборка параметров аугментации и розыгрыш дефекта — **один раз, при создании объекта**,
   из переданного `rng`; результат хранится в объекте. `render()` после этого случайности
   не потребляет. Причина: сцена рендерит каждый активный объект на каждом кадре, выборка
   внутри `render(rng)` дала бы дрожание этикетки от кадра к кадру. Сигнатуру
   `render(rng)` из Files Task 3.1 пересмотреть под это свойство.
2. Рендер слоя: спрайт → `scale` → `rotate_expand` → сдвиг оттенка (HSV по RGB-каналам,
   альфа не трогается) → `composite` на канву объекта со смещением. Канва объекта
   **расширяется** под слой, выехавший за базу, а не обрезает его.
3. Выбранные значения попадают в паспорт (`layer_params: dict[str, dict]`) — симулятор
   собирал объект сам и обязан знать, насколько сдвинута этикетка (задел для Ф5).

**Acceptance criteria** (только границы, литералы — не значения из кода под тестом):
- [ ] Слой `augmented` со всеми дефолтными (вырожденными) диапазонами рендерится
      **побитово** так же, как тот же слой в режиме `static`.
- [ ] Статический слой с `offset_px=(20, 0)`: центроид альфы этого слоя на **20 ± 1 px**
      правее, чем при `offset_px=(0, 0)`.
- [ ] Слой `augmented` с `offset_x_px=(10, 10)` (диапазон-точка): центроид на **10 ± 1 px**
      правее варианта с `(0, 0)` — аугментация реально применяется, не игнорируется.
- [ ] Один и тот же объект, отрендеренный дважды, — побитово идентичен (нет дрожания
      между кадрами).
- [ ] Диапазон `angle_deg=(-30, 30)`: объекты, созданные с `seed=1` и `seed=2`, дают
      разные рендеры; два объекта с `seed=1` — побитово одинаковые.
- [ ] `hue_shift_deg=(90, 90)` меняет RGB-каналы непрозрачных пикселей и **не меняет**
      альфа-канал (сравнение альфы побитовое).
- [ ] Диапазон с `lo > hi` — ошибка валидации при загрузке пресета, с именем слоя и поля
      в тексте, а не `ValueError` из недр `rng.uniform`.
- [ ] `ScenePreset.from_dict(p.to_dict()) == p` для пресета с тремя слоями трёх режимов.
- [ ] `layer_params` в паспорте содержит фактически выбранные значения: для
      диапазона-точки `(10, 10)` там `10.0`.

**Дополнено 2026-09-22 (решение владельца: ред. 3 + три пункта из входа ред. 4, ветка
`docs/line-sim-red4-input`).** Единицы остаются пикселями (`offset_px`); миллиметры и YAML с
сохранением комментариев (`ruamel`) — вместе с редактором Ф7, не здесь.
- [ ] **Направление поворота — литералом:** несимметричный спрайт (метка справа от центра) при
      `angle_deg=+90` у объекта даёт метку **сверху** (CCW, ось Y вниз как в OpenCV, конвенция
      `dataset_gen.core.compose.rotate_expand`). Ожидаемая позиция пикселя — литерал в тесте, не
      вывод `rotate_expand`. Конвенция записана в докстринге `LayerSpec` и абзацем в `README.md`.
- [ ] **Рендер один раз:** объект рендерится при создании и кэшируется как RGBA; повторный
      `render()` возвращает тот же массив без повторной компоновки слоёв (проверяется по
      наблюдаемому эффекту — число вызовов загрузки/компоновки спрайта, а не по имени метода).
- [ ] **Round-trip:** `ScenePreset.from_dict(p.to_dict()) == p` (уже выше) плюс
      `from_yaml(to_yaml(p)) == p` через файл во временном каталоге.

**Out of scope:** эффект налива (`fill_level` из исторического `LayerImage`) — приходит
вместе с пресетом бутылки в плане редактора, добавляется необязательным полем и контракт
не ломает; яркость/контраст/блик слоя — это фотометрия сцены (Ф4.3), не слой.
**Edge cases:** `augment` задан у слоя не в режиме `augmented` — ошибка валидации (тихо
проигнорированный диапазон хуже отказа); слой, целиком выехавший за канву после сдвига, —
объект всё равно рендерится, Post «альфа не пуста» проверяется по объекту, не по слою.
**Dependencies:** входит в Task 3.1.
