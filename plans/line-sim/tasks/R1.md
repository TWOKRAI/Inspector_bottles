### Спавнер и буква → класс

3. **Список в спавнере** (`Services/line_sim/core/spawner.py`, без нового модуля). Новые публичные имена — импорт
   из `Services.line_sim.core.spawner` (так плагин уже берёт `validate_flow`); в `Services.line_sim.core.__init__` и
   `Services.line_sim.__init__` **сознательно не экспортируются** (как `validate_flow`, README строка 31).
   - `SEQUENCE_MIN_INTERVAL_S = 1.0` — константа, не ключ конфига (решение 1.0: `state` word_layout ≤ 1 раз в 1 с,
     `design.md` §2.9).
   - `SEQUENCE_MAX_LEN = 200` — длина списка; причина — `max_active=200` спавнера по умолчанию (список длиннее на
     стоящей ленте упёрся бы в потолок).
   - `class SequenceBusy(Exception)` с атрибутом `remaining: int`.
   - `class SequenceHead(NamedTuple)`: `mode: str` (`"random"` | `"list"`), `generation: int`, `pos: int | None`,
     `letter: str | None`, `angle_deg: float | None`. У `"random"` и у исчерпанного/пустого `"list"` три последних — `None`.
   - `class DiscSequence` — ЕДИНСТВЕННОЕ место, которое трогают оба потока. Состояние (всё под одним `threading.Lock`
     `self._lock`): `_mode` (старт `"random"`), `_generation: int` (старт 0), `_items: list[tuple[str, float]]`, `_pos`
     (индекс головы), `_fed`, `_skipped`. `remaining = len(_items) - _pos`. Методы — каждый ОДНА критическая секция:
     - `next() -> SequenceHead` — снимок `(mode, generation, pos, letter, angle)` головы одним захватом лока. Воркер
       зовёт его **один раз за `tick()`**; отдельных `peek()` и `snapshot()["mode"]` в спавнере нет (TOCTOU).
     - `pop(generation: int) -> bool` — если `generation != _generation` или `_mode != "list"` или `remaining == 0` —
       вернуть `False`, ничего не менять; иначе `_pos += 1`, `_fed += 1`, `True`.
     - `skip(generation: int) -> bool` — то же, но `_skipped += 1`.
     - `load(discs: list[tuple[str, float]], *, replace: bool) -> int` — `remaining` считает приватный
       `self._remaining_locked()` (зовётся только под локом; это шов для теста H2). Если `_mode == "list"`,
       `remaining > 0` и `replace is False` — `raise SequenceBusy(remaining)`, ничего не меняется. Иначе
       `dropped = remaining if _mode == "list" else 0`; `_items = list(discs)`, `_pos = _fed = _skipped = 0`,
       `_mode = "list"`, `_generation += 1`; вернуть `dropped`. Проверка и замена — внутри ОДНОГО `with self._lock`.
     - `set_random() -> int` — `dropped = remaining` (0, если уже `"random"`); `_mode = "random"`, `_items = []`,
       `_pos = _fed = _skipped = 0`, `_generation += 1`; вернуть `dropped`. После него `snapshot()` равен начальному.
     - `snapshot() -> dict` — `{"mode", "total": len(_items), "fed", "skipped", "remaining"}` (JSON-типы).
   - `ObjectSpawner.__init__(..., sequence: DiscSequence | None = None)`.
   - **`tick()` после деспавна:** `head = self._sequence.next() if self._sequence is not None else None`. `head is None`
     или `head.mode == "random"` — прежний код байт в байт (тесты `test_spawner.py`, `test_hazards_3_3.py`, отпечатки
     `test_hazards_1_3h_layout.py` — зелёные). Иначе `_tick_list(head, now_encoder, now_wall_s, rng)`:
     1. `head.letter is None` (список пуст/исчерпан) → `return`; порог не тратится.
     2. Режим `interval_s` и `_deadline is None` → взвести срок, как сейчас, `return`.
     3. Пауза, `len(active) >= max_active`, `_last_spawn_wall_s is not None and now_wall_s - _last_spawn_wall_s <
        SEQUENCE_MIN_INTERVAL_S`, порог потока не достигнут (срок не наступил / пройдено меньше `_next_spacing_mm`;
        ветки разрыва счётчика и `_next_spacing_mm is None` — как в `_tick_spacing`; разрыв счётчика проверяется до
        паузы, как в `_tick_spacing`) → `return`; порог НЕ тратится:
        пришедший позже список спавнит первый диск сразу, как только прошла 1 с и порог выполнен.
     4. Сдвинуть порог, как сейчас (F1 — до `make`).
     5. `head.letter not in factory.class_names` → `self._sequence.skip(head.generation)`, затем
        `raise ValueError("список дисков: буквы нет в каталоге фабрики")` — `produce()` поймает и дедуплицирует
        (`_warn_factory_error`); объект не создан.
     6. `forced_before = factory.force_defect_pending`; `obj = self._make(object_id, now_encoder, rng,
        class_index=factory.class_names.index(head.letter), angle_deg=head.angle_deg)`. Исключение фабрики летит
        наружу, голова НЕ снята (транзитный сбой не теряет диск; следующая попытка — на следующем пороге).
     7. `if not self._sequence.pop(head.generation)`: команда сменила список, пока шёл `make` → объект ВЫБРОСИТЬ: не в
        `active`, `_last_spawn_wall_s` и `_next_id_n` не меняются; если `forced_before` — `factory.force_defect_next()`
        (нажатие оператора не съедено выброшенным объектом); `return`. Порог остаётся сдвинутым (шаг 4) — это
        допустимо: первый диск нового списка ждёт один порог.
     8. Успех: `active.append(obj)`, `_last_spawn_wall_s = now_wall_s`, `_next_id_n += 1`.
   - `_last_spawn_wall_s` пишется при КАЖДОМ спавне (и случайном): первый диск списка после случайного — тоже ≥ 1 с.

### Команда `scene.sequence`

5. **Команда `scene.sequence`** (`Plugins/sim/scene_source/plugin.py`, новая строка таблицы `commands` →
   `cmd_sequence`; процесс стенда — `camera`). В `configure()` плагин создаёт `self._sequence = DiscSequence()` и
   передаёт в `ObjectSpawner(..., sequence=self._sequence)`; движок не собран — `self._sequence = None`.
   Формы запроса — множество ключей `data` ровно одно из трёх:
   - `{"discs"}`: `{"discs": [[буква, угол], …]}` — загрузить список, если текущий исчерпан;
   - `{"discs", "replace"}`: `… "replace": true|false` — `true` заменяет текущий (остаток выброшен);
   - `{"random"}`: `{"random": true}` — выйти из режима списка, остаток выброшен, спавн снова случайный.
   Любой другой набор ключей (лишний ключ, `{"random": true, "replace": …}`, `{"discs", "random"}`, `{}`) — `invalid`.
   **Порядок проверок** (первая сработавшая отвечает; ничего не меняется до шага 5):
   1. Структура запроса: `data` — `dict`, набор ключей, `replace` — `bool`, `random` — ровно `True`.
   2. `discs` — `list`, не пустой, длина ≤ `SEQUENCE_MAX_LEN`.
   3. Форма КАЖДОГО элемента по порядку; первый плохой → `invalid` + `"index"`. Элемент хорош, если: `list`/`tuple`
      длины 2; `[0]` — `str` (`isinstance`, нехешируемое значение — дефект формы, дедупликация до него не доходит);
      `[1]` — `int | float`, не `bool`; `float([1])` не бросает (`OverflowError` на `10**400` ловится → дефект);
      конечное (`math.isfinite`; NaN, inf, -inf — дефект); `0 <= угол < 360`. `-0.0` нормализуется `угол + 0.0` → `+0.0`
      (как `lateral_px`). **Форма раньше букв:** запрос и с дефектом формы, и с неизвестной буквой → `invalid` +
      `index`, без `unknown`.
   4. Движок не собран (`self._spawner is None`) → `{"status": "ok", "applied": false}` (как у ручек 6.1).
   5. Буквы против `self._live_factory.class_names` (чтение списка, без лока), сравнение строк точное, без
      нормализации Юникода и регистра. Пресет без каталога (`class_names == []`) → любая буква неизвестна.
   6. `self._sequence.load(...)` / `set_random()`; `SequenceBusy` → `busy`.
   | Случай | Ответ (литерал) |
   |---|---|
   | шаги 1–2 | `{"status": "error", "code": "invalid", "message": "scene.sequence: …"}`; пустой — `message` содержит `пустой список дисков` |
   | шаг 3 | `{"status": "error", "code": "invalid", "index": i, "message": "scene.sequence: диск i — ожидалась пара [буква, угол], 0 <= угол < 360"}` |
   | шаг 5 | `{"status": "error", "code": "invalid", "unknown": [<буквы>], "message": "scene.sequence: букв нет в каталоге: <число>"}` — `unknown` без повторов, в порядке первого появления |
   | шаг 6, список не исчерпан, `replace` не `true` | `{"status": "error", "code": "busy", "remaining": N, "message": "scene.sequence: подаётся список, осталось N"}` |
   | принят | `{"status": "ok", "queued": len(discs), "dropped": k}` |
   | `random` принят | `{"status": "ok", "mode": "random", "dropped": k}` |
   `message` не повторяет входные значения (только позицию и счёт), как `_check_class_index`.
   **`scene.status`** — новый ключ `"sequence"`: `self._sequence.snapshot()`; движок не собран — `{"mode": "random",
   "total": 0, "fed": 0, "skipped": 0, "remaining": 0}`. Остальные ключи ответа не меняются.
   **После исчерпания** — режим остаётся `"list"`, `remaining 0`, спавн СТОИТ до следующего `scene.sequence` или
   `{"random": true}`. Возврат к случайным сам по себе — нет (иначе в журнал α попадут случайные буквы).

### Опасности для автора

HAZARDS (for the author — each one is a test in FILES 6):

- **H1 Гонка `next → make → pop` с командой.** (а) Детерминированно, без потоков: `head = seq.next()`;
  `seq.load(new, replace=True)`; `seq.pop(head.generation) is False`; `snapshot()` — `fed 0`, `remaining == len(new)`;
  `seq.next().letter == new[0][0]` (голова нового списка цела). (б) На спавнере: фабрика-заглушка, чей `make` сам
  зовёт `seq.load(new, replace=True)` (команда пришла посреди сборки) → после `tick()` в `active` нового объекта нет,
  `_next_id_n` не сдвинут (следующий объект получает тот же `object_id`); следующий успешный спавн — `new[0]`; взведённый
  до этого `force_defect_next` достаётся ему. (в) Нагрузочно: поток команд 200 раз `load(replace=True)`, воркер тикает;
  держит ТОЛЬКО инвариант `fed + skipped + remaining == total` в каждом `snapshot()`. Диск, чей `pop(gen)` прошёл до
  `load` N, вправе появиться после ответа на `load` N: буква сверяется с поколением на момент `pop`, а не со временем
  ответа; «чужие буквы после replace» проверяются детерминированно в (а) и (б), не в (в). Потоки — daemon с
  `join(timeout)`. Break-injection лида: `pop` без проверки поколения → (а) и (б) красные.
- **H2 Две команды без `replace` на исчерпанном списке.** Синхронизация — В КРИТИЧЕСКОЙ ТОЧКЕ, не на входе в метод
  (урок `feedback_barrier_at_entry_does_not_reproduce_the_race.md`): шов — `release()` лока. Тест подменяет
  `DiscSequence._lock` обёрткой, у которой `acquire`/`__enter__` — как у настоящего лока, а `release()`/`__exit__` =
  «отпустить, затем `threading.Barrier(2, timeout=0.5).wait()`» с перехватом `BrokenBarrierError`. Два потока зовут
  `load(..., replace=False)`. Верная реализация (один `with`): один `ok`, второй `SequenceBusy`. При двух `with`
  (проверка и замена раздельно) оба потока отпускают первый лок, встречаются на барьере, входят во второй `with` →
  две `ok` → красный. Предсказание break-injection лида: «проверка и замена в двух `with`» → красный набор = H2;
  «`remaining` вне лока» → красный набор = H2. (Барьер на `_remaining_locked()` эту инъекцию НЕ ловит — модель
  ревьюера 0/15; так не писать.)
- **H3 Повторная команда в середине списка** — A7/A8; плюс `{"random": true}` в середине → `dropped` = остаток,
  следующий объект — случайный.
- **H4 Перезапуск процесса.** Список живёт только в памяти: новый `configure()` → `sequence.mode == "random"`, total 0.
  Это контракт (README), не дефект: скрипт после рестарта шлёт список заново.
- **H5 `force_defect_next` / `scene.defect_now`.** Нажатие в режиме списка → следующий диск СПИСКА получает
  `defect == "damaged"`, буква и угол — его; нажатие на паузе не теряется (как 6.1). `defect_probability` пресета
  действует и на диски списка (DESIGN 7 — скрипт ставит 0).
- **H6 Сбой фабрики на диске списка.** Фабрика бросает на первом `make` → голова не снята, `fed` 0; следующий успех
  даёт ту же букву.
- **H7 Буква пропала из каталога** (`preset.commit` сменил каталог) → `skipped += 1`, объект не создан, следующая буква
  идёт своим чередом; кадр не падает.
- **H8 Потолок 1 с на быстрой ленте.** `spacing_mm [10, 10]` и энкодер, едущий 500 мм/с → зазор по `now_wall_s` между
  дисками списка ≥ 1,0 с; при этом порог шага не копит долг (второй диск — через 1 с, не «сразу пачкой»).
- **H9 `max_active`.** Список из 300 букв при `max_active` 200 → `invalid` по длине (> 200); список 200 на стоящей
  ленте `interval_s` — объекты копятся до потолка, не больше.
- **H10 Случайный режим не тронут:** тот же seed без `sequence` и с `DiscSequence()` в режиме `"random"` дают
  побайтно одинаковые паспорта первых 20 объектов.
- **H11 Без движка и без каталога** (`test_no_engine_and_no_catalog`, строка 10 REDS). Плагин без движка:
  `scene.sequence` с валидным `discs` → `{"status": "ok", "applied": false}`; `{}` → `invalid` (структура раньше
  `applied`); `scene.status.sequence == {"mode": "random", "total": 0, "fed": 0, "skipped": 0, "remaining": 0}`.
  Пресет без `catalog_dir`: любая буква → `invalid` с `unknown`.
