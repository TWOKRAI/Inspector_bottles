# ID3013 через обычный MVS SDK (GenICam) — снято 2026-09-29

Вывод: **управлять прибором с ПК можно, получить кадр — нет.** Настройки из
прототипа (экспозиция, усиление, триггер) — реальны; снимок — только FTP или
`MvCodeReader` SDK. Настройка прибора целиком — [`SETUP.md`](SETUP.md).

Зонды на `MvCamera` из `Services/hikvision_camera/sdk`, без правок биндингов.

- `MV_CC_OpenDevice(Exclusive)` → `0x0`, пока прибор не держит IDMVS (иначе
  `0x80000203`, ACCESS_DENIED — прибор у IDMVS не отнимается). Доступ эксклюзивный.
- Читается: `DeviceFirmwareVersion = V4.0.2.C 251201,25111900,00`, 1280×1024
  `Mono8`, `PayloadSize = 2195624`, `ExposureTime = 880`, `Gain = 0`, авто — выкл,
  `AcquisitionFrameRate = 60`, `TriggerMode = 1`, `TriggerSource = 0` (Line0);
  `TriggerSource` поддерживает `[7, 0, 1, 2, 4, 5, 6, 8, 9, 10, 12, 15]`.
  Узлов `GevSCPSPacketSize`, `AcquisitionMode` нет.
- **Пишется и запускает съёмку:** `TriggerSource → 7 (Software)`, три
  `TriggerSoftware`, затем `TriggerMode → 0` на 3 с — у прибора видно **3 одиночные
  вспышки и 3 с подсветки** (владелец, повторный прогон). Значения возвращены и перечитаны.
- **Параметры триггера заблокированы на время захвата:** запись при запущенном
  `StartGrabbing` → `0x80000106`. Менять только до старта.
- **Кадр в GigE-поток не приходит** — 0 кадров от кнопки (180 с), от трёх
  `TriggerSoftware` и за 3 с свободного режима при 60 к/с. Съёмка при этом идёт
  (вспышки). Брандмауэр выключен. Снимок на ПК — FTP или `MvCodeReader` SDK.
  Параметры потока GVSP не перебирались — до конца не исключено.
- Коммуникационных настроек (TCP Client, тексты NoRead) в GenICam нет:
  `MV_CC_FeatureSave` отдаёт 30 параметров (подсветка, линии, `UserSet1`,
  `ExtCmdTcpPort = 4001` — вероятно, порт внешних команд). Они только в IDMVS.
- `StopGrabbing` + `CloseDevice` прибор НЕ останавливают — коды по TCP шли дальше.
