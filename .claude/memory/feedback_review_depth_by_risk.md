Владелец на вопрос «ревью → слепые тесты → реализация → ревью дорого, не лучше ли реализация, затем ревью» ответил: «как лучше и эффективнее, без костылей и багов». Выбор глубины — за лидом.

**Why:** на полосе Н стадия 0 с двумя раундами на 0.4–0.7 съела больше времени, чем реализация; при этом ревью стадии 5 с воспроизведением и инъекциями находило реальные дыры (0.4: непокрытые ветки handleError; 0.7: непокрытый флаг конфига и цепочка причин).

**How to apply:** стадия 5 (ревью с воспроизведением) — всегда. Стадия 0: тривиальные задачи — без неё; обычные — один раунд; IPC, потоки, жизненный цикл — полностью (до 2 раундов). Break-injection с предсказаниями до прогона не сокращать. Слепой tester — только для контрактов. См. [[feedback-no-crutches-architecture-first]].
