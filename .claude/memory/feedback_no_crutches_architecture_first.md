Главное в Ф1 run-state (владелец, 2026-11-13): «чтобы не было костылей и багов, сделано как полагается, получше по архитектуре».

**Why:** подход «реализуем всё, ревью в конце» быстрее, но даёт риск заплаток по симптому; владелец ставит качество выше скорости.

**How to apply:** в брифе каждого developer — запрет заплаток по симптому (поправка порога, sleep, повтор, широкий except, флаг-исключение), причина вместо симптома; список известных компромиссов лида — `plans/2026-10-27_system-run-state/reports/phase1.known-compromises.md`, ревью Opus проверяет его первым; находку стенда лечить причиной, а не гистерезисом (см. C1). Связано: [[feedback_use_atlas_actively]].
