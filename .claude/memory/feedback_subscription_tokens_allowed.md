Владелец (2026-11-11, atlas-passport) разрешил использовать токены подписки, особенно если это помогает по существующим планам и задачам.

**Why:** лишний расход не проблема для владельца; дороже — выйти на платный прогон с нулевым запасом или с дефектом, который можно было найти разбором заранее.

**How to apply:** запускать разбор `investigator` (Opus), второй раунд ревью, параллельный stage 0 и т.п. там, где это снижает риск перед платным прогоном или слиянием, без отдельного вопроса «запускать?». Это не отменяет цепочку (stage 0 → слепой tester → реализация → инъекции → ревью), правило «лид не исполняет сам», запрет подгонки замеров и «CTO (Fable) только в тяжёлых случаях» — [[feedback-cto-spawn-explicit-fable]]. Платные прогоны бенча (`bench.py run`, `--yes`) разрешением не покрыты: по ним нужно слово владельца (Ш2).
