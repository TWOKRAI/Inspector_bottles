2026-09-25: `PluginRegistry.clear()` в 6 autouse-фикстурах без `restore` стирал регистрации плагинов (побочный
эффект ИМПОРТА, второй раз не случается) — следом падала сборка блюпринта. Первое «правильное» решение —
одна страховка snapshot/restore в корневом `conftest.py` на каждый тест. Замер против `main`: +2 падения в
`backend_ctl`, +27 в прототипе. Страховка откатывала и ЗАКОННЫЕ регистрации — модуль плагина, впервые
импортированный внутри теста, после отката уже никогда не регистрировался. Верно: паттерн самого реестра
(snapshot → clear → yield → clear → restore) в фикстурах, которые чистят реестр.

**Why:** состояние, которое создаёт импорт, монотонно — общий откат не отличает мусор теста от него.
«Одна правка в общем месте» выигрывает, только если общее место видит ту же разницу, что и нарушитель.

**How to apply:** правку, действующую на каждый тест (корневой conftest, autouse), принимать только по
сравнению наборов падений с базой `main` на тех же каталогах (`comm` по спискам FAILED), не по зелени связки,
ради которой она писалась. См. [[feedback_safety_net_masks_primary_fix]].
