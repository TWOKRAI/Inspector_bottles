Если состояние («мы упёрлись», «деградировали», «связь потеряна») снимается по
**отсутствию** события за период — это дефект, а не оптимизация. Ноль отказов за
такт бывает по двум разным причинам: отпустило ИЛИ никто не пробовал. Снимай по
ДОКАЗАТЕЛЬСТВУ: «работа шла И ни одного отказа» (`_seen > 0 and _refused == 0`).

**Why:** 2026-08-17, `CardinalityGuard`. Я перенёс границу «условие отпустило» на
«такт без единого отказа» — и одной строкой сломал СРАЗУ ДВЕ позиции, обе нашло
ревью, обе воспроизвелись:
- живой слой (словарь не чистится вовсе): тихий такт значит лишь «не пришло нового
  ключа» — 1 голос за срок процесса стал **6** при справочнике, полном 4 из 4;
- окно: право на голос возвращал любой сброс, тихий ПО ПОСТРОЕНИЮ (базовый
  `reconfigure` осушает буфер, следом `stop()` сливает остаток) — **2 WARNING на
  одно неизменное условие**, то есть на каждой смене темпа в `config.reload`.

Прежний код держал это свойство СЛУЧАЙНО (владелец звал `allow` только при
отсутствии ключа, при полном словаре тот не мог удаться). Случайная гарантия не
видна в диффе — снял её, не заметив.

**How to apply:**
- Правишь границу состояния — перечисли ВСЕ вызывающие, включая teardown и
  reconfigure. Сброс при остановке и осушение при пересборке тихие по построению,
  и они пройдут любую проверку вида «за период ничего не случилось».
- **Разметка вызывающих («этот вызов — не наблюдение») хуже внутреннего признака:**
  её можно забыть на новом сбросе. Я забыл на первом же — добавил флаг в `stop()`,
  а базовый `reconfigure` дренировал мимо, и M-2 остался жив. Признак, который
  ставит сам механизм, пропустить нельзя.
- **Параметр, разделяющий поведение по позициям, сначала попробуй не заводить.**
  Я добавил `lifts_on_quiet_tick` (True окну, False живому слою) — инъекция
  показала, что он **не различает ни одного теста**: правило «была работа без
  отказов» верно для обеих позиций сразу. Удалил параметр — и заодно отпала правка
  чужого теста, которую он тянул за собой. Проверяй новый флаг инъекцией: если его
  переключение никого не красит, флага быть не должно.
- Тест на такое свойство обязан ЧЕРЕДОВАТЬ такты (тихий / с отказом) несколько раз.
  Ревьюер отдельно отметил: его контроль «живой слой цел» оказался вакуумным, потому
  что сценарий делал ОДИН `flush()`, обещая в тексте «несколько окон подряд».
